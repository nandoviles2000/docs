<ResponseField name="icon" type="string" required>
  L’icône à afficher.

  Options :

  * Nom d’une [icône Font Awesome](https://fontawesome.com/icons), si la [propriété](/fr/organize/settings-appearance#param-icons) `icons.library` est définie sur `fontawesome` dans votre `docs.json`
  * Nom d’une [icône Lucide](https://lucide.dev/icons), si la [propriété](/fr/organize/settings-appearance#param-icons) `icons.library` est définie sur `lucide` dans votre `docs.json`
  * Nom d’une [icône Tabler](https://tabler.io/icons), si la [propriété](/fr/organize/settings-appearance#param-icons) `icons.library` est définie sur `tabler` dans votre `docs.json`
  * URL d’une icône hébergée à l’extérieur
  * Chemin vers un fichier d’icône dans votre projet
</ResponseField>

<ResponseField name="iconType" type="string">
  Le style de l’icône [Font Awesome](https://fontawesome.com/icons). Utilisé uniquement avec les icônes Font Awesome.

  Options : `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ResponseField>
