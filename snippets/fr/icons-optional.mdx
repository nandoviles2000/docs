<ResponseField name="icon" type="string">
  L’icône à afficher.

  Options :

  * nom de l’icône [Font Awesome](https://fontawesome.com/icons), si la [propriété](/fr/organize/settings-appearance#param-icons) `icons.library` est définie sur `fontawesome` dans votre `docs.json`
  * nom de l’icône [Lucide](https://lucide.dev/icons), si la [propriété](/fr/organize/settings-appearance#param-icons) `icons.library` est définie sur `lucide` dans votre `docs.json`
  * nom de l’icône [Tabler](https://tabler.io/icons), si la [propriété](/fr/organize/settings-appearance#param-icons) `icons.library` est définie sur `tabler` dans votre `docs.json`
  * URL d’une icône hébergée à l’extérieur
  * chemin d’accès à un fichier d’icône dans votre projet
  * code SVG entre accolades

  Pour les icônes SVG personnalisées :

  1. Convertissez votre SVG à l’aide du [convertisseur SVGR](https://react-svgr.com/playground/).
  2. Collez votre code SVG dans le champ d’entrée SVG.
  3. Copiez l’élément complet `<svg>...</svg>` depuis le champ de sortie JSX.
  4. Placez le code SVG compatible JSX entre accolades : `icon={<svg ...> ... </svg>}`.
  5. Ajustez `height` et `width` selon vos besoins.
</ResponseField>

<ResponseField name="iconType" type="string">
  Le style de l’icône [Font Awesome](https://fontawesome.com/icons). Utilisé uniquement avec les icônes Font Awesome.

  Options : `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ResponseField>
