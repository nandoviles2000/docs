Para alojar tu documentación en un dominio personalizado:

1. Agrega tu dominio en tu panel.
2. Configura la configuración de DNS con el proveedor de tu dominio.
3. Deja tiempo para que el DNS se propague y los certificados TLS se aprovisionen automáticamente.

<Info>
  ¿Quieres configurar una subruta como `example.com/docs`? Consulta [la subruta /docs](/es/deploy/docs-subpath).
</Info>

<div id="add-your-custom-domain">
  ## Añade tu dominio personalizado
</div>

1. Ve a la página [Configuración de dominio personalizado](https://dashboard.mintlify.com/settings/deployment/custom-domain) en tu panel.
2. Introduce tu nombre de dominio. Por ejemplo, `docs.example.com` o `www.example.com`.
3. Haz clic en **Añadir dominio**.

<div id="configure-your-dns">
  ## Configura tu DNS
</div>

1. En el sitio web de tu proveedor de dominios, ve a la configuración de DNS de tu dominio.
2. Crea un nuevo registro DNS con los siguientes valores:

```text
CNAME | docs | cname.mintlify-dns.com.
```

<Tip>
  Cada proveedor de dominios tiene una forma distinta de agregar registros DNS. Consulta la documentación de tu proveedor de dominios para ver las instrucciones específicas.
</Tip>

<div id="dns-propagation">
  ### Propagación de DNS
</div>

Los cambios de DNS suelen tardar entre 1 y 24 horas en propagarse en todo el mundo, aunque en algunos casos pueden tardar hasta 48 horas. Puedes verificar que tu DNS esté configurado correctamente con [DNSChecker](https://dnschecker.org).

Una vez que tus registros DNS estén activos, tu documentación estará accesible primero a través de HTTP. HTTPS estará disponible después de que Vercel emita tu certificado TLS.

<div id="automatic-tls-provisioning">
  ### Aprovisionamiento automático de TLS
</div>

Una vez que tus registros DNS se hayan propagado y se resuelvan correctamente, Vercel aprovisiona automáticamente un certificado SSL/TLS gratuito para tu dominio mediante Let&#39;s Encrypt.

Esto suele completarse en unas pocas horas después de la propagación del DNS, aunque en casos poco frecuentes puede tardar hasta 24 horas. Los certificados se renuevan automáticamente antes de su vencimiento.

<div id="caa-records">
  ### Registros CAA
</div>

Si tu dominio usa registros CAA (autorización de entidad de certificación), debes autorizar a Let&#39;s Encrypt para emitir certificados para tu dominio. Agrega el siguiente registro CAA a la configuración de DNS:

```text
0 issue "letsencrypt.org"
```

<div id="reserved-paths">
  ### Rutas reservadas
</div>

La ruta `/.well-known/acme-challenge` está reservada para la validación de certificados y no se puede redirigir ni reescribir. Si has configurado redirecciones o reescrituras para esta ruta, el aprovisionamiento del certificado fallará.

<div id="provider-specific-settings">
  ### Configuración específica del proveedor
</div>

<AccordionGroup>
  <Accordion title="Verificación de Vercel">
    Si Vercel es tu proveedor de dominios, debes añadir un registro `TXT` de verificación. Esta información aparece en tu panel después de enviar tu dominio personalizado y también se te envía por correo electrónico.
  </Accordion>

  <Accordion title="Modo de cifrado de Cloudflare">
    Si Cloudflare es tu proveedor de DNS, debes habilitar el modo &quot;Full (strict)&quot; en la configuración de cifrado SSL/TLS. Además, desactiva &quot;Always Use HTTPS&quot; en la configuración de Edge Certificates. La redirección HTTPS de Cloudflare impide que Let&#39;s Encrypt valide tu dominio durante el aprovisionamiento del certificado.
  </Accordion>
</AccordionGroup>

<div id="set-a-canonical-url">
  ## Configura una URL canónica
</div>

Después de configurar el DNS, define una URL canónica para asegurarte de que los motores de búsqueda indexen tu dominio preferido. Una URL canónica indica a los motores de búsqueda qué versión de tu documentación es la principal. Esto mejora el SEO cuando se puede acceder a tu documentación desde varias URL y evita problemas de contenido duplicado.

Agrega la metaetiqueta `canonical` a tu `docs.json`:

```json
"seo": {
    "metatags": {
        "canonical": "https://www.your-custom-domain-here.com"
    }
}
```

Reemplaza `https://www.your-custom-domain-here.com` por tu dominio personalizado. Por ejemplo, si tu dominio personalizado es `docs.mintlify.com`, usarías:

```json
"seo": {
    "metatags": {
        "canonical": "https://docs.mintlify.com"
    }
}
```
