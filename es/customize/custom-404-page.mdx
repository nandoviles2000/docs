---
title: "Página 404 personalizada"
description: "Personaliza el título, la descripción y la apariencia de la página de error 404 de tu sitio de documentación para que se ajuste a tu marca y oriente a los visitantes."
keywords: ["página de error 404", "páginas de error personalizadas"]
---

Todas las páginas 404 sugieren automáticamente páginas relevantes en función de la URL solicitada. Si los usuarios llegan a una página 404, un agente analiza la ruta y recupera páginas de tu documentación relacionadas semánticamente para ayudarlos a encontrar lo que buscan.

Puedes personalizar el título y la descripción de la página de error 404. Usa la descripción para añadir enlaces útiles o instrucciones.

<div id="configuration">
  ## Configuración
</div>

Configura la página 404 en la sección `errors.404` de tu archivo `docs.json`:

```json
"errors": {
  "404": {
    "redirect": false,
    "title": "I can't be found",
    "description": "What ever **happened** to this _page_?"
  }
}
```

<div id="parameters">
  ## Parámetros
</div>

<ResponseField name="redirect" type="boolean">
  Indica si se redirige automáticamente a la página de inicio cuando no se encuentra una página.

  Establece `true` para redirigir a la página de inicio.

  Establece `false` para mostrar la página 404 personalizada.
</ResponseField>

<ResponseField name="title" type="string">
  Título personalizado de la página de error 404. Sustituye el encabezado predeterminado &quot;Página no encontrada&quot;.
</ResponseField>

<ResponseField name="description" type="string">
  Descripción personalizada de la página de error 404. Admite formato MDX, incluidos enlaces, texto en negrita y cursiva, y componentes personalizados.
</ResponseField>
