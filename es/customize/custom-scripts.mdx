Usa CSS para dar estilo a los elementos HTML o agrega CSS y JavaScript personalizados para personalizar por completo la apariencia de tu sitio de documentación.

<div id="style-with-tailwind-css">
  ## Aplica estilos con Tailwind CSS
</div>

Usa Tailwind CSS v3 para dar estilo a elementos HTML. Puedes controlar el diseño, el espaciado, los colores y otras propiedades visuales. Algunas clases comunes son:

* `w-full` - Ancho completo
* `aspect-video` - Relación de aspecto 16:9
* `rounded-xl` - Esquinas redondeadas grandes
* `block`, `hidden` - Control de visualización
* `dark:hidden`, `dark:block` - Visibilidad en modo oscuro

Tailwind CSS no admite valores arbitrarios. Para valores personalizados, usa la prop `style` en su lugar.

```html
<img style={{ width: '350px', margin: '12px auto' }} src="/path/image.jpg" />
```

<Warning>
  Usar la prop `style` puede provocar cambios en el diseño al cargar la página, especialmente en páginas con modo personalizado. En su lugar, usa clases de Tailwind CSS o archivos CSS personalizados para evitar esos cambios o el parpadeo.
</Warning>

<div id="add-custom-css">
  ## Agrega CSS personalizado
</div>

Agrega archivos CSS a tu repositorio para aplicar los nombres de clase que definen y hacer que estén disponibles en todos tus archivos MDX.

Las referencias y los estilos de los elementos comunes pueden cambiar. Usa estilos personalizados con precaución, ya que podrían producirse cambios incompatibles en futuras actualizaciones.

Por ejemplo, puedes agregar el siguiente archivo `style.css` para personalizar el estilo de la barra de navegación y del pie de página.

```css
#navbar {
  background: #fffff2;
  padding: 1rem;
}

footer {
  margin-top: 2rem;
}
```

Mintlify expone dos tipos de selectores de CSS:

* **Selectores de ID**: elementos únicos a nivel de página a los que se dirige con `#value { }` en CSS
* **Selectores de elemento**: elementos de componentes y de diseño a los que se dirige con `value { }` en CSS (sin el prefijo `#` ni `.`)

<Tip>
  Usa Inspeccionar elemento para encontrar referencias a los elementos que quieres personalizar.
</Tip>

<div id="custom-javascript">
  ## JavaScript personalizado
</div>

El JavaScript personalizado te permite añadir código ejecutable personalizado de forma global. Equivale a añadir una etiqueta `<script>` con código JavaScript a cada página.

Mintlify incluye cualquier archivo `.js` que esté dentro de tu directorio de contenido en cada página de tu sitio de documentación. Por ejemplo, puedes añadir el siguiente archivo `ga.js` para habilitar [Google Analytics](https://marketingplatform.google.com/about/analytics) en toda la documentación.

```js
window.dataLayer = window.dataLayer || [];
function gtag() {
  dataLayer.push(arguments);
}
gtag('js', new Date());

gtag('config', 'TAG_ID');
```

<Warning>
  Úsalo con precaución para no introducir vulnerabilidades de seguridad.
</Warning>
