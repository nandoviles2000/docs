<Info>
  El control de acceso basado en roles (RBAC) está disponible en los [planes Enterprise](https://mintlify.com/pricing?ref=rbac).
</Info>

Mintlify ofrece tres niveles de acceso al panel: lector, editor y administrador.

|                                     | Lector | Editor | Administrador |
| ----------------------------------- | :----: | :----: | :-----------: |
| Ver contenido en el editor          |    ✅   |    ✅   |       ✅       |
| Dejar comentarios y sugerencias     |    ✅   |    ✅   |       ✅       |
| Ver el panel y la analítica         |    ✅   |    ✅   |       ✅       |
| Editar contenido en el editor web   |    ❌   |    ✅   |       ✅       |
| Publicar cambios                    |    ❌   |    ✅   |       ✅       |
| Crear, renombrar y eliminar páginas |    ❌   |    ✅   |       ✅       |
| Reordenar la navegación             |    ❌   |    ✅   |       ✅       |
| Subir archivos multimedia           |    ❌   |    ✅   |       ✅       |
| Iniciar despliegues                 |    ❌   |    ✅   |       ✅       |
| Crear y eliminar claves de API      |    ❌   |    ✅   |       ✅       |
| Configurar integraciones            |    ❌   |    ✅   |       ✅       |
| Configurar el asistente             |    ❌   |    ✅   |       ✅       |
| Configurar complementos             |    ❌   |    ✅   |       ✅       |
| Invitar a editores y lectores       |    ❌   |    ✅   |       ✅       |
| Actualizar roles de usuario         |    ❌   |    ❌   |       ✅       |
| Invitar administradores             |    ❌   |    ❌   |       ✅       |
| Eliminar usuarios                   |    ❌   |    ❌   |       ✅       |
| Gestionar la facturación            |    ❌   |    ❌   |       ✅       |
| Gestionar SSO                       |    ❌   |    ❌   |       ✅       |
| Actualizar el dominio personalizado |    ❌   |    ❌   |       ✅       |
| Actualizar el origen de Git         |    ❌   |    ❌   |       ✅       |
| Eliminar la organización            |    ❌   |    ❌   |       ✅       |

<Tip>
  Limita el acceso de administrador únicamente a las personas que necesiten realizar tareas administrativas.
</Tip>

<div id="add-members-to-your-organization">
  ## Añade miembros a tu organización
</div>

De forma predeterminada, la persona que crea tu organización en Mintlify tiene acceso de administrador. Añade editores adicionales en la página [Miembros](https://dashboard.mintlify.com/settings/organization/members) de tu panel.

Puedes tener tantos miembros como necesites en tu organización. Las plazas pueden tener un costo adicional. Consulta la [página de precios](https://mintlify.com/pricing) para obtener más información.
