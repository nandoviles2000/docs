<div id="start-the-local-preview">
  ## Inicia la vista previa local
</div>

Ve al directorio de la documentación que contiene el archivo `docs.json` y ejecuta:

```bash
mint dev
```

La vista previa local se inicia en `http://localhost:3000`. A medida que editas, los cambios se reflejan en tiempo real.

De forma predeterminada, la vista previa se abre automáticamente en tu navegador. Para evitar que el navegador se abra, usa la opción `--no-open`:

```bash
mint dev --no-open
```

Para generar una vista previa sin instalar la CLI de forma global, ejecuta:

```bash
npx mint dev
```

<div id="log-in-for-search-and-assistant">
  ## Inicia sesión para usar la búsqueda y el asistente
</div>

Debes autenticar la CLI con tu cuenta de Mintlify para habilitar la búsqueda y el [asistente](/es/assistant/index).

```bash
mint login
```

Después de autenticarte con el comando `mint login`, la CLI almacena tus credenciales en `~/.config/mintlify/config.json` para que la sesión permanezca iniciada entre sesiones. La CLI también te pide que selecciones un proyecto predeterminado, que utilizan comandos como `mint analytics`.

Una vez que hayas iniciado sesión, ejecuta `mint dev` para iniciar la vista previa local con la búsqueda y el asistente habilitados. El asistente usa el mismo contenido indexado que tu sitio de documentación desplegado.

Para comprobar tu estado de autenticación, ejecuta:

```bash
mint status
```

Para cerrar sesión, ejecuta:

```bash
mint logout
```

<div id="custom-ports">
  ## Puertos personalizados
</div>

De forma predeterminada, la CLI usa el puerto 3000. Para usar otro puerto, utiliza la opción `--port`:

```bash
mint dev --port 3333
```

Si el puerto ya está en uso, la CLI intenta automáticamente usar el siguiente puerto disponible.

<div id="skip-openapi-processing">
  ## Omitir el procesamiento de OpenAPI
</div>

Si tienes muchos archivos OpenAPI, omite el procesamiento de OpenAPI durante el desarrollo local para mejorar el rendimiento con la opción `--disable-openapi`:

```bash
mint dev --disable-openapi
```

<div id="preview-as-a-specific-group">
  ## Vista previa como un grupo específico
</div>

Si usas control de acceso basado en grupos, genera una vista previa como un grupo de autenticación específico con la opción `--groups`:

```bash
mint dev --groups admin
```

Consulta [la configuración de autenticación](/es/deploy/authentication-setup#control-access-with-groups) para obtener más información sobre los grupos.
