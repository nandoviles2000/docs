<div id="prerequisites">
  ## Requisitos previos
</div>

* [Node.js](https://nodejs.org/en) v20.17.0+ (se recomiendan las versiones LTS)

<div id="install-the-cli">
  ## Instala la CLI
</div>

<CodeGroup>
  ```bash npm
  npm i -g mint
  ```

  ```bash pnpm
  pnpm add -g mint
  ```
</CodeGroup>

<div id="create-a-new-project">
  ## Crea un proyecto nuevo
</div>

Para crear un nuevo proyecto de documentación a partir de la plantilla de inicio de Mintlify, ejecuta el siguiente comando:

```bash
mint new [directory]
```

Si no especificas un directorio, la CLI te pedirá que crees un subdirectorio nuevo o que sobrescribas el directorio actual.

<Warning>
  Sobrescribir el directorio actual elimina todos los archivos existentes.
</Warning>

| Flag         | Descripción                                                                      |
| ------------ | -------------------------------------------------------------------------------- |
| `--name`     | Nombre del proyecto. La CLI lo solicita si no se proporciona.                    |
| `--theme`    | [Tema](/es/customize/themes) del proyecto. La CLI lo solicita si no se proporciona. |
| `--template` | Plantilla predefinida. La CLI la solicita si no se proporciona.                  |
| `--force`    | Sobrescribe el directorio actual sin pedir confirmación.                         |

En modo interactivo, la CLI te pregunta si quieres elegir un tema o clonar una plantilla. Para omitir esta solicitud, pasa la marca `--template` directamente:

```bash
mint new my-docs --template <template-name>
```

Puedes combinar `--template` con `--theme` para sobrescribir el tema predeterminado de la plantilla:

```bash
mint new my-docs --template <template-name> --theme <theme>
```

Consulta las plantillas disponibles en el repositorio [mintlify/templates](https://github.com/mintlify/templates) en GitHub. En modo interactivo, la CLI recupera y muestra automáticamente las plantillas disponibles.

En entornos no interactivos, como pipelines de CI/CD o agentes de programación con IA, debes proporcionar las opciones `--name` y `--theme`, o la opción `--template`.

<div id="update">
  ## Update
</div>

Si tu vista previa local no está sincronizada con la documentación desplegada, actualiza la CLI a la versión más reciente:

```bash
mint update
```

Si `mint update` no está disponible en tu versión, vuelve a instalar la CLI con la versión más reciente:

<CodeGroup>
  ```bash npm
  npm i -g mint@latest
  ```

  ```bash pnpm
  pnpm add -g mint@latest
  ```
</CodeGroup>

<div id="troubleshooting">
  ## Solución de problemas
</div>

<AccordionGroup>
  <Accordion title="Error: No se pudo cargar el módulo &#x22;sharp&#x22; con el runtime darwin-arm64">
    Esto puede deberse a una versión desactualizada de Node.js. Prueba lo siguiente:

    1. Elimina la versión instalada actualmente de la CLI de mint: `npm uninstall -g mint`
    2. Actualiza a Node.js v20.17.0+.
    3. Vuelve a instalar la CLI de mint: `npm install -g mint`
  </Accordion>

  <Accordion title="Problema: aparece un error desconocido">
    **Solución**: Ve al directorio raíz de tu dispositivo y elimina la carpeta `~/.mintlify`. Después, vuelve a ejecutar `mint dev`.
  </Accordion>

  <Accordion title="Error: permiso denegado">
    Esto se debe a que no tienes los permisos necesarios para instalar paquetes de Node.js de forma global.

    **Solución**: Prueba a ejecutar `sudo npm i -g mint`. Cuando se te solicite, introduce la contraseña que usas para desbloquear tu equipo.
  </Accordion>

  <Accordion title="La vista previa local no se ve igual que mi documentación en la web">
    Es probable que esto se deba a una versión desactualizada de la CLI.

    **Solución**: Ejecuta `mint update` para obtener los cambios más recientes.
  </Accordion>

  <Accordion title="paquete mintlify frente al paquete mint">
    Si tienes algún problema con el paquete de la CLI, primero ejecuta `npm ls -g` para ver qué paquetes están instalados globalmente. Si no usas npm, prueba `which mint` para localizar la instalación.

    Si tienes instalados tanto un paquete `mint` como uno `mintlify`, desinstala `mintlify`:

    ```bash
    npm uninstall -g mintlify
    npm cache clean --force
    npm i -g mint
    ```
  </Accordion>

  <Accordion title="La versión del cliente muestra 'none' después de la instalación">
    Si ejecutas `mint version` y la versión del cliente aparece como `none`, es posible que la CLI no pueda descargar la aplicación cliente debido a un firewall corporativo o una VPN.

    **Solución**: Pide a tu administrador de TI que agregue `releases.mintlify.com` a la lista de permitidos de tu red.
  </Accordion>
</AccordionGroup>
