<div id="global-flags">
  ## Opciones globales
</div>

Estas opciones están disponibles en todos los comandos.

| Opción              | Descripción                                            |
| ------------------- | ------------------------------------------------------ |
| `--telemetry`, `-t` | Activa o desactiva la telemetría anónima de uso.       |
| `--help`, `-h`      | Muestra la ayuda del comando.                          |
| `--version`, `-v`   | Muestra la versión de la CLI. Alias de `mint version`. |

<div id="mint-dev">
  ## `mint dev`
</div>

Inicia una vista previa local de la documentación.

```bash
mint dev [flags]
```

| Opción              | Descripción                                                                           |
| ------------------- | ------------------------------------------------------------------------------------- |
| `--port`            | Puerto en el que se ejecuta la vista previa local. El valor predeterminado es `3000`. |
| `--no-open`         | No abre el navegador automáticamente.                                                 |
| `--groups`          | Lista de grupos de usuarios separada por comas para simular en la vista previa.       |
| `--disable-openapi` | Omite el procesamiento del archivo OpenAPI para mejorar el rendimiento.               |
| `--local-schema`    | Permite archivos OpenAPI alojados localmente y servidos mediante HTTP.                |

<div id="mint-login">
  ## `mint login`
</div>

Inicia sesión con tu cuenta de Mintlify.

```bash
mint login
```

Abre una ventana del navegador para completar la autenticación. Si el navegador no se abre, la CLI muestra una URL para que la abras manualmente y te pide que pegues el código de autorización. Las credenciales se guardan en `~/.config/mintlify/config.json`.

Si tienes más de un despliegue, la CLI te pedirá que selecciones uno como predeterminado después de iniciar sesión. Puedes cambiar el proyecto predeterminado más adelante con `mint config set subdomain <subdomain>`.

<div id="mint-analytics">
  ## `mint analytics`
</div>

Consulta los datos de analítica de tu documentación. Requiere autenticación con `mint login`.

```bash
mint analytics <subcommand> [flags]
```

Todos los subcomandos aceptan estas opciones compartidas:

| Opción        | Descripción                                                                                                                                              |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--subdomain` | Subdominio de la documentación. De forma predeterminada, usa el valor establecido con `mint config set subdomain` o el del primer proyecto de tu cuenta. |
| `--from`      | Fecha de inicio en formato `YYYY-MM-DD`. De forma predeterminada, usa la fecha de hace 7 días o el valor establecido con `mint config set dateFrom`.     |
| `--to`        | Fecha de fin en formato `YYYY-MM-DD`. De forma predeterminada, usa la fecha de hoy o el valor establecido con `mint config set dateTo`.                  |
| `--format`    | Formato de salida: `plain` (predeterminado), `table`, `json` o `graph`.                                                                                  |

<div id="mint-analytics-stats">
  ### `mint analytics stats`
</div>

Muestra un resumen de las visualizaciones, los visitantes, las búsquedas, los comentarios y el uso del asistente.

```bash
mint analytics stats [flags]
```

| Opción   | Descripción                               |
| -------- | ----------------------------------------- |
| `--page` | Filtra por una ruta de página específica. |

<div id="mint-analytics-search">
  ### `mint analytics search`
</div>

Muestra las consultas de búsqueda con el número de coincidencias y la tasa de clics.

```bash
mint analytics search [flags]
```

| Opción    | Descripción                                          |
| --------- | ---------------------------------------------------- |
| `--query` | Filtra por una subcadena de la consulta de búsqueda. |
| `--page`  | Filtra por la página con más clics.                  |

<div id="mint-analytics-feedback">
  ### `mint analytics feedback`
</div>

Muestra los comentarios enviados por los usuarios.

```bash
mint analytics feedback [flags]
```

| Opción   | Descripción                                                                                          |
| -------- | ---------------------------------------------------------------------------------------------------- |
| `--type` | Tipo de comentarios: `page` (agrupado por página) o `code` (comentarios sobre fragmentos de código). |
| `--page` | Filtra por una ruta de página específica.                                                            |

<div id="mint-analytics-conversation">
  ### `mint analytics conversation`
</div>

Consulta los datos de las conversaciones del asistente.

```bash
mint analytics conversation <subcommand> [flags]
```

<div id="mint-analytics-conversation-list">
  #### `mint analytics conversation list`
</div>

Muestra una lista de conversaciones del asistente. Cada entrada incluye un ID de conversación.

```bash
mint analytics conversation list [flags]
```

| Opción   | Descripción                                                                            |
| -------- | -------------------------------------------------------------------------------------- |
| `--page` | Filtra las conversaciones que hacen referencia a una página específica en las fuentes. |

<div id="mint-analytics-conversation-view-conversation-id">
  #### `mint analytics conversation view <conversation-id>`
</div>

Muestra una sola conversación por ID. Usa `mint analytics conversation list` para obtener los ID.

```bash
mint analytics conversation view <conversation-id>
```

<div id="mint-analytics-conversation-buckets-list">
  #### `mint analytics conversation buckets list`
</div>

Muestra las categorías de conversaciones agrupadas. Cada entrada incluye un ID del bucket.

```bash
mint analytics conversation buckets list
```

<div id="mint-analytics-conversation-buckets-view-bucket-id">
  #### `mint analytics conversation buckets view <bucket-id>`
</div>

Muestra las conversaciones de un bucket de categorías. Usa `mint analytics conversation buckets list` para obtener los ID.

```bash
mint analytics conversation buckets view <bucket-id>
```

<div id="mint-config">
  ## `mint config`
</div>

Gestiona los valores predeterminados persistentes de los comandos de la CLI. La configuración se guarda en `~/.config/mintlify/config.json`.

```bash
mint config <subcommand> <key> [value]
```

| Subcomando          | Descripción                          |
| ------------------- | ------------------------------------ |
| `set <key> <value>` | Establece un valor de configuración. |
| `get <key>`         | Muestra el valor de configuración.   |
| `clear <key>`       | Elimina un valor de configuración.   |

<div id="configuration-keys">
  ### Claves de configuración
</div>

| Clave       | Descripción                                                                    | Utilizado por    |
| ----------- | ------------------------------------------------------------------------------ | ---------------- |
| `subdomain` | Subdominio predeterminado de la documentación.                                 | `mint analytics` |
| `dateFrom`  | Fecha de inicio predeterminada para las consultas de analítica (`YYYY-MM-DD`). | `mint analytics` |
| `dateTo`    | Fecha de fin predeterminada para las consultas de analítica (`YYYY-MM-DD`).    | `mint analytics` |

<div id="mint-broken-links">
  ## `mint broken-links`
</div>

Comprueba si hay enlaces internos rotos en tu documentación.

```bash
mint broken-links [flags]
```

El comando excluye los archivos que coinciden con los patrones de [.mintignore](/es/organize/mintignore). Los enlaces que apuntan a archivos ignorados se marcan como rotos.

| Opción             | Descripción                                                                                                       |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `--check-anchors`  | También valida los enlaces con anclas (por ejemplo, `/page#section`) con respecto a los slugs de los encabezados. |
| `--check-external` | También comprueba si hay URL externas rotas.                                                                      |
| `--check-snippets` | También comprueba los enlaces dentro de los componentes `<Snippet>`.                                              |

<div id="mint-validate">
  ## `mint validate`
</div>

Valida la compilación de tu documentación en modo estricto. Finaliza con un error si hay alguna advertencia o algún error. Incluye la validación automática de las especificaciones de OpenAPI a las que se hace referencia en tu `docs.json`.

```bash
mint validate [flags]
```

| Opción              | Descripción                                                                                                         |
| ------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `--groups`          | Lista de grupos de usuarios, separada por comas, para simular durante la validación.                                |
| `--disable-openapi` | Omite el procesamiento y la validación de archivos OpenAPI.                                                         |
| `--local-schema`    | Permite validar archivos OpenAPI alojados localmente y servidos a través de HTTP. En producción, solo admite HTTPS. |

<Note>
  El comando independiente `mint openapi-check` está obsoleto. Usa `mint validate` en su lugar.
</Note>

<div id="mint-export">
  ## `mint export`
</div>

Exporta tu documentación como un archivo ZIP independiente para verla y distribuirla sin conexión.

```bash
mint export [flags]
```

| Opción              | Descripción                                                                                           |
| ------------------- | ----------------------------------------------------------------------------------------------------- |
| `--output`          | Nombre del archivo de salida. El valor predeterminado es `export.zip`.                                |
| `--groups`          | Lista de grupos de usuarios, separados por comas, para los que se incluirán las páginas restringidas. |
| `--disable-openapi` | Omite el procesamiento de OpenAPI.                                                                    |

Consulta [Exportación sin conexión](/es/deploy/export) para obtener más información.

<div id="mint-score">
  ## `mint score`
</div>

Ejecuta comprobaciones para evaluar la preparación del agente en un sitio público de documentación. Requiere autenticación con `mint login`.

```bash
mint score <url> [flags]
```

| Opción     | Descripción                                                                                    |
| ---------- | ---------------------------------------------------------------------------------------------- |
| `--format` | Formato de salida: `table` (por defecto, con color), `plain` (TSV para canalización) o `json`. |

El comando muestra una puntuación general de preparación y un desglose de las comprobaciones individuales con indicadores de éxito o fallo.

<div id="checks">
  ### Comprobaciones
</div>

La puntuación evalúa las siguientes áreas:

| Comprobación                  | Qué verifica                                                                                                                                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `llmsTxtExists`               | Los agentes pueden acceder a un archivo [llms.txt](/es/ai/llmstxt) en la raíz del sitio.                                                                                                             |
| `llmsTxtValid`                | El archivo `llms.txt` sigue el formato esperado, con encabezados, un resumen en cita en bloque y enlaces Markdown.                                                                                |
| `llmsTxtSize`                 | El archivo `llms.txt` está dentro del umbral de tamaño para que los agentes puedan procesarlo sin truncarse.                                                                                      |
| `llmsTxtLinksResolve`         | Los enlaces dentro de `llms.txt` apuntan a páginas activas.                                                                                                                                       |
| `llmsTxtLinksMarkdown`        | Los enlaces dentro de `llms.txt` usan sintaxis Markdown.                                                                                                                                          |
| `llmsTxtDirective`            | El archivo `llms.txt` contiene directivas de uso.                                                                                                                                                 |
| `llmsTxtFullExists`           | Hay un archivo [llms-full.txt](/es/ai/llmstxt/#llms-full-txt) disponible para los agentes que necesitan el contenido completo. Se ejecuta de forma independiente de `llmsTxtExists`.                 |
| `llmsTxtFullSize`             | El archivo `llms-full.txt` tiene un tamaño razonable para que los agentes lo procesen.                                                                                                            |
| `llmsTxtFullValid`            | El archivo `llms-full.txt` contiene contenido válido con encabezados.                                                                                                                             |
| `llmsTxtFullLinksResolve`     | Los enlaces dentro de `llms-full.txt` apuntan a páginas activas.                                                                                                                                  |
| `skillMd`                     | Los agentes pueden acceder a un archivo [skill.md](https://www.mintlify.com/docs/ai/skillmd) para usar herramientas del agente.                                                                   |
| `contentNegotiationMarkdown`  | El sitio devuelve Markdown cuando los agentes lo solicitan mediante negociación de contenido.                                                                                                     |
| `contentNegotiationPlaintext` | El sitio devuelve texto sin formato cuando los agentes lo solicitan mediante negociación de contenido.                                                                                            |
| `mcpServerDiscoverable`       | Los agentes pueden detectar un [MCP server](/es/ai/model-context-protocol) para agentes basados en herramientas.                                                                                     |
| `mcpToolCount`                | El MCP server expone al menos una herramienta.                                                                                                                                                    |
| `openApiSpec`                 | Hay una especificación OpenAPI o Swagger disponible en una ruta estándar.                                                                                                                         |
| `robotsTxtAllowsAI`           | El archivo `robots.txt` no bloquea a los rastreadores de IA.                                                                                                                                      |
| `sitemapExists`               | Hay un mapa del sitio disponible para descubrir páginas.                                                                                                                                          |
| `structuredData`              | La página de inicio contiene datos estructurados [JSON-LD](https://json-ld.org/) (`<script type="application/ld+json">`). Indica el número de bloques JSON-LD y los tipos de esquema encontrados. |
| `responseLatency`             | El sitio responde en un tiempo aceptable para los agentes.                                                                                                                                        |

Algunas comprobaciones solo se ejecutan si antes supera una comprobación de la que dependen. Si una comprobación falla, no se ejecuta ninguna de las comprobaciones que dependen de ella. Fallan automáticamente. Por ejemplo, `llmsTxtValid` solo se supera si antes se supera `llmsTxtExists`.

La puntuación general usa una ponderación, por lo que las comprobaciones de mayor impacto contribuyen más a tu puntuación.

<div id="mint-new">
  ## `mint new`
</div>

Crea un nuevo proyecto de documentación seleccionando un tema o clonando una plantilla predefinida del repositorio [mintlify/templates](https://github.com/mintlify/templates).

```bash
mint new [directory] [flags]
```

| Opción       | Descripción                                                                                                |
| ------------ | ---------------------------------------------------------------------------------------------------------- |
| `--name`     | Nombre del proyecto. La CLI te lo solicitará si no lo proporcionas en modo interactivo.                    |
| `--theme`    | [Tema](/es/customize/themes) del proyecto. La CLI te lo solicitará si no lo proporcionas en modo interactivo. |
| `--template` | Plantilla predefinida. La CLI te la solicitará si no la proporcionas en modo interactivo.                  |
| `--force`    | Sobrescribe el directorio sin pedir confirmación.                                                          |

<div id="telemetry">
  ## Telemetría
</div>

La CLI recopila telemetría de uso anónima para ayudar a mejorar Mintlify. Los datos de telemetría incluyen el nombre del comando, la versión de la CLI, el sistema operativo y la arquitectura. Mintlify **no** recopila información personal identificable, contenido del proyecto ni rutas de archivos.

De forma predeterminada, la CLI recopila datos de telemetría. Puedes desactivarla en cualquier momento con la opción `--telemetry`:

```bash
# Deshabilitar telemetría
mint --telemetry false

# Volver a habilitar telemetría
mint --telemetry true
```

También puedes desactivar la telemetría configurando una de estas variables de entorno:

| Variable                      | Valor | Descripción                                                                                          |
| ----------------------------- | ----- | ---------------------------------------------------------------------------------------------------- |
| `MINTLIFY_TELEMETRY_DISABLED` | `1`   | Desactiva la telemetría de la CLI de Mintlify.                                                       |
| `DO_NOT_TRACK`                | `1`   | Desactiva la telemetría mediante el estándar [Console Do Not Track](https://consoledonottrack.com/). |

Esta preferencia se guarda en `~/.config/mintlify/config.json` y persiste entre sesiones de la CLI.
