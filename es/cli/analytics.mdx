El comando `mint analytics` te da acceso a la [analítica de tu documentación](/es/optimize/analytics) desde la terminal. Esto resulta útil para generar informes de analítica con scripts, pasar datos a otras herramientas y hacer comprobaciones rápidas sin abrir el panel.

<div id="prerequisites">
  ## Requisitos previos
</div>

Debes iniciar sesión para usar los comandos de analítica. Ejecuta `mint login` para autenticarte con tu cuenta de Mintlify.

Consulta [Vista previa en local](/es/cli/preview#log-in-for-search-and-assistant) para obtener más información sobre la autenticación.

<div id="view-key-metrics">
  ## Ver métricas clave
</div>

Muestra un resumen de las visualizaciones, los visitantes, las búsquedas, los comentarios y el uso del asistente:

```bash
mint analytics stats
```

Usa flags para filtrar por rango de fechas o por página:

* `--from`: Fecha de inicio en formato `YYYY-MM-DD`. De forma predeterminada, se establece en hace 7 días.
* `--to`: Fecha de fin en formato `YYYY-MM-DD`. De forma predeterminada, se establece en hoy.
* `--page`: Filtra por una ruta de página específica.

```bash Example analytics stats flags
mint analytics stats --from 2025-01-01 --to 2025-01-31
mint analytics stats --page /quickstart
```

<div id="view-search-analytics">
  ## Consulta la analítica de búsqueda
</div>

Consulta qué buscan tus usuarios, con número de resultados y tasas de clics:

```bash
mint analytics search
```

Usa opciones para filtrar por la cadena de búsqueda o por página:

* `--query`: Filtra por una subcadena de la consulta de búsqueda.
* `--page`: Filtra por una ruta de página específica.

```bash Example analytics search flags
mint analytics search --query "authentication"

mint analytics search --page /api-reference
```

<div id="view-feedback">
  ## Ver comentarios
</div>

Revisa los comentarios que enviaron los usuarios en las páginas de tu documentación:

```bash
mint analytics feedback
```

Usa opciones para agrupar los comentarios por página o filtrar los comentarios sobre fragmentos de código:

* `--type`: Agrupa los comentarios por página o por fragmento de código. El valor predeterminado es página.
* `--page`: Filtra por una ruta de página específica.

```bash Example analytics feedback flags
mint analytics feedback --type page
mint analytics feedback --type code
```

<div id="view-assistant-conversations">
  ## Ver las conversaciones del asistente
</div>

Enumera las conversaciones recientes y los grupos de categorías de conversaciones del asistente de IA:

```bash
mint analytics conversation list
mint analytics conversation buckets list
```

La salida de cada lista incluye un ID para cada entrada. Pasa ese ID al comando `view` correspondiente para ver todos los detalles:

```bash
mint analytics conversation view <conversation-id>
mint analytics conversation buckets view <bucket-id>
```

<div id="choose-an-output-format">
  ## Elige un formato de salida
</div>

Todos los comandos de analítica usan por defecto la salida `plain`, separada por tabulaciones y adecuada para redirigirla a otras herramientas. Usa `--format` para cambiar el formato de salida:

```bash
mint analytics stats --format table    # Tabla con formato y colores
mint analytics stats --format json     # JSON sin procesar
mint analytics stats --format graph    # Gráfico de barras horizontal
```

La CLI detecta automáticamente entornos de agentes de IA como Claude Code o terminales no interactivos, y usa la salida en JSON de forma predeterminada.

<div id="set-defaults-with-config">
  ## Configura valores predeterminados con `config`
</div>

Para evitar repetir opciones comunes, configura valores predeterminados con `mint config`. La configuración se guarda en `~/.config/mintlify/config.json`.

Cuando ejecutas `mint login`, la CLI establece la clave `subdomain`. Si tienes varias implementaciones, la CLI te pedirá que elijas una. Puedes reemplazar el valor predeterminado en cualquier momento con `mint config set subdomain <subdomain>`.

Claves de configuración disponibles:

| Clave       | Descripción                                                                                     |
| ----------- | ----------------------------------------------------------------------------------------------- |
| `subdomain` | Subdominio predeterminado para los comandos de analítica. La establece el comando `mint login`. |
| `dateFrom`  | Fecha de inicio predeterminada para las consultas de analítica (`YYYY-MM-DD`).                  |
| `dateTo`    | Fecha de finalización predeterminada para las consultas de analítica (`YYYY-MM-DD`).            |

```bash Example configs
mint config set subdomain my-docs
mint config set dateFrom 2025-01-01
```

Una vez configurados, los comandos de analítica usan automáticamente estos valores:

```bash
# Usa el subdominio y dateFrom configurados sin indicadores
mint analytics stats
```

Para ver o eliminar un valor, ejecuta:

```bash
mint config get subdomain
mint config clear subdomain
```
