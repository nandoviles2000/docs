Los usuarios tienen varias formas de iniciar una conversación con el asistente. Cada método abre un panel de chat en el lado derecho de tu documentación. Los usuarios pueden hacer cualquier pregunta y el asistente busca una respuesta en tu documentación. Si el asistente no puede recuperar información relevante, responde que no puede contestar la pregunta.

<div id="use-the-assistant-in-local-preview">
  ## Usa el asistente en la vista previa local
</div>

El asistente está disponible en tu vista previa local cuando inicias sesión con la CLI. Esto te permite probar el comportamiento del asistente, las instrucciones personalizadas en `Assistant.md` y las respuestas mientras desarrollas la documentación en local.

1. Si aún no lo has hecho, instala la CLI con `npm i -g mint`.
2. Ejecuta `mint login` para autenticarte.
3. Ejecuta `mint dev` para iniciar la vista previa local.

El asistente en la vista previa local usa el mismo contenido indexado que tu sitio de documentación desplegado.

<div id="keyboard-shortcut">
  ## Atajo de teclado
</div>

Abre el panel de chat del asistente con el atajo de teclado <kbd>Command</kbd> + <kbd>I</kbd> en macOS y <kbd>Ctrl</kbd> + <kbd>I</kbd> en Windows.

<div id="highlight-text">
  ## Resaltar texto
</div>

Resalta texto en una página y haz clic en el botón emergente **Agregar al asistente** para abrir el panel del chat del asistente y agregar el texto resaltado como contexto. Puedes agregar varios fragmentos de texto o bloques de código al contexto del asistente.

<div id="file-attachments">
  ## Archivos adjuntos
</div>

Adjunta archivos a los mensajes del asistente para proporcionar contexto adicional.

Tipos de archivo compatibles:

* **Imágenes**: JPEG, PNG, GIF, WebP, SVG
* **Documentos**: PDF
* **Archivos de código y texto**: JavaScript (`.js`, `.jsx`, `.mjs`, `.cjs`), TypeScript (`.ts`, `.tsx`), Python, HTML, CSS, Markdown, MDX, JSON, YAML, XML, SQL, CSV, texto sin formato, scripts de shell (`.sh`, `.bash`, `.env`), GraphQL, TOML, Go, Rust, Ruby, Java, Kotlin, Swift, C (`.c`, `.h`), C++ (`.cpp`, `.hpp`), C#, PHP, Lua, R, Scala

Límites:

* Tamaño máximo de archivo: 5 MB por archivo adjunto
* Número máximo de archivos adjuntos por mensaje: 10

<div id="urls">
  ## URL
</div>

Abre el asistente con un parámetro de consulta en la URL para crear enlaces directos que lleven a los usuarios a información específica o para compartir conversaciones del asistente con preguntas precargadas.

* **Abrir el asistente**: Añade `?assistant=open` para abrir el panel de chat del asistente cuando se cargue la página.
  * Ejemplo: [https://mintlify.com/docs?assistant=open](https://mintlify.com/docs?assistant=open)
* **Abrir con una consulta precargada**: Añade `?assistant=YOUR_QUERY` para abrir el asistente y enviar una pregunta automáticamente.
  * Ejemplo: [https://mintlify.com/docs?assistant=explain webhooks](https://mintlify.com/docs?assistant=explain%20webhooks)

<div id="troubleshooting">
  ## Solución de problemas
</div>

<Accordion title="La barra de chat de Assistant no aparece">
  Si la interfaz del asistente no se muestra en determinados navegadores, es posible que debas enviar un informe de falso positivo a [EasyList](https://easylist.to). Los navegadores que usan la EasyList Cookies List, como Brave y Comet, a veces bloquean el asistente u otros elementos de la interfaz. La EasyList Cookies List incluye una regla específica para ciertos dominios que oculta elementos fijos para bloquear los banners de cookies. Esta regla también afecta, sin querer, a componentes legítimos de la interfaz.

  Envía un informe de falso positivo a [EasyList](https://github.com/easylist/easylist) para solicitar que eliminen la regla. Esto resuelve el problema para todos los usuarios una vez que se actualiza la lista de filtros.
</Accordion>
