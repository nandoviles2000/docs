title: "Personaliza el comportamiento del Assistant"
description: "Dale al Assistant instrucciones personalizadas mediante un archivo Assistant.md para definir su tono, personalidad y áreas de enfoque."
keywords: ["asistente", "instrucciones personalizadas", "Assistant.md", "prompt del sistema", "personalidad"]
---

Agrega un archivo `.mintlify/Assistant.md` en la raíz de tu proyecto de documentación para darle al Assistant instrucciones personalizadas que definan cómo responde (`ASSISTANT.md` también es un nombre de archivo válido). El Assistant usa estas instrucciones como contexto a nivel de sistema en cada respuesta.

<Warning>
  Coloca tu archivo `Assistant.md` dentro del directorio `.mintlify/`, no en la raíz de tu proyecto. Si almacenas el archivo en la raíz de tu proyecto, tus instrucciones personalizadas quedarán accesibles públicamente a través de la ruta `/assistant.md`. El directorio `.mintlify/` no se sirve públicamente, por lo que tu archivo `Assistant.md` no será accesible públicamente si está en ese directorio.

  Si debes almacenar tu archivo `Assistant.md` en la raíz de tu proyecto o en cualquier otro directorio, agrégalo a tu archivo [`.mintignore`](/es/organize/mintignore) para excluirlo de tu sitio de documentación.
</Warning>

Las instrucciones de un archivo `Assistant.md` se agregan al prompt del sistema del Assistant. No sustituyen ni anulan las instrucciones predeterminadas del Assistant.

Para eliminar las instrucciones personalizadas, elimina el archivo `Assistant.md`.

Usa `Assistant.md` para:

* Ajustar la personalidad y el tono del Assistant
* Proporcionar contexto específico del producto
* Definir vías de escalado para soporte
* Especificar preferencias de terminología
* Restringir o delimitar las áreas de enfoque del Assistant
* Proporcionar instrucciones específicas para cada versión

<div id="example-assistantmd-file">
  ## Ejemplo de archivo `Assistant.md`
</div>

```markdown .mintlify/Assistant.md
You are a helpful assistant for Acme Corp's developer platform.

## Tone
- Be concise and direct. Getting to the point helps people more than being exhaustive.
- Use technical language appropriate for software developers. Most people asking you questions are familiar with Acme's products.

## Product context
- Acme SDK v3 is the current stable release. v2 is deprecated. If people ask about v2, remind them it's deprecated but answer their questions.
- Direct billing questions to support@acme.com.

## Terminology
- Use "workspace" instead of "project" or "organization".
- Use "access token" instead of "API key".
```
