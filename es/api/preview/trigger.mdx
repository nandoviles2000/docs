<Info>
  Los despliegues de vista previa están disponibles en los [planes Pro y Enterprise](https://mintlify.com/pricing?ref=preview-deployments).
</Info>

Usa este endpoint para crear o actualizar mediante programación un despliegue de vista previa para una rama de Git. Si ya existe una vista previa para la rama especificada, el endpoint activa un nuevo despliegue en lugar de crear un duplicado.

La respuesta incluye un `statusId` que puedes pasar a [Obtener el estado del despliegue](/es/api/update/status) para hacer seguimiento del progreso del despliegue.

<div id="use-cases">
  ## Casos de uso
</div>

* **Pipelines de CI/CD**: Crea automáticamente despliegues de vista previa cuando se abren o actualizan solicitudes de extracción (pull requests, PR).
* **Vistas previas programadas**: Genera vistas previas a partir de ramas de funcionalidad de larga duración según una programación definida.
* **Herramientas personalizadas**: Integra la creación de vistas previas en flujos de trabajo internos o bots de Slack.

<div id="rate-limits">
  ## Límites de solicitudes
</div>

Este endpoint admite hasta 5 solicitudes por minuto por organización.
