La API REST (Representational State Transfer) de Mintlify te permite interactuar de forma programática con tu documentación, desencadenar actualizaciones, integrar experiencias de chat con IA y exportar datos de analítica.

<div id="endpoints">
  ## Endpoints
</div>

* [Activar actualización](/es/api/update/trigger): Activa una actualización de tu sitio cuando lo desees.
* [Obtener el estado de la actualización](/es/api/update/status): Obtén el estado de una actualización y otros detalles sobre tu documentación.
* [Activar despliegue de vista previa](/es/api/preview/trigger): Crea o actualiza un despliegue de vista previa para una rama específica.
* [Crear trabajo del agente](/es/api/agent/v2/create-agent-job): Crea un trabajo del agente para editar automáticamente tu documentación.
* [Obtener trabajo del agente](/es/api/agent/v2/get-agent-job): Recupera los detalles y el estado de un trabajo del agente específico.
* [Enviar mensaje de seguimiento](/es/api/agent/v2/send-message): Envía un mensaje de seguimiento a un trabajo del agente existente.
* [Crear mensaje del asistente](/es/api/assistant/create-assistant-message-v2): Integra el asistente, entrenado con tu documentación, en cualquier aplicación que elijas.
* [Buscar en la documentación](/es/api/assistant/search): Busca en tu documentación.
* [Obtener contenido de la página](/es/api/assistant/get-page-content): Recupera el contenido de texto completo de una página de documentación.
* [Obtener comentarios de usuarios](/es/api/analytics/feedback): Exporta los comentarios de usuarios de tu documentación.
* [Obtener comentarios por página](/es/api/analytics/feedback-by-page): Exporta los recuentos de comentarios agregados por página.
* [Obtener conversaciones del asistente](/es/api/analytics/assistant-conversations): Exporta el historial de conversaciones del asistente de IA.
* [Obtener estadísticas de origen del asistente](/es/api/analytics/assistant-caller-stats): Recupera un desglose del número de consultas del asistente por tipo de origen.
* [Obtener consultas de búsqueda](/es/api/analytics/searches): Exporta los términos de búsqueda de la documentación y la analítica.
* [Obtener vistas de página](/es/api/analytics/views): Exporta los recuentos de vistas de contenido por página y de todo el sitio.
* [Obtener visitantes únicos](/es/api/analytics/visitors): Exporta los recuentos de visitantes únicos por página y de todo el sitio.

<div id="common-use-cases">
  ### Casos de uso comunes
</div>

* **Despliegues automatizados**: Activa actualizaciones del sitio a intervalos definidos o cuando se produzcan eventos con [Activar actualización](/es/api/update/trigger) y [Obtener el estado de la actualización](/es/api/update/status).
* **Integración con CI/CD**: Actualiza la documentación como parte de tu pipeline de despliegue cuando cambie el código con [Activar actualización](/es/api/update/trigger).
* **Despliegues de vista previa**: Crea o actualiza despliegues de vista previa de forma programática en tu pipeline de CI/CD con [Activar despliegue de vista previa](/es/api/preview/trigger).
* **Integraciones personalizadas**: Integra el asistente de IA en tu producto, portal de soporte o herramientas internas con [Crear mensaje del asistente](/es/api/assistant/create-assistant-message-v2), [Buscar en la documentación](/es/api/assistant/search) y [Obtener el contenido de la página](/es/api/assistant/get-page-content).
* **Edición automatizada**: Usa trabajos del agente para actualizar la documentación de forma programática y a escala con [Crear trabajo del agente](/es/api/agent/v2/create-agent-job), [Obtener trabajo del agente](/es/api/agent/v2/get-agent-job) y [Enviar mensaje de seguimiento](/es/api/agent/v2/send-message).
* **Exportación de analítica**: Exporta comentarios, conversaciones del asistente, analítica de búsquedas, vistas de página y datos de visitantes para analizarlos externamente con [Obtener comentarios de usuarios](/es/api/analytics/feedback), [Obtener comentarios por página](/es/api/analytics/feedback-by-page), [Obtener conversaciones del asistente](/es/api/analytics/assistant-conversations), [obtener estadística de origen del asistente](/es/api/analytics/assistant-caller-stats), [Obtener consultas de búsqueda](/es/api/analytics/searches), [Obtener vistas de página](/es/api/analytics/views) y [Obtener visitantes únicos](/es/api/analytics/visitors).

<div id="authentication">
  ## Autenticación
</div>

Genera claves de API en la [página de claves de API](https://dashboard.mintlify.com/settings/organization/api-keys) de tu panel. Cada clave de API pertenece a una organización; puedes usar claves en varios despliegues dentro de la misma organización.

Puedes crear hasta 10 claves de API por hora por organización.

<div id="admin-api-key">
  ### Clave de API de administrador
</div>

Usa la clave de API de administrador para autenticar las solicitudes a [activar actualización](/es/api/update/trigger), [Obtener el estado de la actualización](/es/api/update/status), [activar despliegue de vista previa](/es/api/preview/trigger), [Crear trabajo del agente](/es/api/agent/v2/create-agent-job), [Obtener trabajo del agente](/es/api/agent/v2/get-agent-job), [Enviar mensaje de seguimiento](/es/api/agent/v2/send-message), [Obtener comentarios de usuarios](/es/api/analytics/feedback), [Obtener comentarios por página](/es/api/analytics/feedback-by-page), [Obtener conversaciones del asistente](/es/api/analytics/assistant-conversations), [obtener estadística de origen del asistente](/es/api/analytics/assistant-caller-stats), [Obtener consultas de búsqueda](/es/api/analytics/searches), [Obtener vistas de página](/es/api/analytics/views) y [Obtener visitantes únicos](/es/api/analytics/visitors).

Las claves de API de administrador comienzan con el prefijo `mint_`.

La clave de API de administrador es un secreto del servidor. No la expongas en código del cliente.

<div id="assistant-api-key">
  ### Clave de la API de Assistant
</div>

Usa la clave de la API de Assistant para autenticar las solicitudes a los endpoints [Crear mensaje del asistente](/es/api/assistant/create-assistant-message-v2), [Buscar en la documentación](/es/api/assistant/search) y [Obtener el contenido de la página](/es/api/assistant/get-page-content).

Las claves de la API de Assistant comienzan con el prefijo `mint_dsc_`.

La clave de la API de Assistant es un token público que puedes usar en el código frontend.

<Note>
  Las llamadas que usan el token de la API de Assistant pueden generar costos: ya sea consumiendo tus créditos de Assistant o generando cargos por exceso.
</Note>
