<div id="usage">
  ## Uso
</div>

Usa este endpoint para ver cómo se distribuyen las consultas del asistente entre los distintos tipos de origen. La respuesta desglosa el total de consultas en:

* **web**: Consultas del sitio de documentación
* **api**: Consultas de llamadas directas a la API
* **other**: Consultas de otras fuentes (por ejemplo, integraciones, SDKs)
* **total**: Suma de todos los tipos de consultas

<div id="filtering">
  ## Filtrado
</div>

Filtra por un rango de fechas usando los parámetros `dateFrom` y `dateTo`.
