<Warning>Este endpoint está obsoleto. Usa en su lugar el endpoint [v2 create agent job](/es/api/agent/v2/create-agent-job).</Warning>

Este endpoint crea un trabajo de agente a partir de los mensajes y la información de la rama proporcionados. El trabajo se ejecuta de forma asíncrona y devuelve una respuesta en streaming con los detalles y los resultados de la ejecución.

Si no existe una rama, el agente la crea. Si los archivos se editan correctamente, se crea automáticamente una solicitud de extracción (pull request, PR) al final del trabajo.

<div id="rate-limits">
  ## Límites de uso
</div>

La API del agente tiene los siguientes límites:

* 100 usos por proyecto de Mintlify por hora

<div id="suggested-usage">
  ## Uso recomendado
</div>

Para obtener mejores resultados, usa el [hook `useChat` de ai-sdk](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#usechat) para enviar solicitudes y manejar las respuestas.
