---
title: "Obtener tarea del agente"
description: "Recupera el estado y los detalles de una tarea del agente,
  incluido el progreso y el enlace de la solicitud de extracción (pull request,
  PR)."
openapi: /es/admin-openapi.json GET /v2/agent/{projectId}/job/{id}
keywords: [ "tarea del agente", "estado", "recuperar", "detalles", "sondeo" ]
---

Consulta este endpoint periódicamente para seguir el progreso de una tarea del agente. El campo `status` pasa de `active` a `completed` o `failed`.

Una vez que el agente crea una solicitud de extracción (pull request, PR), se rellena el campo `prLink`.
