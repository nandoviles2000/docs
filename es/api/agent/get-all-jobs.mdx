<div id="usage">
  ## Uso
</div>

Este endpoint recupera todos los trabajos del agente del dominio especificado y ofrece una visión general de todas las actividades del agente y su estado actual. Esto es útil para supervisar y gestionar varios trabajos del agente simultáneos o anteriores.

<div id="response">
  ## Respuesta
</div>

Usa este endpoint para obtener una visión completa de todas las sesiones anteriores del agente.
