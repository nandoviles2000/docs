  ## Componente Visibility

  El nuevo componente [`Visibility`](/es/components/visibility) te permite mostrar contenido distinto a lectores humanos y agentes de IA en la misma página. Envuelve el contenido en `<Visibility for="humans">` para mostrarlo solo en la versión web de una página, o en `<Visibility for="agents">` para incluirlo solo en la [salida Markdown](/es/ai/markdown-export) que consumen las herramientas de IA. Es útil para adaptar instrucciones, ejemplos o formato a cada audiencia sin tener que mantener páginas separadas.

  ## Comentarios de agentes

  Habilita los [comentarios de agentes](/es/optimize/feedback#agent-feedback) en la configuración de tu despliegue para permitir que los agentes envíen comentarios estructurados sobre tu documentación. Cuando esta opción está activada, las versiones en Markdown de tus páginas incluyen instrucciones de comentarios para que los agentes sepan cómo informar cualquier problema que encuentren al acceder a tu documentación. Está disponible como función beta en el panel, en los complementos de despliegue.

  ## Acceso al sistema de archivos de MCP

  Los [MCP servers](/es/ai/model-context-protocol) ahora incluyen una herramienta para consultar el sistema de archivos de la documentación, lo que permite a los agentes explorar y leer directamente la estructura de archivos de tu documentación. Los agentes pueden recorrer directorios, leer el contenido completo de las páginas y leer varias páginas por lotes en una sola llamada. Esta herramienta sustituye a `get_page`.

  ## Asistente de configuración de Git

  Un nuevo asistente paso a paso en la página de Git Settings te guía para conectar un repositorio de GitHub o GitLab por primera vez. Elige entre la clonación con un clic o la selección manual del repositorio, con compatibilidad para seleccionar la organización, configurar la rama y definir el subdirectorio.

  ## OAuth de GitLab para flujos de trabajo

  Los [flujos de trabajo](/es/agent/workflows) ahora admiten repositorios de GitLab mediante autenticación OAuth. Conecta tu cuenta de GitLab desde el panel para usar repositorios de GitLab como fuentes de documentación, repositorios de activación o repositorios de contexto en tus flujos de trabajo. El agente abre merge requests en GitLab igual que abre solicitudes de extracción (pull requests, PR) en GitHub.

  ## Mejoras

  * Al pegar componentes MDX válidos en el editor, ahora se conserva la estructura del componente en lugar de convertirse en texto sin formato.
  * Los títulos largos de la navegación de la barra lateral ahora se dividen automáticamente con guiones para evitar desbordamientos.
  * El editor ahora resuelve las [referencias `$ref`](/es/organize/settings#split-configuration-with-%24ref) en archivos de configuración divididos.
  * Se ha mejorado el prompt del sistema del [agente de Slack](/es/agent/slack) para ofrecer respuestas más precisas y útiles.
  * `llms.txt` ahora incluye resúmenes en bloque de cita para mejorar las descripciones de las páginas.
  * Los archivos `skill.md` personalizados de tu repositorio ahora se detectan correctamente durante el despliegue.

  ## Elementos obsoletos

  * Los flujos de trabajo basados en archivos han quedado obsoletos. Crea los flujos de trabajo desde el panel. Los flujos de trabajo existentes definidos en archivos seguirán funcionando, pero los nuevos deben crearse en el panel.

  ## Correcciones de errores

  * Se corrigieron casos en los que los enlaces relativos en archivos `index.mdx` no se resolvían correctamente.
  * Se corrigió el botón de copia de los bloques de código en las respuestas de Assistant.
  * Se corrigió un problema que impedía que la tabla de contenido se actualizara después de cambios en el contenido de la página.
  * Se corrigió un problema que impedía que los títulos de los bloques de código se mostraran correctamente.
  * Se corrigió el color de borde predeterminado en el modo oscuro.
  * Se corrigió un problema por el que el comando de CLI `mint analytics feedback` enviaba valores incorrectos para el tipo de comentarios.
  * Se corrigió un artefacto de sombra en los botones del selector numérico.
  * Se corrigió la navegación del lado del cliente para los enlaces relacionados.

  ## Analítica de CLI

  El comando [`mint analytics`](/es/cli/analytics) te permite ver tráfico, consultas de búsqueda, comentarios de usuarios y conversaciones del asistente desde la terminal para una mejor integración con agentes.

  Usa subcomandos para explorar datos específicos:

  * `mint analytics stats` — vistas, visitantes, búsquedas, comentarios y uso del asistente para un intervalo de fechas
  * `mint analytics search` — consultas de búsqueda con recuentos de resultados y tasas de clics
  * `mint analytics feedback` — comentarios sobre páginas y fragmentos de código enviados por los usuarios
  * `mint analytics conversation list` — conversaciones recientes del asistente

  Todos los subcomandos admiten las marcas `--from`, `--to` y `--format`. Los formatos de salida incluyen `plain` (predeterminado), `table`, `json` y `graph`.

  ## Listados de directorios

  Los grupos de [navegación](/es/organize/navigation#root-page) con una [página raíz](/es/organize/navigation#root-page) ahora pueden mostrar un [listado de directorio](/es/organize/navigation#directory-listings) de sus páginas secundarias. Establece la propiedad `directory` en un grupo, una pestaña o el objeto `navigation` de nivel superior como `"accordion"` o `"card"` para generar automáticamente una vista general del contenido de la sección. Resulta útil para centros de ayuda y otros sitios donde los usuarios necesitan una forma rápida de explorar todas las páginas disponibles en una sección.

  ## Compatibilidad con múltiples skills

  Sirve varios [archivos de skill](/es/ai/skillmd) desde un directorio `.mintlify/skills/`. Cada subdirectorio con un archivo `SKILL.md` se detecta y sirve automáticamente, para que puedas organizar las skills por función o dominio.

  ## Mejoras del agente de Slack

  * **Múltiples despliegues**: Las organizaciones con varios sitios de documentación ahora pueden usar el [agente de Slack](/es/agent/slack) en todos ellos. El agente te pide que elijas un despliegue en el primer uso, y tu preferencia se guarda por cuenta de Slack.
  * **Modo de solo lectura**: El agente de Slack ahora clasifica los mensajes y responde en modo de solo lectura a las preguntas que solo requieren recuperación de información, reservando el acceso de escritura para las solicitudes que requieren cambios en la documentación.

  ## Credenciales de cliente para MCP autenticado

  Las [credenciales de cliente](/es/ai/model-context-protocol#client-credentials) ya están disponibles para MCP server autenticados. Usa credenciales de cliente para conectarte mediante programación sin un inicio de sesión basado en navegador: ideal para integraciones del lado del servidor, canalizaciones de CI/CD y flujos de trabajo automatizados. Crea y administra credenciales desde la página de MCP server en tu panel.

  ## Mejoras

  * El comando [`mint new`](/es/cli/commands#mint-new) ahora admite la creación de proyectos a partir de plantillas predefinidas con la marca `--template`.
  * La CLI ahora actualiza automáticamente los tokens de acceso vencidos, por lo que ya no necesitas volver a ejecutar `mint login` cuando una sesión caduca.
  * El [asistente](/es/assistant/index) ya está disponible en las vistas previas locales de `mint dev`.
  * Mejoras en la UX de la CLI: URL de inicio de sesión atenuadas para mayor claridad, formato de registros estandarizado y `mint status` ahora muestra la versión de la CLI.
  * Compatibilidad con la extensión OpenAPI `x-group` para organizar endpoints de API en grupos personalizados.
  * Las reglas horizontales (`<hr />`) ahora son compatibles con contenido MDX.
  * Los [flujos de trabajo](/es/agent/workflows) ahora aparecen en la bandeja de entrada del panel para facilitar el seguimiento. La lista de flujos de trabajo también muestra nombres de PR para identificarlos más rápido.
  * El comando `mint export` ahora incluye páginas de referencia de API generadas a partir de especificaciones OpenAPI.
  * El menú de comandos de barra inclinada del editor se ha rediseñado con mejor organización y capacidad de descubrimiento.
  * Se mejoró la IU del flujo de publicación del editor y la interfaz de creación de páginas.
  * Se mejoró la prevención de abuso para el asistente.
  * Se agregó el finés como idioma de localización compatible.

  ## Correcciones de errores

  * Se corrigió un problema por el que los ID personalizados de encabezados no se procesaban antes del análisis de MDX, lo que podía hacer que los anclajes fallaran en ciertas páginas.

  * Se corrigió el ajuste de línea del texto de etiquetas obsoletas en el panel.

  * Se corrigió que los colores de los iconos de carpetas de directorio no coincidieran con el tema configurado.

  ## Integración con Linear

  Conecta tu espacio de trabajo de Linear desde la página de configuración del agente para darle al [agente](/es/agent/linear) acceso a tus incidencias de Linear. El agente puede usar incidencias y comentarios como contexto al generar actualizaciones de documentación, o puedes delegarle incidencias directamente en tu espacio de trabajo de Linear.

  ## Integración con Notion

  Conecta tu espacio de trabajo de Notion desde la página de configuración del agente para darle al [agente](/es/agent/notion) acceso de lectura a tu contenido de Notion. El agente puede usar páginas de Notion como contexto al generar actualizaciones de documentación.

  ## Exportación sin conexión

  Empaqueta todo tu sitio de documentación en un archivo zip autocontenido con el comando CLI [`mint export`](/es/deploy/export). Comparte el zip para que tus usuarios puedan ver tu documentación en su navegador sin conexión a Internet y sin una cuenta de Mintlify.

  ## Edición de IA en línea

  Usa la edición de IA en línea para generar, reescribir y reorganizar contenido directamente en el editor visual. Selecciona texto y elige entre acciones predefinidas o escribe una instrucción personalizada. Los cambios se muestran en tiempo real como una diferencia resaltada para que puedas revisarlos antes de aplicarlos.

  ## `docs.json` componible

  Divide configuraciones grandes en archivos más pequeños con [referencias `$ref`](/es/organize/settings#split-configuration-with-%24ref). Cada `$ref` apunta a un archivo JSON independiente que se resuelve en tiempo de compilación.

  ## Selectores CSS `data-active`

  Los elementos de la barra lateral, las entradas de la tabla de contenidos y los menús desplegables de navegación ahora exponen un [atributo `data-active`](/es/customize/custom-scripts#css-selectors) estable para aplicar CSS personalizado. Usa selectores como `.toc-item[data-active]` o `#sidebar-content li[data-active]` para dar estilo a los estados activos sin depender de nombres de clase internos.

  ## endpoint de descubrimiento de agent-skills

Los agentes de IA pueden descubrir y obtener programáticamente tus [archivos de skills](/es/ai/skillmd#discovery) con verificación de integridad del contenido.

Es útil para API que usan autenticación basada en cookies.

  * Despliegues de vista previa: cuando creas una solicitud de extracción (pull request, PR), generaremos un enlace único que muestra una vista previa en tiempo real de cómo se verá tu documentación en producción. Puedes compartir este enlace con tus compañeros de equipo.
  * Snippets V2: ahora admitimos componentes y variables totalmente reutilizables para los snippets.
  * Motor MDX de código abierto: hemos expuesto dos API—getCompiledMdx y MDXComponent—para que puedas acceder al resaltado de sintaxis de Markdown y código de Mintlify. [Las contribuciones al proyecto](https://github.com/mintlify/mdx) son bienvenidas.
  * Estadísticas de AI Chat: segmenta el historial del chat por fecha, aumenta la cuota de AI Chat desde el panel y consulta con qué frecuencia aparece una consulta específica.
</Update>
