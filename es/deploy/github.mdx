Mintlify usa la GitHub App para sincronizar automáticamente tu documentación con tu repositorio de GitHub.

<Tip>
  **¿Necesitas la GitHub App?**

  * **Repositorio alojado por Mintlify** en la organización `mintlify-community`: No. La GitHub App ya está configurada.
  * **Tu propio repositorio**: Sí. Instala la GitHub App para habilitar los despliegues automáticos cuando envíes cambios.

  Consulta tu repositorio en la página [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) de tu panel.
</Tip>

Si tu documentación está en un repositorio privado propiedad de la organización Mintlify, la GitHub App se configura y administra automáticamente por Mintlify. Puedes usar el editor web para hacer cambios en tu documentación. Si quieres trabajar en tu documentación localmente, clona el repositorio en tu propia organización y actualiza tu configuración de Git para usar tu propio repositorio.

<div id="clone-to-your-own-repository">
  ## Clona en tu propio repositorio
</div>

Si omitiste conectar tu propio repositorio de Git durante la configuración inicial, tu documentación se encuentra en un repositorio privado propiedad de la organización de Mintlify. Para moverla a tu propia cuenta u organización, ve a [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) en tu panel. Un asistente de configuración te guía por el proceso con dos opciones:

<AccordionGroup>
  <Accordion title="Clonar con un clic (recomendado)">
    La opción de clonación crea automáticamente una copia de tu documentación en tu cuenta de GitHub.

    1. Selecciona **GitHub** como proveedor y elige **Clone**.
    2. Autoriza con GitHub cuando se te solicite.
    3. Selecciona la organización de GitHub en la que quieres crear el repositorio.
    4. Confirma la clonación. Mintlify copia tus archivos de documentación a un nuevo repositorio.
    5. Opcionalmente, instala la GitHub App de Mintlify para habilitar despliegues automáticos.
  </Accordion>

  <Accordion title="Configuración manual">
    <Warning>
      Este proceso elimina de forma permanente tu contenido del repositorio alojado por Mintlify.

      Descarga tu documentación desde el asistente de configuración antes de completar el proceso de configuración manual.
    </Warning>

    Si prefieres configurar tu repositorio manualmente:

    1. Descarga tu documentación como un archivo ZIP para tener una copia de seguridad de tus archivos.
    2. Selecciona **GitHub** como proveedor y elige **Continue setup**.
    3. Autoriza con GitHub cuando se te solicite.
    4. Selecciona tu organización, repositorio y rama.
    5. Opcionalmente, especifica un subdirectorio si tu documentación no está en la raíz del repositorio.
    6. Guarda tu configuración.
  </Accordion>
</AccordionGroup>

Después de completar cualquiera de las dos opciones, instala la GitHub App siguiendo los pasos de [Install the GitHub App](#install-the-github-app).

<div id="install-the-github-app">
  ## Instala la GitHub App
</div>

<Note>
  Debes ser propietario de la organización o tener permisos de administrador en un repositorio para instalar la aplicación. Si no tienes los permisos necesarios, el propietario del repositorio debe aprobar la solicitud de instalación.
</Note>

Instala la GitHub App de Mintlify desde tu [panel](https://dashboard.mintlify.com/settings/organization/github-app).

<Tip>
  Te recomendamos conceder acceso solo a tu repositorio de documentación.
</Tip>

<div id="permissions">
  ## Permisos
</div>

Cuando instales la GitHub App, concede los siguientes permisos.

Permisos de lectura:

* `metadata`: Información básica del repositorio

Permisos de lectura y escritura:

* `checks`: Crear comprobaciones de estado en las solicitudes de extracción (pull request, PR)
* `code`: Leer cambios en los archivos cuando haces commit en tu rama de documentación
* `deployments`: Generar despliegues de vista previa para las solicitudes de extracción (pull request, PR)
* `pull requests`: Crear ramas y solicitudes de extracción (pull request, PR) desde el editor web

<Info>
  La aplicación solo accede a los repositorios a los que le otorgas acceso explícitamente. Si tienes habilitadas reglas de protección de ramas, la aplicación no puede hacer push directamente a las ramas protegidas.
</Info>

<div id="manage-repository-access">
  ## Administra el acceso al repositorio
</div>

Al instalar la GitHub App, puedes conceder acceso a todos tus repositorios o solo a algunos específicos. Te recomendamos conceder acceso únicamente a tu repositorio de documentación y a cualquier repositorio que quieras usar como contexto para el agente. Puedes modificar esta selección en cualquier momento en la [configuración de la GitHub App](https://github.com/apps/mintlify/installations/new).

<div id="configure-docs-source">
  ## Configurar el origen de la documentación
</div>

Cambia la organización, el repositorio o la rama a partir de los cuales se genera tu documentación en la sección [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) de tu panel.

<div id="github-enterprise-with-ip-allowlists">
  ## GitHub Enterprise con listas de IP permitidas
</div>

Si tu organización de GitHub Enterprise Cloud tiene habilitada una lista de IP permitidas, debes añadir la dirección IP de salida de Mintlify (`54.242.90.151`) a esa lista para que la GitHub App funcione correctamente.

Sigue la [documentación de GitHub](https://docs.github.com/en/enterprise-cloud@latest/organizations/keeping-your-organization-secure/managing-security-settings-for-your-organization/managing-allowed-ip-addresses-for-your-organization) para configurar tu lista de IP permitidas.

<div id="troubleshooting">
  ## Solución de problemas
</div>

<div id="deployment-not-triggering-automatically">
  ### El despliegue no se activa automáticamente
</div>

Si los pushes a tu repositorio no activan despliegues, revisa los siguientes posibles problemas.

<AccordionGroup>
  <Accordion title="Verifica la instalación de GitHub App">
    Comprueba que la aplicación esté instalada en el repositorio correcto.

    1. Ve a la [configuración de GitHub App](https://dashboard.mintlify.com/settings/organization/github-app) en tu panel.
    2. Comprueba que tu repositorio aparezca en la lista de instalaciones activas de la aplicación.
  </Accordion>

  <Accordion title="Comprueba la rama de despliegue">
    Asegúrate de hacer push a la rama correcta.

    1. Ve a [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings)
    2. Verifica que la rama en tu panel coincida con la rama a la que haces push.
  </Accordion>
</AccordionGroup>

<div id="github-app-connection-issues">
  ### Problemas de conexión con la GitHub App
</div>

Si tienes problemas con la GitHub App, restablecer la conexión suele resolver la mayoría de ellos.

<Steps>
  <Step title="Desinstala la app de Mintlify desde GitHub.">
    1. En GitHub, ve a [installations](https://github.com/settings/installations) y selecciona **Configure** junto a la app de Mintlify. Desplázate hacia abajo y selecciona **Uninstall**.
    2. Ve a [Authorized GitHub Apps](https://github.com/settings/apps/authorizations) y selecciona **Revoke** junto a la app de Mintlify.
  </Step>

  <Step title="Vuelve a instalar la app de Mintlify.">
    1. En tu panel de Mintlify, ve a [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) e instala la GitHub App.
    2. Autoriza tu cuenta en la sección [My Profile](https://dashboard.mintlify.com/settings/account) de tu panel.
  </Step>
</Steps>

<div id="feedback-add-ons-are-unavailable">
  ### Los complementos de comentarios no están disponibles
</div>

Las funciones de sugerencias de edición y de reporte de incidencias solo están disponibles para repositorios públicos de GitHub. Si estas opciones están deshabilitadas en tu panel, comprueba la visibilidad de tu repositorio.

Si tu repositorio es público y no puedes habilitar las opciones de sugerencias de edición o de reporte de incidencias en tu panel, vuelve a validar la configuración de Git.

<Steps>
  <Step title="Ir a la configuración de Git">
    Ve a [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) en tu panel.
  </Step>

  <Step title="Volver a validar la configuración">
    Haz clic en la marca de verificación verde de la esquina del cuadro de configuración de Git para volver a validar la configuración de tu repositorio. Esto fuerza una actualización de la configuración de tu repositorio para reflejar si es público o privado.

    <Frame>
      <img src="/images/github/revalidate-settings-light.png" alt="La página de Git Settings en el panel de Mintlify. Una flecha naranja señala la marca de verificación verde que vuelve a validar la configuración del repositorio." className="block dark:hidden" />

      <img src="/images/github/revalidate-settings-dark.png" alt="La página de Git Settings en el panel de Mintlify. Una flecha naranja señala la marca de verificación verde que vuelve a validar la configuración del repositorio." className="hidden dark:block" />
    </Frame>
  </Step>
</Steps>
