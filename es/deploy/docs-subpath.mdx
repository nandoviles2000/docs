Aloja tu documentación en una subruta como `your-domain.com/docs` para mantenerla en tu dominio principal, de modo que sea más fácil de encontrar y ofrezca una experiencia de marca coherente para tus usuarios.

<div id="set-up-by-hosting-provider">
  ## Configuración según el proveedor de hosting
</div>

La configuración de una subruta `/docs` varía según tu proveedor de hosting. Elige tu proveedor de hosting y sigue las instrucciones de configuración.

* [Cloudflare](/es/deploy/cloudflare): Configura Cloudflare Workers para tu dominio para servir tu documentación en la subruta `/docs`.
* [AWS Route 53 and CloudFront](/es/deploy/route53-cloudfront): Despliega tu documentación en la subruta `/docs` con AWS mediante DNS de Route 53 y la CDN de CloudFront.
* [Vercel](/es/deploy/vercel) - Usa reescrituras para desplegar tu documentación en la subruta `/docs`.
* [Custom reverse proxy](/es/deploy/reverse-proxy) - Para otras plataformas de hosting, configura un proxy inverso para desplegar tu documentación en la subruta `/docs`.

<div id="additional-configuration-for-strict-security-policies">
  ### Configuración adicional para políticas de seguridad estrictas
</div>

Si haces pasar todo el tráfico de tu dominio personalizado por un proxy, es posible que debas configurar tu proxy o las reglas de tu firewall para añadir los [encabezados](/es/deploy/csp-configuration) correctos, de modo que tu documentación se muestre correctamente.
