Esta guía te explica cómo configurar la GitHub App de Mintlify en tu instalación de GitHub Enterprise Server (GHES). Para conectar una instancia de GHES a Mintlify, debes crear una versión local de nuestra aplicación dentro de tu entorno autoalojado que se comunique con nuestro servidor remoto.

Si usas una instancia de GitHub alojada en la nube, consulta la página de [GitHub](/es/deploy/github) para ver las instrucciones de configuración.

<div id="prerequisites">
  ## Requisitos previos
</div>

* Privilegios de administrador en la organización de GitHub Enterprise Server donde quieres instalar la aplicación
* Acceso a los repositorios de la organización donde quieres instalar la aplicación
* Conectividad de red para comunicarte con nuestros servicios externos (consulta la sección [Requisitos de red](#network-requirements) más abajo)

<div id="network-requirements">
  ### Requisitos de red
</div>

<div id="outbound-connectivity">
  #### Conectividad saliente
</div>

Tu GitHub Enterprise Server debe poder acceder a:

* los endpoints de la API de Mintlify (https://leaves.mintlify.com)
* los receptores de webhooks (puerto 443)

<div id="firewall-configuration">
  #### Configuración del firewall
</div>

Se deben permitir las siguientes conexiones salientes:

* Conexiones desde la dirección IP estática de Mintlify: `54.242.90.151`
* HTTPS (puerto 443) a los dominios de servicio de Mintlify
* Resolución DNS para los dominios de servicio de Mintlify

<div id="step-1-register-the-github-app">
  ## Paso 1: Registrar una GitHub App
</div>

Consulta [Registering a GitHub App](https://docs.github.com/en/enterprise-server@3.18/apps/creating-github-apps/registering-a-github-app/registering-a-github-app) en la documentación de GitHub para obtener instrucciones detalladas.

<Steps>
  <Step title="Accede a la configuración de tu organización">
    1. En la esquina superior derecha de cualquier página de GitHub, haz clic en tu foto de perfil.
    2. Haz clic en **Your organizations**.
    3. Haz clic en **Settings** junto a la organización para la que quieres crear la app.
  </Step>

  <Step title="Crea una nueva GitHub App">
    1. En la barra lateral izquierda, haz clic en **Developer settings**.
    2. Haz clic en **GitHub Apps**.
    3. Haz clic en **New GitHub App**.
  </Step>

  <Step title="Configura la información básica de la app">
    Configura lo siguiente:

    * **GitHub App name:** `Mintlify`
    * **Description:** `Integración con los servicios de Mintlify`
    * **Homepage URL:** `https://mintlify.com`
    * **User authorization callback URL:** `https://your-github-server.com/` (sustitúyelo por tu dominio real de GHES)
  </Step>
</Steps>

<div id="step-2-configure-app-permissions">
  ## Paso 2: Configura los permisos de la aplicación
</div>

<Steps>
  <Step title="Configura los permisos del repositorio">
    Configura los siguientes permisos para la aplicación. No se requieren permisos de organización, cuenta ni empresa:

    * **Checks:** Lectura y escritura
    * **Contents:** Lectura y escritura
    * **Deployments:** Lectura y escritura
    * **Metadata:** Solo lectura
    * **Pull Requests:** Lectura y escritura
  </Step>

  <Step title="Suscríbete a los eventos">
    Selecciona los siguientes eventos de webhook:

    * Installation
    * Installation Target
    * Create
    * Delete
    * Public
    * Pull Request
    * Push
    * Repository
  </Step>
</Steps>

<div id="step-3-generate-and-secure-credentials">
  ## Paso 3: Genera y protege las credenciales
</div>

<Steps>
  <Step title="Crea la aplicación">
    Haz clic en **Create GitHub App**.

    Se te redirigirá a la página de configuración de la aplicación.
  </Step>

  <Step title="Genera una clave privada">
    1. Desplázate hacia abajo hasta la sección **Private keys**.
    2. Haz clic en **Generate a private key**.
    3. Descarga el archivo `.pem` y guárdalo en un lugar seguro.
  </Step>

  <Step title="Anota las credenciales de la aplicación">
    Anota lo siguiente:

    * **App ID** (visible en la parte superior de la página de configuración)
    * **Client ID** (en la sección &quot;About&quot;)
    * **Client Secret** (genéralo y guárdalo en un lugar seguro)
  </Step>
</Steps>

<div id="step-4-install-the-app">
  ## Paso 4: Instala la aplicación
</div>

<Steps>
  <Step title="Ve a la instalación de la aplicación">
    1. En la página de configuración de la aplicación, haz clic en **Install App** en la barra lateral izquierda.
    2. Selecciona tu organización en la lista.
  </Step>

  <Step title="Elige el alcance de la instalación">
    Selecciona una de estas opciones:

    * **All repositories** (para dar acceso a toda la organización)
    * **Only select repositories** (elige repositorios específicos)

    <Tip>
      Te recomendamos seleccionar &quot;Only select repositories&quot; y limitar la aplicación únicamente a los repositorios donde está tu documentación.
    </Tip>
  </Step>

  <Step title="Completa la instalación">
    1. Haz clic en **Install**.
    2. Anota el ID de instalación que aparece en la URL. Por ejemplo, en `https://your-github-server.com/settings/installations/12345`, la cadena `12345` es el ID de instalación.
  </Step>
</Steps>

<div id="step-5-configure-webhook-url">
  ## Paso 5: Configura la URL del webhook
</div>

<Steps>
  <Step title="Vuelve a la configuración de la aplicación">
    1. Vuelve a la página de configuración de tu aplicación.
    2. Desplázate hasta la sección **Webhook**.
  </Step>

  <Step title="Configura la URL del webhook">
    Configura lo siguiente:

    * **Webhook URL:** `https://leaves.mintlify.com/github-enterprise/:subdomain` (sustituye `:subdomain` por la URL que te proporcionemos)
    * **Webhook secret:** Genera una cadena aleatoria (de 32 caracteres o más) y guárdala en un lugar seguro. Mintlify también puede generarla y proporcionártela.
  </Step>
</Steps>

<div id="share-credentials-with-us">
  ## Comparta sus credenciales con nosotros
</div>

Comparta la siguiente información con nuestro equipo a través del método seguro de transferencia de información que prefiera.

<div id="required-credentials">
  ### Credenciales requeridas
</div>

* URL base de GitHub Enterprise Server: https://your-github-server.com
* ID de la aplicación: (del paso 3)
* ID de cliente de la aplicación: (del paso 3)
* Secreto de cliente de la aplicación: (del paso 3)
* ID de la instalación: (del paso 4)
* Clave privada: Todo el contenido del archivo `.pem` (debe compartirse mediante una transferencia segura de archivos)
* Secreto del webhook: (del paso 5)

<div id="optional-credentials-for-troubleshooting">
  ### Credenciales opcionales para la solución de problemas
</div>

* Nombre de la organización: El nombre de tu organización en GitHub
* Nombres de los repositorios: Los repositorios específicos donde está instalada la aplicación
* Versión de GitHub Enterprise Server: Se encuentra en el panel de administración de tu sitio

<div id="mintlify-connection">
  ## Conexión con Mintlify
</div>

Tomamos las credenciales que nos proporcionas y las almacenamos cifradas en una ubicación segura. Luego trabajamos contigo para hacer una de estas dos cosas:

* Integrar tu entorno de GHES con un despliegue existente de Mintlify.
* Integrar tu entorno de GHES con un nuevo despliegue de Mintlify que aprovisionamos para ti.

Una vez que tu entorno de GHES esté integrado con un despliegue de Mintlify, podrás habilitar los webhooks para tu GitHub App.

<Note>
  La URL del webhook puede cambiar según nuestra configuración. Probamos la integración y te proporcionamos la nueva URL.
</Note>

<div id="test-the-integration">
  ## Prueba la integración
</div>

<Steps>
  <Step title="Verifica la entrega del webhook">
    1. Ve a la configuración de tu GitHub App.
    2. Haz clic en la pestaña **Advanced**.
    3. Revisa &quot;Recent Deliveries&quot; para confirmar que las entregas del webhook se hayan completado correctamente.
    4. Busca respuestas HTTP 200.
  </Step>

  <Step title="Prueba el acceso al repositorio">
    1. Crea un issue de prueba o una solicitud de extracción (pull request, PR) en un repositorio instalado.
    2. Verifica que Mintlify responda correctamente.
  </Step>
</Steps>

<div id="faq-and-troubleshooting">
  ## Preguntas frecuentes y resolución de problemas
</div>

<AccordionGroup>
  <Accordion title="La instalación de la aplicación falla por errores de permisos.">
    Asegúrate de tener:

    * Privilegios de administrador del sitio para crear la aplicación.
    * Permisos de propietario o administrador de la organización para instalar la aplicación.
    * Los permisos de repositorio adecuados si la instalas en repositorios específicos.
  </Accordion>

  <Accordion title="Los webhooks no se están entregando">
    * Verifica que la URL del webhook sea correcta y accesible.
    * Asegúrate de que tu firewall permita conexiones HTTPS salientes.
    * Comprueba que el secreto del webhook coincida con el configurado.
    * Revisa los registros de entrega del webhook en la pestaña &quot;Advanced&quot; de la configuración de tu GitHub App.
  </Accordion>

  <Accordion title="Recibo errores de certificado SSL/TLS">
    Es posible que tu GHES use certificados autofirmados. Nuestros servicios no pueden verificar el certificado de tu servidor.

    **Solución:** Asegúrate de que tu GHES tenga un certificado SSL válido.
  </Accordion>

  <Accordion title="La aplicación se instala, pero no responde a los eventos.">
    * Asegúrate de que los webhooks se estén entregando y de que nuestro servidor los confirme con un código de respuesta 200.
    * Asegúrate de que se hayan concedido los permisos necesarios durante la instalación.
  </Accordion>

  <Accordion title="¿Puedo limitar a qué repositorios accede la aplicación?">
    Sí, durante la instalación puedes seleccionar &quot;Only select repositories&quot; y elegir repositorios específicos. Puedes modificar esto más adelante en la configuración de aplicaciones instaladas de tu organización. Esta es la forma de instalación recomendada.
  </Accordion>

  <Accordion title="¿Cómo actualizo más adelante los permisos de la aplicación?">
    * Ve a la configuración de la aplicación como administrador del sitio.
    * Modifica los permisos según sea necesario.
    * Los propietarios de la organización deberán volver a aprobar la aplicación.
    * Avísanos de cualquier cambio en los permisos para que podamos indicarte si será necesario seguir pasos adicionales.
  </Accordion>

  <Accordion title="Nuestro GHES está detrás de un firewall corporativo, un proxy nginx o una configuración similar.">
    Debes:

    * Añadir los dominios de nuestro servicio a la lista de permitidos de tu firewall.
    * Asegurarte de que haya conectividad HTTPS saliente (puerto 443).
    * Si no se permite el acceso directo a internet, configurar un proxy.
  </Accordion>

  <Accordion title="¿Puede funcionar con GHES en entornos aislados de internet?">
    No, tu GHES debe poder comunicarse con nuestro servidor alojado en la nube.
  </Accordion>

  <Accordion title="¿Con quién debo ponerme en contacto si necesito ayuda?">
    Ponte en contacto con el representante de Customer Success de Mintlify con quien hayas hablado, o con nuestro equipo de soporte en <a href="mailto:support@mintlify.com">support@mintlify.com</a>, e incluye:

    * Tu versión de GitHub Enterprise Server.
    * Los mensajes de error concretos.
    * Capturas de pantalla de cualquier problema.
    * Detalles de la configuración de red/firewall (si corresponde).
  </Accordion>
</AccordionGroup>
