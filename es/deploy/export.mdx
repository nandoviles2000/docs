Usa `mint export` para empaquetar todo tu sitio de documentación en un archivo zip autocontenido. Los destinatarios pueden descomprimirlo y ver la documentación en su navegador sin conexión a Internet, sin una cuenta de Mintlify ni herramientas de compilación; solo necesitan tener [Node.js](https://nodejs.org) instalado.

Esto resulta útil cuando necesitas distribuir documentación a usuarios que no pueden acceder a tu sitio en línea, por ejemplo, clientes on-premise, entornos aislados o revisiones internas de cumplimiento.

<div id="prerequisites">
  ## Requisitos previos
</div>

* Tener la [CLI](/es/cli/install) instalada y actualizada
* Tener [Node.js](https://nodejs.org) v20.17.0+ instalado

<div id="export-your-site">
  ## Exporta tu sitio
</div>

Ve al directorio de tu documentación que contiene el archivo `docs.json` y ejecuta:

```bash
mint export
```

La CLI genera tu sitio, recorre cada página definida en tu navegación y empaqueta el resultado en un archivo .zip en tu directorio actual.

<div id="options">
  ### Opciones
</div>

| Flag                | Descripción                                                                                                                                                                                                                                  | Predeterminado |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| `--output <path>`   | Establece la ruta del archivo ZIP de salida.                                                                                                                                                                                                 | `export.zip`   |
| `--groups <group>`  | Simula [grupos de usuarios](/es/deploy/authentication-setup#control-access-with-groups) para la exportación. Resulta útil cuando tu documentación usa control de acceso basado en grupos y quieres que el archivo incluya páginas restringidas. | —              |
| `--disable-openapi` | Omite la generación del archivo OpenAPI durante la exportación. Úsalo si tienes muchas especificaciones OpenAPI y quieres compilaciones más rápidas.                                                                                         | —              |

Por ejemplo, para exportar tu sitio con un nombre de archivo personalizado y un grupo de usuarios específico:

```bash
mint export --output customer-docs.zip --groups enterprise
```

<Note>
  La exportación solo incluye las páginas que aparecen en tu Navegación. Las [páginas ocultas](/es/organize/hidden-pages) no se incluyen en el archivo.
</Note>

<div id="whats-in-the-zip">
  ## Qué incluye el archivo zip
</div>

El archivo exportado contiene todo lo necesario para ver la documentación sin conexión:

| Archivo              | Propósito                                                        |
| -------------------- | ---------------------------------------------------------------- |
| Páginas HTML         | Versión prerenderizada de cada página de tu Navegación           |
| `_next/static/`      | CSS, JavaScript y otros recursos estáticos incluidos             |
| `serve.js`           | Servidor HTTP de Node.js sin dependencias que sirve el sitio     |
| `Start Docs.command` | Iniciador de macOS: haz doble clic para abrir la documentación   |
| `Start Docs.bat`     | Iniciador de Windows: haz doble clic para abrir la documentación |

<div id="view-the-exported-docs">
  ## Ver la documentación exportada
</div>

Comparte el archivo ZIP con cualquier persona que tenga Node.js instalado. Para ver la documentación:

<Tabs>
  <Tab title="Manual">
    1. Descomprime el archivo.
    2. Abre una terminal en el directorio descomprimido.
    3. Ejecuta `node serve.js`.
    4. Abre `http://localhost:3000` en tu navegador.
  </Tab>

  <Tab title="macOS">
    1. Descomprime el archivo.
    2. Haz doble clic en **Start Docs.command**.
    3. La documentación se abre en tu navegador predeterminado en `http://localhost:3000`.

    <Note>
      macOS puede bloquear el archivo porque se descargó de internet. Si ves una advertencia de seguridad, ve a **Ajustes del Sistema &gt; Privacidad y seguridad** y selecciona **Abrir de todos modos**. Consulta la [guía de Apple para anular los ajustes de seguridad](https://support.apple.com/guide/mac-help/mh40617/mac) para obtener más información.
    </Note>
  </Tab>

  <Tab title="Windows">
    1. Descomprime el archivo.
    2. Haz doble clic en **Start Docs.bat**.
    3. La documentación se abre en tu navegador predeterminado en `http://localhost:3000`.

    <Note>
      Windows puede mostrar una advertencia de &quot;Windows protegió tu PC&quot; porque el archivo se descargó de internet. Selecciona **Más información** y, luego, **Ejecutar de todas formas**.
    </Note>
  </Tab>
</Tabs>
