Cuando completes esta guía, tendrás un sitio de documentación en vivo listo para personalizar y actualizar.

<div id="before-you-begin">
  ## Antes de empezar
</div>

Mintlify utiliza un enfoque de documentación como código para gestionar tu documentación. Cada página de tu sitio tiene un archivo correspondiente almacenado en el <Tooltip tip="El código fuente de tu documentación, donde se almacenan todos los archivos y su historial. El editor web se conecta al repositorio de tu documentación para acceder al contenido y modificarlo, o también puedes editar los archivos localmente en tu IDE preferido.">repositorio</Tooltip> de tu documentación.

Cuando conectas el repositorio de tu documentación a tu proyecto, puedes trabajar en tu documentación de forma local o en el editor web, y sincronizar cualquier cambio con tu repositorio remoto.

<div id="deploy-your-documentation-site">
  ## Despliega tu sitio de documentación
</div>

<Tip>
  Si tu código o documentación ya están en un repositorio público de GitHub, [genera tu sitio de documentación automáticamente](https://mintlify.com/explore).

  Sustituye `github.com` por `mintlify.com` en cualquier URL de un repositorio público:

  ```
  https://mintlify.com/github-org/repo-name
  ```
</Tip>

Ve a [mintlify.com/start](https://mintlify.com/start) y completa el proceso de configuración inicial. Durante este proceso, conectarás tu cuenta de GitHub, crearás o seleccionarás un repositorio para tu documentación e instalarás la GitHub App para habilitar los despliegues automáticos.

Después de la configuración inicial, tu sitio de documentación se despliega y queda accesible en tu URL `.mintlify.app`.

<AccordionGroup>
  <Accordion title="Opcional: omite la conexión a un proveedor de Git durante la configuración inicial">
    Si quieres empezar rápidamente sin conectar tu propio repositorio, puedes omitir la conexión al proveedor de Git durante la configuración inicial. Mintlify crea un repositorio privado en una organización privada y configura automáticamente la GitHub App por ti.

    Esto te permite usar el editor web de inmediato. Si más adelante quieres usar tu propio repositorio, ve a [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) en tu panel para migrar tu contenido con el asistente de configuración de Git. Consulta [Clonar en tu propio repositorio](/es/deploy/github#clone-to-your-own-repository) para obtener más información.
  </Accordion>
</AccordionGroup>

<div id="make-your-first-change">
  ## Haz tu primer cambio
</div>

<Tabs>
  <Tab title="CLI">
    <Steps>
      <Step title="Instala la CLI">
        La CLI requiere [Node.js](https://nodejs.org/en) v20.17.0 o superior. Usa una versión LTS para mayor estabilidad.

        <CodeGroup>
          ```bash npm
          npm i -g mint
          ```

          ```bash pnpm
          pnpm add -g mint
          ```
        </CodeGroup>

        Consulta [Instala la CLI](/es/cli/install) para ver todos los detalles y la resolución de problemas.
      </Step>

      <Step title="Clona tu repositorio">
        Si aún no has clonado tu repositorio localmente, sigue las instrucciones en [Clona tu repositorio](/es/cli/install#clone-your-repository).
      </Step>

      <Step title="Edita una página">
        Abre `index.mdx` en tu editor preferido y actualiza la descripción en el frontmatter:

        ```mdx
        ---
        title: "Introducción"
        description: "Tu descripción personalizada aquí"
        ---
        ```
      </Step>

      <Step title="Previsualiza localmente">
        Ejecuta el siguiente comando desde tu directorio de documentación:

        ```bash
        mint dev
        ```

        Consulta tu vista previa en `http://localhost:3000`.
      </Step>

      <Step title="Envía tus cambios">
        Haz commit y push de tus cambios para activar una implementación:

        ```bash
        git add .
        git commit -m "Actualizar descripción"
        git push
        ```

        Mintlify implementa automáticamente tus cambios. Consulta el estado de tu implementación en la página [Resumen](https://dashboard.mintlify.com/) de tu panel.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Editor web">
    <Steps>
      <Step title="Abre el editor web">
        Ve al [editor web](https://dashboard.mintlify.com/editor) en tu panel.
      </Step>

      <Step title="Edita una página">
        Abre la página **Introducción** y actualiza la descripción.

        <Frame>
          <img src="/images/quickstart/hello-world-light.png" alt="Página de introducción abierta en el editor web con la descripción editada para decir ¡Hola mundo!." className="block dark:hidden" />

          <img src="/images/quickstart/hello-world-dark.png" alt="Página de introducción abierta en el editor web con la descripción editada para decir ¡Hola mundo!." className="hidden dark:block" />
        </Frame>
      </Step>

      <Step title="Publica">
        Haz clic en el botón **Publicar** en la esquina superior derecha de la barra de herramientas del editor web.
      </Step>

      <Step title="Ver en vivo">
        En la página [Resumen](https://dashboard.mintlify.com/) de tu panel, puedes ver el estado de implementación de tu sitio. Cuando termine de implementarse, actualiza tu sitio de documentación para ver tus cambios en vivo.
      </Step>
    </Steps>
  </Tab>
</Tabs>
