Los Accordions permiten a los usuarios expandir y contraer secciones de contenido. Usa Accordions para mostrar la información de forma progresiva y para organizarla.

Cuando abres un Accordion, el hash de la URL se actualiza, lo que te permite compartir enlaces directos a secciones específicas del Accordion.

<div id="single-accordion">
  ## Un solo Accordion
</div>

<Accordion title="Soy un Accordion.">
  Puedes poner cualquier tipo de contenido aquí, incluidos otros componentes, como código:

  ```java HelloWorld.java
   class HelloWorld {
       public static void main(String[] args) {
           System.out.println("Hello, World!");
       }
   }
  ```
</Accordion>

<div id="accordion-groups">
  ## Grupos de Accordion
</div>

Agrupa acordeones relacionados con `<AccordionGroup>`. Esto crea una sección unificada de acordeones que se pueden expandir o contraer individualmente.

<AccordionGroup>
  <Accordion title="Primeros pasos">
    Puedes colocar otros componentes dentro de los acordeones.

    ```java HelloWorld.java
    class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="Funciones avanzadas" icon="bot">
    Agrega iconos para que los acordeones se distingan mejor visualmente y sean más fáciles de identificar.
  </Accordion>

  <Accordion title="Solución de problemas">
    Mantén el contenido relacionado organizado en grupos.
  </Accordion>
</AccordionGroup>

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="title" type="string" required>
  Título en la vista previa del Accordion.
</ResponseField>

<ResponseField name="description" type="string">
  Descripción debajo del título en la vista previa del Accordion.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Indica si el Accordion está abierto de forma predeterminada.
</ResponseField>

<ResponseField name="id" type="string">
  Un ID personalizado para el Accordion que se usa para enlaces de anclaje. Si se omite, el valor predeterminado será el mismo que `title`.
</ResponseField>
