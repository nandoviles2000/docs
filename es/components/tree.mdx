Usa componentes de árbol para mostrar estructuras jerárquicas, como sistemas de archivos, directorios de proyectos o contenido anidado. El componente de árbol admite la navegación con teclado y funciones de accesibilidad.

<div id="nested-folders">
  ## Carpetas anidadas
</div>

Crea estructuras con varios niveles anidando componentes `Tree.Folder` unos dentro de otros.

<Tree>
  <Tree.Folder name="app" defaultOpen>
    <Tree.File name="layout.tsx" />

    <Tree.File name="page.tsx" />

    <Tree.Folder name="api" defaultOpen>
      <Tree.Folder name="auth">
        <Tree.File name="route.ts" />
      </Tree.Folder>

      <Tree.File name="route.ts" />
    </Tree.Folder>

    <Tree.Folder name="components">
      <Tree.File name="button.tsx" />

      <Tree.File name="dialog.tsx" />

      <Tree.File name="tabs.tsx" />
    </Tree.Folder>
  </Tree.Folder>

  <Tree.File name="package.json" />
</Tree>

<div id="keyboard-navigation">
  ## Navegación con teclado
</div>

El componente de árbol admite la navegación con teclado.

* **Teclas de dirección**: Navega hacia arriba y hacia abajo entre los elementos visibles.
* **Flecha derecha**: Expande una carpeta cerrada o se mueve al primer elemento secundario de una carpeta abierta.
* **Flecha izquierda**: Contrae una carpeta abierta o se mueve a la carpeta principal.
* **Home**: Salta al primer elemento del árbol.
* **End**: Salta al último elemento visible del árbol.
* **Enter/Space**: Alterna el estado abierto/cerrado de la carpeta.
* *****: Expande todas las carpetas hermanas del nivel actual.
* **Búsqueda incremental**: Escribe caracteres para saltar a los elementos que comienzan con ellos.

<div id="properties">
  ## Propiedades
</div>

<div id="treefolder">
  ### Tree.Folder
</div>

<ResponseField name="name" type="string" required>
  El nombre de la carpeta que se muestra en el árbol.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Indica si la carpeta está expandida de forma predeterminada.
</ResponseField>

<ResponseField name="openable" type="boolean" default="true">
  Indica si la carpeta se puede abrir y cerrar. Establece este valor en false para las carpetas no interactivas.
</ResponseField>

<div id="treefile">
  ### Tree.File
</div>

<ResponseField name="name" type="string" required>
  El nombre del archivo que se muestra en el árbol.
</ResponseField>
