Usa Steps para mostrar una serie de acciones o eventos secuenciales. Puedes añadir tantos pasos como necesites.

<Steps>
  <Step title="Primer paso">
    Estas son instrucciones o contenido que solo se aplican al primer paso.
  </Step>

  <Step title="Segundo paso">
    Estas son instrucciones o contenido que solo se aplican al segundo paso.
  </Step>

  <Step title="Tercer paso">
    Estas son instrucciones o contenido que solo se aplican al tercer paso.
  </Step>
</Steps>

```mdx Steps example
<Steps>
  <Step title="First Step">
    These are instructions or content that only pertain to the first step.
  </Step>
  <Step title="Second Step">
    These are instructions or content that only pertain to the second step.
  </Step>
  <Step title="Third Step">
    These are instructions or content that only pertain to the third step.
  </Step>
</Steps>
```

<div id="steps-properties">
  ## Propiedades de Steps
</div>

<ResponseField name="children" type="ReactElement<StepProps>[]" required>
  Una lista de componentes `Step`.
</ResponseField>

<ResponseField name="titleSize" type="string" default="p">
  El tamaño de los títulos de los pasos. Puede ser `p`, `h2`, `h3` o `h4`.
</ResponseField>

<div id="individual-step-properties">
  ## Propiedades de cada paso
</div>

<ResponseField name="title" type="string" required>
  El título es el texto principal del paso y aparece junto al indicador.
</ResponseField>

<ResponseField name="children" type="string | ReactNode">
  El contenido de un paso, ya sea como texto sin formato o como componentes.
</ResponseField>

<IconsOptional />

<ResponseField name="stepNumber" type="number">
  El número del paso.
</ResponseField>

<ResponseField name="titleSize" type="string" default="p">
  El tamaño de los títulos de los pasos. Puede ser `p`, `h2`, `h3` o `h4`.
</ResponseField>

<ResponseField name="id" type="string">
  Un ID personalizado para el paso, que se usa para enlaces de anclaje y la navegación de la tabla de contenidos.
</ResponseField>

<ResponseField name="noAnchor" type="boolean" default="false">
  Indica si se debe ocultar el enlace de anclaje del paso.
</ResponseField>
