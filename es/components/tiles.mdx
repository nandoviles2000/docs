Usa mosaicos para crear elementos visuales destacados con un fondo con patrón, título y descripción. Los mosaicos son ideales para mostrar vistas previas de componentes, funciones destacadas o elementos de Navegación en una cuadrícula.

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="href" type="string" required>
  URL a la que se dirige al hacer clic en el mosaico.
</ResponseField>

<ResponseField name="title" type="string">
  El título que se muestra debajo de la vista previa del mosaico.
</ResponseField>

<ResponseField name="description" type="string">
  Una descripción breve que se muestra debajo del título.
</ResponseField>

<ResponseField name="children" type="React.ReactNode" required>
  Contenido que se muestra dentro del área de vista previa del mosaico, normalmente imágenes o SVG.
</ResponseField>
