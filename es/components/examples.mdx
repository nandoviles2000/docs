Los componentes `<RequestExample>` y `<ResponseExample>` muestran bloques de código en la barra lateral derecha para crear un diseño de dos columnas que mantiene los ejemplos visibles mientras los usuarios se desplazan por el contenido. Usa estos componentes para la documentación de la API, aunque funcionan en cualquier página.

Casos de uso comunes:

* Documentación de endpoints de la API con ejemplos de solicitud y respuesta
* Ejemplos de configuración junto con texto explicativo
* Ejemplos de código que los usuarios consultan mientras siguen las instrucciones
* Ejemplos de antes y después en tutoriales

En dispositivos móviles, los componentes `<RequestExample>` y `<ResponseExample>` se muestran como bloques de código normales por los que los usuarios pueden pasar al desplazarse.

<RequestExample>
  ```bash Request
  curl --request POST \
    --url https://dog-api.kinduff.com/api/facts
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  { "status": "success" }
  ```
</ResponseExample>

<div id="requestexample">
  ## RequestExample
</div>

Usa `<RequestExample>` para anclar ejemplos de código en la barra lateral derecha. Este componente funciona de forma similar al componente [CodeGroup](/es/components/code-groups), pero muestra el código en la barra lateral en lugar de integrarlo en el contenido.

Puedes incluir varios bloques de código dentro de un solo `<RequestExample>`. Cada bloque de código debe tener un atributo title.

````mdx RequestExample
<RequestExample>

```bash Request
curl --request POST \
  --url https://dog-api.kinduff.com/api/facts
```

</RequestExample>
````

<div id="responseexample">
  ## ResponseExample
</div>

El componente `<ResponseExample>` fija los ejemplos de código en la barra lateral derecha, debajo de cualquier contenido de `<RequestExample>` en la misma página.

````mdx ResponseExample
<ResponseExample>

```json Response
{ "status": "success" }
```

</ResponseExample>
````

<div id="properties">
  ## Propiedades
</div>

Tanto `<RequestExample>` como `<ResponseExample>` aceptan las siguientes propiedades:

<ResponseField name="dropdown" type="boolean">
  Muestra un menú desplegable de idiomas para alternar entre bloques de código, en lugar del diseño predeterminado con pestañas.
</ResponseField>
