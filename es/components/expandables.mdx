---
title: "Desplegables"
description: "Usa el componente Expandable para mostrar u ocultar propiedades de objetos anidados en la documentación de la API, mostrando campos hijo para objetos de solicitud y respuesta."
keywords: ["desplegables", "propiedades anidadas", "campos desplegables", "mostrar u ocultar contenido"]
---

Usa desplegables para mostrar y ocultar contenido anidado dentro de los campos de respuesta. Son especialmente útiles para mostrar propiedades complejas de objetos en la documentación de la API.

<ResponseField name="user" type="Objeto de usuario">
  <Expandable title="propiedades">
    <ResponseField name="full_name" type="string">
      El nombre completo del usuario
    </ResponseField>

    <ResponseField name="is_over_21" type="boolean">
      Si el usuario es mayor de 21 años
    </ResponseField>
  </Expandable>
</ResponseField>

```mdx Expandable example
<ResponseField name="user" type="User Object">
  <Expandable title="properties">
    <ResponseField name="full_name" type="string">
      The full name of the user
    </ResponseField>

    <ResponseField name="is_over_21" type="boolean">
      Whether the user is over 21 years old
    </ResponseField>
  </Expandable>
</ResponseField>
```

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="title" type="string">
  El nombre del objeto que se muestra.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Establécelo en `true` para que el Expandable se abra cuando se cargue la página
</ResponseField>
