title: "Tooltips"
description: "Agrega tooltips para mostrar definiciones y explicaciones contextuales cuando los usuarios pasan el cursor sobre términos, abreviaturas o conceptos técnicos en tu documentación."
keywords: ["tooltips", "ayuda al pasar el cursor", "información contextual", "explicaciones", "definiciones"]
---

Usa tooltips para proporcionar contexto adicional o definiciones cuando un usuario pasa el cursor sobre un fragmento de texto. Los tooltips pueden incluir enlaces opcionales con llamada a la acción.

**Ejemplo**: <Tooltip headline="API" tip="Interfaz de Programación de Aplicaciones: un conjunto de protocolos que permite que las aplicaciones de software se comuniquen entre sí." cta="Lee nuestra guía de API" href="/es/api-reference">API</Tooltip> la documentación ayuda a los desarrolladores a entender cómo integrarse con tu servicio.

```mdx Tooltip example wrap
<Tooltip headline="API" tip="Application Programming Interface: a set of protocols for software applications to communicate." cta="Read our API guide" href="/api-reference">API</Tooltip> documentation helps developers understand how to integrate with your service.
```

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="tip" type="string" required>
  El texto que se muestra en la tooltip.
</ResponseField>

<ResponseField name="headline" type="string">
  Texto que se muestra antes del texto de `tip`.
</ResponseField>

<ResponseField name="cta" type="string">
  El texto de llamada a la acción de un enlace dentro de la tooltip.
</ResponseField>

<ResponseField name="href" type="string">
  URL del enlace de llamada a la acción. Obligatorio cuando se usa `cta`.
</ResponseField>
