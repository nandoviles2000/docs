Usa el componente `Update` para mostrar entradas del registro de cambios, actualizaciones de versiones y notas de la versión con un formato coherente.

<Update label="Ejemplo" description="v0.1.1">
  ## Actualización de ejemplo

  Puedes agregar cualquier cosa aquí, como una captura de pantalla, un fragmento de código o una lista de cambios.

  <Frame>
    <img className="block" src="https://mintlify-assets.b-cdn.net/hero-light.png" alt="Captura de pantalla de la página de introducción de PearsDB como ejemplo de una imagen en un componente Update." />
  </Frame>

  ### Funciones

  * Diseño adaptable
  * Un ancla para cada actualización
  * Una entrada de feed RSS generada para cada actualización
</Update>

<div id="how-to-use">
  ## Cómo usarlo
</div>

```mdx Update example
<Update label="2024-10-11" description="v0.1.0" tags={["Mintlify"]}>
  This is an update with a label, description, and tag.
</Update>
```

Usa varios componentes `Update` para crear [registros de cambios](/es/create/changelogs).

Los componentes `Update` generan automáticamente entradas del feed RSS. Las entradas contienen solo Markdown puro: no se incluyen componentes, bloques de código, código en línea ni elementos HTML sin procesar.

Si tu actualización incluye componentes o HTML, usa la prop `rss` para proporcionar texto alternativo a los suscriptores del RSS.

```mdx Custom RSS content
<Update
  label="March 2025"
  description="v2.0.0"
  rss={{
    title: "March 2025 - Major redesign",
    description: "Complete UI overhaul with new components"
  }}
>
  ## New dashboard

  <Frame>
    <img src="/dashboard.png" alt="New dashboard UI displaying updated components." />
  </Frame>

  Check out our redesigned dashboard with improved navigation.
</Update>
```

<div id="props">
  ## Props
</div>

<ResponseField name="label" type="string" required>
  Etiqueta de la actualización. Aparece a la izquierda de la actualización y crea un enlace de anclaje. Las etiquetas deben ser únicas.
</ResponseField>

<ResponseField name="tags" type="string[]">
  Etiquetas de la actualización. Se muestran como filtros en el panel lateral derecho.
</ResponseField>

<ResponseField name="description" type="string">
  Descripción de la actualización. Aparece debajo de la etiqueta y de las etiquetas.
</ResponseField>

<ResponseField name="rss" type="object">
  Los componentes Update generan automáticamente entradas del feed RSS. Usa la propiedad `rss` para crear una sola entrada del feed RSS con un título y una descripción personalizados.

  Si no se proporciona:

  * Las actualizaciones con encabezados de Markdown crean una entrada independiente del feed RSS para cada encabezado.
  * Las actualizaciones sin encabezados de Markdown crean una sola entrada del feed RSS usando `label` como título.

  <Expandable title="propiedades">
    <ResponseField name="title" type="string">
      Título personalizado para la entrada del feed RSS.
    </ResponseField>

    <ResponseField name="description" type="string">
      Descripción personalizada para la entrada del feed RSS.
    </ResponseField>
  </Expandable>
</ResponseField>
