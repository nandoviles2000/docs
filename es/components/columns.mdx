El componente `Columns` te permite organizar contenido en una cuadrícula adaptable. Se usa sobre todo para colocar cards en una cuadrícula indicando el número de columnas. También puedes usar el subcomponente `Column` para agrupar cualquier tipo de contenido. Las columnas son adaptables y se ajustan automáticamente a pantallas más pequeñas.

<div id="column-sub-component">
  ## Subcomponente Column
</div>

Usa el componente `Column` para colocar texto o código en columnas individuales. Esto resulta útil cuando quieres mostrar contenido diverso en paralelo, no solo cards u otros componentes.

<Columns cols={2}>
  <Column>
    **Instalación**

    ```bash
    npm install my-package
    ```
  </Column>

  <Column>
    **Uso**

    ```javascript
    import { init } from 'my-package';
    init();
    ```
  </Column>
</Columns>

````mdx Column sub-component example
<Columns cols={2}>
  <Column>

  **Instalación**

  ```bash
  npm install my-package
  ```

  </Column>
  <Column>

  **Uso**

  ```javascript
  import { init } from 'my-package';
  init();
  ```

  </Column>
</Columns>
````

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="cols" type="number" default={2}>
  La cantidad de columnas por fila. Acepta valores de 1 a 4.
</ResponseField>
