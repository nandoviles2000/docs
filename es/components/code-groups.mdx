Usa el componente `CodeGroup` para mostrar varios bloques de código en una interfaz con pestañas, lo que permite a los usuarios comparar implementaciones en distintos lenguajes de programación o ver enfoques alternativos para una misma tarea.

<CodeGroup>
  ```javascript helloWorld.js
  console.log("Hello World");
  ```

  ```python hello_world.py
  print('Hello World!')
  ```

  ```java HelloWorld.java
  class HelloWorld {
      public static void main(String[] args) {
          System.out.println("Hello, World!");
      }
  }
  ```
</CodeGroup>

Los grupos de código heredan el estilo global de tu archivo `docs.json`. Personaliza el tema con `styling.codeblocks`. Consulta [Configuración](/es/organize/settings-appearance#styling) para ver las opciones de configuración.

Los grupos de código se sincronizan automáticamente con otros grupos de código y [pestañas](/es/components/tabs) de la misma página cuando sus etiquetas coinciden. Cuando seleccionas un idioma en un grupo de código, todas las pestañas y los grupos de código con etiquetas coincidentes se actualizan para mostrar ese mismo idioma.

<div id="create-code-groups">
  ## Crear grupos de código
</div>

Para crear un grupo de código, agrupa varios bloques de código entre las etiquetas `<CodeGroup>`. Cada bloque de código debe incluir un título, que se usará como etiqueta de la pestaña.

````mdx
<CodeGroup>

```javascript helloWorld.js
console.log("Hello World");
```

```python hello_world.py
print('Hello World!')
```

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

</CodeGroup>
````

<div id="language-dropdown">
  ## Menú desplegable de idiomas
</div>
