Usa el componente `View` para crear contenido que cambie según la vista seleccionada en un menú desplegable de varias vistas. Esto resulta especialmente útil para mostrar ejemplos de código o documentación específicos de distintos lenguajes de programación o frameworks.

<Tip>
  Usa un componente `View` por lenguaje en cada página. Usa [pestañas](/es/components/tabs) para procedimientos que varían según el lenguaje y [grupos de código](/es/components/code-groups) para ejemplos de código que varían según el lenguaje.
</Tip>

<div id="table-of-contents-behavior">
  ## Comportamiento de la tabla de contenido
</div>

La tabla de contenido se actualiza automáticamente para mostrar solo los encabezados de la vista seleccionada. Cuando cambias de vista con el menú desplegable de varias vistas, la tabla de contenido se actualiza para mostrar los encabezados correspondientes a esa vista.

Si tienes estructuras de encabezados distintas en cada vista, los usuarios solo verán los encabezados correspondientes al idioma o framework que hayan seleccionado.

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="title" type="string" required>
  El título que identifica esta vista. Debe coincidir con una de las opciones del menú desplegable de varias vistas.
</ResponseField>

<ResponseField name="icon" type="string">
  Un icono de [Font Awesome](https://fontawesome.com/icons), un icono de [Lucide](https://lucide.dev/icons), una URL de un icono o una ruta relativa a un icono.
</ResponseField>

<ResponseField name="iconType" type="string">
  Solo para iconos de Font Awesome: Uno de estos valores: `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ResponseField>
