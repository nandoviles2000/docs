Da estilo a los callouts como Note, Warning, Info, Tip, Check, Danger, o crea tu propio callout:

<Note>Esto añade una nota al contenido</Note>

```mdx
<Note>This adds a note in the content</Note>
```

<Warning>Esto muestra una advertencia para que la tengas en cuenta</Warning>

```mdx
<Warning>This raises a warning to watch out for</Warning>
```

<Info>Esto destaca información importante</Info>

```mdx
<Info>This draws attention to important information</Info>
```

<Tip>Esto ofrece un consejo útil</Tip>

```mdx
<Tip>This suggests a helpful tip</Tip>
```

<Check>Esto nos da un estado marcado</Check>

```mdx
<Check>Esto nos muestra un estado verificado</Check>
```

<Danger>Este es un callout de peligro</Danger>

```mdx
<Danger>This is a danger callout</Danger>
```

<Callout icon="key" color="#FFC107" iconType="regular"> Este es un callout personalizado</Callout>

```mdx wrap
<Callout icon="key" color="#FFC107" iconType="regular">This is a custom callout</Callout>
```

<div id="custom-callout-properties">
  ## Propiedades personalizadas de los callouts
</div>

El componente genérico `Callout` admite iconos y colores personalizados. Los callouts con tipo (`Note`, `Warning`, `Info`, `Tip`, `Check`, `Danger`) usan iconos y colores predefinidos y solo aceptan `children`.

<IconsOptional />

<ResponseField name="color" type="string">
  Color personalizado en código hexadecimal (por ejemplo, `#FFC107`). Define el borde, el tono de fondo y el color del texto del callout.
</ResponseField>
