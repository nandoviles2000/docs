Mintlify aloja un archivo `skill.md` en la raíz de tu proyecto que describe lo que los agentes de IA pueden hacer con tu producto.

La [especificación de skill.md](https://agentskills.io/specification) es un formato estructurado y legible por máquinas que hace explícitas las capacidades, los datos de entrada necesarios y las restricciones de los productos para que los agentes puedan utilizarlos de forma más fiable.

Mintlify genera automáticamente un archivo `skill.md` para tu proyecto analizando tu documentación mediante un proceso iterativo con agentes. Este archivo se mantiene actualizado a medida que haces cambios en tu documentación y no requiere mantenimiento. También puedes añadir opcionalmente un archivo `skill.md` personalizado en la raíz de tu proyecto para sustituir al que se genera automáticamente.

<Note>Generar o actualizar un archivo `skill.md` puede tardar hasta 24 horas.</Note>

Consulta tu `skill.md` añadiendo `/skill.md` a la URL de tu sitio de documentación. Mintlify solo genera archivos `skill.md` para sitios de documentación públicos.

<PreviewButton href="https://mintlify.com/docs/skill.md">
  Abre el skill.md de este sitio.
</PreviewButton>

<Tip>
  Tanto los archivos `llms.txt` como `skill.md` ayudan a los agentes a trabajar con tu documentación, pero sirven para cosas distintas.

  * `llms.txt` es un directorio. Enumera todas las páginas de tu documentación con descripciones para que los agentes sepan dónde encontrar información.
  * `skill.md` es un resumen de capacidades. Indica a los agentes qué pueden lograr con tu producto, qué datos de entrada necesitan y qué restricciones se aplican.
</Tip>

<div id="use-skillmd-files-with-agents">
  ## Usa archivos `skill.md` con agentes
</div>

<Note>
  Si usas un [proxy inverso](/es/deploy/reverse-proxy), configúralo para que reenvíe las rutas `/skill.md`, `/.well-known/skills/*` y `/.well-known/agent-skills/*` a tu subdominio de Mintlify.
</Note>

Cuando los usuarios se conectan a tu MCP server, sus agentes pueden descubrir y usar tus archivos `skill.md` como [recursos de MCP](/es/ai/model-context-protocol#mcp-resources) sin tener que instalar las skills por separado.

Para agregar manualmente tus skills al contexto de un agente, usa la [CLI de skills](https://www.npmjs.com/package/skills).

```bash
npx skills add https://your-docs-domain.com
```

Esto agrega las capacidades de tu producto al contexto del agente para que pueda realizar acciones en nombre de los usuarios.

<Tip>
  Enseña a tus usuarios a usar archivos `skill.md` con agentes para obtener mejores resultados al usar tu producto con sus herramientas de IA.
</Tip>

<div id="skillmd-structure">
  ## Estructura de `skill.md`
</div>

Mintlify genera un archivo `skill.md` conforme a la [especificación de agentskills.io](https://agentskills.io/specification). El archivo generado incluye:

* **Metadatos**: Nombre, descripción y versión del proyecto.
* **Capacidades**: Lo que los agentes pueden hacer con tu producto.
* **Habilidades**: Acciones específicas organizadas por categoría.
* **Flujos de trabajo**: Procedimientos paso a paso para tareas comunes.
* **Integración**: Herramientas y servicios compatibles.
* **Contexto**: Información general sobre la arquitectura de tu producto.

<div id="custom-skill-files">
  ## Archivos de skills personalizados
</div>

Agrega archivos de skills personalizados para sustituir el `skill.md` generado automáticamente. Mintlify admite alojar un único archivo de skill y un directorio para varias skills. Si eliminas todos los archivos de skills personalizados, Mintlify genera un nuevo archivo `skill.md`.

<div id="single-skill-file">
  ### Un único archivo de skill
</div>

Añade un archivo `skill.md` en la raíz de tu proyecto para reemplazar el archivo generado automáticamente.

<div id="multiple-skill-files">
  ### Múltiples archivos de skills
</div>

Agrega varios archivos de skills al directorio `.mintlify/skills/` de tu proyecto. Cada skill debe estar en su propio subdirectorio con un archivo `SKILL.md`:

```
.mintlify/
  skills/
    payments/
      SKILL.md
    analytics/
      SKILL.md
```

Cuando tienes varias habilidades, el endpoint `/skill.md` redirige al endpoint de descubrimiento `/.well-known/skills/index.json`, que enumera todas las habilidades disponibles. Los endpoints de descubrimiento hacen que cada habilidad sea accesible por separado.

<Note>
  Puedes usar ambos enfoques a la vez con un archivo `skill.md` raíz y el directorio `.mintlify/skills/`. El índice de descubrimiento incluye todas las habilidades.
</Note>

<div id="use-symlinks-to-avoid-duplication">
  ### Usa enlaces simbólicos para evitar duplicaciones
</div>

Si tus archivos de skills están en otra ubicación dentro de tu repositorio (por ejemplo, en un directorio `plugins/` o `skills/`), puedes crear un enlace simbólico de `.mintlify/skills` a esa ubicación en lugar de duplicar los archivos:

```bash
# Los skills están en un directorio skills/ de nivel superior
ln -s ../skills .mintlify/skills
```

```
project/
  skills/
    payments/
      SKILL.md
    analytics/
      SKILL.md
  .mintlify/
    skills -> ../skills
  docs.json
```

Mintlify sigue los enlaces simbólicos durante el despliegue, por lo que detecta y sirve los archivos de skills como si estuvieran directamente dentro de `.mintlify/skills/`. Esto funciona tanto con enlaces simbólicos a directorios como con enlaces simbólicos a skills individuales.

<div id="frontmatter-fields">
  ### Campos del frontmatter
</div>

Los archivos `skill.md` personalizados deben comenzar con un frontmatter YAML.

| Campo           | Tipo   | Descripción                                                                                         |
| --------------- | ------ | --------------------------------------------------------------------------------------------------- |
| `name`          | string | El nombre de tu skill.                                                                              |
| `description`   | string | Una breve descripción de lo que hace tu skill.                                                      |
| `license`       | string | La licencia de tu skill (por ejemplo, `MIT` o `Apache-2.0`).                                        |
| `compatibility` | string | Requisitos o notas de compatibilidad (por ejemplo, dependencias del entorno de ejecución).          |
| `metadata`      | object | Metadatos adicionales en forma de pares clave-valor de cadenas (por ejemplo, `author` o `version`). |
| `allowed-tools` | string | Lista de herramientas preaprobadas, separadas por espacios, que la skill puede usar (experimental). |

```md Example frontmatter
---
name: mintlify
description: Build and maintain documentation sites with Mintlify. Use when creating docs pages, configuring navigation, adding components, or setting up API references.
license: MIT
compatibility: Requires Node.js for CLI. Works with any Git-based workflow.
metadata:
  author: mintlify
  version: "1.0"
---
```

<div id="skills-discovery-endpoints">
  ## Endpoints de descubrimiento de skills
</div>

Mintlify aloja directorios de skills en `/.well-known/skills/` y `/.well-known/agent-skills/`, a los que los agentes pueden acceder para descubrir y recuperar tus archivos de skills de forma programática.

<div id="agent-skills-discovery-recommended">
  ### Descubrimiento de agent-skills (recomendado)
</div>

El endpoint `/.well-known/agent-skills/` sigue la [especificación de descubrimiento de agent-skills 0.2.0](https://schemas.agentskills.io/discovery/0.2.0/schema.json) e incluye verificación de la integridad del contenido.

`GET /.well-known/agent-skills/index.json` devuelve un manifiesto JSON con la lista de todas las habilidades disponibles:

```json
{
  "$schema": "https://schemas.agentskills.io/discovery/0.2.0/schema.json",
  "skills": [
    {
      "name": "my-product",
      "type": "skill-md",
      "description": "A brief description of what your skill does.",
      "url": "/.well-known/agent-skills/my-product/SKILL.md",
      "digest": "sha256:a1b2c3..."
    }
  ]
}
```

| Campo         | Descripción                                                                                |
| ------------- | ------------------------------------------------------------------------------------------ |
| `$schema`     | URL del esquema para la especificación de descubrimiento de agent-skills 0.2.0.            |
| `name`        | Un slug apto para URL derivado de `name` en el frontmatter de tu `skill.md`.               |
| `type`        | El formato de la habilidad. Siempre `skill-md`.                                            |
| `description` | Una breve descripción tomada del frontmatter de tu `skill.md`, truncada a 1024 caracteres. |
| `url`         | La ruta para obtener el archivo completo de la habilidad.                                  |
| `digest`      | Un hash `sha256` del contenido del archivo de la habilidad para verificar su integridad.   |

`GET /.well-known/agent-skills/{name}/SKILL.md` devuelve el archivo `skill.md` de una habilidad específica identificada por el slug de su nombre en el índice.

<div id="skills-index">
  ### Índice de habilidades
</div>

El endpoint `/.well-known/skills/` es el formato de descubrimiento original.

`GET /.well-known/skills/index.json` devuelve un manifiesto JSON que enumera todas las habilidades disponibles:

```json
{
  "skills": [
    {
      "name": "my-product",
      "description": "A brief description of what your skill does.",
      "files": ["SKILL.md"]
    }
  ]
}
```

El campo `name` es un slug compatible con URL derivado del `name` del frontmatter de tu `skill.md`.

<div id="individual-skill-files">
  ### Archivos de skills individuales
</div>

`GET /.well-known/skills/{name}/skill.md` devuelve el archivo `skill.md` de un skill específico, identificado en el índice por su nombre en formato slug.
