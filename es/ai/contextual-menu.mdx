El menú contextual ofrece acceso rápido a contenido optimizado para IA y a integraciones directas con herramientas de IA populares. Cuando los usuarios seleccionan el menú contextual en cualquier página, pueden copiar contenido como contexto para herramientas de IA o abrir conversaciones en ChatGPT, Claude, Perplexity, Google AI Studio, Grok, Devin, Windsurf o una herramienta personalizada de su elección, con la documentación ya cargada como contexto.

<div id="menu-options">
  ## Opciones del menú
</div>

El menú contextual incluye varias opciones predefinidas que puedes habilitar añadiendo su identificador a tu configuración.

| Opción                                              | Identificador | Descripción                                                                           |
| :-------------------------------------------------- | :------------ | :------------------------------------------------------------------------------------ |
| **Copiar página**                                   | `copy`        | Copia la página actual como Markdown para pegarla como contexto en herramientas de IA |
| **Ver como Markdown**                               | `view`        | Abre la página actual como Markdown                                                   |
| **Preguntar al asistente**                          | `assistant`   | Abre el [asistente](/es/assistant/index) con la página actual como contexto              |
| **Abrir en ChatGPT**                                | `chatgpt`     | Crea una conversación de ChatGPT con la página actual como contexto                   |
| **Abrir en Claude**                                 | `claude`      | Crea una conversación de Claude con la página actual como contexto                    |
| **Abrir en Perplexity**                             | `perplexity`  | Crea una conversación de Perplexity con la página actual como contexto                |
| **Abrir en Grok**                                   | `grok`        | Crea una conversación de Grok con la página actual como contexto                      |
| **Abrir en Google AI Studio**                       | `aistudio`    | Crea una conversación de Google AI Studio con la página actual como contexto          |
| **Abrir en Devin**                                  | `devin`       | Crea una sesión de Devin con la página actual como contexto                           |
| **Abrir en Windsurf**                               | `windsurf`    | Abre Windsurf Cascade con la página actual como contexto                              |
| **Copiar la URL del MCP server**                    | `mcp`         | Copia la URL de tu MCP server al portapapeles                                         |
| **Copiar el comando de instalación del MCP server** | `add-mcp`     | Copia el comando `npx add-mcp` para instalar el MCP server                            |
| **Conectar con Cursor**                             | `cursor`      | Instala tu MCP server alojado en Cursor                                               |
| **Conectar con VS Code**                            | `vscode`      | Instala tu MCP server alojado en VS Code                                              |
| **Conectar con Devin**                              | `devin-mcp`   | Instala tu MCP server alojado en Devin                                                |
| **Opciones personalizadas**                         | Object        | Añade opciones personalizadas al menú contextual                                      |

<div id="enabling-the-contextual-menu">
  ## Habilita el menú contextual
</div>

Añade el campo `contextual` a tu archivo `docs.json` y especifica qué opciones quieres incluir.

```json
{
 "contextual": {
   "options": [
     "copy",
     "view",
     "assistant",
     "chatgpt",
     "claude",
     "perplexity",
     "grok",
     "aistudio",
     "devin",
     "windsurf",
      "mcp",
      "cursor",
      "vscode",
      "devin-mcp"
    ]
 }
}
```

<div id="display-location">
  ## Ubicación de visualización
</div>

De forma predeterminada, el menú contextual aparece en el encabezado de la página. Puedes configurarlo para que se muestre en la barra lateral de la tabla de contenidos mediante la opción `display`.

```json
{
  "contextual": {
    "options": ["copy", "view", "chatgpt", "claude"],
    "display": "toc"
  }
}
```

| Valor    | Descripción                                                                                   |
| :------- | :-------------------------------------------------------------------------------------------- |
| `header` | Muestra las opciones en el menú contextual de la parte superior de la página (predeterminado) |
| `toc`    | Muestra las opciones en la barra lateral de la tabla de contenidos                            |

<div id="adding-custom-options">
  ## Añadir opciones personalizadas
</div>

Crea opciones personalizadas en el menú contextual agregando un objeto al array `options`. Cada opción personalizada requiere las siguientes propiedades:

<ResponseField name="title" type="string" required>
  El título de la opción.
</ResponseField>

<ResponseField name="description" type="string" required>
  La descripción de la opción. Se muestra debajo del título cuando se expande el menú contextual.
</ResponseField>

<IconsRequired />

<ResponseField name="href" type="string | object" required>
  El `href` de la opción. Usa una cadena para enlaces simples o un objeto para enlaces dinámicos con parámetros de consulta.

  <Expandable title="objeto href">
    <ResponseField name="base" type="string" required>
      La URL base de la opción.
    </ResponseField>

    <ResponseField name="query" type="object" required>
      Los parámetros de consulta de la opción.

      <Expandable title="objeto query">
        <ResponseField name="key" type="string" required>
          La clave del parámetro de consulta.
        </ResponseField>

        <ResponseField name="value" type="string" required>
          El valor del parámetro de consulta. Mintlify reemplaza los siguientes marcadores de posición por los valores correspondientes:

          * Usa `$page` para insertar el contenido de la página actual en Markdown.
          * Usa `$path` para insertar la ruta de la página actual.
          * Usa `$mcp` para insertar la URL del MCP server alojado.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

Ejemplo de opción personalizada:

```json {9-14} wrap
{
    "contextual": {
        "options": [
            "copy",
            "view",
            "chatgpt",
            "claude",
            "perplexity",
            {
                "title": "Request a feature",
                "description": "Join the discussion on GitHub to request a new feature",
                "icon": "plus",
                "href": "https://github.com/orgs/mintlify/discussions/categories/feature-requests"
            }
        ]
    }
}
```
