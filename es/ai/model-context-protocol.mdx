<div id="about-mcp-servers">
  ## Acerca de los servidores MCP
</div>

El Model Context Protocol (MCP) es un protocolo abierto que crea conexiones estandarizadas entre aplicaciones de IA y servicios externos, como la documentación. Mintlify genera un MCP server a partir de tu documentación y prepara tu contenido para el ecosistema de IA en general, donde cualquier cliente MCP, como Claude, Cursor, Goose, ChatGPT y otros, puede conectarse a tu documentación.

Tu MCP server expone herramientas para que las aplicaciones de IA busquen en tu documentación y obtengan el contenido completo de las páginas. Tus usuarios deben conectar tu MCP server a sus herramientas.

<div id="how-mcp-servers-work">
  ### Cómo funcionan los servidores MCP
</div>

Cuando una aplicación de IA se conecta al MCP server de tu documentación, puede buscar en ella y recuperar directamente el contenido completo de las páginas en respuesta a la solicitud de un usuario, en lugar de basarse en información de sus datos de entrenamiento o hacer una búsqueda web genérica. Tu MCP server proporciona acceso a todo el contenido indexado de tu sitio de documentación.

* Las aplicaciones de IA pueden buscar de forma proactiva en tu documentación mientras generan una respuesta, incluso si no se les pide explícitamente que lo hagan para encontrar una respuesta.
* Las aplicaciones de IA determinan cuándo usar las herramientas disponibles en función del contexto de la conversación y de la relevancia de tu documentación.
* Cada invocación de una herramienta se produce durante el proceso de generación, por lo que la aplicación de IA usa información actualizada de tu documentación para generar su respuesta.

<Tip>
  Algunas herramientas de IA, como Claude, admiten tanto MCP como skills. MCP da acceso al contenido de tu documentación, mientras que las skills indican a los agentes cómo usar ese contenido de forma eficaz. Son complementarios, y conectar tu MCP server les da a los agentes acceso a ambos.
</Tip>

<div id="mcp-tools">
  ### Herramientas de MCP
</div>

Tu MCP server proporciona dos herramientas que los agentes pueden usar:

* **Búsqueda**: Busca en toda tu documentación contenido relevante y devuelve fragmentos con títulos y enlaces. Úsala para descubrir información o encontrar páginas que coincidan con una consulta.
* **Query docs filesystem**: Lee y recorre el sistema de archivos virtual de tu documentación mediante comandos tipo shell. Úsala para recuperar el contenido de páginas, explorar la estructura de la documentación o extraer secciones específicas, incluida la lectura por lotes de varias páginas en una sola llamada.

Los agentes determinan cuándo usar cada herramienta según el contexto de la conversación. Por ejemplo, un agente podría primero buscar en tu documentación para encontrar páginas relevantes y luego usar la herramienta query docs filesystem para leer el contenido completo de los resultados más relevantes.

<div id="mcp-resources">
  ### Recursos de MCP
</div>

Tu MCP server también expone tus [archivos skill.md](/es/ai/skillmd) como recursos de MCP. Los agentes conectados a tu MCP server pueden descubrir y acceder a tus archivos skill sin tener que instalarlos por separado.

Los recursos `Skill.md` aparecen en la lista de recursos del MCP server y contienen las descripciones de capacidades que genera Mintlify o que defines en tus [archivos skill personalizados](/es/ai/skillmd#custom-skill-files).

<div id="search-parameters">
  ### Parámetros de Búsqueda
</div>

La herramienta de búsqueda de MCP admite parámetros opcionales que las aplicaciones de IA usan para controlar y ajustar los resultados de búsqueda.

* **`pageSize`**: Número de resultados que se devolverán, entre 1 y 50. El valor predeterminado es 10.
* **`scoreThreshold`**: Puntuación mínima de relevancia entre 0 y 1. Solo devuelve resultados que alcanzan o superan este umbral. Úsalo para filtrar coincidencias con baja relevancia.
* **`version`**: Filtra los resultados por una versión específica de la documentación. Por ejemplo, `'v0.7'`. Solo devuelve contenido etiquetado con la versión especificada o contenido disponible en todas las versiones.
* **`language`**: Filtra los resultados por un código de idioma específico. Por ejemplo, `'en'`, `'zh'` o `'es'`. Solo devuelve contenido en el idioma especificado o contenido disponible en todos los idiomas.

Las aplicaciones de IA determinan cuándo aplicar estos parámetros en función del contexto de la consulta del usuario. Por ejemplo, si un usuario pregunta por una versión específica de la API, la aplicación de IA puede aplicar automáticamente el filtro adecuado para ofrecer resultados más relevantes.

<div id="mcp-compared-to-web-search">
  ### MCP frente a la búsqueda web
</div>

Las herramientas de IA pueden buscar en la web, pero MCP ofrece ventajas diferenciadas para la documentación.

* **Acceso directo a la fuente**: La búsqueda web depende de lo que los motores de búsqueda hayan indexado, que puede estar desactualizado o incompleto. MCP busca directamente en la versión actual indexada de tu documentación.
* **workflow integrado**: MCP permite que la IA busque mientras genera la respuesta, en lugar de realizar una búsqueda web por separado.
* **Sin ruido en la búsqueda**: El SEO y los algoritmos de clasificación influyen en los resultados de la búsqueda web. MCP va directamente al contenido de tu documentación.

<div id="access-your-mcp-server">
  ## Accede a tu MCP server
</div>

Mintlify genera un MCP server para tu documentación y lo aloja en la ruta `/mcp` de la URL de tu documentación. Por ejemplo, el MCP server de Mintlify está disponible en `https://mintlify.com/docs/mcp`.

* En la documentación pública, tu MCP server está disponible para cualquier persona. Busca en todas las páginas públicas indexadas.
* En la documentación con autenticación parcial, donde algunas páginas son públicas y otras requieren iniciar sesión, debes habilitar tu MCP server para que los usuarios puedan acceder a él. Los usuarios no autenticados pueden buscar contenido público. Los usuarios autenticados pueden buscar en todo el contenido al que tengan permiso de acceso según sus [grupos de usuarios](/es/deploy/authentication-setup).
* En la documentación donde todas las páginas requieren autenticación, debes habilitar tu MCP server para que esté disponible para los usuarios. Los usuarios deben autenticarse antes de conectarse a tu MCP server. Tu MCP server solo busca en el contenido al que cada usuario tiene acceso según sus [grupos de usuarios](/es/deploy/authentication-setup).

Consulta y copia la URL de tu MCP server en la [página de MCP server](https://dashboard.mintlify.com/products/mcp) de tu panel.

<div id="enable-authenticated-mcp">
  ### Habilitar MCP autenticado
</div>

Si tu documentación requiere autenticación, tu MCP server exige que los usuarios se autentiquen antes de conectarse. Cuando un usuario agrega la URL de tu MCP server a su herramienta de IA, debe iniciar sesión con sus credenciales habituales. Después de autenticarse, se le redirige de vuelta a su herramienta. El MCP server solo devuelve el contenido al que cada usuario tiene permiso de acceso según sus [grupos de usuarios](/es/deploy/authentication-setup).

Si tu documentación tiene autenticación parcial, con páginas públicas y protegidas, tienes dos endpoints del MCP server:

* `/mcp`: No requiere autenticación. Devuelve solo contenido público. Compártelo con los usuarios que necesiten acceso a contenido público.
* `/authed/mcp`: Siempre requiere autenticación. Devuelve contenido según los permisos de cada usuario en función de sus [grupos de usuarios](/es/deploy/authentication-setup). Compártelo con los usuarios que necesiten acceso a contenido protegido.

El endpoint `/authed/mcp` usa su propio flujo de OAuth en `/authed/mcp/oauth/*`. Los dominios de redirección configurados para tu MCP server se aplican tanto a `/mcp` como a `/authed/mcp`.

De forma predeterminada, tu MCP server solo está disponible para herramientas en localhost. Para permitir que se conecten herramientas web, agrega los dominios de redirección de las herramientas de IA. Un dominio de redirección es el nombre de host que usa una herramienta de IA después de que un usuario completa la autenticación, como `claude.ai` o `app.cursor.ai`. Las herramientas de IA de tus usuarios no pueden completar la autenticación a menos que su dominio de redirección esté en esta lista.

<Steps>
  <Step title="Habilita MCP autenticado en tu panel">
    1. Ve a la [página del MCP server](https://dashboard.mintlify.com/products/mcp) en tu panel.
    2. Haz clic en el interruptor **Enable MCP Server**.
  </Step>

  <Step title="Agregar dominios de redirección">
    Agrega los dominios de redirección de las herramientas de IA a las que quieras dar acceso a tus usuarios. Las herramientas de IA de tus usuarios no pueden completar la autenticación a menos que su dominio de redirección esté en esta lista. Algunos dominios de redirección comunes son `claude.ai` y `vscode.dev/redirect`.

    De forma predeterminada, los dominios de redirección usan `https://`. Para permitir un esquema de protocolo personalizado, incluye el protocolo completo en la entrada del dominio. Por ejemplo, una URL de retorno de una aplicación nativa como `myapp://callback`. Mintlify siempre bloquea protocolos peligrosos como `javascript:`, `data:` y `file:`.

    Las direcciones de loopback (`localhost`, `127.0.0.1`) siempre se consideran seguras y no es necesario agregarlas.
  </Step>
</Steps>

<div id="client-credentials">
  ### Credenciales de cliente
</div>

Las credenciales de cliente te permiten conectarte de forma programática a tu MCP server autenticado sin iniciar sesión en el navegador. Usa credenciales de cliente para integraciones del lado del servidor, canalizaciones de CI/CD, flujos de trabajo automatizados y cualquier entorno en el que un usuario no pueda completar un flujo interactivo de OAuth.

Las credenciales de cliente se autentican contra el endpoint `/authed/mcp` y devuelven el mismo contenido que un usuario autenticado con acceso a todas las páginas.

<Steps>
  <Step title="Crear una credencial de cliente">
    1. Ve a la [página del MCP server](https://dashboard.mintlify.com/products/mcp) en tu panel.
    2. En la sección **Client Credentials**, selecciona **Create credential**.
    3. Introduce una etiqueta para la credencial a fin de identificar su propósito.
    4. Copia el **ID de cliente** y el **secreto de cliente**. El secreto de cliente solo se muestra una vez. No podrás recuperarlo más adelante.
  </Step>

  <Step title="Intercambiar credenciales por un token de acceso">
    Envía una solicitud POST al endpoint de token de tu MCP server con tu ID de cliente y secreto. El endpoint de token se encuentra en la ruta `/authed/mcp/oauth/token` de la URL de tu documentación.

    <CodeGroup>
      ```bash cURL
      curl -X POST https://your-docs.com/authed/mcp/oauth/token \
        -H 'Content-Type: application/x-www-form-urlencoded' \
        -d 'grant_type=client_credentials&client_id=CLIENT_ID&client_secret=CLIENT_SECRET'
      ```

      ```bash cURL (Basic Auth)
      curl -X POST https://your-docs.com/authed/mcp/oauth/token \
        -H 'Content-Type: application/x-www-form-urlencoded' \
        -H 'Authorization: Basic BASE64_CLIENT_ID_COLON_SECRET' \
        -d 'grant_type=client_credentials'
      ```
    </CodeGroup>

    La respuesta incluye un token de acceso:

    ```json
    {
      "access_token": "eyJhbGciOi...",
      "token_type": "Bearer",
      "expires_in": 1209600,
      "scope": "mcp:search"
    }
    ```

    Los tokens de acceso vencen después de 14 días. Solicita uno nuevo cuando venza el actual.
  </Step>

  <Step title="Conectarte al MCP server">
    Usa el token de acceso como token bearer al conectarte al endpoint `/authed/mcp`.

    <CodeGroup>
      ```bash cURL
      curl -X POST https://your-docs.com/authed/mcp \
        -H 'Authorization: Bearer ACCESS_TOKEN' \
        -H 'Content-Type: application/json' \
        -H 'Accept: application/json, text/event-stream' \
        -d '{
          "jsonrpc": "2.0",
          "id": 1,
          "method": "initialize",
          "params": {
            "protocolVersion": "2025-03-26",
            "capabilities": {},
            "clientInfo": {"name": "my-integration", "version": "1.0.0"}
          }
        }'
      ```

      ```bash Claude Code
      claude mcp add --transport http \
        --header "Authorization: Bearer ACCESS_TOKEN" \
        my-docs https://your-docs.com/authed/mcp
      ```
    </CodeGroup>
  </Step>
</Steps>

<div id="rate-limits">
  ### Límites de tasa
</div>

Para proteger la disponibilidad, Mintlify aplica límites de tasa a los MCP servers.

| Alcance                                                                | Límite                      | Descripción                                                                                                                       |
| :--------------------------------------------------------------------- | :-------------------------- | :-------------------------------------------------------------------------------------------------------------------------------- |
| Por usuario (dirección IP)                                             | 5,000 solicitudes por hora  | Limita la frecuencia con la que un solo usuario puede consultar la configuración de tu MCP server.                                |
| Búsqueda por sitio de documentación (dominio)                          | 10,000 solicitudes por hora | Limita el número total de llamadas a la herramienta de búsqueda entre todos los usuarios de tu MCP server.                        |
| Query docs filesystem por sitio de documentación (dominio)             | 10,000 solicitudes por hora | Limita el número total de llamadas a la herramienta query docs filesystem entre todos los usuarios de tu MCP server.              |
| Búsqueda autenticada por sitio de documentación (dominio)              | 5,000 solicitudes por hora  | Limita el número total de llamadas autenticadas a la herramienta de búsqueda entre todos los usuarios de tu MCP server.           |
| Query docs filesystem autenticado por sitio de documentación (dominio) | 5,000 solicitudes por hora  | Limita el número total de llamadas autenticadas a la herramienta query docs filesystem entre todos los usuarios de tu MCP server. |

<div id="content-filtering-and-indexing">
  ## Filtrado e indexación del contenido
</div>

Tu MCP server busca el contenido que Mintlify indexa desde tu repositorio de documentación. El procesamiento de archivos y la indexación para la búsqueda controlan qué contenido está disponible a través de tu MCP server.

En la documentación que requiere autenticación, tu MCP server solo indexa las páginas de [grupos de usuarios públicos](/es/deploy/authentication-setup#make-pages-public). En la documentación con autenticación parcial, tu MCP server indexa las páginas públicas para usuarios no autenticados y cualquier página de grupos de usuarios públicos.

<div id="file-processing-with-mintignore">
  ### Procesamiento de archivos con `.mintignore`
</div>

Si los archivos coinciden con los patrones de [.mintignore](/es/organize/mintignore), Mintlify no los procesa ni los indexa. Estos archivos no están disponibles a través de tu MCP server.

<div id="search-indexing-with-docsjson">
  ### Indexación de búsqueda con `docs.json`
</div>

De forma predeterminada, Mintlify solo indexa para la búsqueda, a través de tu MCP server, las páginas incluidas en la navegación de tu `docs.json`.

Mintlify excluye del índice de búsqueda las [páginas ocultas](/es/organize/hidden-pages) (páginas que no están en tu navegación), a menos que elijas indexar todas las páginas. Para incluir páginas ocultas en los resultados de búsqueda de tu MCP server, agrega la propiedad `seo.indexing` a tu `docs.json`.

```json
"seo": {
    "indexing": "all"
}
```

Para excluir una página específica del índice de búsqueda, agrega `noindex: true` a su frontmatter.

```mdx
---
title: "Hidden page"
description: "This page is not in the navigation and is not available through search."
noindex: true
---
```

<div id="use-your-mcp-server">
  ## Usa tu MCP server
</div>

Tus usuarios deben conectar tu MCP server a las herramientas de IA que prefieran.

1. Haz que la URL de tu MCP server esté disponible públicamente.
2. Los usuarios copian la URL de tu MCP server y la añaden a sus herramientas.
3. Los usuarios acceden a tu documentación desde sus herramientas.

Estas son algunas formas de ayudar a tus usuarios a conectarse a tu MCP server:

<Tabs>
  <Tab title="Menú contextual">
    Agrega opciones en el [menú contextual](/es/ai/contextual-menu) para que tus usuarios puedan conectarse a tu MCP server desde cualquier página de tu documentación.

    | Opción                                           | Identificador | Descripción                                                   |
    | :----------------------------------------------- | :------------ | :------------------------------------------------------------ |
    | **Copiar URL del MCP server**                    | `mcp`         | Copia la URL de tu MCP server en el portapapeles del usuario. |
    | **Copiar comando de instalación del MCP server** | `add-mcp`     | Copia el comando `npx add-mcp` para instalar el MCP server.   |
    | **Conectar a Cursor**                            | `cursor`      | Instala tu MCP server en Cursor.                              |
    | **Conectar a VS Code**                           | `vscode`      | Instala tu MCP server en VS Code.                             |
  </Tab>

  <Tab title="Claude">
    <Steps>
      <Step title="Obtén la URL de tu MCP server.">
        Ve a tu [panel](https://dashboard.mintlify.com/products/mcp) y busca la URL de tu MCP server.
      </Step>

      <Step title="Publica la URL de tu MCP server para tus usuarios.">
        Crea una guía para tus usuarios que incluya la URL de tu MCP server y los pasos para conectarlo a Claude.

        1. Ve a la página de [Connectors](https://claude.ai/settings/connectors) en la configuración de Claude.
        2. Selecciona **Add custom connector**.
        3. Agrega el nombre y la URL de tu MCP server.
        4. Selecciona **Add**.
        5. Cuando uses Claude, selecciona el botón de archivos adjuntos (el icono de más).
        6. Selecciona tu MCP server.
      </Step>
    </Steps>

    Consulta la [documentación de Model Context Protocol](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server) para obtener más información.
  </Tab>

  <Tab title="Claude Code">
    <Steps>
      <Step title="Obtén la URL de tu MCP server.">
        Ve a tu [panel](https://dashboard.mintlify.com/products/mcp) y busca la URL de tu MCP server.
      </Step>

      <Step title="Publica la URL de tu MCP server para tus usuarios.">
        Crea una guía para tus usuarios que incluya la URL de tu MCP server y el comando para conectarlo a Claude Code.

        ```bash
        claude mcp add --transport http <name> <url>
        ```
      </Step>
    </Steps>

    Consulta la [documentación de Claude Code](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers) para obtener más información.
  </Tab>

  <Tab title="Cursor">
    <Steps>

        Ve a tu [panel](https://dashboard.mintlify.com/products/mcp) y busca la URL de tu MCP server.
      </Step>

      <Step title="Publica la URL de tu MCP server para tus usuarios.">

        4. En `mcp.json`, configura tu servidor:

        ```json
        {
          "mcpServers": {
            "<your-mcp-server-name>": {
              "url": "<your-mcp-server-url>"
            }
          }
        }
        ```
      </Step>
    </Steps>

    Consulta la [documentación de Cursor](https://docs.cursor.com/en/context/mcp#installing-mcp-servers) para obtener más información.

              "url": "<your-mcp-server-url>"

<div id="example-connect-to-the-mintlify-mcp-server">
  ### Ejemplo: Conectarse al MCP server de Mintlify
</div>

Conéctate al MCP server de Mintlify para buscar en este sitio de documentación desde tu herramienta de IA preferida. Así obtendrás respuestas más precisas sobre cómo usar Mintlify en tu entorno local y verás cómo ayudar a tus usuarios a conectarse a tu MCP server.

<Tabs>
  <Tab title="Menú contextual">
    En la parte superior de esta página, selecciona el menú contextual y elige **Connect to Cursor** o **Connect to VS Code** para conectar el MCP server de Mintlify al IDE que prefieras.
  </Tab>

  <Tab title="Claude">
    Para usar el MCP server de Mintlify con Claude:

    <Steps>
      <Step title="Agregar el MCP server de Mintlify a Claude">
        1. Ve a la página de [Connectors](https://claude.ai/settings/connectors) en la configuración de Claude.
        2. Selecciona **Add custom connector**.
        3. Agrega el MCP server de Mintlify:

        * Nombre: `Mintlify`
        * URL: `https://mintlify.com/docs/mcp`

        4. Selecciona **Add**.
      </Step>

      <Step title="Acceder al MCP server en tu chat">
        1. Cuando uses Claude, selecciona el botón de adjuntos (el ícono de signo más).
        2. Selecciona el MCP server de Mintlify.
        3. Hazle una pregunta a Claude sobre Mintlify.
      </Step>
    </Steps>

    Consulta la [documentación de Model Context Protocol](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server) para obtener más información.
  </Tab>

  <Tab title="Claude Code">
    Para usar el MCP server de Mintlify con Claude Code, ejecuta el siguiente comando:

    ```bash
    claude mcp add --transport http Mintlify https://mintlify.com/docs/mcp
    ```

    Comprueba la conexión ejecutando:

    ```bash
    claude mcp list
    ```

    Consulta la [documentación de Claude Code](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers) para obtener más información.
  </Tab>

  <Tab title="Cursor">
    <PreviewButton href="cursor://anysphere.cursor-deeplink/mcp/install?name=mintlify&config=eyJ1cmwiOiJodHRwczovL21pbnRsaWZ5LmNvbS9kb2NzL21jcCJ9">Instalar en Cursor</PreviewButton>

    Para conectar el MCP server de Mintlify a Cursor, haz clic en el botón **Instalar en Cursor**. O, si prefieres conectarlo manualmente, sigue estos pasos:

<div id="using-multiple-mcp-servers">
  ### Uso de varios MCP servers
</div>

Los usuarios pueden conectar varios MCP servers a sus herramientas de IA. Los MCP servers conectados no consumen contexto hasta que la IA usa una herramienta de búsqueda. La IA decide cuándo buscar en función de la relevancia de la consulta, por lo que no busca en todos los servidores conectados para cada pregunta.

Cuando la IA busca, cada consulta devuelve varios resultados que se añaden al contexto de la conversación. Si la IA busca en varios servidores para una sola pregunta, esto puede consumir una cantidad considerable de contexto.

Mejores prácticas para usar varios MCP servers:

* Conecta solo los MCP servers relevantes para tu trabajo actual.
* Sé específico en tus prompts para que la IA busque en el servidor más relevante.
* Desconecta los servidores que no estés usando activamente para reducir el posible consumo de contexto.
