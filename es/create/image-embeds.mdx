<div id="images">
  ## Imágenes
</div>

Agrega imágenes para aportar contexto visual, ejemplos o un toque decorativo a tu documentación.

<div id="basic-image-syntax">
  ### Sintaxis básica de imágenes
</div>

Usa la [sintaxis de Markdown](https://www.markdownguide.org/basic-syntax/#images) para agregar imágenes a tu documentación:

```mdx
![Alt text describing the image](/path/to/image.png)
```

<Tip>
  Incluye siempre un texto alternativo descriptivo para mejorar la accesibilidad y el SEO. El texto alternativo debe describir claramente lo que muestra la imagen.
</Tip>

Los archivos de imagen deben medir menos de 20 MB. Para archivos más grandes, alójalos en un servicio de CDN como [Amazon S3](https://aws.amazon.com/s3) o [Cloudinary](https://cloudinary.com).

<div id="html-image-embeds">
  ### Imágenes incrustadas con HTML
</div>

Para tener más control sobre cómo se muestran las imágenes, usa etiquetas HTML `<img>`:

```jsx
<img 
  src="/images/dashboard.png" 
  alt="Main dashboard interface"
  style={{height: "300px", width: "400px"}}
  className="rounded-lg"
/>
```

<div id="resize-images-with-inline-styles">
  #### Cambia el tamaño de las imágenes con estilos en línea
</div>

Usa estilos en línea de JSX con el atributo `style` para cambiar el tamaño de las imágenes:

```jsx
<img
  src="/images/architecture.png"
  style={{width: "450px", height: "auto"}}
  alt="Diagram showing the architecture of the system"
/>
```

<div id="disable-image-zoom">
  #### Desactivar el zoom en las imágenes
</div>

Para desactivar el zoom predeterminado al hacer clic en las imágenes, agrega la propiedad `noZoom`:

```html highlight="4"
<img 
  src="/images/screenshot.png" 
  alt="Descriptive alt text"
  noZoom
/>
```

<div id="link-images">
  #### Imágenes con enlace
</div>

Para hacer que una imagen sea un enlace en el que se puede hacer clic, envuelve la imagen en una etiqueta `<a>` y agrega la propiedad `noZoom`:

```html
<a href="https://mintlify.com" target="_blank">
  <img 
    src="/images/logo.png" 
    alt="Mintlify logo"
    noZoom
  />
</a>
```

<Note>
  Las imágenes dentro de etiquetas de anclaje muestran automáticamente un cursor de puntero para indicar que se pueden clicar.
</Note>

<div id="light-and-dark-mode-images">
  #### Imágenes para los modos claro y oscuro
</div>

Para mostrar imágenes distintas en los temas claro y oscuro, usa clases de Tailwind CSS:

```html
<!-- Imagen en modo claro -->
<img 
  className="block dark:hidden" 
  src="/images/light-mode.png" 
  alt="Light mode interface"
/>

<!-- Imagen en modo oscuro -->
<img 
  className="hidden dark:block" 
  src="/images/dark-mode.png" 
  alt="Dark mode interface"
/>
```

<div id="svg-images">
  ### Imágenes SVG
</div>

Los archivos SVG que usan elementos `foreignObject` se muestran de forma diferente en producción que en el entorno de desarrollo local. La CDN de imágenes de Mintlify elimina `foreignObject` de los SVG como medida de seguridad, lo que puede truncar u ocultar texto y otro contenido HTML incrustado.

Esto suele afectar a los SVG exportados desde herramientas como [draw.io](https://www.drawio.com) que tienen activado el formato de texto HTML o el ajuste de texto. Para solucionarlo, desactiva **Formatted Text** y **Word Wrap** en todas las etiquetas de tu diagrama antes de exportarlo a SVG. Consulta la [documentación de draw.io](https://www.drawio.com/doc/faq/svg-export-text-problems) para obtener más información sobre la exportación de SVG.

<div id="videos">
  ## Videos
</div>

Mintlify admite [etiquetas HTML en Markdown](https://www.markdownguide.org/basic-syntax/#html), lo que te da flexibilidad para crear contenido más completo.

<Tip>
  Incluye siempre texto de respaldo dentro de los elementos de video para los navegadores que no admiten la reproducción de video.
</Tip>

<div id="youtube-embeds">
  ### Videos incrustados de YouTube
</div>

Incrusta videos de YouTube mediante elementos iframe:

```html
<iframe
  className="w-full aspect-video rounded-xl"
  src="https://www.youtube.com/embed/4KzFe50RQkQ"
  title="YouTube video player"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
></iframe>
```

<Frame>
  <iframe className="w-full aspect-video rounded-xl" src="https://www.youtube.com/embed/4KzFe50RQkQ" title="Reproductor de video de YouTube" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen />
</Frame>

<div id="self-hosted-videos">
  ### Videos autohospedados
</div>

Usa el elemento HTML `<video>` para contenido de video autohospedado:

```html
<video
  controls
  className="w-full aspect-video rounded-xl"
  src="link-to-your-video.com"
></video>
```

<div id="autoplay-videos">
  ### Reproducción automática de videos
</div>

Para reproducir un video automáticamente, usa:

```html
<video
  autoPlay
  muted
  loop
  playsInline
  className="w-full aspect-video rounded-xl"
  src="/videos/demo.mp4"
></video>
```

<Note>
  Al usar la sintaxis JSX, escribe los atributos formados por dos palabras en camelCase: `autoPlay`, `playsInline`, `allowFullScreen`.
</Note>

<div id="iframes">
  ## Iframes
</div>

Incrusta contenido externo con elementos iframe:

```html
<iframe 
  src="https://example.com/embed" 
  title="Embedded content"
  className="w-full h-96 rounded-xl"
></iframe>
```
