Cuando cambias la ruta de un archivo en tu carpeta docs, también cambia la URL de esa página. Esto puede ocurrir al reestructurar tu documentación o al cambiar el título en la barra lateral.

<div id="redirects">
  ## Redirecciones
</div>

<Note>
  Las redirecciones **no pueden** incluir anclas en la URL como `path#anchor` ni parámetros de consulta como `path?query=value`.
</Note>

Configura las redirecciones agregando el campo `redirects` a tu archivo `docs.json`.

```json
"redirects": [
  {
    "source": "/source/path",
    "destination": "/destination/path"
  }
]
```

Esto redirige `/source/path` a `/destination/path`.

De forma predeterminada, las redirecciones son permanentes (308). Para usar una redirección temporal (307), establece `permanent` en `false`.

```json
"redirects": [
  {
    "source": "/source/path",
    "destination": "/destination/path",
    "permanent": false
  }
]
```

Tanto 307 como 308 conservan el método HTTP de la solicitud original (a diferencia de 301 y 302), por lo que son adecuados para redirigir solicitudes POST.

<div id="wildcard-redirects">
  ### Redirecciones con comodines
</div>

Para que coincida una ruta con comodín, usa `*` después de un parámetro. En este ejemplo, `/beta/:slug*` coincide con `/beta/introduction` y la redirige a `/v2/introduction`.

```json
"redirects": [
  {
    "source": "/beta/:slug*",
    "destination": "/v2/:slug*"
  }
]
```

<div id="partial-wildcard-redirects">
  ### Redirecciones con comodines parciales
</div>

Usa comodines parciales para que coincidan con segmentos de URL que empiecen por un prefijo específico.

```json
"redirects": [
  {
    "source": "/articles/concepts-*",
    "destination": "/collections/overview"
  }
]
```

Esto coincide con cualquier URL que tenga la ruta `/articles/concepts-`, como `/articles/concepts-getting-started` y `/articles/concepts-overview`, y las redirige a `/collections/overview`.

También puedes sustituir en el destino el valor del comodín capturado.

```json
"redirects": [
  {
    "source": "/old/article-*",
    "destination": "/new/article-*"
  }
]
```

Esto redirige `/old/article-123` a `/new/article-123` y conserva el valor capturado después del prefijo.

<div id="avoid-infinite-redirects">
  ### Evita los bucles de redirección infinitos
</div>

Para evitar bucles infinitos, no crees redirecciones circulares en las que las rutas se redirijan unas a otras.

```json
"redirects": [
  {
    "source": "/docs/:slug*",
    "destination": "/help/:slug*"
  },
  {
    "source": "/help/:slug*",
    "destination": "/docs/:slug*"
  }
]
```

<div id="check-for-broken-links">
  ## Comprueba si hay enlaces rotos
</div>

Encuentra enlaces rotos con la [CLI](/es/cli).

```bash
mint broken-links
```
