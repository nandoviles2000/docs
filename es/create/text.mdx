<div id="headers">
  ## Encabezados
</div>

Los encabezados organizan tu contenido y crean anclas de navegación. Aparecen en la tabla de contenido y ayudan a los usuarios a examinar tu documentación rápidamente.

<div id="creating-headers">
  ### Crear encabezados
</div>

Usa los símbolos `#` para crear encabezados de diferentes niveles:

```mdx
## Main section header
### Subsection header
#### Sub-subsection header
```

<Tip>
  Usa encabezados descriptivos y con palabras clave que indiquen claramente el contenido que sigue. Esto mejora tanto la navegación de los usuarios como la optimización para motores de búsqueda.
</Tip>

<div id="custom-heading-ids">
  ### ID de encabezado personalizados
</div>

De forma predeterminada, Mintlify genera automáticamente los ID de anclaje a partir del texto del encabezado. Puedes reemplazar el ID generado por uno personalizado con la sintaxis `{#custom-id}`:

```mdx
## My section {#my-custom-anchor}
### Configuration options {#config}
##### Deep detail {#detail}
```

El ID personalizado reemplaza el ancla generada automáticamente, por lo que puedes enlazar al encabezado con `#my-custom-anchor` o `#config` en lugar del slug predeterminado generado a partir del texto.

Esto es útil cuando quieres enlaces de anclaje estables que no cambien si actualizas el texto del encabezado, o cuando necesitas anclas más cortas y fáciles de recordar.

<div id="disabling-anchor-links">
  ### Deshabilitar los enlaces de anclaje
</div>

De forma predeterminada, los encabezados incluyen enlaces de anclaje en los que se puede hacer clic, lo que permite a los usuarios enlazar directamente a secciones específicas. Puedes deshabilitar estos enlaces de anclaje con la prop `noAnchor` en encabezados HTML o React.

<CodeGroup>
  ```mdx Ejemplo de encabezado HTML
  <h2 noAnchor>
  Header without anchor link
  </h2>
  ```

  ```mdx Ejemplo de encabezado React
  <Heading level={2} noAnchor>
  Header without anchor link
  </Heading>
  ```
</CodeGroup>

Cuando se usa `noAnchor`, el encabezado no muestra el indicador de anclaje y, al hacer clic en el texto del encabezado, no se copia el enlace de anclaje al portapapeles.

## Formato de texto

Admitimos la mayoría de las opciones de formato de Markdown para resaltar y dar estilo al texto.

<div id="basic-formatting">
  ### Formato básico
</div>

Aplica los siguientes estilos de formato a tu texto:

| Estilo      | Sintaxis    | Ejemplo               | Resultado            |
| ----------- | ----------- | --------------------- | -------------------- |
| **Negrita** | `**texto**` | `**nota importante**` | **nota importante**  |
| *Cursiva*   | `_texto_`   | `_énfasis_`           | *énfasis*            |
| ~~Tachado~~ | `~texto~`   | `~función obsoleta~`  | ~~función obsoleta~~ |

<div id="combining-formats">
  ### Combinación de formatos
</div>

Puedes combinar estilos de formato:

```mdx
**_bold and italic_**
**~~bold and strikethrough~~**
*~~italic and strikethrough~~*
```

***negrita y cursiva***<br />
**~~negrita y tachado~~**<br />
*~~cursiva y tachado~~*

<div id="superscript-and-subscript">
  ### Superíndice y subíndice
</div>

Para expresiones matemáticas o notas al pie, usa las etiquetas HTML:

| Tipo        | Sintaxis          | Ejemplo               | Resultado           |
| ----------- | ----------------- | --------------------- | ------------------- |
| Superíndice | `<sup>text</sup>` | `example<sup>2</sup>` | example<sup>2</sup> |
| Subíndice   | `<sub>text</sub>` | `example<sub>n</sub>` | example<sub>n</sub> |

## Enlaces

Los enlaces ayudan a los usuarios a navegar entre páginas y a acceder a recursos externos. Usa un texto de enlace descriptivo para mejorar la accesibilidad y la experiencia del usuario.

<div id="internal-links">
  ### Enlaces internos
</div>

Enlaza a otras páginas de tu documentación mediante rutas relativas a la raíz:

```mdx
[Quickstart](/quickstart)
[Steps](/components/steps)
```

[Guía de inicio rápido](/es/quickstart)<br />
[Steps](/es/components/steps)

<div id="external-links">
  ### Enlaces externos
</div>

Para recursos externos, incluye la URL completa:

```mdx
[Markdown Guide](https://www.markdownguide.org/)
```

[Guía de Markdown](https://www.markdownguide.org/)

<div id="broken-links">
  ### Enlaces rotos
</div>

Puedes comprobar si hay enlaces rotos en tu documentación con la [CLI](/es/cli):

```bash
mint broken-links
```

<div id="block-quotes">
  ## Citas en bloque
</div>

Las citas en bloque resaltan información importante, citas o ejemplos dentro de tu contenido.

<div id="single-line-block-quotes">
  ### Citas en bloque de una sola línea
</div>

Añade `>` antes del texto para crear una cita en bloque:

```mdx
> This is text that stands out from the main content.
```

> Este es un texto que se distingue del contenido principal.

<div id="multi-line-block-quotes">
  ### Citas en bloque de varias líneas
</div>

Para citas más largas o para varios párrafos:

```mdx
> Este es el primer párrafo de una cita en bloque de varias líneas.
>
> Este es el segundo párrafo, separado por una línea vacía con `>`.
```

> Este es el primer párrafo de una cita en bloque de varias líneas.
>
> Este es el segundo párrafo, separado por una línea en blanco con `>`.

<Tip>
  Usa las citas en bloque con moderación para conservar su impacto visual y significado. Considera usar [callouts](/es/components/callouts) para notas, advertencias y otra información.
</Tip>

<div id="mathematical-expressions">
  ## Expresiones matemáticas
</div>

Admitimos LaTeX para representar expresiones matemáticas y ecuaciones. Puedes omitir la detección automática configurando `styles.latex` en la [configuración](/es/organize/settings-appearance#styling) de tu `docs.json`.

<div id="inline-math">
  ### Matemáticas en línea
</div>

Usa un solo signo de dólar, `$`, para las expresiones matemáticas en línea:

```mdx
The Pythagorean theorem states that $(a^2 + b^2 = c^2)$ in a right triangle.
```

El teorema de Pitágoras establece que en un triángulo rectángulo se cumple $(a^2 + b^2 = c^2)$.

<div id="block-equations">
  ### Ecuaciones en bloque
</div>

Usa signos de dólar dobles, `$$`, para ecuaciones en una línea aparte:

```mdx
$$
E = mc^2
$$
```

$$
E = mc^2
$$

<Info>
  La compatibilidad con LaTeX requiere una sintaxis matemática correcta. Consulta la [documentación de LaTeX](https://www.latex-project.org/help/documentation/) para obtener una guía completa sobre la sintaxis.
</Info>

<div id="line-breaks-and-spacing">
  ## Saltos de línea y espaciado
</div>

Controla el espaciado y los saltos de línea para mejorar la legibilidad del contenido.

<div id="paragraph-breaks">
  ### Saltos de párrafo
</div>

Separa los párrafos con una línea en blanco:

```mdx
Este es el primer párrafo.

Este es el segundo párrafo, separado por una línea en blanco.
```

Este es el primer párrafo.

Este es el segundo párrafo, separado por una línea en blanco.

<div id="manual-line-breaks">
  ### Saltos de línea manuales
</div>

Usa las etiquetas HTML `<br />` para forzar saltos de línea dentro de los párrafos:

```mdx
This line ends here.<br />
This line starts on a new line.
```

Esta línea termina aquí.<br />
Esta línea empieza en una línea nueva.

<Tip>
  En la mayoría de los casos, los saltos de párrafo con líneas en blanco ofrecen mejor legibilidad que los saltos de línea manuales.
</Tip>

<div id="horizontal-rules">
  ### Líneas horizontales
</div>

Usa la sintaxis de Markdown `---` o las etiquetas HTML `<hr />` para añadir una línea horizontal que separe visualmente las secciones del contenido:

```mdx
Content preceding the rule.

<hr />

Content following the rule.
```

Contenido antes de la regla.

<hr />

Contenido después de la regla.

<Tip>
  Usa las reglas horizontales con moderación. En la mayoría de los casos, los encabezados separan mejor el contenido y, además, ofrecen anclas de navegación.
</Tip>

<div id="best-practices">
  ## Buenas prácticas
</div>

<div id="content-organization">
  ### Organización del contenido
</div>

* Usa encabezados para crear una jerarquía de contenido clara
* Sigue la jerarquía correcta de encabezados (no pases de H2 a H4)
* Escribe encabezados descriptivos y con palabras clave relevantes

<div id="text-formatting">
  ### Formato del texto
</div>

* Usa la negrita para resaltar, no para párrafos enteros
* Reserva la cursiva para términos, títulos o énfasis sutiles
* Evita el exceso de formato que distraiga del contenido

<div id="links">
  ### Enlaces
</div>

* Usa un texto descriptivo para los enlaces en lugar de &quot;haz clic aquí&quot; o &quot;leer más&quot;
* Usa rutas relativas a la raíz para los enlaces internos
* Comprueba los enlaces con regularidad para evitar referencias rotas
