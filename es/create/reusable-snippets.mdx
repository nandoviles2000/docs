Uno de los principios fundamentales del desarrollo de software es DRY (Don&#39;t Repeat Yourself), y también se aplica a la documentación. Si ves que repites el mismo contenido en varios lugares, crea un fragmento personalizado para ese contenido. Los fragmentos contienen contenido que puedes importar en otros archivos para reutilizarlo. Tú decides dónde aparece el fragmento en una página. Si en algún momento necesitas actualizar el contenido, solo tendrás que editar el fragmento en lugar de hacerlo en cada archivo donde se use.

<div id="how-snippets-work">
  ## Cómo funcionan los fragmentos
</div>

Los fragmentos son archivos `.mdx`, `.md` o `.jsx` que se importan en otro archivo. Puedes colocar los archivos de fragmentos en cualquier parte de tu proyecto.

Cuando importas un fragmento en otro archivo, el fragmento solo aparece donde lo importas y no se muestra como una página independiente. Cualquier archivo de la carpeta `/snippets/` siempre se considera un fragmento, aunque no se importe en otro archivo.

<div id="create-snippets">
  ## Crear fragmentos
</div>

Crea un archivo con el contenido que quieras reutilizar. Los fragmentos pueden incluir todos los tipos de contenido compatibles con Mintlify y también importar otros fragmentos.

<div id="import-snippets-into-pages">
  ## Importa fragmentos en las páginas
</div>

Importa fragmentos en las páginas usando una ruta absoluta o relativa.

* **Importaciones absolutas**: Empiezan con `/` para importar desde la raíz de tu proyecto.
* **Importaciones relativas**: Usa `./` o `../` para importar fragmentos con relación a la ubicación del archivo actual.

<Tip>
  Las importaciones relativas permiten la navegación en el IDE. Presiona <kbd>CMD</kbd> y haz clic en el nombre de un fragmento en tu editor para ir directamente a la definición del fragmento.
</Tip>

<div id="import-text">
  ### Importar texto
</div>

1. Agrega al archivo de fragmento el contenido que quieras reutilizar.

   ```mdx shared/my-snippet.mdx wrap
   ¡Hola, mundo! Este es el contenido que quiero reutilizar en varias páginas.
   ```

2. Importa el fragmento en tu archivo de destino usando una ruta absoluta o una relativa.

   <CodeGroup>
     ```mdx Importación absoluta
     ---
     title: "Una página de ejemplo"
     description: "Esta es una página de ejemplo que importa un fragmento."
     ---

     import MySnippet from "/shared/my-snippet.mdx";

     El contenido del fragmento aparece debajo de esta frase.

     <MySnippet />
     ```

     ```mdx Importación relativa
     ---
     title: "Una página de ejemplo"
     description: "Esta es una página de ejemplo que importa un fragmento."
     ---

     import MySnippet from "../shared/my-snippet.mdx";

     El contenido del fragmento aparece debajo de esta frase.

     <MySnippet />
     ```
   </CodeGroup>

<div id="import-variables">
  ### Importar variables
</div>

Usa variables de un fragmento en una página.

1. Exporta variables desde un archivo de fragmento.

   ```mdx shared/custom-variables.mdx
   export const myName = "Ronan";

   export const myObject = { fruit: "strawberries" };

   ;
   ```

2. Importa el fragmento en tu archivo de destino y usa las variables.

   ```mdx destination-file.mdx
   ---
   title: "Una página de ejemplo"
   description: "Esta es una página de ejemplo que importa un fragmento con variables."
   ---

   import { myName, myObject } from "/shared/custom-variables.mdx";

   Hola, me llamo {myName} y me gustan {myObject.fruit}.
   ```

<div id="import-snippets-with-variables">
  ### Importa fragmentos con variables
</div>

Usa variables para pasar datos a un fragmento cuando lo importes.

1. Agrega variables a tu fragmento y pasa propiedades al importarlo. En este ejemplo, la variable es `{word}`.

   ```mdx shared/my-snippet.mdx
   Mi palabra clave del día es {word}.
   ```

2. Importa el fragmento en el archivo de destino con la variable. La propiedad que pases reemplaza la variable en la definición del fragmento.

   ```mdx destination-file.mdx
   ---
   title: "Una página de ejemplo"
   description: "Esta es una página de ejemplo que importa un fragmento con una variable."
   ---

   import MySnippet from "/shared/my-snippet.mdx";

   <MySnippet word="bananas" />
   ```

<div id="import-react-components">
  ### Importar componentes de React
</div>

1. Crea un fragmento con un componente JSX. Consulta [componentes de React](/es/customize/react-components) para obtener más información.

   ```js components/my-jsx-snippet.jsx
   export const MyJSXSnippet = () => {
     return (
       <div>
         <h1>Hello, world!</h1>
       </div>
     );
   };
   ```

<Note>
  Al crear fragmentos de JSX, usa la sintaxis de funciones flecha (`=>`) en lugar de las declaraciones de función. La palabra clave `function` no es compatible con los fragmentos.
</Note>

2. Importa el fragmento.

   ```mdx destination-file.mdx
   ---
   title: "Una página de ejemplo"
   description: "Esta es una página de ejemplo que importa un fragmento con un componente de React."
   ---

   import { MyJSXSnippet } from "/components/my-jsx-snippet.jsx";

   <MyJSXSnippet />
   ```
