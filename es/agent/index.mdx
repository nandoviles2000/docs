<Info>
  El agente está disponible en los [planes Pro y Enterprise](https://mintlify.com/pricing?ref=agent).
</Info>

El agente es una herramienta de IA que crea solicitudes de extracción (pull request, PR) con cambios propuestos en tu documentación a partir de tus instrucciones. Cuando envías una solicitud, el agente:

* **Investiga**: Busca y lee tu documentación existente, los repositorios conectados, el contexto relevante y la web.
* **Planifica**: Crea una lista de tareas estructurada para trabajos complejos de documentación.
* **Escribe**: Genera o actualiza contenido siguiendo estándares de redacción y buenas prácticas.
* **Valida**: Ejecuta comprobaciones con la CLI de Mintlify para asegurarse de que la documentación se compile correctamente.
* **Crea una PR**: Abre una solicitud de extracción (pull request, PR) con cambios propuestos para su revisión.

Todos los cambios pasan por solicitudes de extracción (pull request, PR). El agente nunca hace commits directamente en tu rama `main`.

<div id="what-you-can-do-with-the-agent">
  ## Lo que puedes hacer con el agente
</div>

Usa el agente para:

* Escribir contenido nuevo a partir de tus prompts, solicitud de extracción (pull request, PR), tickets de Linear, hilos de Slack o archivos adjuntos.
* Actualizar la documentación existente para reflejar nuevas funciones o cambios en la API.
* Procesar e incluir imágenes, diagramas y otros archivos adjuntos de Slack.
* Buscar y revisar ejemplos de código y referencias de API en toda tu documentación.
* Automatizar el mantenimiento de la documentación con flujos de trabajo.
* Responder preguntas sobre tu documentación y sobre redacción técnica.
* Incorporar comentarios de revisión de código para mantener la calidad de la documentación.
* Capturar información de conversaciones de Slack y solicitud de extracción (pull request, PR) antes de que se pierda.
* Recorrer y coordinar cambios en varios archivos y directorios de forma eficiente.

<div id="connect-your-github-account">
  ## Conecta tu cuenta de GitHub
</div>

De forma predeterminada, el agente abre solicitud de extracción (pull request, PR) a nombre del bot de Mintlify. Para que las solicitud de extracción (pull request, PR) se te atribuyan a ti, conecta tu cuenta de GitHub en la página [Mi perfil](https://dashboard.mintlify.com/settings/account) del panel.

<div id="connect-repositories-as-context">
  ## Conecta repositorios como contexto
</div>

El agente solo puede acceder a los repositorios que conectes mediante la GitHub App de Mintlify. Configura a qué repositorios puede acceder el agente en **Configuración** del panel del agente o en la [configuración de la GitHub App](https://github.com/apps/mintlify/installations/new).
