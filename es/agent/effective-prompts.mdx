Piensa en el agente como un asistente útil que necesita tu orientación para completar tareas. Dale instrucciones claras y contexto. Las tareas más concretas son más fáciles de completar, así que divide los proyectos complejos en pasos más pequeños.

<div id="make-prompts-specific-and-outcome-focused">
  ## Haz que los prompts sean específicos y se centren en el objetivo
</div>

Los prompts genéricos como `@mintlify Improve the onboarding page` aplican buenas prácticas generales, pero puede que no mejoren el contenido exactamente de la forma que tenías en mente.

Prueba con prompts basados en los objetivos que quieres que alcancen tus usuarios o en los problemas con los que se encuentran.

* `@mintlify A lot of users have trouble installing the CLI. Review the onboarding page and update the docs so that users can easily install the CLI`
* `@mintlify Developers keep getting 401 errors when following our authentication guide. Review the auth docs and add clearer examples showing how to properly format the API key`

<div id="use-broad-prompts-for-maintenance-tasks">
  ## Usa prompts amplios para tareas de mantenimiento
</div>

Usa prompts amplios para el mantenimiento general del contenido, como corregir errores tipográficos, actualizar redirecciones o cambiar el nombre de una funcionalidad en toda la documentación.

* `@mintlify Find and fix all typos in the docs`
* `@mintlify change all unordered lists to use * instead of -`

<div id="specify-a-domain-name-for-multi-site-organizations">
  ## Especifica un nombre de dominio para organizaciones con varios sitios
</div>

Si tienes varios sitios de documentación, incluye el parámetro `subdomain` en tu mensaje para especificar en qué conjunto de documentación debe trabajar el agente.

Para encontrar tu nombre de dominio, consulta la URL de tu panel del conjunto de documentación que quieres actualizar. El nombre de dominio es la última parte después del nombre de tu organización. Por ejemplo, si la URL de tu panel es `https://dashboard.mintlify.com/org-name/domain-name`, tu nombre de dominio es `domain-name`.

Usa el formato `@mintlify subdomain=<your-domain-name> <your-prompt>` para indicarle al agente que trabaje en un conjunto de documentación específico.

* `@mintlify subdomain=public-docs Add a new section to the quickstart about inviting collaborators based on this PR`: Le indica al agente que actualice la guía de inicio rápido solo en el sitio `public-docs`.
* `@mintlify subdomain=customer-docs Update the auth docs for the new authentication method`: Le indica al agente que actualice la documentación de autenticación solo en el sitio `customer-docs`.
