Las guías de esta sección ofrecen consejos para crear documentación que ayude a tus usuarios a alcanzar sus objetivos. Tanto si empiezas desde cero como si estás mejorando la documentación existente, estas guías te ayudarán a planificar, redactar y mantener tu documentación.

Por encima de todo, ten en cuenta las necesidades y los objetivos de tus usuarios. Documenta lo que les ayude a usar tu producto y retomar sus tareas.

<div id="topics">
  ## Temas
</div>

<div id="ai-tools">
  ### Herramientas de IA
</div>

Usa herramientas con IA para acelerar tu flujo de trabajo de documentación.

* [Automatiza las actualizaciones de la documentación](/es/guides/automate-agent): Tutorial para aprender a configurar actualizaciones automáticas de la documentación con el agente.
* [Crea un asistente integrado en la aplicación](/es/guides/assistant-embed): Tutorial para aprender a añadir un chatbot de IA en una aplicación React que ayude a los usuarios a encontrar respuestas en tu documentación.
* [Configura automerge](/es/guides/configure-automerge): Agrega la GitHub App de Mintlify a la lista de omisión de un conjunto de reglas para habilitar la fusión automática en los flujos de trabajo.
* [Claude Code](/es/guides/claude-code), [Cursor](/es/guides/cursor), [Windsurf](/es/guides/windsurf): Guías para usar asistentes de programación con IA para mantener la documentación.
* [GEO](/es/guides/geo): Buenas prácticas para optimizar tu documentación para motores de búsqueda y de respuestas con IA.

<div id="api-documentation">
  ### Documentación de la API
</div>

Crea documentación de la API que permita a los usuarios probar y aprender a usar tu API, y que además sea fácil de mantener.

* [Migra de MDX a OAS](/es/guides/migrating-from-mdx): Pasa tu documentación de la API de páginas MDX individuales a páginas autogeneradas a partir de una especificación OpenAPI.

<div id="best-practices">
  ### Buenas prácticas
</div>

Crea documentación de primer nivel.

* [Accesibilidad](/es/guides/accessibility): Haz que tu documentación sea accesible para la mayor cantidad posible de usuarios.
* [Tipos de contenido](/es/guides/content-types): Elige el formato adecuado para tutoriales, guías prácticas, referencias y explicaciones.
* [Plantillas de contenido](/es/guides/content-templates): Copia y adapta plantillas para cada tipo de contenido.
* [Diseños de página personalizados](/es/guides/custom-layouts): Usa modos de página y componentes para crear páginas de destino y otros diseños personalizados.
* [Mejora tu documentación](/es/guides/improving-docs): Usa datos y comentarios para mejorar continuamente tu documentación.
* [Internacionalización](/es/guides/internationalization): Configura documentación en varios idiomas para llegar a audiencias globales.
* [Enlaces](/es/guides/linking): Crea enlaces internos, haz referencia a endpoints de API y mantén la integridad de los enlaces en toda tu documentación.
* [Mantenimiento](/es/guides/maintenance): Mantén tu documentación precisa y actualizada.
* [Contenido multimedia](/es/guides/media): Añade imágenes, videos y otros recursos multimedia de forma eficaz sin aumentar la carga de mantenimiento.
* [Organiza la navegación](/es/guides/navigation): Diseña una arquitectura de la información que funcione para tus usuarios.
* [SEO](/es/guides/seo): Optimiza tu documentación para los motores de búsqueda.
* [Estilo y tono](/es/guides/style-and-tone): Escribe con una voz coherente.
* [Comprende a tu audiencia](/es/guides/understand-your-audience): Investiga y responde a las necesidades y los objetivos de tus usuarios.

<div id="git-workflows">
  ### Flujos de trabajo de Git
</div>

Comprende Git para sacar el máximo partido a Mintlify y al enfoque docs-as-code para la documentación.

* [Conceptos de Git](/es/guides/git-concepts): Aprende los fundamentos de Git para la documentación.
* [Ramas](/es/guides/branches): Usa ramas para gestionar los cambios en la documentación.

<div id="use-cases">
  ### Casos de uso
</div>

Descubre cómo Mintlify se adapta a distintos casos de uso y encuentra la solución que mejor te funcione.

* [Crear documentación para desarrolladores](/es/guides/developer-documentation): Ayuda a tus usuarios a sacar el máximo partido de tu producto o API con documentación para desarrolladores que responda sus preguntas y les permita volver rápidamente a sus tareas principales.
* [Crear una base de conocimientos](/es/guides/knowledge-base): Configura una base de conocimientos interna para centralizar la información de tu equipo, mejorar la Búsqueda y reducir la carga de mantenimiento.
* [Crear un centro de ayuda](/es/guides/help-center): Crea un centro de ayuda de autoservicio que permita a los usuarios encontrar respuestas por sí mismos, reduzca el volumen de tickets y mejore la satisfacción del cliente.
* [Crear un frontend personalizado](/es/guides/custom-frontend): Usa la integración de Astro de Mintlify para renderizar tu documentación con un frontend totalmente personalizado.
