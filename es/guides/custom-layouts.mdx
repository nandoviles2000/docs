De forma predeterminada, las páginas de Mintlify usan un diseño estándar, con una barra lateral, un área de contenido y un índice. Personaliza este diseño con [modos de página](/es/organize/pages#page-mode) para crear landing pages, páginas para destacar funciones o cualquier página que necesite un diseño único.

En esta guía se explica cómo usar modos de página, Tailwind CSS y componentes para crear diseños personalizados.

<div id="choose-a-page-mode">
  ## Elige un modo de página
</div>

Configura el campo `mode` en el frontmatter de tu página para controlar qué elementos de la interfaz de usuario aparecen.

| Modo      | Barra lateral | Tabla de contenidos | Pie de página | Compatibilidad con temas     | Mejor para                                                              |
| --------- | ------------- | ------------------- | ------------- | ---------------------------- | ----------------------------------------------------------------------- |
| `default` | Sí            | Sí                  | Sí            | Todos los temas              | Páginas de documentación estándar                                       |
| `wide`    | Sí            | No                  | Sí            | Todos los temas              | Páginas sin encabezados o que necesitan más ancho                       |
| `custom`  | No            | No                  | No            | Todos los temas              | Landing pages, páginas de marketing o diseños de página completa        |
| `frame`   | Sí            | No                  | Modificado    | Aspen, Almond, Luma, Sequoia | Contenido personalizado que aún necesita navegación en la barra lateral |
| `center`  | No            | No                  | Sí            | Mint, Linden, Willow, Maple  | Registros de cambios y experiencias de lectura enfocadas                |

Para las landing pages, el modo `custom` te da el mayor control. Elimina todos los elementos de la interfaz de usuario excepto la barra de navegación superior, lo que te deja un lienzo en blanco sobre el que construir.

```yaml Example page frontmatter
---
title: "Welcome"
mode: "custom"
---
```

<div id="build-a-landing-page">
  ## Crea una landing page
</div>

Una landing page típica combina una sección hero, tarjetas de funcionalidades y llamadas a la acción.

<div id="set-up-the-page">
  ### Configura la página
</div>

Crea un archivo MDX en modo `custom`:

```yaml Example landing page frontmatter
---
title: "Documentation"
description: "Everything you need to build with our platform."
mode: "custom"
---
```

<div id="create-a-hero-section">
  ### Crear una sección hero
</div>

Usa HTML con clases de Tailwind CSS para crear una sección hero centrada:

```mdx Example hero section
<div className="px-4 py-16 lg:py-32 max-w-3xl mx-auto text-center">
  <h1 className="text-4xl font-medium text-gray-900 dark:text-zinc-50 tracking-tight">
    Documentation
  </h1>
  <p className="mt-4 text-lg text-gray-500 dark:text-zinc-500">
    Everything you need to build, deploy, and scale your application.
  </p>
</div>
```

<Tip>
  Incluye estilos tanto para el modo claro como para el modo oscuro. Usa clases de Tailwind con el prefijo `dark:` para manejar el modo oscuro.
</Tip>

<div id="add-navigation-cards">
  ### Añade tarjetas de navegación
</div>

Usa los componentes [Card](/es/components/cards) y [Columns](/es/components/columns) para crear una cuadrícula de enlaces debajo de la sección hero:

```mdx Example navigation cards
<div className="max-w-4xl mx-auto px-6">
  <Columns cols={2}>
    <Card title="Quickstart" icon="rocket" href="/quickstart">
      Comienza a funcionar en menos de cinco minutos.
    </Card>
    <Card title="API reference" icon="code" href="/api-reference">
      Explora endpoints, parámetros y ejemplos.
    </Card>
    <Card title="Guides" icon="book" href="/guides">
      Tutoriales paso a paso para tareas comunes.
    </Card>
    <Card title="Components" icon="puzzle" href="/components">
      Componentes de interfaz reutilizables para tu documentación.
    </Card>
  </Columns>
</div>
```

<div id="use-images-with-dark-mode-support">
  ### Usa imágenes compatibles con el modo oscuro
</div>

Muestra imágenes diferentes para los modos claro y oscuro con las clases de visibilidad de Tailwind:

```mdx Example images with dark mode support
<img
  src="/images/hero-light.png"
  alt="Platform overview showing the main dashboard."
  className="block dark:hidden"
/>
<img
  src="/images/hero-dark.png"
  alt="Platform overview showing the main dashboard."
  className="hidden dark:block"
/>
```

<div id="use-react-components-for-interactive-layouts">
  ## Usa componentes de React para diseños interactivos
</div>

Para elementos reutilizables o interactivos, define [componentes de React](/es/customize/react-components) directamente en tu archivo MDX:

```mdx Example React component
export const FeatureCard = ({ title, description, href }) => (
  <a className="group block p-6 rounded-xl border border-gray-200 dark:border-zinc-800 hover:border-gray-300 dark:hover:border-zinc-700 transition-colors" href={href}>
    <h3 className="font-medium text-gray-900 dark:text-zinc-50 group-hover:underline">
      {title}
    </h3>
    <p className="mt-2 text-sm text-gray-500 dark:text-zinc-500">
      {description}
    </p>
  </a>
);

<div className="max-w-4xl mx-auto px-6 grid sm:grid-cols-2 gap-4">
  <FeatureCard
    title="Authentication"
    description="Set up OAuth, API keys, and session management."
    href="/guides/authentication"
  />
  <FeatureCard
    title="Webhooks"
    description="Receive real-time notifications for events."
    href="/guides/webhooks"
  />
</div>
```

<Warning>
  Evita usar la prop `style` en elementos HTML. Puede provocar un cambio en el diseño al cargar la página. En su lugar, usa clases de Tailwind CSS o un [archivo CSS personalizado](/es/customize/custom-scripts).
</Warning>

<div id="add-custom-css">
  ## Añade CSS personalizado
</div>

Para los estilos que Tailwind no cubre, añade un archivo CSS a tu repositorio. Mintlify aplica los archivos CSS en todo el sitio, por lo que sus nombres de clase están disponibles en todos los archivos MDX.

<Note>
  Los valores arbitrarios de Tailwind CSS (por ejemplo, `w-[350px]`) no se admiten. Usa un archivo CSS personalizado para los valores que no cubren las clases de utilidad de Tailwind.
</Note>

```css Example custom CSS file
.landing-hero {
  background: linear-gradient(135deg, #f0f9ff 0%, #e0f2fe 100%);
  padding: 4rem 2rem;
}

@media (prefers-color-scheme: dark) {
  .landing-hero {
    background: linear-gradient(135deg, #0c1222 0%, #1a1a2e 100%);
  }
}
```

Luego, haz referencia a la clase en tu MDX:

```mdx Example custom CSS usage
<div className="landing-hero">
  <h1>Welcome to the docs</h1>
</div>
```

Consulta [Custom scripts](/es/customize/custom-scripts) para obtener más información sobre CSS personalizado y los selectores de CSS disponibles.

<div id="tips">
  ## Consejos
</div>

* **Prueba el modo claro y oscuro.** Previsualiza tu diseño personalizado en ambos modos para detectar estilos `dark:` que falten.
* **Usa clases `max-w-*`** para limitar el ancho del contenido y mantener el texto legible.
* **Hazlo adaptable.** Usa los prefijos responsivos de Tailwind (`sm:`, `md:`, `lg:`) para que tu diseño funcione en todos los tamaños de pantalla.
* **Combina modos.** Usa el modo `custom` para la página de inicio de tu documentación y el modo `default` para todo lo demás. Configuras el modo por página, así que distintas páginas pueden usar diferentes diseños.
* **Comprueba si hay saltos de diseño.** Si los elementos se desplazan al cargar la página, sustituye las props `style` inline por clases de Tailwind o CSS personalizado.
