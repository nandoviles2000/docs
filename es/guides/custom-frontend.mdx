El modo headless de Mintlify te permite controlar el aspecto y el comportamiento de tu documentación mientras usas Mintlify para gestionar el contenido. En lugar de usar el frontend alojado de Mintlify, puedes crear tu propio frontend personalizado con [Astro](https://astro.build) y renderizar tu contenido MDX y la configuración de `docs.json` como quieras.

Este enfoque headless es útil cuando necesitas control total sobre el diseño, la estructura o el comportamiento de tu documentación para adaptarla a un sistema de diseño existente o integrarla en un sitio más amplio, sin dejar de usar Mintlify para la publicación, la Búsqueda, los componentes MDX y las funciones de IA.

La integración `@mintlify/astro` lee la configuración de `docs.json` y el contenido MDX en tiempo de compilación, y después procesa todo en un formato que Astro puede renderizar. A partir de ahí, puedes crear tus propios diseños, componentes y estilos.

Esta guía te explica cómo configurar un proyecto headless de Mintlify con la plantilla inicial y ejecutarlo localmente.

<div id="prerequisites">
  ## Requisitos previos
</div>

* Una [cuenta de Mintlify](https://dashboard.mintlify.com)
* Una [cuenta de GitHub](https://github.com)
* [Node.js](https://nodejs.org) v20.17.0 o posterior (se recomiendan las versiones LTS)
* Conocimientos de [Astro](https://docs.astro.build)

<div id="set-up-your-project">
  ## Configura tu proyecto
</div>

<Steps>
  <Step title="Crea un repositorio a partir de la plantilla inicial">
    Ve al repositorio [mintlify-astro-starter](https://github.com/mintlify/mintlify-astro-starter) en GitHub y haz clic en **Use this template** para crear un repositorio nuevo en tu cuenta.

    Clona el repositorio en tu equipo local.
  </Step>

  <Step title="Regístrate en Mintlify">
    Si no tienes una cuenta de Mintlify, regístrate en [dashboard.mintlify.com/signup](https://dashboard.mintlify.com/signup).
  </Step>

  <Step title="Instala la GitHub App">
    En la página [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) de tu panel de Mintlify, instala la [Mintlify GitHub App](/es/deploy/github). Si ya la tienes instalada, desinstálala y vuelve a instalarla para que puedas conectar tu nuevo repositorio.
  </Step>

  <Step title="Conecta tu repositorio">
    1. En la página [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings), selecciona el repositorio que creaste a partir de la plantilla inicial.
    2. Activa el interruptor **Set up as monorepo**.
    3. Introduce `/docs` como la ruta al directorio que contiene tu archivo `docs.json`.
    4. Haz clic en **Save changes**.

    <Frame>
      <img src="/images/guides/astro/repo-settings-light.png" alt="Configuración del repositorio en la página de Git Settings." className="block dark:hidden" />

      <img src="/images/guides/astro/repo-settings-dark.png" alt="Configuración del repositorio en la página de Git Settings." className="hidden dark:block" />
    </Frame>
  </Step>

  <Step title="Configura las variables de entorno">
    Clona tu nuevo repositorio en local y crea un archivo `.env` en la raíz del proyecto con tus credenciales de Mintlify:

    ```bash .env
    PUBLIC_MINTLIFY_SUBDOMAIN=your-subdomain
    PUBLIC_MINTLIFY_ASSISTANT_KEY=your-assistant-api-key
    ```

    Tu subdominio es el nombre de dominio de tu proyecto. Es la parte de la URL de tu panel que aparece después del nombre de la organización. Por ejemplo, si la URL de tu panel es `https://dashboard.mintlify.com/org-name/domain-name`, tu subdominio es `domain-name`.

    Si tienes un plan Pro o Enterprise, genera una clave de API del asistente en la página [API keys](https://dashboard.mintlify.com/settings/organization/api-keys) de tu panel. La clave de API del asistente empieza por `mint_dsc_`.
  </Step>

  <Step title="Inicia el servidor de desarrollo">
    Instala las dependencias e inicia el servidor de desarrollo local en tu repositorio clonado:

    ```bash
    cd path/to/your-repository
    npm install
    npm run dev
    ```

    Tu sitio ya se estará ejecutando localmente en `http://localhost:4321`.
  </Step>
</Steps>

<div id="how-it-works">
  ## Cómo funciona
</div>

La integración conecta tres partes: el sistema de compilación de Astro, tu contenido en el directorio `docs/` y los paquetes de Mintlify que procesan y renderizan ese contenido.

<div id="astro-configuration">
  ### Configuración de Astro
</div>

Configura la integración `mintlify()` en `astro.config.mjs` con la ruta al directorio de tu documentación:

```javascript astro.config.mjs
import { defineConfig } from 'astro/config';
import react from '@astrojs/react';
import mdx from '@astrojs/mdx';
import { mintlify } from '@mintlify/astro';

export default defineConfig({
  integrations: [mintlify({ docsDir: './docs' }), react(), mdx()],
});
```

En el momento de la compilación, la integración lee tus archivos `docs.json` y MDX desde la ruta `docsDir` y los procesa en `.mintlify/docs/`, donde las colecciones de contenido de Astro los recogen.

<div id="content-structure">
  ### Estructura del contenido
</div>

El contenido de tu documentación se encuentra en el directorio `docs/`, organizado de la misma forma que cualquier otro proyecto de Mintlify:

```text
docs/
├── docs.json          # Navegación y configuración del sitio
├── index.mdx          # Páginas MDX para el contenido
├── quickstart.mdx
└── guides/            # Directorios para organizar páginas
    ├── setup.mdx
    └── troubleshooting.mdx
```

Los archivos MDX usan el [frontmatter](/es/organize/pages#page-metadata) estándar de Mintlify y pueden utilizar componentes de Mintlify sin necesidad de importarlos.

<div id="routing-and-navigation">
  ### Enrutamiento y navegación
</div>

Una ruta comodín renderiza cada página de MDX. El paquete `@mintlify/astro/helpers` proporciona funciones para determinar el estado de navegación a partir de tu `docs.json`.

* `resolvePageData()`: Devuelve las pestañas, la navegación de la barra lateral, los enlaces del pie de página y los anclajes para una ruta de página determinada.
* `unwrapNav()`: Convierte el árbol de navegación en una lista para renderizar la barra lateral.

<div id="layouts-and-styling">
  ### Diseños y estilos
</div>

Controlas por completo la capa de presentación. La plantilla inicial incluye diseños, una barra lateral, una tabla de contenidos y estilos basados en Tailwind CSS, pero puedes reemplazar cualquiera de estos elementos por los tuyos.

Archivos clave para personalizar:

| Archivo                              | Propósito                                         |
| ------------------------------------ | ------------------------------------------------- |
| `src/layouts/Layout.astro`           | Diseño HTML principal                             |
| `src/pages/[...slug].astro`          | Plantilla de página y carga de datos              |
| `src/components/Header.astro`        | Encabezado del sitio                              |
| `src/components/Sidebar/`            | Navegación de la barra lateral                    |
| `src/components/TableOfContents.tsx` | Tabla de contenidos de la página                  |
| `src/styles/`                        | Estilos globales, tipografía y esquema de colores |

<div id="connect-search-and-assistant">
  ## Conecta la Búsqueda y el asistente
</div>

<Note>
  El asistente está disponible en los [planes Pro y Enterprise](https://mintlify.com/pricing).
</Note>

La plantilla inicial incluye componentes de Búsqueda y asistente que se conectan a las API de Mintlify mediante las variables de entorno que configuras durante la instalación.

* **Búsqueda**: El componente `SearchBar` en `src/components/SearchBar.tsx` consulta la API de búsqueda de Mintlify.
* **Assistant**: El componente `Assistant` en `src/components/Assistant/` ofrece una interfaz de chat con IA que responde preguntas con el contenido de tu documentación.

Ambos requieren las variables de entorno `PUBLIC_MINTLIFY_SUBDOMAIN` y `PUBLIC_MINTLIFY_ASSISTANT_KEY`.

<div id="next-steps">
  ## Próximos pasos
</div>

Después de configurar tu proyecto:

1. Reemplaza el contenido inicial de `docs/` por tus propios archivos MDX y la configuración de `docs.json`.
2. Personaliza los diseños y estilos para que se ajusten a tu sistema de diseño.
3. Despliega tu sitio de Astro en el proveedor de alojamiento que prefieras.
