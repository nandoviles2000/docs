Agrega lo siguiente a tu archivo `docs.json` para enviar analítica a Hightouch.

<Info>
  No incluyas `https://` en `apiHost`.
</Info>

<CodeGroup>
  ```json Opciones de analítica en docs.json
  "integrations": {
      "hightouch": {
          "writeKey": "required"
          "apiHost": "optional"
      }
  }
  ```

  ```json Ejemplo
  "integrations": {
      "hightouch": {
          "writeKey": "9132c81do371p76sr11da0075469b54f77649c9a067dp0303p56q0q64n072336"
          "apiHost": "us-east-1.hightouch-events.com" # opcional; el valor predeterminado es `us-east-1.hightouch-events.com`
      }
  }
  ```
</CodeGroup>
