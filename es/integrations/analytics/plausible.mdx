---
title: "Plausible"
description: "Integra Plausible Analytics con tu documentación de Mintlify para obtener un seguimiento ligero de visitantes que respeta la privacidad, sin cookies ni banners de consentimiento."
keywords: ["Plausible Analytics", "analítica respetuosa con la privacidad", "analítica autohospedada", "configuración del dominio"]
---

Agrega el dominio de tu sitio a `docs.json` para enviar analítica a Plausible.

<Info>
  No incluyas `https://` en el dominio ni en el servidor.
</Info>

<CodeGroup>
  ```json Opciones de analítica en docs.json
  "integrations": {
      "plausible": {
          "domain": "obligatorio: el dominio de tu documentación",
          "server": "opcional: la URL de tu servidor autohospedado de Plausible"
      }
  }
  ```

  ```json Ejemplo
  "integrations": {
      "plausible": {
          "domain": "docs.domain.com"
      }
  }
  ```
</CodeGroup>
