Agrega lo siguiente a tu archivo `docs.json` para enviar analítica a PostHog.

Solo necesitas incluir `apiHost` si alojas PostHog por tu cuenta. De forma predeterminada, enviamos eventos a `https://app.posthog.com`.

<CodeGroup>
  ```json Opciones de analítica en docs.json
  "integrations": {
      "posthog": {
          "apiKey": "YOUR_POSTHOG_PROJECT_API_KEY",
          "apiHost": "optional",
          "sessionRecording": true
      }
  }
  ```

  ```json Ejemplo
  "integrations": {
      "posthog": {
          "apiKey": "phc_TXdpocbYTeZVm5VJmMzHTMrCofBQu3e0kN7HGMNGTVW"
      }
  }
  ```
</CodeGroup>

<div id="configuration-options">
  ### Opciones de configuración
</div>

<ParamField path="apiKey" type="string" required>
  Tu clave de API del proyecto de PostHog. Debe comenzar por `phc_`.
</ParamField>

<ParamField path="apiHost" type="string">
  La URL de tu instancia de PostHog. Solo es necesaria si alojas PostHog por tu cuenta. El valor predeterminado es `https://app.posthog.com`.
</ParamField>

<ParamField path="sessionRecording" type="boolean" default="true">
  Activa o desactiva la grabación de sesiones. Establece `false` para desactivar las grabaciones de sesiones y mantener la analítica habilitada.
</ParamField>

<div id="session-recordings">
  ## Grabaciones de sesiones
</div>

Las grabaciones de sesiones están habilitadas de forma predeterminada cuando configuras PostHog. Para deshabilitarlas sin dejar de mantener habilitada la analítica, establece `sessionRecording` en `false` en tu configuración.

```json Disable session recordings
"integrations": {
    "posthog": {
        "apiKey": "phc_your-key",
        "sessionRecording": false
    }
}
```

Debes añadir la URL de tu sitio de documentación a &quot;Authorized domains for recordings&quot; de PostHog antes de poder recibir grabaciones de sesiones. La opción para añadir tu URL se encuentra en la configuración del proyecto de PostHog.
