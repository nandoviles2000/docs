description: "Integra Pirsch con tu documentación de Mintlify para obtener analítica compatible con el RGPD y sin cookies, que rastrea las vistas de página sin recopilar datos personales."
keywords: ["analítica de Pirsch", "analítica centrada en la privacidad", "código de identificación", "compatible con el RGPD"]
---

Agrega lo siguiente a tu archivo `docs.json` para enviar datos de analítica a Pirsch.

Puedes obtener el ID de tu sitio en Settings &gt; Developer &gt; Identification Code.

<CodeGroup>
  ```json Opciones de analítica en docs.json
  "integrations": {
      "pirsch": {
          "id": "required"
      }
  }
  ```

  ```json Ejemplo
  "integrations": {
      "pirsch": {
          "id": "8Kw7OKxBfswOjnKGZa7P9Day8JmVYwTp"
      }
  }
  ```
</CodeGroup>
