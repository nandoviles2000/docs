Debes generar una nueva propiedad de <Tooltip tip="Google Analytics 4">GA4</Tooltip> para usarla con Mintlify. Los datos recopilados se incorporan al mismo proyecto que tus otros datos de Google Analytics.

Si usas la versión anterior de Google Analytics, Universal Analytics, igualmente puedes generar una propiedad de <Tooltip tip="Google Analytics 4">GA4</Tooltip>. Los datos de <Tooltip tip="Google Analytics 4">GA4</Tooltip> son ligeramente distintos de los de UA, pero se siguen recopilando en el mismo proyecto.

<div id="connect-ga4-to-mintlify">
  ## Conecta GA4 con Mintlify
</div>

<div id="create-a-web-stream">
  ### Crear un flujo web
</div>

Debes crear un flujo web para obtener el ID de medición que luego añadirás en Mintlify.

Haz clic en el icono de engranaje en la esquina inferior izquierda de la pantalla de Google Analytics. Después, haz clic en Flujos de datos.

<Frame>![Captura de pantalla de la página Flujos de datos en el panel de Google Analytics.](/images/ga4-web-streams.png)</Frame>

Crea un flujo web e introduce la URL de tu sitio de documentación de Mintlify como URL del flujo.

Tu ID de medición tiene este formato: `G-XXXXXXX` y aparece en Detalles del flujo justo después de crear el flujo web.

<div id="put-measurement-id-in-docsjson">
  ### Incluye el ID de medición en docs.json
</div>

Añade tu ID de medición al archivo `docs.json` de esta forma:

```json docs.json
"integrations": {
    "ga4": {
        "measurementId": "G-XXXXXXX"
    }
}
```

<div id="wait">
  ### Espera
</div>

Google Analytics tarda de dos a tres días en mostrar tus datos.

Puedes usar [Google Analytics Debugger](https://chrome.google.com/webstore/detail/google-analytics-debugger/jnkmfdileelhofjcijamephohjechhna?hl=en) para comprobar la configuración de tu analítica. La extensión registra información en la consola de tu navegador cada vez que GA4 hace una solicitud.

<Note>
  Los enlaces de vista previa tienen la analítica desactivada.
</Note>
