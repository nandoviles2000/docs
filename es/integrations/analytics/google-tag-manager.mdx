---
title: "Google Tag Manager"
description: "Integra Google Tag Manager con tu documentación de Mintlify para gestionar de forma centralizada etiquetas de analítica, seguimiento de conversiones y eventos de marketing."
keywords: ["integración de GTM", "gestión de etiquetas", "ID de etiqueta", "consentimiento de cookies"]
---

Agrega tu ID de etiqueta al archivo `docs.json` y añadiremos el script de Google Tag Manager a todas tus páginas.

Si lo necesitas, eres responsable de configurar los banners de consentimiento de cookies con Google Tag Manager.

<CodeGroup>
  ```json Opciones de analítica en docs.json
  "integrations": {
      "gtm": {
          "tagId": "required"
      }
  }
  ```

  ```json Ejemplo
  "integrations": {
      "gtm": {
          "tagId": "GTM-MGBL4PW"
      }
  }
  ```
</CodeGroup>
