<div id="cookie-consent-and-disabling-telemetry">
  ## Consentimiento de cookies y desactivación de la telemetría
</div>

Si necesitas comprobar si un usuario ya ha aceptado las cookies para cumplir con el RGPD, puedes especificar una clave y un valor en el almacenamiento local en `cookies`:

```json
  "integrations": {
    "cookies": {
      "key": "LOCAL STORAGE KEY",
      "value": "LOCAL STORAGE VALUE"
    }
  }
```

Si se establecen estos valores, tu sitio consulta el almacenamiento local para la clave y el valor especificados a fin de determinar si un usuario dio su consentimiento para las cookies. Si un usuario no ha dado su consentimiento para las cookies, tu sitio desactiva la telemetría para ese usuario.

Si quieres desactivar la telemetría para todos los usuarios, agrega lo siguiente a tu archivo `docs.json`:

```json
  "integrations": {
    "telemetry": {
      "enabled": false
    }
  }
```

<Note>
  Si desactivas la telemetría, no podrás recopilar comentarios en tus páginas de documentación, aunque habilites los comentarios en tu panel.
</Note>
