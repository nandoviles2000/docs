Puedes integrar directamente fragmentos de código autogenerados de los SDK de Speakeasy en la referencia de API de Mintlify. Los fragmentos de uso del SDK aparecen en el [entorno de pruebas interactivo](/es/api-playground/overview) de los sitios de documentación creados con Mintlify.

<Frame>
  ![Un entorno de pruebas de API de Mintlify con fragmentos de código de Speakeasy.](/images/speakeasy/mintlify-with-speakeasy-openapi.png)
</Frame>

<div id="prerequisites">
  ## Requisitos previos
</div>

Para integrar Mintlify con Speakeasy, necesitarás lo siguiente:

* Un [repositorio de documentación de Mintlify](/es/quickstart).
  * Un SDK generado por Speakeasy con una [URL automatizada para ejemplos de código](https://www.speakeasy.com/docs/code-samples/automated-code-sample-urls) configurada.

<div id="setting-up-the-integration">
  ## Configuración de la integración
</div>

Para integrar Speakeasy con Mintlify, debes obtener del registro la URL pública de la especificación combinada de la API y actualizar tu archivo de configuración `docs.json`.

<div id="get-the-apis-combined-spec-public-url-from-the-registry">
  ### Obtén la URL pública de la especificación combinada de la API desde el registro
</div>

Ve a tu [panel de Speakeasy](https://app.speakeasy.com) y abre la pestaña **API Registry**. Abre la entrada `*-with-code-samples` correspondiente a la API.

<Frame>
  ![Captura de pantalla de la página API Registry de Speakeasy. La pestaña API Registry está resaltada con un recuadro rojo y el número 1, y la entrada de la API está resaltada con un recuadro rojo y el número 2.](/images/speakeasy/openapi-registry-and-combined-spec.png)
</Frame>

<Note>
  Si la entrada no aparece como **Combined Spec**, asegúrate de que la API tenga configurada una [URL automática para ejemplos de código](https://www.speakeasy.com/docs/code-samples/automated-code-sample-urls).
</Note>

En la página de la entrada del registro, copia la URL pública proporcionada.

<Frame>
  ![Captura de pantalla que muestra la entrada del registro de la especificación combinada, con la opción para copiar la URL resaltada con un recuadro rojo.](/images/speakeasy/copy-combined-spec-url.png)
</Frame>

<div id="update-your-docsjson-configuration-file">
  ### Actualiza el archivo de configuración `docs.json`
</div>

Añade la URL de la especificación combinada a una sección de **Anchors** o **Tabs** en tu archivo `docs.json`.

Añade la URL de la especificación combinada a un ancla actualizando el campo `anchor` de tu archivo `docs.json` de la siguiente manera:

```json docs.json
{
  "anchors": [
    {
      "name": "API Reference",
      // !mark
      "openapi": "SPEAKEASY_COMBINED_SPEC_URL",
      "url": "api-reference",
      "icon": "square-terminal"
    }
  ]
}
```

Agrega la URL de la especificación combinada a una pestaña; para ello, actualiza el campo `tab` en el archivo `docs.json` de la siguiente manera:

```json docs.json
{
  "tabs": [
    {
      "name": "API Reference",
      "url": "api-reference",
      // !mark
      "openapi": "SPEAKEASY_COMBINED_SPEC_URL"
    }
  ]
}
```

Ahora puedes ver fragmentos de código generados por Speakeasy en la documentación de tu API e interactuar con ellos en el entorno de pruebas.
