Mintlify gestiona automáticamente muchas prácticas recomendadas de SEO, entre ellas:

* Generación de metaetiquetas
* Generación del sitemap y del archivo `robots.txt`
* Estructura HTML semántica
* Optimización para dispositivos móviles

Puedes personalizar por completo las metaetiquetas de tu sitio añadiendo el campo `metatags` a tu `docs.json` o al frontmatter de una página.

<div id="automatically-generated-meta-tags">
  ## Metaetiquetas generadas automáticamente
</div>

Mintlify genera las siguientes metaetiquetas para cada página. Puedes reemplazarlas especificándolas en tu `docs.json` o en el frontmatter de una página.

**Metadatos básicos:**

* `charset: utf-8` - Codificación de caracteres
* `og:type: website` - Tipo de Open Graph
* `og:site_name` - Nombre de tu sitio de documentación
* `twitter:card: summary_large_image` - Tipo de tarjeta de Twitter

**Metadatos específicos de la página:**

* `title` - Título de la página, con el formato &quot;Título de la página - Nombre del sitio&quot;
* `og:title` - Título de Open Graph; de forma predeterminada, usa el título de la página
* `twitter:title` - Título de Twitter; si no está definido, usa `og:title` y, después, el título de la página
* `description` - Descripción de la página
* `og:description` - Descripción de Open Graph; si no está definida, usa la descripción de la página
* `twitter:description` - Descripción de Twitter; si no está definida, usa `og:description` y, después, la descripción de la página

**URL y canónica:**

* `canonical` - Se genera automáticamente a partir de la URL de la página
* `og:url` - Se establece con la URL canónica

**SEO e indexación:**

* `robots` - Se genera a partir de los metadatos de la página
* `noindex` - Se genera a partir de los metadatos de la página
* `keywords` - Se genera a partir de los metadatos de la página

**Imágenes:**

* `og:image` - Imagen de Open Graph; `og:image:width` se establece en 1200 y `og:image:height` en 630
* `twitter:image` - Imagen de Twitter; `twitter:image:width` se establece en 1200 y `twitter:image:height` en 630

**Metadatos del navegador y la aplicación:**

* `applicationName` - Nombre de tu sitio de documentación
* `generator: Mintlify` - Identifica a Mintlify como el generador del sitio
* `apple-mobile-web-app-title` - Nombre de la app en la pantalla de inicio de iOS
* `msapplication-TileColor` - Color del mosaico de Windows
* Favicons e iconos de tu configuración
* Enlace de referencia al sitemap

Cualquier metaetiqueta de la configuración `seo.metatags` de tu `docs.json` también se inyecta automáticamente en cada página, como `google-site-verification` para la validación en Search Console.

<div id="og-images">
  ## Imágenes OG
</div>

Mintlify genera automáticamente una imagen de Open Graph (OG) para cada página. Esta imagen aparece como vista previa en redes sociales cuando compartes un enlace en plataformas de redes sociales y aplicaciones de mensajería.

Propiedades predeterminadas de la imagen OG:

* Ancho: 1200px
* Alto: 630px
* El logotipo de tu sitio del campo `logo` de `docs.json`
* El título de la página del `title` del frontmatter de la página
* La descripción de la página del `description` del frontmatter de la página
* El color principal de tu sitio del campo `colors` de `docs.json`

<div id="custom-og-images">
  ### Imágenes OG personalizadas
</div>

Hay tres formas de personalizar las imágenes OG, según el nivel de control que necesites.

**Imagen de fondo personalizada**

Para usar una imagen de fondo personalizada y mantener la superposición automática con el logotipo, el título y la descripción, configura `thumbnails.background` en tu `docs.json`.

```json Example docs.json
"thumbnails": {
  "background": "/images/og-background.png"
}
```

Consulta [`thumbnails`](/es/organize/settings-appearance#thumbnails) para obtener la lista completa de opciones de personalización.

**Imagen OG estática para todas las páginas**

Para sustituir por completo la imagen generada automáticamente por una sola imagen estática en todas las páginas, configura `og:image` en tus metadatos globales.

```json Example docs.json
"seo": {
  "metatags": {
    "og:image": "https://example.com/og-image.png"
  }
}
```

**Imagen OG estática para una página específica**

Para anular la imagen OG de una sola página, establece `og:image` en el frontmatter de esa página.

```yaml Example frontmatter
---
title: "Your page title"
description: "Your page description"
"og:image": "https://example.com/custom-og.png"
---
```

<Note>
  Configurar `og:image` en las metaetiquetas, ya sea de forma global o por página, sustituye la vista previa para redes sociales generada automáticamente por una imagen estática. Si quieres que Mintlify superponga automáticamente tu logotipo, el título y la descripción de la página sobre un fondo personalizado, usa [`thumbnails.background`](/es/organize/settings-appearance#param-thumbnails-background) en su lugar.
</Note>

<div id="global-meta-tags">
  ## Metaetiquetas globales
</div>

Para establecer metaetiquetas predeterminadas para todas las páginas, agrega el campo `metatags` a tu `docs.json`.

```json
"seo": {
    "metatags": {
        "og:image": "link to your default meta tag image"
    }
}
```

<div id="set-a-canonical-url">
  ### Establece una URL canónica
</div>

Si usas un dominio personalizado, configura la metaetiqueta `canonical` para asegurarte de que los motores de búsqueda indexen el dominio que prefieres. Una URL canónica indica a los motores de búsqueda qué versión de tu documentación es la principal. Esto mejora el SEO cuando tu documentación está disponible en varias URL y evita problemas de contenido duplicado.

```json
"seo": {
    "metatags": {
        "canonical": "https://www.your-custom-domain-here.com"
    }
}
```

<Note>
  Verifica siempre el comportamiento de la URL canónica en tu sitio desplegado. Las compilaciones locales añaden `/src/_props` a las URL como un artefacto, pero no forma parte de la URL canónica.
</Note>

<div id="page-specific-meta-tags">
  ## Metaetiquetas específicas de la página
</div>

Para configurar metaetiquetas específicas de una página, agrégalas al frontmatter de la página.

Las metaetiquetas específicas de la página incluyen:

* `title` - Título de la página
* `description` - La descripción de la página aparece debajo del título y en algunos resultados de motores de búsqueda
* `keywords` - Palabras clave separadas por comas
* `og:title` - Título de Open Graph para compartir en redes sociales
* `og:description` - Descripción de Open Graph; usa `description` como valor predeterminado
* `og:image` - URL de la imagen de Open Graph
* `og:url` - URL de Open Graph
* `og:type` - Tipo de Open Graph, como &quot;article&quot; o &quot;website&quot;
* `og:image:width` - Ancho de la imagen de Open Graph
* `og:image:height` - Altura de la imagen de Open Graph
* `twitter:title` - Título de la tarjeta de Twitter; usa `og:title` como valor predeterminado y luego `title`
* `twitter:description` - Descripción de la tarjeta de Twitter; usa `og:description` como valor predeterminado y luego `description`
* `twitter:image` - Imagen de la tarjeta de Twitter
* `twitter:card` - Tipo de tarjeta de Twitter, como `summary` o `summary_large_image`
* `twitter:site` - Identificador del sitio en Twitter
* `twitter:image:width` - Ancho de la imagen de Twitter
* `twitter:image:height` - Altura de la imagen de Twitter
* `noindex` - Establécelo en `true` para evitar que los motores de búsqueda la indexen
* `robots` - Valor de la metaetiqueta robots

<Tip>
  Las metaetiquetas de Twitter heredan automáticamente de sus equivalentes de Open Graph. Por ejemplo, si configuras `og:title` pero no `twitter:title`, la tarjeta de Twitter usa el valor de `og:title`. Configura `twitter:title` o `twitter:description` explícitamente solo si quieres que el texto en Twitter sea diferente del de otras plataformas.
</Tip>

```mdx
---
title: "Your example page title"
description: "Page-specific description"
"og:title": "Social media title"
"og:description": "Custom description for social sharing"
"og:image": "link to your meta tag image"
"twitter:title": "Twitter-specific title"
keywords: ["keyword1", "keyword2"]
---
```

<Note>
  Debes poner entre comillas las metaetiquetas que incluyen dos puntos. Por ejemplo, `og:title: "Social media title"`.

  Debes dar formato al campo `keywords` como un array de YAML. Por ejemplo, `keywords: ["keyword1", "keyword2", "keyword3"]`.
</Note>

<div id="sitemaps-and-robotstxt-files">
  ## Archivos sitemap y robots.txt
</div>

Mintlify genera automáticamente un archivo `sitemap.xml` y un archivo `robots.txt`. Puedes ver tu sitemap añadiendo `/sitemap.xml` a la URL de tu sitio de documentación.

De forma predeterminada, Mintlify indexa solo las páginas que incluyes en la navegación de tu `docs.json`. Excluye de lo siguiente las [páginas ocultas](/es/organize/hidden-pages) que existen en tu repositorio pero no aparecen en la navegación:

* Sitemaps para motores de búsqueda
  * Búsqueda interna de la documentación
  * contexto del [asistente de IA](/es/assistant/index)
  * resultados de búsqueda del [MCP server](/es/ai/model-context-protocol)

Para incluir páginas ocultas en la indexación de búsqueda, agrega `seo.indexing` a tu `docs.json`:

```json
"seo": {
    "indexing": "all"
}
```

<Note>
  En los sitios de documentación que requieren autenticación, también debes autenticarte para acceder a los sitemaps y a los archivos `robots.txt`. Los sitemaps excluyen las páginas que pertenecen a [grupos de usuarios](/es/deploy/authentication-setup#control-access-with-groups).
</Note>

<div id="custom-sitemaps-and-robotstxt-files">
  ### Sitemaps y archivos robots.txt personalizados
</div>

Para añadir un archivo `sitemap.xml` o `robots.txt` personalizado, crea un archivo `sitemap.xml` o `robots.txt` en la raíz de tu proyecto. Al añadir un archivo personalizado, se reemplaza el archivo generado automáticamente con el mismo nombre. Si eliminas un archivo personalizado, vuelve a aplicarse automáticamente el archivo predeterminado.

<Tip>
  Si tu archivo `robots.txt` personalizado bloquea agentes de usuario de IA como `GPTBot`, `ClaudeBot` o `PerplexityBot`, las herramientas de IA no podrán rastrear tu documentación ni citarla en sus respuestas. Consulta [Permitir agentes de IA en robots.txt](/es/guides/geo#allow-ai-agents-in-robotstxt) para obtener más información.
</Tip>

<div id="disable-indexing">
  ## Desactivar la indexación
</div>

Para evitar que los motores de búsqueda indexen una página, agrega `noindex: true` al [frontmatter](/es/organize/pages) de la página.

```yaml
---
noindex: true
---
```

<Tip>
  Las páginas con `hidden: true` en su frontmatter se tratan automáticamente como `noindex: true`. Consulta [Páginas ocultas](/es/organize/hidden-pages) para más información.
</Tip>

También puedes especificar `noindex` para todas las páginas de tu documentación configurando el campo `metatags.robots` con el valor `"noindex"` en tu `docs.json`:

```json
"seo": {
    "metatags": {
      "robots": "noindex"
    }
  }
```

<div id="seo-best-practices">
  ## Prácticas recomendadas de SEO
</div>

<AccordionGroup>
  <Accordion title="Escribe títulos y descripciones claras">
    * Usa títulos de página claros y descriptivos (50-60 caracteres)
    * Escribe descripciones atractivas (150-160 caracteres)
    * Incluye palabras clave relevantes
    * Haz que el título y la descripción de cada página sean únicos
  </Accordion>

  <Accordion title="Optimiza la estructura de tu contenido">
    * Usa una jerarquía correcta de encabezados (H1 → H2 → H3)
    * Escribe primero para las personas y después para los motores de búsqueda
    * Incluye palabras clave relevantes en los encabezados y en el contenido
    * Mantén las URL cortas, descriptivas y organizadas jerárquicamente
    * Divide el contenido extenso con subtítulos y listas
  </Accordion>

  <Accordion title="Estrategia de enlaces internos">
    * Enlaza páginas relacionadas dentro de tu documentación
    * Usa texto de anclaje descriptivo en lugar de &quot;haz clic aquí&quot;
    * Crea grupos temáticos enlazando conceptos relacionados
    * Usa las funciones automáticas de referencias cruzadas
  </Accordion>

  <Accordion title="SEO de imágenes">
    * Usa nombres de archivo descriptivos para las imágenes
    * Incluye siempre texto alternativo por accesibilidad y SEO
    * Optimiza el tamaño de los archivos de imagen para que carguen más rápido
    * Usa imágenes relevantes que refuercen tu contenido
  </Accordion>
</AccordionGroup>
