El archivo `docs.json` es el archivo de configuración principal de tu sitio de documentación de Mintlify. Controla la configuración global del sitio, incluida la identidad visual, la estructura de navegación, las integraciones, la configuración de la API y mucho más. Es, en esencia, el plano de tu sitio.

<div id="required-fields">
  ## Campos obligatorios
</div>

Debes definir cuatro campos para configurar un sitio funcional.

| Campo            | Descripción                                          |
| ---------------- | ---------------------------------------------------- |
| `name`           | El nombre de tu proyecto u organización              |
| `theme`          | El [tema](/es/customize/themes) de tu sitio             |
| `colors.primary` | El color principal de tu marca en código hexadecimal |
| `navigation`     | La estructura de tu contenido                        |

Todos los demás campos son opcionales. Agrégalos a medida que personalizas y perfeccionas tu sitio.

<div id="minimal-configuration">
  ## Configuración mínima
</div>

Para disfrutar de la mejor experiencia de edición, incluye la referencia `$schema` al principio de tu `docs.json`. Esto habilita el autocompletado, la validación y la documentación en línea en la mayoría de los editores.

```json docs.json
{
  "$schema": "https://mintlify.com/docs.json",
  "theme": "mint",
  "name": "Your project name",
  "colors": {
    "primary": "#ff0000"
  },
  "navigation": {
    "groups": [
      {
        "group": "Home",
        "pages": ["index"]
      }
    ]
  }
}
```

<div id="split-configuration-with-ref">
  ## Divide la configuración con `$ref`
</div>

A medida que tu configuración crece, puedes dividir `docs.json` en archivos más pequeños mediante referencias `$ref`. Cada referencia apunta a un archivo JSON independiente que se resuelve durante la compilación.

Agrega una propiedad `$ref` con una ruta de archivo relativa en cualquier parte de tu `docs.json`. Mintlify reemplaza el objeto `$ref` por el contenido del archivo referenciado.

```json docs.json
{
  "$schema": "https://mintlify.com/docs.json",
  "theme": "mint",
  "name": "Acme Docs",
  "colors": {
    "primary": "#1a73e8"
  },
  "navigation": {
    "$ref": "./config/navigation.json"
  }
}
```

```json config/navigation.json
{
  "groups": [
    {
      "group": "Get started",
      "pages": ["index", "quickstart"]
    },
    {
      "group": "Guides",
      "pages": ["guides/first-steps", "guides/advanced"]
    }
  ]
}
```

* Los archivos referenciados pueden contener sus propias referencias `$ref`. Las rutas anidadas se resuelven en relación con el archivo que las contiene, no con `docs.json`.
* Las referencias deben apuntar a archivos JSON válidos.
* Las rutas deben ser relativas y mantenerse dentro de la raíz del proyecto. No se permite la navegación de rutas (por ejemplo, `../../outside`).
* Las referencias circulares provocan un error de compilación.

<div id="merging-sibling-keys">
  ### Fusión de claves del mismo nivel
</div>

Si un `$ref` se resuelve como un objeto, Mintlify fusiona las claves del mismo nivel del mismo bloque sobre el contenido referenciado, lo que permite que esas claves tengan prioridad sobre las claves coincidentes de la referencia. Si un `$ref` se resuelve como un valor que no es un objeto, como un array, Mintlify ignora las claves del mismo nivel.

```json docs.json
{
  "appearance": {
    "$ref": "./config/appearance.json",
    "strict": true
  }
}
```

<div id="upgrading-from-mintjson">
  ## Migrar desde `mint.json`
</div>

Si tu proyecto usa el archivo `mint.json`, que está obsoleto, usa la [CLI](/es/cli) para migrar a `docs.json`.

<Steps>
  <Step title="Instala o actualiza la CLI">
    Si aún no has instalado la [CLI](/es/cli/install), hazlo ahora:

    <CodeGroup>
      ```bash npm
      npm i -g mint
      ```

      ```bash yarn
      yarn global add mint
      ```

      ```bash pnpm
      pnpm add -g mint
      ```
    </CodeGroup>

    Si ya tienes la CLI instalada, asegúrate de que esté actualizada:

    ```bash
    mint update
    ```
  </Step>

  <Step title="Crea tu archivo docs.json">
    En tu repositorio de documentación, ejecuta:

    ```bash
    mint dev
    ```

    Este comando crea un archivo `docs.json` a partir del `mint.json` existente. Revisa el archivo generado para asegurarte de que toda la configuración sea correcta.
  </Step>

  <Step title="Elimina tu archivo mint.json">
    Después de verificar que `docs.json` esté configurado correctamente, puedes eliminar sin problemas tu antiguo archivo `mint.json`.
  </Step>
</Steps>
