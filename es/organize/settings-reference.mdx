<div id="ref">
  ### `$ref`
</div>

Carga la configuración desde otro archivo JSON. Usa `$ref` en cualquier nivel de tu `docs.json` para dividir la configuración entre varios archivos.

**Tipo:** string: ruta relativa a un archivo `.json`

* Cuando `$ref` se resuelve como un objeto, Mintlify fusiona las claves del mismo nivel del mismo bloque sobre el contenido referenciado, lo que permite que esas claves tengan prioridad sobre las claves coincidentes de la referencia.
* Cuando `$ref` se resuelve como un valor que no es un objeto, como un array, Mintlify ignora cualquier clave del mismo nivel.
* Los archivos referenciados pueden contener sus propias entradas de `$ref`, que se resuelven de forma relativa a ese archivo.
* Las rutas deben permanecer dentro de la raíz del proyecto. Las referencias circulares provocan un error de compilación.

Consulta [Dividir la configuración con `$ref`](/es/organize/settings#split-configuration-with-%24ref) para ver ejemplos.

### `theme` - <Badge color="red">obligatorio</Badge>

El tema de diseño de tu sitio.

**Tipo:** string
**Opciones:** `mint`, `maple`, `palm`, `willow`, `linden`, `almond`, `aspen`, `sequoia`, `luma`

Consulta [Themes](/es/customize/themes) para ver vistas previas.

***

### `name` - <Badge color="red">obligatorio</Badge>

El nombre de tu proyecto, organización o producto.

**Tipo:** string

***

### `colors` - <Badge color="red">obligatorio</Badge>

Los colores que se usan en tu documentación.

**Tipo:** object

<div id="colorsprimary">
  #### `colors.primary`
</div>

<Badge color="red">obligatorio</Badge>

El color primario. Por lo general, se usa para destacar en el modo claro.

**Type:** string—código hexadecimal que coincide con `^#([a-fA-F0-9]{6}|[a-fA-F0-9]{3})$`

<div id="colorslight">
  #### `colors.light`
</div>

El color que se usa para resaltar en el modo oscuro.

**Tipo:** string—código hexadecimal que coincide con `^#([a-fA-F0-9]{6}|[a-fA-F0-9]{3})$`

<div id="colorsdark">
  #### `colors.dark`
</div>

El color que se usa para los botones y los estados al pasar el cursor en ambos modos.

**Tipo:** string—código hexadecimal que coincide con `^#([a-fA-F0-9]{6}|[a-fA-F0-9]{3})$`

### `navigation` - <Badge color="red">obligatorio</Badge>

La estructura de navegación de tu contenido.

**Tipo:** object

Consulta [Navegación](/es/organize/navigation) para ver la documentación completa.

<div id="navigationglobal">
  #### `navigation.global`
</div>

Elementos de navegación globales que aparecen en todas las páginas y todos los idiomas.

**Tipo:** objeto

<div id="navigationglobaltabs">
  ##### `navigation.global.tabs`
</div>

Pestañas de navegación de nivel superior.

**Tipo:** matriz de objetos; cada uno con: `tab` (string, required), `icon` (string), `iconType` (string), `hidden` (boolean), `href` (string uri, required)

<div id="navigationglobalanchors">
  ##### `navigation.global.anchors`
</div>

Enlaces de anclaje de la barra lateral.

**Tipo:** matriz de objetos; cada uno con: `anchor` (string, required), `icon` (string), `iconType` (string), `color.light` (string hex), `color.dark` (string hex), `hidden` (boolean), `href` (string uri, required)

<div id="navigationglobaldropdowns">
  ##### `navigation.global.dropdowns`
</div>

Menús desplegables.

**Tipo:** array de objetos; cada uno con: `dropdown` (string, obligatorio), `icon` (string), `iconType` (string), `hidden` (boolean), `href` (string uri, obligatorio)

<div id="navigationgloballanguages">
  ##### `navigation.global.languages`
</div>

Selector de idioma en la Navegación global.

**Tipo:** matriz de objetos; cada uno con: `language` (string, required), `default` (boolean), `hidden` (boolean), `href` (string uri, required)

**Códigos de idioma admitidos:** `ar`, `ca`, `cn`, `cs`, `de`, `en`, `es`, `fr`, `fr-CA`, `he`, `hi`, `hu`, `id`, `it`, `ja`, `jp`, `ko`, `lv`, `nl`, `no`, `pl`, `pt`, `pt-BR`, `ro`, `ru`, `sv`, `tr`, `uk`, `uz`, `vi`, `zh`, `zh-Hans`, `zh-Hant`

<div id="navigationglobalversions">
  ##### `navigation.global.versions`
</div>

Selector de versiones en la navegación global.

**Tipo:** array de objetos; cada uno con: `version` (string, required, min length 1), `default` (boolean), `hidden` (boolean), `href` (string uri, required)

<div id="navigationglobalproducts">
  ##### `navigation.global.products`
</div>

Selector de productos en la navegación global.

**Tipo:** array de objetos; cada uno con: `product` (string, obligatorio), `description` (string), `icon` (string), `iconType` (string)

<div id="navigationlanguages">
  #### `navigation.languages`
</div>

Selector de idioma para sitios en varios idiomas. Cada entrada puede incluir personalizaciones específicas del idioma para `banner`, `footer` y `navbar`.

**Tipo:** matriz de objetos; cada uno con: `language` (string, required), `default` (boolean), `hidden` (boolean), `banner` (object), `footer` (object), `navbar` (object)

**Códigos de idioma compatibles:** `ar`, `ca`, `cn`, `cs`, `de`, `en`, `es`, `fr`, `fr-CA`, `he`, `hi`, `hu`, `id`, `it`, `ja`, `jp`, `ko`, `lv`, `nl`, `no`, `pl`, `pt`, `pt-BR`, `ro`, `ru`, `sv`, `tr`, `uk`, `uz`, `vi`, `zh`, `zh-Hans`, `zh-Hant`

<div id="navigationversions">
  #### `navigation.versions`
</div>

Selector de versiones para sitios con varias versiones.

**Tipo:** array de objetos; cada objeto con: `default` (boolean), `tag` (string)

<div id="navigationtabs">
  #### `navigation.tabs`
</div>

Pestañas de navegación de nivel superior.

**Tipo:** matriz de objetos; consulta `navigation.global.tabs` para ver la estructura.

<div id="navigationanchors">
  #### `navigation.anchors`
</div>

Enlaces de anclaje en la barra lateral.

**Tipo:** array de objetos; consulta `navigation.global.anchors` para ver la estructura.

<div id="navigationdropdowns">
  #### `navigation.dropdowns`
</div>

Menús desplegables.

**Tipo:** matriz de objetos; consulta `navigation.global.dropdowns` para ver la estructura.

<div id="navigationproducts">
  #### `navigation.products`
</div>

Selector de productos.

**Tipo:** array de objetos; consulta `navigation.global.products` para ver la estructura.

<div id="navigationgroups">
  #### `navigation.groups`
</div>

Grupos para organizar el contenido en secciones con etiquetas.

**Tipo:** matriz de objetos

<div id="navigationpages">
  #### `navigation.pages`
</div>

Páginas individuales de tu documentación.

**Tipo:** matriz de cadenas u objetos

<div id="navigationdirectory">
  #### `navigation.directory`
</div>

Disposición del directorio para las páginas raíz en los grupos de navegación. Se hereda de forma recursiva; los elementos descendientes pueden anularla. Consulta [Listados de directorios](/es/organize/navigation#directory-listings).

**Tipo:** `"none"` | `"accordion"` | `"card"` — valor predeterminado `"none"`
