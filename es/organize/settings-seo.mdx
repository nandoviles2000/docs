Usa estas opciones en tu archivo `docs.json` para controlar cómo los motores de búsqueda indexan tu documentación, qué metadatos aparecen en los resultados de búsqueda, cómo funciona la barra de búsqueda y si las páginas muestran la fecha de última modificación.

<div id="settings">
  ## Configuración
</div>

<div id="description">
  ### `description`
</div>

**Type:** `string`

Una descripción de tu sitio de documentación para SEO y su indexación por IA. Aparece en los resultados de los motores de búsqueda, y las herramientas de IA la usan para comprender el propósito de tu sitio.

```json docs.json
"description": "Documentation for Example Co.'s API and developer platform."
```

***

<div id="seo">
  ### `seo`
</div>

**Type:** `object`

Configuración de indexación y metadatos para motores de búsqueda.

<ResponseField name="seo.indexing" type="&#x22;navigable&#x22; | &#x22;all&#x22;">
  Especifica qué páginas deben indexar los motores de búsqueda.

  * `navigable` — Indexa solo las páginas incluidas en la Navegación de tu `docs.json`. Este es el valor predeterminado.
  * `all` — Indexa todas las páginas de tu proyecto, incluidas las que no están en la Navegación.
</ResponseField>

<ResponseField name="seo.metatags" type="object">
  Metaetiquetas personalizadas que se añaden a cada página. Proporciónalas como pares clave-valor, donde cada clave es el nombre de una metaetiqueta y el valor es su contenido.

  Consulta la [referencia de metaetiquetas comunes](/es/optimize/seo#common-meta-tags-reference) para ver las opciones disponibles.

  ```json
  "metatags": {
    "og:site_name": "Example Co. Docs",
    "twitter:card": "summary_large_image"
  }
  ```
</ResponseField>

```json docs.json
"seo": {
  "indexing": "navigable",
  "metatags": {
    "og:site_name": "Example Co. Docs"
  }
}
```

***

<div id="search">
  ### `search`
</div>

**Type:** `object`

Configuración de visualización de la barra de Búsqueda.

<ResponseField name="search.prompt" type="string">
  Texto de marcador de posición que aparece en la barra de Búsqueda cuando está vacía.
</ResponseField>

```json docs.json
"search": {
  "prompt": "Search the docs..."
}
```

***

<div id="metadata">
  ### `metadata`
</div>

**Tipo:** `object`

Configuración de metadatos a nivel de página que se aplica globalmente a todas las páginas.

<ResponseField name="metadata.timestamp" type="boolean">
  Muestra la fecha de la última modificación en todas las páginas. Cuando está habilitado, cada página muestra la fecha en que se modificó por última vez su contenido. El valor predeterminado es `false`.

  Puedes sobrescribir esta configuración en páginas individuales mediante el campo `timestamp` del frontmatter. Consulta [Pages](/es/organize/pages#last-modified-timestamp) para obtener más información.
</ResponseField>

```json docs.json
"metadata": {
  "timestamp": true
}
```

<div id="example">
  ## Ejemplo
</div>

```json docs.json
{
  "description": "Documentation for Example Co.'s API and developer platform.",
  "seo": {
    "indexing": "navigable",
    "metatags": {
      "og:site_name": "Example Co. Docs",
      "twitter:card": "summary_large_image"
    }
  },
  "search": {
    "prompt": "Search the docs..."
  },
  "metadata": {
    "timestamp": true
  }
}
```
