Usa esta configuración en tu archivo `docs.json` para controlar la arquitectura de la información y la experiencia del usuario de tu sitio. Modifica la barra de navegación, el pie de página, los banners, el comportamiento de la navegación, los menús contextuales, las redirecciones y las variables globales de contenido.

<div id="settings">
  ## Configuración
</div>

### `navigation` - <Badge color="red">obligatorio</Badge>

**Tipo:** `object`

La estructura de navegación de tu contenido. Aquí defines la jerarquía completa de páginas de tu sitio con grupos, pestañas, menús desplegables, anclas y más.

Consulta [Navegación](/es/organize/navigation) para ver la documentación completa sobre cómo crear tu estructura de navegación.

<div id="navbar">
  ### `navbar`
</div>

**Type:** `object`

Enlaces y botones que se muestran en la barra de navegación superior.

<ResponseField name="navbar.links" type="array of object">
  Enlaces que se muestran en la barra de navegación.

  <Expandable title="navbar.links">
    <ResponseField name="type" type="&#x22;github&#x22; | &#x22;discord&#x22;">
      Tipo de enlace opcional. Omítelo para usar un enlace de texto estándar. Usa `github` para enlazar a un repositorio de GitHub y mostrar su número de estrellas. Usa `discord` para enlazar a un servidor de Discord y mostrar su número de usuarios en línea.
    </ResponseField>

    <ResponseField name="label" type="string">
      Texto del enlace. Obligatorio cuando no se especifica `type`. Opcional para `github` y `discord`. Si se omite, Mintlify genera el texto a partir de los datos de la API.
    </ResponseField>

    <ResponseField name="href" type="string (uri)" required>
      Destino del enlace. Debe ser una URL externa válida. Para `github`, debe ser la URL de un repositorio de GitHub. Para `discord`, debe ser una URL de invitación de Discord.
    </ResponseField>

    <IconsOptional />
  </Expandable>
</ResponseField>

<ResponseField name="navbar.primary" type="object">
  Botón de llamada a la acción principal de la barra de navegación.

  <Expandable title="navbar.primary">
    <ResponseField name="type" type="&#x22;button&#x22; | &#x22;github&#x22; | &#x22;discord&#x22;" required>
      Estilo del botón. Elige `button` para un botón estándar, `github` para un enlace a un repositorio de GitHub con número de estrellas o `discord` para una invitación de Discord con número de usuarios en línea.
    </ResponseField>

    <ResponseField name="label" type="string">
      Texto del botón. Obligatorio cuando `type` es `button`. Opcional para `github` y `discord`.
    </ResponseField>

    <ResponseField name="href" type="string (uri)" required>
      Destino del botón. Debe ser una URL externa. Para `github`, debe ser la URL de un repositorio de GitHub. Para `discord`, debe ser una URL de invitación de Discord.
    </ResponseField>
  </Expandable>
</ResponseField>

```json docs.json
"navbar": {
  "links": [
    { "type": "github", "href": "https://github.com/your-org/your-repo" },
    { "label": "Community", "href": "https://example.com/community" }
  ],
  "primary": {
    "type": "button",
    "label": "Get started",
    "href": "https://example.com/signup"
  }
}
```

Contenido del pie de página y enlaces a redes sociales.

<ResponseField name="footer.socials" type="object">
  Perfiles de redes sociales que se mostrarán en el pie de página. Cada clave es el nombre de una plataforma y cada valor es la URL de tu perfil.

  Claves válidas: `x`, `website`, `facebook`, `youtube`, `discord`, `slack`, `github`, `linkedin`, `instagram`, `hacker-news`, `medium`, `telegram`, `twitter`, `x-twitter`, `earth-americas`, `bluesky`, `threads`, `reddit`, `podcast`

  <Expandable title="footer.links">

    <ResponseField name="items" type="array of object" required>

      <Expandable title="items">

        <ResponseField name="href" type="string (uri)" required>

  </Expandable>

"footer": {

<div id="banner">
  ### `banner`
</div>

**Tipo:** `object`

Un banner visible en todo el sitio que se muestra en la parte superior de cada página.

<ResponseField name="banner.content" type="string" required>
  El contenido de texto que se muestra en el banner. Admite formato básico de MDX, incluidos enlaces y texto en negrita y cursiva. No se admiten componentes personalizados.

  ```json
  "content": "Acabamos de lanzar algo nuevo. [Más información](https://example.com)"
  ```
</ResponseField>

<ResponseField name="banner.dismissible" type="boolean">
  Indica si se muestra un botón para descartar el banner, de modo que los usuarios puedan cerrarlo. El valor predeterminado es `false`.
</ResponseField>

```json docs.json
"banner": {
  "content": "We just launched something new. [Learn more](https://example.com)",
  "dismissible": true
}
```

</div>

**Tipo:** `object`

Controla cómo interactúan los usuarios con los elementos de navegación.

<ResponseField name="interaction.drilldown" type="boolean">

<div id="contextual">
  ### `contextual`
</div>

**Type:** `object`

El menú contextual ofrece a los usuarios acceso rápido a herramientas de IA y acciones de la página. Aparece en el encabezado de la página o en la barra lateral de la tabla de contenidos.

<Note>
  El menú contextual solo está disponible en los despliegues de vista previa y producción.
</Note>

<ResponseField name="contextual.options" type="array" required>
  Acciones disponibles en el menú contextual. La primera opción del array aparece como acción predeterminada.

  Opciones predefinidas:

  * `"add-mcp"` — Añade tu MCP server a la configuración del usuario
  * `"aistudio"` — Envía la página actual a Google AI Studio
  * `"assistant"` — Abre el asistente de IA con la página actual como contexto
  * `"copy"` — Copia la página actual como Markdown al portapapeles
  * `"chatgpt"` — Envía la página actual a ChatGPT
  * `"claude"` — Envía la página actual a Claude
  * `"cursor"` — Instala tu MCP server alojado en Cursor
  * `"devin"` — Envía la página actual a Devin
  * `"devin-mcp"` — Instala tu MCP server alojado en Devin
  * `"grok"` — Envía la página actual a Grok
  * `"mcp"` — Copia la URL de tu MCP server al portapapeles
  * `"perplexity"` — Envía la página actual a Perplexity
  * `"view"` — Abre la página actual como Markdown en una pestaña nueva
  * `"vscode"` — Instala tu MCP server alojado en VS Code
  * `"windsurf"` — Envía la página actual a Windsurf

  Define opciones personalizadas como objetos:

  <Expandable title="Opción personalizada">
    <ResponseField name="title" type="string" required>
      Título visible de la opción personalizada.
    </ResponseField>

    <ResponseField name="description" type="string" required>
      Texto descriptivo de la opción personalizada.
    </ResponseField>

    <ResponseField name="icon" type="string">
      Icono de la opción personalizada. Admite nombres de bibliotecas de iconos, URL, rutas o código SVG.
    </ResponseField>

    <ResponseField name="href" type="string or object" required>
      Destino del enlace. Puede ser una cadena con una URL o un objeto con `base` y el parámetro opcional `query`.

      Valores de marcador de posición disponibles:

      * `$page` — Contenido de la página actual
      * `$path` — Ruta de la página actual
      * `$mcp` — URL del MCP server
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="contextual.display" type="&#x22;header&#x22; | &#x22;toc&#x22;">
  Dónde mostrar las opciones contextuales. Elige `header` para mostrarlas en el menú contextual de la parte superior de la página, o `toc` para mostrarlas en la barra lateral de la tabla de contenidos. El valor predeterminado es `header`.
</ResponseField>

```json docs.json
"contextual": {
  "options": ["copy", "view", "chatgpt", "claude"],
  "display": "header"
}
```

<div id="redirects">
  ### `redirects`
</div>

**Tipo:** `matriz de objetos`

Redirecciones para páginas movidas, renombradas o eliminadas. Úsalas para conservar los enlaces al reorganizar tu contenido.

<ResponseField name="redirects[].source" type="string" required>
  La ruta desde la que se redirige. Ejemplo: `/old-page`
</ResponseField>

<ResponseField name="redirects[].destination" type="string" required>
  La ruta a la que se redirige. Ejemplo: `/new-page`
</ResponseField>

<ResponseField name="redirects[].permanent" type="boolean">
  Si es `true`, emite una redirección permanente (308). Si es `false`, emite una redirección temporal (307). El valor predeterminado es `true`.
</ResponseField>

```json docs.json
"redirects": [
  {
    "source": "/old-page",
    "destination": "/new-page"
  },
  {
    "source": "/temp-redirect",
    "destination": "/destination",
    "permanent": false
  }
]
```

<div id="variables">
  ### `variables`
</div>

**Tipo:** `object`

Variables globales para usar en toda la documentación. Mintlify reemplaza los marcadores de posición `{{variableName}}` con los valores definidos en el momento de la compilación.

<ResponseField name="variables.[variableName]" type="string">
  Un par clave-valor en el que la clave es el nombre de la variable y el valor es el texto de reemplazo.

  * Los nombres de las variables pueden contener caracteres alfanuméricos y guiones.
  * Debes definir todas las variables a las que se haga referencia en tu contenido; de lo contrario, la compilación fallará.
  * Mintlify sanitiza los valores para evitar ataques XSS.
</ResponseField>

```json docs.json
"variables": {
  "version": "2.0.0",
  "api-url": "https://api.example.com"
}
```

En tu contenido, haz referencia a las variables entre llaves dobles:

```mdx
The current version is {{version}}. Make requests to {{api-url}}.
```

<div id="metadata">
  ### `metadata`
</div>

**Tipo:** `object`

Configuración de metadatos a nivel de página que se aplica globalmente.

<ResponseField name="metadata.timestamp" type="boolean">
  Habilita una fecha de última modificación en todas las páginas. Cuando está habilitada, las páginas muestran la fecha en que se modificó el contenido por última vez. El valor predeterminado es `false`.

  Puedes anular esta configuración en páginas individuales mediante el campo `timestamp` del frontmatter. Consulta [Páginas](/es/organize/pages#last-modified-timestamp) para obtener más información.
</ResponseField>

```json docs.json
"metadata": {
  "timestamp": true
}
```
