Usa el campo `integrations` de `docs.json` para conectar plataformas de analítica de terceros, herramientas de chat y otros servicios a tu sitio de documentación.

<div id="settings">
  ## Configuración
</div>

Configura todas las integraciones como propiedades del objeto `integrations` en tu archivo `docs.json`:

```json docs.json
"integrations": {
  "ga4": {
    "measurementId": "G-XXXXXXXXXX"
  }
}
```

<div id="example">
  ## Ejemplo
</div>

```json docs.json
"integrations": {
  "ga4": {
    "measurementId": "G-XXXXXXXXXX"
  },
  "posthog": {
    "apiKey": "phc_XXXXXXXXXX"
  },
  "intercom": {
    "appId": "abc12345"
  },
  "telemetry": {
    "enabled": true
  }
}
```
