La propiedad [navigation](/es/organize/settings-structure#navigation) de `docs.json` controla la estructura y la jerarquía de la información de tu documentación.

Con una configuración de navegación adecuada, puedes organizar tu contenido para que los usuarios encuentren exactamente lo que buscan.

Elige un patrón de organización principal en el nivel raíz de la navegación. Una vez que hayas elegido ese patrón principal, puedes anidar otros elementos de navegación dentro de él.

<div id="pages">
  ## Páginas
</div>

Las páginas son el componente más básico de la Navegación. Cada página es un archivo MDX de tu repositorio de documentación.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/pages-light.png" alt="Gráfico decorativo de páginas." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/pages-dark.png" alt="Gráfico decorativo de páginas." />

En el objeto `navigation`, `pages` es un array en el que cada entrada debe hacer referencia a la ruta de un [archivo de página](/es/organize/pages).

```json
{
  "navigation": {
    "pages": [
      "settings",
      "pages",
      "navigation",
      "themes",
      "custom-domain"
    ]
  }
}
```

<div id="groups">
  ## Grupos
</div>

Usa grupos para organizar la navegación de la barra lateral en secciones. Puedes anidar grupos dentro de otros, etiquetarlos con etiquetas y personalizarlos con iconos.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/groups-light.png" alt="Gráfico decorativo de grupos." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/groups-dark.png" alt="Gráfico decorativo de grupos." />

En el objeto `navigation`, `groups` es un array en el que cada elemento es un objeto que requiere un campo `group` y un campo `pages`. Los campos `icon`, `tag`, `root` y `expanded` son opcionales.

```json
{
  "navigation": {
    "groups": [
      {
        "group": "Getting started",
        "icon": "play",
        "pages": [
          "quickstart",
          {
            "group": "Editing",
            "expanded": false,
            "icon": "pencil",
            "pages": [
              "installation",
              "editor"
            ]
          }
        ]
      },
      {
        "group": "Writing content",
        "icon": "notebook-text",
        "tag": "NEW",
        "pages": [
          "writing-content/page",
          "writing-content/text"
        ]
      }
    ]
  }
}
```

<div id="root-page">
  ### Página raíz
</div>

Usa la propiedad `root` para definir una página principal para un grupo. Cuando un grupo tiene una página raíz, al hacer clic en el título del grupo en la navegación de la barra lateral se abre la página raíz. Las páginas raíz funcionan tanto para grupos de nivel superior como para grupos anidados.

```json Example group with a root page
{
  "navigation": {
    "groups": [
      {
        "group": "API pages",
        "root": "api-overview",
        "pages": [
          "api-reference/get",
          "api-reference/post",
          "api-reference/delete"
        ]
      }
    ]
  }
}
```

<div id="directory-listings">
  ### Listados de directorio
</div>

Usa la propiedad `directory` para mostrar automáticamente un directorio de páginas y grupos hijos en las páginas raíz de los grupos. Cuando estableces `directory` en cualquier objeto dentro del árbol `navigation` en `docs.json`, los grupos cuya página `root` coincide con ese objeto o se encuentra debajo de él muestran un listado de sus páginas y grupos debajo del contenido de la página.

La propiedad `directory` acepta tres valores:

| Valor         | Comportamiento                                                          |
| :------------ | :---------------------------------------------------------------------- |
| `"none"`      | No muestra ningún listado de directorio. Valor predeterminado.          |
| `"accordion"` | Muestra las páginas hijas en una lista contraíble agrupada por sección. |
| `"card"`      | Muestra las páginas hijas en un diseño horizontal de tarjetas.          |

El valor de `directory` se hereda de forma recursiva en todo el árbol de navegación. Puedes establecerlo en cualquier lugar dentro del objeto de navegación, y todos los grupos descendientes heredarán ese mismo valor. Cualquier descendiente puede anular el valor heredado estableciendo `directory` en un valor distinto.

Puedes establecer `directory` en cualquier parte del objeto de navegación de tu archivo `docs.json`, incluso en pestañas, anclajes, menús desplegables, productos, versiones, idiomas y grupos individuales.

```json
{
  "navigation": {
    "groups": [
      {
        "group": "Help Center",
        "root": "help/index",
        "directory": "accordion",
        "pages": [
          {
            "group": "Getting Started",
            "root": "help/getting-started/index",
            "pages": [
              "help/getting-started/quickstart",
              "help/getting-started/install"
            ]
          },
          {
            "group": "API Reference",
            "root": "help/api/index",
            "directory": "none",
            "pages": [
              "help/api/overview",
              "help/api/endpoints"
            ]
          }
        ]
      }
    ]
  }
}
```

En este ejemplo:

* **Centro de ayuda** usa `"accordion"` y su página raíz muestra un listado del directorio.
* **Primeros pasos** hereda `"accordion"` de su padre y también muestra un listado del directorio.
* **Referencia de API** lo reemplaza por `"none"`, por lo que su página raíz no muestra un listado del directorio.

<Note>
  La propiedad `directory` solo afecta a los grupos que tienen una página `root`. Los grupos sin una página `root` no se ven afectados.
</Note>

<div id="default-expanded-state">
  ### Estado expandido predeterminado
</div>

Usa la propiedad `expanded` para controlar el estado predeterminado de un grupo anidado en la barra lateral de Navegación.

* `expanded: true`: Expande el grupo de forma predeterminada.
* `expanded: false` o se omite: Contrae el grupo de forma predeterminada.

<Note>
  La propiedad `expanded` solo afecta a los grupos anidados: grupos dentro de otros grupos. Los grupos de nivel superior siempre se expanden y no puedes contraerlos.
</Note>

```json
{
  "group": "Getting started",
  "pages": [
    "quickstart",
    {
      "group": "Advanced",
      "expanded": false,
      "pages": ["installation", "configuration"]
    }
  ]
}
```

<div id="tabs">
  ## Pestañas
</div>

Las pestañas crean secciones diferenciadas en tu documentación con rutas URL independientes. También crean una barra de navegación horizontal en la parte superior de la documentación que permite a los usuarios cambiar entre secciones.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/tabs-light.png" alt="Gráfico decorativo de una navegación por pestañas." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/tabs-dark.png" alt="Gráfico decorativo de una navegación por pestañas." />

En el objeto `navigation`, `tabs` es un array en el que cada elemento es un objeto que requiere un campo `tab` y puede incluir otros campos de navegación, como grupos, páginas, iconos o enlaces a páginas externas.

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "API reference",
        "icon": "square-terminal",
        "pages": [
          "api-reference/get",
          "api-reference/post",
          "api-reference/delete"
        ]
      },
      {
        "tab": "SDKs",
        "icon": "code",
        "pages": [
          "sdk/fetch",
          "sdk/create",
          "sdk/delete"
        ]
      },
      {
        "tab": "Blog",
        "icon": "newspaper",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

<div id="menus">
  ### Menús
</div>

Los menús añaden elementos de navegación desplegables a una pestaña. Úsalos para ayudar a los usuarios a ir directamente a páginas específicas dentro de una pestaña.

En el objeto `navigation`, `menu` es un array en el que cada entrada es un objeto que requiere un campo `item` y puede incluir otros campos de navegación, como grupos, páginas, iconos o enlaces a páginas externas.

Los elementos del menú solo pueden contener grupos, páginas y enlaces externos.

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Developer tools",
        "icon": "square-terminal",
        "menu": [
          {
            "item": "API reference",
            "icon": "rocket",
            "groups": [
              {
                "group": "Core endpoints",
                "icon": "square-terminal",
                "pages": [
                  "api-reference/get",
                  "api-reference/post",
                  "api-reference/delete"
                ]
              }
            ]
          },
          {
            "item": "SDKs",
            "icon": "code",
            "description": "SDKs are used to interact with the API.",
            "pages": [
              "sdk/fetch",
              "sdk/create",
              "sdk/delete"
            ]
          }
        ]
      }
    ]
  }
}
```

<div id="anchors">
  ## Anclas
</div>

Las anclas agregan elementos de navegación persistentes en la parte superior de la barra lateral. Usa las anclas para dividir tu contenido en secciones, ofrecer acceso rápido a recursos externos o crear llamadas a la acción destacadas.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/anchors-light.png" alt="Gráfico decorativo de una navegación con anclas." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/anchors-dark.png" alt="Gráfico decorativo de una navegación con anclas." />

En el objeto `navigation`, `anchors` es un array en el que cada elemento es un objeto que requiere un campo `anchor` y puede contener otros campos de navegación, como grupos, páginas, iconos o enlaces a páginas externas.

```json
{
  "navigation": {
    "anchors": [
      {
        "anchor": "Documentation",
        "icon": "book-open",
        "pages": [
          "quickstart",
          "development",
          "navigation"
        ]
      },
      {
        "anchor": "API reference",
        "icon": "square-terminal",
        "pages": [
          "api-reference/get",
          "api-reference/post",
          "api-reference/delete"
        ]
      },
      {
        "anchor": "Blog",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

<div id="global-anchors">
  ### Anclas globales
</div>

Usa anclas globales para los enlaces que deben aparecer en todas las páginas, independientemente de la sección de tu Navegación que esté viendo el usuario. Las anclas globales son especialmente útiles para enlazar a recursos fuera de tu documentación (como un blog, un foro de la comunidad o un portal de soporte) o para ofrecer acceso constante a páginas internas importantes (como un registro de cambios o una página de estado).

Las anclas globales admiten tanto URL externas como rutas relativas a páginas dentro de tu documentación.

```json
{
  "navigation": {
    "global":  {
      "anchors": [
        {
          "anchor": "Changelog",
          "icon": "list",
          "href": "/changelog"
        },
        {
          "anchor": "Blog",
          "icon": "pencil",
          "href": "https://mintlify.com/blog"
        }
      ]
    },
    "tabs": /*...*/
  }
}
```

<div id="openapi">
  ## OpenAPI
</div>

Integra especificaciones OpenAPI directamente en tu estructura de navegación para generar automáticamente la documentación de la API. Crea secciones de API específicas o coloca páginas de endpoints dentro de otros componentes de navegación.

Establece una especificación OpenAPI predeterminada en cualquier nivel de la jerarquía de navegación. Los elementos secundarios heredan la especificación, salvo que definan la suya propia.

<Note>
  Cuando agregas la propiedad `openapi` a un elemento de navegación (como un `anchor`, una pestaña o un grupo) sin especificar ninguna página, Mintlify genera automáticamente páginas para **todos los endpoints** definidos en tu especificación OpenAPI.

  Para controlar qué endpoints aparecen, incluye explícitamente los endpoints que quieras en un array `pages`.
</Note>

Para obtener más información sobre cómo hacer referencia a endpoints de OpenAPI en tu documentación, consulta la [configuración de OpenAPI](/es/api-playground/openapi-setup).

```json
{
  "navigation": {
    "groups": [
      {
        "group": "API reference",
        "openapi": "/path/to/openapi-v1.json",
        "pages": [
          "overview",
          "authentication",
          "GET /users",
          "POST /users",
          {
            "group": "Products",
            "openapi": "/path/to/openapi-v2.json",
            "pages": [
              "GET /products",
              "POST /products"
            ]
          }
        ]
      }
    ]
  }
}
```

<div id="versions">
  ## Versiones
</div>

Divide la Navegación en distintas versiones. Las versiones se pueden seleccionar desde un menú desplegable.

<img className="block dark:hidden pointer-events-none" src="/images/navigation/versions-light.png" alt="Gráfico decorativo de un selector de versiones." />

<img className="hidden dark:block pointer-events-none" src="/images/navigation/versions-dark.png" alt="Gráfico decorativo de un selector de versiones." />

En el objeto `navigation`, `versions` es un array en la que cada entrada es un objeto que requiere un campo `version` y puede incluir cualquier otro campo de navegación.

```json
{
  "navigation": {
    "versions": [
      {
        "version": "1.0.0",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["v1/overview", "v1/quickstart", "v1/development"]
          }
        ]
      },
      {
        "version": "2.0.0",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["v2/overview", "v2/quickstart", "v2/development"]
          }
        ]
      }
    ]
  }
}
```

<div id="default-version">
  ### Versión predeterminada
</div>

Mintlify usa la primera versión del array `versions` como versión predeterminada. Usa el campo `default` para establecer otra versión como predeterminada.

```json
{
  "navigation": {
    "versions": [
      {
        "version": "1.0.0",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["v1/overview", "v1/quickstart"]
          }
        ]
      },
      {
        "version": "2.0.0",
        "default": true,
        "groups": [
          {
            "group": "Getting started",
            "pages": ["v2/overview", "v2/quickstart"]
          }
        ]
      }
    ]
  }
}
```

<div id="version-tags">
  ### Etiquetas de versión
</div>

Agrega una etiqueta de insignia a las entradas de versión en el menú desplegable del selector de versiones mediante el campo opcional `tag`. Usa etiquetas para destacar versiones específicas como &quot;Latest,&quot; &quot;Recommended,&quot; o &quot;Beta.&quot;

```json
{
  "navigation": {
    "versions": [
      {
        "version": "2026_03",
        "tag": "Latest",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["getting-started", "quickstart"]
          }
        ]
      },
      {
        "version": "2025_12",
        "tag": "Recommended",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["2025_12/getting-started", "2025_12/quickstart"]
          }
        ]
      },
      {
        "version": "2025_09",
        "tag": "Deprecated",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["2025_09/getting-started", "2025_09/quickstart"]
          }
        ]
      }
    ]
  }
}
```

<div id="nesting">
  ## Anidación
</div>

Puedes anidar elementos de navegación entre sí para crear jerarquías complejas. Debes tener un elemento de navegación principal en el nivel raíz, como pestañas, grupos o un menú desplegable. Puedes anidar otros tipos de elementos de navegación dentro de tu estructura de navegación principal.

Cada elemento de navegación puede contener un solo tipo de elemento secundario en cada nivel de la jerarquía de navegación. Por ejemplo, una pestaña puede contener anclas que contienen grupos, pero no puede contener tanto anclas como grupos en el mismo nivel.

<div id="breadcrumbs">
  ## Migas de pan
</div>

Las migas de pan muestran la ruta de navegación completa en la parte superior de las páginas. Algunos temas las tienen habilitadas de forma predeterminada y otros no. Puedes controlar si se muestran en tu sitio con la propiedad `styling` de tu `docs.json`.

<CodeGroup>
  ```json Mostrar todas las migas de pan
  "styling": {
    "eyebrows": "breadcrumbs"
  }
  ```

  ```json Mostrar solo la sección padre
  "styling": {
    "eyebrows": "section"
  }
  ```
</CodeGroup>

<div id="interaction-configuration">
  ## Configuración de la interacción
</div>

Controla cómo interactúan los usuarios con los elementos de Navegación mediante la propiedad `interaction` de tu `docs.json`.

<div id="enable-auto-navigation-for-groups">
  ### Habilita la navegación automática para los grupos
</div>

Cuando un usuario expande un grupo de Navegación, algunos temas lo llevan automáticamente a la primera página del grupo. Puedes anular el comportamiento predeterminado del tema con la opción `drilldown`.

* Establece `true` para forzar la navegación automática a la primera página cuando un usuario seleccione un grupo de Navegación.
* Establece `false` para evitar la navegación y solo expandir o contraer el grupo cuando un usuario seleccione un grupo de Navegación.
* Déjalo sin definir para usar el comportamiento predeterminado del tema.

<CodeGroup>
  ```json Forzar la navegación
  "interaction": {
    "drilldown": true  // Forzar la navegación a la primera página cuando un usuario expande un menú desplegable
  }
  ```

  ```json Evitar la navegación
  "interaction": {
    "drilldown": false // No navegar nunca; solo expandir o contraer el grupo
  }
  ```
</CodeGroup>
