title: "Intercom"
description: "将 Intercom 聊天组件集成到你的 Mintlify 文档站点中，以提供实时客户消息、支持和新手引导帮助。"
keywords: ["Intercom 集成", "Intercom 组件", "应用 ID", "应用内消息"]
---

将以下内容添加到你的 `docs.json` 文件中，以添加 [Intercom](https://www.intercom.com) 组件。

<CodeGroup>
  ```json docs.json 中的集成选项
  "integrations": {
        "intercom": {
              "appId": "APP_ID"
        }
  }
  ```

  ```json 示例
  "integrations": {
        "intercom": {
              "appId": "abc123def4"
        }
  }
  ```
</CodeGroup>
