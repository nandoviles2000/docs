使用仓库中的[自定义 JavaScript 文件](/zh/customize/custom-scripts#custom-javascript)，为你的文档添加 [Osano](https://www.osano.com/) Cookie 同意功能。

<div id="setup">
  ## 设置
</div>

在文档仓库中创建一个 `osano.js` 文件，内容如下：

<CodeGroup>
  ```js Format
  var script = document.createElement("script");
  script.src = "OSANO_SCRIPT_URL";
  document.head.appendChild(script);
  ```

  ```js Example
  var script = document.createElement("script");
  script.src = "https://cmp.osano.com/your-tenant-id/your-site-id/osano.js";
  document.head.appendChild(script);
  ```
</CodeGroup>

将 `OSANO_SCRIPT_URL` 替换为你的 Osano 脚本 URL。该 URL 是 Osano 生成的代码片段中的 `src` 值。你的脚本 URL 始终以 `https://cmp.osano.com/` 开头，并以 `/osano.js` 结尾。

<div id="troubleshooting">
  ## 故障排查
</div>

<Accordion title="在 Strict 合规模式下页面无法加载">
  如果你在使用 Osano 的 **Strict** 合规模式时文档页面无法正常加载，需要将 Mintlify 的域名添加到允许列表中，这样图片和其他资源才能正常加载。

  <Steps>
    <Step title="前往 Managed Rules">
      在 Osano 仪表板中，依次进入 **Scripts** → **Managed Rules**。
    </Step>

    <Step title="添加 Mintlify 域名">
      将 `.mintlify.app/` 添加为一条托管规则。

      <Frame>
        <img src="/images/integrations/osano-managed-rule.png" alt="Osano 托管规则" />
      </Frame>

      <Info>
        这样可确保所有由 Mintlify 提供的资源 (包括图片、样式表和其他文档资源) 都被视为必要资源，即使 Osano 阻止了未分类的第三方内容，这些资源也仍然会加载。
      </Info>
    </Step>
  </Steps>
</Accordion>
