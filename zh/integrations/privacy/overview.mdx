<div id="cookie-consent-and-disabling-telemetry">
  ## Cookie 同意和禁用遥测
</div>

如果你需要检查用户是否已同意 Cookie，以满足 GDPR 合规要求，可以在 `cookies` 下指定本地存储的键和值：

```json
  "integrations": {
    "cookies": {
      "key": "LOCAL STORAGE KEY",
      "value": "LOCAL STORAGE VALUE"
    }
  }
```

如果设置了这些值，您的站点会检查本地存储中指定的键和值，以判断用户是否已同意 Cookie。若用户尚未同意 Cookie，您的站点会为该用户禁用遥测。

如果您希望为所有用户禁用遥测，请将以下内容添加到您的 `docs.json` 文件中：

```json
  "integrations": {
    "telemetry": {
      "enabled": false
    }
  }
```

<Note>
  如果您禁用了遥测功能，那么即使已在仪表板中启用反馈，也无法收集文档页面上的反馈。
</Note>
