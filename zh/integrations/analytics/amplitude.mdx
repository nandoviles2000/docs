将以下内容添加到您的 `docs.json` 文件中，即可将分析数据发送到 Amplitude。

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "amplitude": {
          "apiKey": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "amplitude": {
          "apiKey": "76bb138bf3fbf58186XXX00000"
      }
  }
  ```
</CodeGroup>
