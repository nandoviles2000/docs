---
title: "Google Tag Manager"
description: "将 Google Tag Manager 集成到您的 Mintlify 文档中，以集中管理分析标签、转化跟踪和营销事件。"
keywords: ["GTM 集成", "标签管理", "标签 ID", "Cookie 同意"]
---

将您的标签 ID 添加到 `docs.json` 文件中，我们会把 Google Tag Manager 脚本注入到您的所有页面中。

如果您需要 Cookie 同意横幅，则需由您自行通过 Google Tag Manager 进行设置。

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "gtm": {
          "tagId": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "gtm": {
          "tagId": "GTM-MGBL4PW"
      }
  }
  ```
</CodeGroup>
