title: "Segment"
description: "将 Segment 集成到您的 Mintlify 文档中，把分析事件转发到数据仓库、CRM 和营销平台等下游工具。"
keywords: ["Segment 集成", "写入密钥", "事件流", "CDP 集成"]
---

将 Segment 写入密钥添加到您的 `docs.json` 文件中，以便将分析事件发送到 Segment。

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "segment": {
          "key": "required",
      }
  }
  ```

  ```json 示例
  "integrations": {
      "segment": {
          "key": "nqJxiRG15Y6M594P8Sb8ESEciU3VC2"
      }
  }
  ```
</CodeGroup>
