将以下内容添加到您的 `docs.json` 文件中，以将分析数据发送到 Hightouch。

<Info>
  请勿在 `apiHost` 中包含 `https://`。
</Info>

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "hightouch": {
          "writeKey": "required"
          "apiHost": "optional"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "hightouch": {
          "writeKey": "9132c81do371p76sr11da0075469b54f77649c9a067dp0303p56q0q64n072336"
          "apiHost": "us-east-1.hightouch-events.com" # 可选，默认为 `us-east-1.hightouch-events.com`
      }
  }
  ```
</CodeGroup>
