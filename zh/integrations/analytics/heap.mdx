title: "Heap"
description: "将 Heap 分析集成到你的 Mintlify 文档站点中，自动捕获用户交互和事件，以进行行为分析。"
keywords: ["Heap 分析", "自动事件跟踪", "Heap 应用 ID", "用户交互跟踪"]
---

将以下内容添加到你的 `docs.json` 文件中，以便将分析数据发送到 Heap。

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "heap": {
          "appId": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "heap": {
          "appId": "1234567890"
      }
  }
  ```
</CodeGroup>

将 `1234567890` 替换为你的 Heap 应用 ID。你可以在 [Heap 账户设置](https://heapanalytics.com/app/settings) 中找到它。
