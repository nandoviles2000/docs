---
title: "Plausible"
description: "将 Plausible Analytics 集成到你的 Mintlify 文档中，以轻量且尊重隐私的方式跟踪访客，无需使用 Cookie 或征得同意的横幅。"
keywords: ["Plausible Analytics", "注重隐私的分析", "自托管分析", "域名配置"]
---

将站点域名添加到 `docs.json` 中，以便将分析数据发送到 Plausible。

<Info>
  域名或服务器地址中不要包含 `https://`。
</Info>

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "plausible": {
          "domain": "必填 - 你的文档域名",
          "server": "可选 - 你的自托管 Plausible 服务器 URL"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "plausible": {
          "domain": "docs.domain.com"
      }
  }
  ```
</CodeGroup>
