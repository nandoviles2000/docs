将以下内容添加到您的 `docs.json` 文件中，以将分析数据发送到 Clearbit。

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "clearbit": {
          "publicApiKey": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "clearbit": {
          "publicApiKey": "pk_1a1882"
      }
  }
  ```
</CodeGroup>
