keywords: ["Microsoft Clarity", "会话录制", "热力图", "用户会话"]

将以下内容添加到您的 `docs.json` 文件中，以向 Microsoft Clarity 发送分析数据。

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "clarity": {
          "projectId": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "clarity": {
          "projectId": "abc123xyz"
      }
  }
  ```
</CodeGroup>

<div id="get-your-project-id">
  ## 获取您的项目 ID
</div>

1. 创建一个 [Clarity 账户](https://clarity.microsoft.com/projects)。
2. 点击 **Get tracking code**。
3. 从跟踪代码中复制您的项目 ID。
