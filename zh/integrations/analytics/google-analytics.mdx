您需要创建一个新的 <Tooltip tip="Google Analytics 4">GA4</Tooltip> 属性，以便与 Mintlify 一起使用。收集到的数据会进入与您其他 Google Analytics 数据相同的项目中。

如果您使用的是旧版 Google Analytics (Universal Analytics) ，仍然可以创建一个 <Tooltip tip="Google Analytics 4">GA4</Tooltip> 属性。<Tooltip tip="Google Analytics 4">GA4</Tooltip> 数据与 UA 数据略有不同，但仍会收集到同一个项目中。

<div id="connect-ga4-to-mintlify">
  ## 将 GA4 接入 Mintlify
</div>

<div id="create-a-web-stream">
  ### 创建网页数据流
</div>

你需要先创建一个网页数据流，才能获取填入 Mintlify 的 Measurement ID。

点击 Google Analytics 界面左下角的齿轮图标，然后点击“Data Streams”。

<Frame>![Google Analytics 仪表板中 Data Streams 页面的截图。](/images/ga4-web-streams.png)</Frame>

创建一个网页数据流，并将你的 Mintlify 文档站点 URL 填入数据流 URL。

你的 Measurement ID 格式如 `G-XXXXXXX`，创建网页数据流后会立即显示在 Stream Details 下方。

<div id="put-measurement-id-in-docsjson">
  ### 在 docs.json 中填写 Measurement ID
</div>

按如下方式将您的 Measurement ID 添加到 `docs.json` 文件中：

```json docs.json
"integrations": {
    "ga4": {
        "measurementId": "G-XXXXXXX"
    }
}
```

<div id="wait">
  ### 稍候
</div>

Google Analytics 需要两到三天才会显示你的数据。

你可以使用 [Google Analytics Debugger](https://chrome.google.com/webstore/detail/google-analytics-debugger/jnkmfdileelhofjcijamephohjechhna?hl=en) 检查你的分析配置。每次 GA4 发起请求时，该扩展程序都会在浏览器控制台中记录日志。

<Note>
  预览链接不会启用分析。
</Note>
