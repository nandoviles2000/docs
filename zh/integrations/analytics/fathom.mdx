keywords: ["Fathom Analytics", "隐私优先分析", "站点 ID", "简单分析"]

将以下内容添加到你的 `docs.json` 文件中，以便将分析数据发送到 Fathom。

你可以在脚本设置中找到 `siteId`。

<CodeGroup>
  ```json docs.json 中的分析选项
  "integrations": {
      "fathom": {
          "siteId": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "fathom": {
          "siteId": "YSVMSDAY"
      }
  }
  ```
</CodeGroup>
