您可以将 Speakeasy SDK 自动生成的代码片段直接集成到 Mintlify API 参考文档中。SDK 使用代码片段会显示在由 Mintlify 提供支持的文档站点的[交互式 API 操场](/zh/api-playground/overview)中。

<Frame>
  ![带有 Speakeasy 代码片段的 Mintlify API 操场。](/images/speakeasy/mintlify-with-speakeasy-openapi.png)
</Frame>

<div id="prerequisites">
  ## 前提条件
</div>

要将 Mintlify 与 Speakeasy 集成，您需要准备以下内容：

* 一个 [Mintlify 文档仓库](/zh/quickstart)。
  * 由 Speakeasy 生成的 SDK，并已配置[自动生成的代码示例 URL](https://www.speakeasy.com/docs/code-samples/automated-code-sample-urls)。

<div id="setting-up-the-integration">
  ## 设置集成
</div>

要将 Speakeasy 与 Mintlify 集成，您需要从注册表获取该 API 的合并规范公开 URL，并更新 `docs.json` 配置文件。

<div id="get-the-apis-combined-spec-public-url-from-the-registry">
  ### 从注册表获取 API 合并规范的公开 URL
</div>

前往你的 [Speakeasy 仪表板](https://app.speakeasy.com)，打开 **API Registry** 选项卡。打开该 API 的 `*-with-code-samples` 条目。

<Frame>
  ![Speakeasy API Registry 页面截图。红色方框和数字 1 标出了 API Registry 选项卡，红色方框和数字 2 标出了该 API 的条目。](/images/speakeasy/openapi-registry-and-combined-spec.png)
</Frame>

<Note>
  如果该条目未标记为 **Combined Spec**，请确保该 API 已配置[自动代码示例 URL](https://www.speakeasy.com/docs/code-samples/automated-code-sample-urls)。
</Note>

在该注册表条目页面中，复制提供的公开 URL。

<Frame>
  ![显示合并规范注册表条目的截图，其中复制 URL 的功能以红色方框标出。](/images/speakeasy/copy-combined-spec-url.png)
</Frame>

<div id="update-your-docsjson-configuration-file">
  ### 更新 `docs.json` 配置文件
</div>

将合并规范 URL 添加到 `docs.json` 文件中的 **Anchors** 或 **Tabs** 部分。

按如下所示更新 `docs.json` 文件中的 `anchor` 字段，将合并规范 URL 添加到锚点：

```json docs.json
{
  "anchors": [
    {
      "name": "API Reference",
      // !mark
      "openapi": "SPEAKEASY_COMBINED_SPEC_URL",
      "url": "api-reference",
      "icon": "square-terminal"
    }
  ]
}
```

按如下方式更新 `docs.json` 文件中的 `tab` 字段，将合并规范 URL 添加到标签页中：

```json docs.json
{
  "tabs": [
    {
      "name": "API Reference",
      "url": "api-reference",
      // !mark
      "openapi": "SPEAKEASY_COMBINED_SPEC_URL"
    }
  ]
}
```

您现在可以在 API 文档中查看由 Speakeasy 生成的代码片段，并在 playground 中进行交互。
