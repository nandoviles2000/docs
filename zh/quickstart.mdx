完成本指南后，你将拥有一个可供自定义和更新的在线文档站点。

<div id="before-you-begin">
  ## 开始之前
</div>

Mintlify 采用 docs-as-code 的方式管理您的文档。您站点中的每个页面都对应一个文件，该文件存储在您的文档<Tooltip tip="这里存放着您的文档源代码，以及所有文件及其历史记录。网页编辑器会连接到您的文档仓库以访问和修改内容，您也可以在自己常用的 IDE 中本地编辑文件。">仓库</Tooltip>中。

将文档仓库连接到项目后，您可以在本地或通过网页编辑器处理文档，并将任何更改同步到远程仓库。

<Tip>
  正在使用 AI 编码工具？

  复制以下提示词，添加 Mintlify [skill](/zh/ai/skillmd) 和 [MCP server](/zh/ai/model-context-protocol)，这样在更新文档时就能获得更好的效果。
</Tip>

<div id="deploy-your-documentation-site">
  ## 部署您的文档站点
</div>

<Tip>
  如果您的代码或文档已经位于公开的 GitHub 仓库中，请改用[自动生成您的文档站点](https://mintlify.com/explore)。

  将任意公开仓库 URL 中的 `github.com` 替换为 `mintlify.com`：

  ```
  https://mintlify.com/github-org/repo-name
  ```
</Tip>

前往 [mintlify.com/start](https://mintlify.com/start) 并完成引导流程。在此过程中，您需要连接 GitHub 账户，为文档创建或选择一个仓库，并安装 GitHub App 以启用自动部署。

完成引导后，您的文档站点就会部署完成，并可通过您的 `.mintlify.app` URL 访问。

<AccordionGroup>
  <Accordion title="可选：在引导过程中跳过连接 Git 提供方">
    如果您想快速开始，而不连接自己的仓库，可以在引导过程中跳过 Git 提供方连接。Mintlify 会在一个私有组织中为您创建一个私有仓库，并自动配置 GitHub App。

    这样您就可以立即使用网页编辑器。如果您之后想改用自己的仓库，请前往仪表板中的 [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings)，使用 Git 设置向导迁移您的内容。详情请参阅[克隆到您自己的仓库](/zh/deploy/github#clone-to-your-own-repository)。
  </Accordion>
</AccordionGroup>

<div id="make-your-first-change">
  ## 做出第一次更改
</div>

<Tabs>
  <Tab title="CLI">
    <Steps>
      <Step title="安装 CLI">
        CLI 需要 [Node.js](https://nodejs.org/en) v20.17.0 或更高版本。为确保稳定性，请使用 LTS 版本。

        <CodeGroup>
          ```bash npm
          npm i -g mint
          ```

          ```bash pnpm
          pnpm add -g mint
          ```
        </CodeGroup>

        完整说明和故障排查信息，请参阅[安装 CLI](/zh/cli/install)。
      </Step>

      <Step title="克隆仓库">
        如果你还没有在本地克隆仓库，请按照[克隆仓库](/zh/cli/install#clone-your-repository)中的说明操作。
      </Step>

      <Step title="编辑页面">
        在你常用的编辑器中打开 `index.mdx`，并更新 frontmatter 中的描述：

        ```mdx
        ---
        title: "Introduction"
        description: "Your custom description here"
        ---
        ```
      </Step>

      <Step title="本地预览">
        在文档目录中运行以下命令：

        ```bash
        mint dev
        ```

        在 `http://localhost:3000` 查看预览。
      </Step>

      <Step title="推送更改">
        提交并推送更改以触发部署：

        ```bash
        git add .
        git commit -m "Update description"
        git push
        ```

        Mintlify 会自动部署你的更改。你可以在仪表板的 [概览](https://dashboard.mintlify.com/) 页面查看部署状态。
      </Step>
    </Steps>
  </Tab>

  <Tab title="网页编辑器">
    <Steps>
      <Step title="打开网页编辑器">
        在仪表板中前往[网页编辑器](https://dashboard.mintlify.com/editor)。
      </Step>

      <Step title="编辑页面">
        打开 **Introduction** 页面并更新描述。

        <Frame>
          <img src="/images/quickstart/hello-world-light.png" alt="网页编辑器中已打开 Introduction 页面，描述已编辑为 Hello world!。" className="block dark:hidden" />

          <img src="/images/quickstart/hello-world-dark.png" alt="网页编辑器中已打开 Introduction 页面，描述已编辑为 Hello world!。" className="hidden dark:block" />
        </Frame>
      </Step>

      <Step title="发布">
        点击网页编辑器工具栏右上角的 **Publish** 按钮。
      </Step>

      <Step title="查看线上效果">
        在仪表板的 [概览](https://dashboard.mintlify.com/) 页面，你可以查看站点的部署状态。部署完成后，刷新文档站点即可查看已上线的更改。
      </Step>
    </Steps>
  </Tab>
</Tabs>
