<div id="usage">
  ## 用法
</div>

此接口通过唯一标识符获取特定智能体作业的详细信息和状态。你可以使用此接口查看先前创建的智能体作业的进度、状态和结果。

<div id="job-details">
  ## 任务详情
</div>

响应包含以下信息：

* 任务执行状态和完成情况
* 分支信息和拉取请求 (PR) 详情
* 会话元数据和时间戳
