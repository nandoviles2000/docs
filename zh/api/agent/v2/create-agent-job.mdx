description: "创建一个在后台运行的智能体作业，并自动创建包含文档更改的拉取请求（PR）。"
openapi: /zh/admin-openapi.json POST /v2/agent/{projectId}/job
keywords: [ "智能体作业", "创建", "自动化", "自动执行" ]
---

此端点会创建一个在后台运行的智能体作业。该作业会异步运行——请使用 [获取智能体作业](/zh/api/agent/v2/get-agent-job) 端点轮询状态更新。

如果智能体成功编辑了文件，则会自动创建拉取请求 (PR) ，并在作业响应中填入 `prLink` 字段。

<div id="rate-limits">
  ## 速率限制
</div>

* 每个 Mintlify 项目每小时可使用 100 次

<div id="usage">
  ## 用法
</div>

```bash
curl -X POST https://api.mintlify.com/v2/agent/{projectId}/job \
  -H "Authorization: Bearer mint_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Add a quickstart guide for the Python SDK"}'
```
