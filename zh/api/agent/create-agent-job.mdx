<Warning>此端点已弃用。请改用 [v2 创建智能体任务](/zh/api/agent/v2/create-agent-job) 端点。</Warning>

此端点会根据提供的消息和分支信息创建智能体任务。该任务会异步执行，并返回包含执行详情和结果的流式响应。

如果分支不存在，智能体会创建分支。如果文件已成功编辑，系统会在任务结束时自动创建拉取请求 (PR) 。

* 每个 Mintlify 项目每小时最多可使用 100 次
