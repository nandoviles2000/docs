<div id="integration-with-usechat">
  ## 与 `useChat` 集成
</div>

Vercel AI SDK 中的 `useChat` hook 是将助手 API 集成到应用中的推荐方式。

<Steps>
  <Step title="安装 AI SDK v4">
    ```bash
    npm i ai@^4.1.15
    ```
  </Step>

  <Step title="使用该 hook">
    ```tsx
    import { useChat } from 'ai/react';

    function MyComponent({ domain }) {
      const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat({
        api: `https://api.mintlify.com/discovery/v1/assistant/${domain}/message`,
        headers: {
          'Authorization': `Bearer ${process.env.PUBLIC_MINTLIFY_ASSISTANT_KEY}`,
        },
        body: {
          fp: 'anonymous',
          retrievalPageSize: 5,
          context: [
            {
              type: 'code',
              value: 'const example = "code snippet";',
              elementId: 'code-block-1',
            },
          ],
        },
        streamProtocol: 'data',
        sendExtraMessageFields: true,
      });

      return (
        <div>
          {messages.map((message) => (
            <div key={message.id}>
              {message.role === 'user' ? 'User: ' : 'Assistant: '}
              {message.content}
            </div>
          ))}
          <form onSubmit={handleSubmit}>
            <input value={input} onChange={handleInputChange} />
            <button type="submit">Send</button>
          </form>
        </div>
      );
    }
    ```

    **Mintlify 的必需配置：**

    * `streamProtocol: 'data'` - 流式响应必填。
    * `sendExtraMessageFields: true` - 发送消息元数据必填。
    * `body.fp` - 指纹标识符 (使用 `'anonymous'` 或用户标识符) 。
    * `body.retrievalPageSize` - 要使用的搜索结果数量 (推荐值：5) 。

    **可选配置：**

    * `body.context` - 提供给助手的上下文信息数组。每个上下文对象包含：
      * `type` - `'code'` 或 `'textSelection'`。
      * `value` - 代码片段或所选文本内容。
      * `elementId` (可选) - 包含该上下文的 UI 元素标识符。
    * `body.currentPath` - 用户当前查看的页面路径。提供后，助手会利用此上下文给出更相关的回答。最大长度：200 个字符。
  </Step>
</Steps>

更多详情，请参阅 AI SDK 文档中的 [useChat](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat)。

<div id="rate-limits">
  ## 速率限制
</div>

助手 API 的限制如下：

* 每个密钥每月可使用 10,000 次
* 每个 Mintlify 组织每小时可发起 10,000 个请求
* 每个 IP 每天可发起 10,000 个请求
