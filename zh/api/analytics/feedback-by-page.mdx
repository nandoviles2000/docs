<div id="usage">
  ## 用法
</div>

使用此端点可按文档页面路径导出汇总的用户反馈。每条记录都会显示某个页面的反馈总数，并按类型划分。

<div id="filtering">
  ## 筛选
</div>

可按以下条件筛选反馈：

* **日期范围**：使用 `dateFrom` 和 `dateTo` 将结果限定在特定时间范围内
* **来源**：按 `code_snippet`、`contextual` 或 `agent` 反馈类型筛选
* **状态**：按 `pending`、`in_progress`、`resolved` 或 `dismissed` 等状态值筛选
