<div id="usage">
  ## 用法
</div>

通过此端点导出从您的文档中收集的用户反馈。反馈包括页面评分附带的上下文反馈、代码片段反馈以及智能体反馈。

使用响应中返回的 `cursor` 参数对结果进行分页查询。只要 `hasMore` 为 `true`，就继续获取下一页。

<div id="filtering">
  ## 筛选
</div>

可按以下条件筛选反馈：

* **日期范围**：使用 `dateFrom` 和 `dateTo` 将结果限定在特定时间段内
* **来源**：按 `code_snippet`、`contextual` 或 `agent` 反馈类型筛选
* **状态**：按 `pending`、`in_progress`、`resolved` 或 `dismissed` 等状态值筛选

<div id="response-types">
  ## 响应类型
</div>

响应会根据来源包含不同类型的反馈：

* **上下文反馈**：包含 `helpful` 布尔值和可选的 `contact` 电子邮件地址
* **代码片段反馈**：包含 `code`、`filename` 和 `lang` 字段
* **代理反馈**：包含 `comment` (代理的反馈文本) 以及对应页面的 `path`
