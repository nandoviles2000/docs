<div id="usage">
  ## 用法
</div>

使用此端点导出页面浏览分析数据。结果同时包含全站汇总数据和按页面划分的明细数据，并区分真人流量和 AI 流量。

使用基于偏移量的分页方式获取结果。当 `hasMore` 为 true 时，按 `limit` 的值递增 `offset`。

<div id="filtering">
  ## 筛选
</div>

使用 `dateFrom` 和 `dateTo` 参数按日期范围筛选浏览量数据。
