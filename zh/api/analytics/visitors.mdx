<div id="usage">
  ## 用法
</div>

使用此端点导出独立访客分析数据。结果同时包含全站汇总数据和按页面划分的明细，并按人工流量和 AI 流量分别统计。`total` 字段会对人工流量和 AI 流量进行去重汇总。

使用基于偏移量的分页方式获取结果。在 `hasMore` 为 true 时，将 `offset` 增加 `limit`。

<div id="filtering">
  ## 过滤
</div>

使用 `dateFrom` 和 `dateTo` 参数按日期范围过滤访客数据。
