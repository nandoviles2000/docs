<Info>
  智能体仅适用于 [Pro 和 Enterprise 套餐](https://mintlify.com/pricing?ref=agent)。
</Info>

智能体是一款 AI 工具，会根据你的提示为文档创建包含建议变更的拉取请求 (PR) 。当你发送请求时，智能体会：

* **研究**：搜索并阅读你现有的文档、已连接的代码仓库、相关上下文以及网页信息。
* **规划**：为复杂的文档任务创建结构化的任务清单。
* **编写**：按照写作标准和最佳实践生成或更新内容。
* **验证**：运行 Mintlify CLI 检查，确保文档能够正确构建。
* **创建 PR**：创建包含建议变更的拉取请求 (PR) 以供审核。

所有更改都通过拉取请求 (PR) 进行。智能体绝不会直接提交到你的 main 分支。

<div id="what-you-can-do-with-the-agent">
  ## 你可以用智能体做什么
</div>

使用智能体可以：

* 根据你的提示、拉取请求 (PR) 、Linear issue、Slack 讨论串或文件附件编写新内容。
* 针对新功能或 API 变更更新现有文档。
* 处理并纳入 Slack 附件中的图片、图表和其他文件。
* 在文档中搜索并修订代码示例和 API 参考。
* 使用工作流自动化文档维护。
* 回答与你的文档和技术写作相关的问题。
* 处理代码审查反馈，保持文档质量。
* 在 Slack 对话和拉取请求 (PR) 中的知识丢失前，先将其沉淀下来。
* 高效地在多个文件和目录之间定位并协调变更。

<div id="connect-your-github-account">
  ## 连接你的 GitHub 账户
</div>

默认情况下，智能体创建的拉取请求 (PR) 会记在 Mintlify bot 名下。若要将拉取请求 (PR) 记在你名下，请在仪表板的 [我的资料](https://dashboard.mintlify.com/settings/account) 页面连接你的 GitHub 账户。

<div id="connect-repositories-as-context">
  ## 连接仓库作为上下文
</div>

智能体只能访问你通过 Mintlify GitHub App 连接的仓库。你可以在智能体面板的 **Settings** 中，或在 [GitHub App settings](https://github.com/apps/mintlify/installations/new) 中，配置智能体可访问哪些仓库。
