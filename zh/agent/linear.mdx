将你的 Linear 工作区连接到智能体，即可根据 Linear 中的信息更新文档。当你在 Linear 的评论中提及 Mintlify 智能体，或将其分配给某个问题时，智能体会根据该问题整理上下文，并创建一个拉取请求 (PR) ，其中包含对文档的建议修改。

<div id="connect-your-linear-workspace">
  ## 连接你的 Linear 工作区
</div>

1. 前往仪表板中的 [智能体](https://dashboard.mintlify.com/products/agent) 页面。
2. 在“智能体设置”部分中，点击 **Install Linear app**。

<Frame>
  <img src="/images/agent/install-apps-light.png" alt="应用设置部分，其中包含 Slack、Linear 和 Notion 的安装按钮。" className="block dark:hidden" />

  <img src="/images/agent/install-apps-dark.png" alt="应用设置部分，其中包含 Slack、Linear 和 Notion 的安装按钮。" className="hidden dark:block" />
</Frame>

3. 按照 Linear 的提示，在你的工作区中授权 Mintlify 应用。

<div id="use-the-agent-in-linear">
  ## 在 Linear 中使用智能体
</div>

连接完成后，在 Linear 问题中提及 `@mintlify`，或将某个问题分配给 `Mintlify`，即可触发文档更新。智能体会使用该问题的标题、描述和评论线程作为上下文，然后在你的文档仓库中创建一个拉取请求 (PR) 。

在 Linear 中使用智能体可以：

* **根据功能问题更新文档**：当某项功能发布后，在对应问题中提及智能体，让其起草或更新相关文档。
* **处理文档反馈**：为文档改进创建 Linear 问题，并提及智能体进行相应修改。
* **生成发布说明**：在与发布相关的问题中提及智能体，让其根据问题详情起草变更日志条目。
* **修复已报告的问题**：当有人在 Linear 中报告文档问题时，提及智能体即可让其处理。

<div id="best-practices">
  ## 最佳实践
</div>

* **在 问题 中提供上下文**：你在 问题 中提供的上下文越充分，最终生成的拉取请求 (PR) 就越好。
* **审查拉取请求 (PR)&#x20;**：在合并智能体创建的拉取请求 (PR) 之前，务必先审查。
* **在评论中迭代**：在同一个 问题 讨论串中回复，不断完善智能体的输出，方式类似于你在 Slack 中的沟通。
