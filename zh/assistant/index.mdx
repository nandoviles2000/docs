<Info>
  助手适用于 [Pro 和 Enterprise 套餐](https://mintlify.com/pricing?ref=assistant)，且在这些套餐中默认启用。
</Info>

<div id="about-the-assistant">
  ## 关于助手
</div>

助手可通过自然语言查询来回答与您的文档相关的问题。用户可以在您的文档站点上使用助手，因此即使不知道该去哪里查找，也能快速找到答案并顺利使用您的产品。

助手采用具备工具调用能力的 agentic RAG (检索增强生成) 。当用户提问时，助手会：

* **搜索并提取**您文档中的相关内容，以提供准确的答案。
* 在用户提问时，结合其正在查看的页面**构建上下文**。
* **引用来源**并提供可跳转的链接，直接将用户带到所引用的页面。
* 在回答有关您 API 的问题时，**返回详细的 API 信息**，包括 OpenAPI 规范中的方法、参数、请求体和响应 Schema。
* **生成可复制的代码示例**，帮助用户根据您的文档实现解决方案。
* 允许用户添加文本、图片和其他文件作为上下文，从而**支持多模态输入**。

<div id="how-indexing-works">
  ### 索引如何工作
</div>

助手会为你已发布的文档和 API 规范索引，以便准确回答问题。当你发布更改时，助手会立即索引新增、更新或删除的内容。助手不会索引草稿分支或预览部署。

默认情况下，助手不会索引隐藏页面。若要将隐藏页面纳入助手的索引范围，请在 `docs.json` 中设置 `seo.indexing: "all"`。更多信息，请参阅[隐藏页面](/zh/organize/hidden-pages#search-seo-and-ai-indexing)。

<div id="how-the-assistant-handles-unknown-questions">
  ### 助手如何处理无法回答的问题
</div>

助手只会根据您的文档内容回答问题。如果搜索后仍找不到相关信息，它会说明自己没有足够的信息来回答。

您可以[设置转接邮箱](/zh/assistant/configure#set-deflection-email)，这样当助手无法回答用户的问题时，就会向他们提供您的支持邮箱。即使文档未涵盖他们的具体问题，这也能为用户指明下一步的处理方式。

<div id="assistant-insights">
  ## Assistant 洞察
</div>

通过助手洞察了解用户如何与您的文档交互，并发现可改进之处。

[助手页面](https://dashboard.mintlify.com/products/assistant)会显示本月至今的使用趋势。前往[分析](/zh/optimize/analytics#assistant)页面查看更详细的洞察。

<div id="make-content-ai-ingestible">
  ## 让内容易于被 AI 理解
</div>

通过合理组织文档，帮助助手提供准确且相关的回答。清晰的结构和完整的上下文既有助于读者阅读，也有助于 AI 理解内容。

<Card title="结构与组织">
  * 使用语义化标记。
  * 为各个章节编写清晰明确的标题。
  * 建立逻辑清晰的信息层级。
  * 在整个文档中保持格式一致。
  * 在页面 frontmatter 中包含完整的元数据。
  * 将大段文字拆分为更短的段落。
</Card>

<Card title="上下文">
  * 首次引入术语和缩写时，给出明确定义。
  * 为功能和流程提供充分的概念说明。
  * 添加示例和用例。
  * 交叉引用相关主题。
  * 添加[隐藏页面](/zh/organize/hidden-pages)来补充用户无需阅读、但助手可以引用的额外上下文。
</Card>
