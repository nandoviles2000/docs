<div id="feedback-types">
  ## 反馈类型
</div>

<Note>
  上下文反馈和代码片段反馈目前处于测试版阶段。要为你的文档站点启用这些功能，请[联系我们的销售团队](mailto:hahnbee@mintlify.com)。
</Note>

反馈标签页会根据你启用的[反馈附加组件](https://dashboard.mintlify.com/products/addons)显示相应的信息。

<Frame>
  <img className="block dark:hidden" src="/images/analytics/feedback-addons-light.png" alt="Add-ons 页面中的反馈开关。" />

  <img className="hidden dark:block" src="/images/analytics/feedback-addons-dark.png" alt="Add-ons 页面中的反馈开关。" />

* **顶/踩评分**：通过简单的顶/踩投票来衡量用户对页面的整体满意度。
* **编辑建议**：允许用户为你的文档提出修改建议。仅适用于公开的 GitHub 仓库。
* **提出问题**：允许用户直接从你的文档创建 GitHub issue。仅适用于公开的 GitHub 仓库。
* **上下文反馈**：针对页面内容的自由反馈。
* **代码片段反馈**：专门针对代码片段的反馈。
* **智能体反馈**：由访问你的文档的第三方 AI 智能体提交的反馈。

<div id="collect-email-addresses">
  ## 收集电子邮件地址
</div>

启用电子邮件收集后，用户在提交反馈时可选择提供自己的电子邮件地址。

1. 前往仪表板中的 [Add-ons](https://dashboard.mintlify.com/products/addons) 页面。
2. 在反馈设置中启用 **Collect reader emails** 开关。
3. 你也可以添加一则隐私声明，说明团队将如何使用收集到的电子邮件地址。

你可以在[反馈仪表板](https://dashboard.mintlify.com/products/analytics/v2/feedback)中查看随反馈一并提交的电子邮件地址和反馈内容。

<Note>
  如果你在 `docs.json` 文件中禁用了遥测功能，文档页面将无法使用反馈功能。
</Note>

<div id="manage-feedback">
  ## 管理反馈
</div>

对于上下文反馈和代码片段反馈，您可以设置单条反馈的状态，并添加内部备注，以跟踪处理用户反馈的进展。

<div id="change-feedback-status">
  ### 更改反馈状态
</div>

选择某条反馈旁边的状态，将其标记为 **待处理**、**处理中**、**已解决** 或 **已忽略**。

设置反馈状态的最佳实践：

* **待处理**：反馈正在等待审核。
* **处理中**：正在着手处理该反馈。
* **已解决**：反馈已处理完毕。
* **已忽略**：反馈不相关或不准确。

<div id="filter-by-status">
  ### 按状态筛选
</div>

使用 **Filters** 菜单控制要显示哪些反馈。清除某个状态，即可隐藏所有处于该状态的反馈。默认会显示所有类型的反馈。

<div id="filter-by-type">
  ### 按类型筛选
</div>

根据你要分析的信息，选择 **按页面评分**、**详细反馈** 或 **代码片段**。

* **按页面评分**：查看哪些页面收到的正面和负面反馈最多。利用这些量化数据，找出用户认为最有帮助和最没帮助的页面。
* **详细反馈**：查看用户在页面上留下的未处理反馈，以便找出针对特定页面的改进方向。
* **代码片段**：查看用户对代码片段留下的未处理反馈，以便找出针对特定代码块的改进方向。

<div id="add-internal-notes">
  ### 添加内部备注
</div>

点击一条反馈即可添加内部备注。这些备注仅对有权访问你仪表板的人员可见。

你可以使用备注补充协作所需的信息、关联相关的支持或工程工单，或记录任何其他有用信息。

<div id="agent-feedback">
  ## 代理反馈
</div>

<Note>
  代理反馈目前为测试版，后续可能会调整。
</Note>

当第三方 AI 代理获取您的文档时，它们可以针对其发现有误、已过时或难以使用的页面提交结构化反馈。

这些反馈会显示在[反馈仪表板](https://dashboard.mintlify.com/products/analytics/v2/feedback)中，并标有 **代理** 徽章。您可以像处理人工反馈一样管理代理反馈：设置状态、添加内部备注，并筛选反馈。

<div id="how-agent-feedback-works">
  ### 智能体反馈的工作原理
</div>

你必须在仪表板中启用智能体反馈，才能收集这类反馈。

启用后，当智能体通过 Markdown 导出获取页面时，Mintlify 会附加一个 `<AgentInstructions>` 块，其中包含说明以及用于提交反馈的端点。

智能体会将页面路径和反馈内容发送到该端点。反馈会与人工反馈一同显示在仪表板中。

即使你没有将这些说明添加到 Markdown 导出中，反馈端点也始终可通过 `https://your-domain.com/feedback` 以 `POST` 请求的方式使用，因此你也可以提示智能体通过向该端点发送请求来手动提交反馈。

<div id="enable-agent-feedback">
  ### 启用代理反馈
</div>

1. 在仪表板中，前往 [Add-ons](https://dashboard.mintlify.com/products/addons) 页面。
2. 打开 **代理反馈** 开关。

<div id="retrieve-agent-feedback-via-api">
  ### 通过 API 获取代理反馈
</div>

使用[分析反馈端点](/zh/api/analytics/feedback)以编程方式获取代理反馈。按 `source=agent` 筛选，即可仅返回代理反馈。

代理反馈响应包括：

* `comment`：代理提交的反馈文本。
* `path`：该反馈对应页面的路径。

<div id="use-feedback-data">
  ## 利用反馈数据
</div>

查看反馈数据，以便：

* **识别表现良好的内容**：获得正面反馈最多的页面，说明你的文档中哪些内容效果较好。
* **确定改进优先级**：获得负面反馈最多的页面，表明哪些内容可能需要优先关注。
* **采取行动**：根据用户的直接反馈更新文档。
