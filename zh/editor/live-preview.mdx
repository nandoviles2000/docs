title: "实时预览"
description: "使用网页编辑器的并排实时预览和响应式视口选项，让您在编辑时即可实时查看文档站点效果。"
keywords: ["preview"]
---

边编辑，边预览您的文档站点。实时预览会按页面发布后的实际显示效果呈现，并在您修改内容、导航和配置时实时更新。

<div id="open-live-preview">
  ## 打开实时预览
</div>

点击工具栏中的 <Icon icon="play" /> 播放按钮，即可在新标签页中打开实时预览。

<Frame>
  <img src="/images/editor/live-preview-light.png" alt="编辑器工具栏中的实时预览按钮。" className="block dark:hidden" />

  <img src="/images/editor/live-preview-dark.png" alt="编辑器工具栏中的实时预览按钮。" className="hidden dark:block" />
</Frame>

<Note>
  实时预览仅适用于公开文档。如果你的文档需要身份验证，编辑器会显示“实时预览不可用”消息。
</Note>

<div id="live-preview-versus-preview-deployments">
  ## 实时预览与预览部署的对比
</div>

|          | 实时预览    | 预览部署      |
| -------- | ------- | --------- |
| **速度**   | 即时      | 需要构建时间    |
| **访问方式** | 本地 URL  | 可共享的 URL  |
| **使用场景** | 编辑时查看更改 | 与团队共享以供审阅 |
| **可用时长** | 编辑器打开时  | 只要分支存在    |

在你编辑时，使用实时预览即可立即获得反馈。需要与团队共享更改或在不同设备上测试时，请创建预览部署。
