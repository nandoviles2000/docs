<div id="brand-your-site">
  ## 设置站点品牌
</div>

设置站点标识及其在访客面前的呈现方式。

* **Docs title**：文档名称。会显示在浏览器标签页和搜索结果中。
* **Description**：文档的简要说明。用于 SEO 和站点元数据。
* **Favicon**：显示在浏览器标签页中的小图标。可上传 ICO、PNG、GIF 或 JPG 文件。
* **主题**：为文档的整体外观选择一个[主题](/zh/customize/themes)。

<div id="customize-colors-and-appearance">
  ## 自定义颜色和外观
</div>

控制站点的视觉风格和配色方案。

* **主色**：整个站点中用于链接、按钮和高亮元素的主要强调色。
* **浅色模式颜色**：浅色模式下的强调色变体。不同主题的应用方式可能有所不同。
* **深色模式颜色**：深色模式下的强调色变体。不同主题的应用方式可能有所不同。
* **Logo**：你的品牌 Logo。上传 PNG 或 JPG 文件。你可以为浅色模式和深色模式分别设置不同的 Logo。若要使用 SVG Logo，请通过 Git 将文件添加到仓库中，并在 [docs.json](/zh/organize/settings-appearance#logos) 配置中引用其路径。
* **Logo 链接**：用户点击 Logo 后跳转到的位置。通常为你的主页或营销网站。
* **背景颜色**：分别为浅色模式和深色模式设置自定义背景颜色。
* **背景图片**：为站点添加背景图片。上传 PNG、GIF 或 JPG 文件。
* **背景装饰**：为背景图片应用视觉样式。
* **主题切换**：向用户显示或隐藏浅色/深色模式切换器。
* **默认主题**：设置站点默认以浅色模式还是深色模式加载。

<div id="set-custom-fonts">
  ## 设置自定义字体
</div>

用您品牌的字体替换默认字体。

* **默认字体**：所有文本使用的基础字体系列和字重。请提供来源 URL 和格式 (WOFF 或 WOFF2) 。
* **标题字体**：专门用于标题 (h1、h2 等) 的字体系列和字重。可与正文字体分开设置。
* **正文字体**：用于正文文本和段落的字体系列和字重。

对于每种字体，请指定字体系列名称、字重、来源 URL (如 Google Fonts) 和格式。

<div id="configure-header">
  ## 配置页眉
</div>

将导航元素添加到站点顶部。

* **导航栏按钮**：在页眉中添加一个主要行动按钮。设置按钮类型、标签和目标 URL。
* **导航栏链接**：在页眉中添加其他导航链接。每个链接都包含文本和 URL。

<div id="configure-footer">
  ## 配置页脚
</div>

为网站页脚添加链接和社交媒体账号。

* **社交链接**：添加你在 GitHub、X (Twitter) 、LinkedIn、Discord、YouTube、Slack 等平台上的个人主页链接。
* **页脚列**：使用自定义标题和链接分组，将页脚链接整理为多列。

<div id="enhance-content">
  ## 优化内容呈现
</div>

自定义内容在站点上的呈现方式。

* **缩略图背景**：为页面缩略图和社交预览设置自定义背景图片。
* **缩略图外观**：控制缩略图的显示效果。
* **缩略图字体**：为缩略图中的文本设置自定义字体。
* **页面眉标**：在页面标题上方添加小标签。
* **代码块主题**：为代码块选择语法高亮主题。
* **LaTeX 支持**：启用使用 LaTeX 渲染数学公式。

<div id="set-up-ai-chat-and-search">
  ## 设置 AI 聊天与搜索
</div>

自定义搜索体验。

* **搜索占位符**：用户输入前显示在搜索框中的文本。默认值为“搜索或提问...”。

<div id="configure-api-specifications">
  ## 配置 API 规范
</div>

添加 [OpenAPI](/zh/api-playground/openapi-setup) 或 [AsyncAPI](/zh/api-playground/asyncapi-setup) 规范文件，以记录 API 接口。

* **OpenAPI specs**：上传 OpenAPI 规范文件，或输入外部 OpenAPI 文件的 URL。
* **AsyncAPI specs**：上传 AsyncAPI 规范文件，或输入外部 AsyncAPI 文件的 URL。
* **Playground display**：选择显示交互式 API 操场、简易 API 操场，或不显示 API 操场。
* **Proxy server**：启用或禁用 API 请求的代理服务器。

<div id="add-analytics-and-integrations">
  ## 添加分析和集成
</div>

将分析工具和第三方工具接入您的文档站点。

使用以下工具跟踪访客行为：

* **Amplitude, Mixpanel, Heap**：产品分析平台
* **Google Analytics, Google Tag Manager**：网站分析工具
* **PostHog, Plausible, Fathom**：注重隐私的分析工具
* **Segment, Hightouch**：客户数据平台
* **Hotjar, LogRocket**：会话回放和热力图工具
* **Microsoft Clarity**：用户行为分析工具
* **Intercom**：客户沟通工具
* **Clearbit, Koala**：访客身份识别工具

其他集成：

* **Telemetry**：启用或禁用使用情况遥测
* **Cookies**：设置自定义 Cookie 键值对
