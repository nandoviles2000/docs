使用网页编辑器，您可以直接在浏览器中创建、编辑和发布文档。您还可以查看并分享更改预览，使用拖放组件管理站点导航结构，并按团队偏好的工作流发布更新。

<div id="key-features">
  ## 主要功能
</div>

* **可视化与 Markdown 编辑**：在可视化编辑和 Markdown 编辑模式之间切换，以适应你的工作流。
* **实时预览**：无需创建预览部署，即可实时查看更改。
* **可共享的预览链接**：直接在编辑器中为团队创建预览链接。
* **拖放式导航**：无需编辑配置文件，即可通过可视化方式整理站点结构。
* **Git 同步**：所有更改都会自动同步到你的文档仓库。
* **团队协作**：多个团队成员可同时协作，并使用基于分支的工作流。
