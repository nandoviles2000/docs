使用导航侧边栏整理你的文档。你在网页编辑器的导航树中所做的更改会显示在站点的导航侧边栏中，并同步到 `docs.json` 配置文件。

<div id="add-navigation-elements">
  ## 添加导航元素
</div>

要添加新的导航元素，请点击导航树底部的 **Add new**。

<Frame>
  <img src="/images/editor/navigation-light.png" alt="添加新的导航元素。" className="block dark:hidden" />

  <img src="/images/editor/navigation-dark.png" alt="添加新的导航元素。" className="hidden dark:block" />
</Frame>

要在另一个元素内添加嵌套的导航元素，请点击顶层元素名称旁边的 <Icon icon="plus" /> 加号按钮。

创建元素后，你可以通过拖放来调整顺序，或将其嵌套到其他元素中。将鼠标悬停在某个元素上，然后点击齿轮图标来配置其属性；或者右键点击某个元素，以访问更多选项，例如复制、转换为其他元素或删除。

要取消组或其他导航元素中的页面分组，请右键点击相应元素，然后点击 **Ungroup**。该元素中的所有页面都会移到导航的根级别。

<Note>
  某些元素不能嵌套在其他元素中。例如，标签页不能嵌套在组内。网页编辑器会阻止你创建无效的嵌套。
</Note>

<div id="add-existing-files">
  ### 添加现有文件
</div>

添加仓库中尚未显示在导航中的文件。

1. 点击你想将文件添加到的导航元素上的 <Icon icon="plus" /> 加号按钮。
2. 在下拉菜单中点击 **添加现有文件**。

<div id="organize-into-sections">
  ## 按分区组织
</div>

根据文档的范围和受众，选择合适的导航结构。

<div id="when-to-use-pages">
  ### 何时使用页面
</div>

页面用于单个文档文件。页面是导航的核心组成单元——所有内容都承载在页面上。将页面添加到导航中后，它们就会显示在站点侧边栏中。

页面既可以位于根级别，也可以位于组、Tabs、锚点、下拉菜单或菜单中。

未包含在导航中的文件会在已发布的文档中被[隐藏](/zh/organize/hidden-pages)。

<div id="when-to-use-groups">
  ### 何时使用分组
</div>

使用分组可将相关页面整理为可折叠的区块。分组会将相似内容归类在一起，帮助用户更高效地浏览导航，例如将所有与身份验证相关的页面或所有 API 端点参考集中到一组中。

分组可以嵌套在其他分组中，以形成层级结构。分组也可以位于Tabs、锚点、下拉菜单中，或直接位于根级别。

<div id="when-to-use-tabs">
  ### 何时使用Tabs
</div>

使用Tabs可在站点顶部通过横向导航创建彼此独立的顶层版块。当你的内容分为 API 参考、指南和 SDK 等不同区域，且用户需要在它们之间切换时，Tabs尤其适用。

Tabs可包含页面、分组和菜单项。你还可以配置Tabs，添加图标或链接到外部资源。

<div id="when-to-use-anchors">
  ### 何时使用锚点
</div>

使用锚点可在侧边栏顶部创建固定的导航项。当你想将内容分区，或在不切换 Tabs 的情况下快速访问外部资源时，锚点会很有帮助。

锚点可以包含页面和分组，也可以链接到外部 URL。

**全局锚点：**

创建无论用户正在查看哪个部分、都会在所有页面上显示的全局锚点。全局锚点必须链接到外部 URL，适合用于博客、状态页面或支持链接等资源。

<div id="when-to-use-dropdowns">
  ### 何时使用下拉菜单
</div>

使用下拉菜单，可以在侧边栏顶部创建一个可展开的菜单。当你有多个相关部分，用户可能想进一步浏览，但又不需要像Tabs那样始终显示时，下拉菜单就很适合。

下拉菜单可以包含页面和分组，也可以链接到外部 URL。

<div id="when-to-use-menus">
  ### 何时使用菜单
</div>

使用菜单可在 Tab 内添加下拉式导航项。菜单可帮助用户从顶部导航栏直接跳转到特定页面。

菜单可以包含页面和分组。

<div id="when-to-use-products">
  ### 何时使用产品
</div>

当你有多个彼此独立且各自需要单独文档的产品时，请使用产品。产品会创建一个切换菜单，让用户可以在不同产品的文档集之间切换。

每个产品都可以拥有自己的导航结构，包括Tabs、页面和分组。

<div id="when-to-use-versions">
  ### 何时使用版本
</div>

当你需要同时维护多个版本的文档时，请使用版本，例如 API 的 v1.0、v2.0 和 v3.0。版本会生成一个切换菜单，方便用户选择要查看的版本。

每个版本都可以有不同的内容和导航结构。

<div id="when-to-use-languages">
  ### 何时使用语言功能
</div>

当你需要以多种语言提供文档时，请使用语言功能。它会生成一个语言切换菜单，让用户能够以自己偏好的语言查看文档。

每种语言都会保持相同的导航结构，只是内容会翻译为对应语言。

<div id="customize-appearance">
  ## 自定义外观
</div>

**添加图标：**

1. 将鼠标悬停在某个导航项上。
2. 点击齿轮图标。
3. 点击图标字段。

**添加标签：**

1. 将鼠标悬停在某个导航项上。
2. 点击齿轮图标。
3. 点击标签字段。
4. 输入“NEW”或“BETA”等标签，以突出重要项。

**控制可见性：**

隐藏导航元素中的内容，而无需将其从仓库中删除。

1. 右键点击任意项。
2. 点击 **Hide** 标签旁边的开关。
