<div id="navigate-files">
  ## 浏览文件
</div>

在左侧面板的 **导航** 标签页中浏览你的文档页面。

* 点击导航项以展开或折叠。
* 点击页面即可在编辑器中打开。
* 点击搜索图标，或按 <kbd>Cmd</kbd> + <kbd>K</kbd> (macOS) 或 <kbd>Ctrl</kbd> + <kbd>K</kbd> (Windows) 搜索文件和内容。搜索会在文件名和页面内容中查找匹配项。
* 点击工具栏中的隐藏侧边栏按钮，折叠侧边栏，为编辑器腾出更多空间。

<Note>
  导航标签页按页面标题列出页面。文件标签页按页面的文件名和扩展名列出页面。
</Note>

<div id="create-new-pages">
  ## 创建新页面
</div>

1. 在要添加页面的导航项中，点击 <Icon icon="plus" /> 加号按钮。
2. 点击**添加页面**。
3. 输入文件名。编辑器会自动添加 `.mdx` 扩展名。

<div id="edit-content">
  ## 编辑内容
</div>

使用工具栏中的切换按钮，在可视化模式和 Markdown 模式之间切换。切换模式时，网页编辑器会自动保存你的更改。

<Note>
  API 规范文件 (OpenAPI 和 AsyncAPI) 在网页编辑器中为只读。你可以查看其内容，但无法直接编辑。要更新规范文件，请使用你常用的代码编辑器进行修改，并将更改推送到文档仓库。
</Note>

<div id="visual-mode">
  ### 可视化模式
</div>

通过实时预览编辑内容，查看内容发布后的实际效果。编辑器会使用浏览器内置的拼写检查功能，在你输入时高亮标出拼写错误的单词。

* **添加文本**：在编辑器中输入，查看文本发布后的显示效果。
* **设置文本格式**：使用工具栏将文本加粗、设为斜体或应用其他格式。
* **添加组件**：按 <kbd>/</kbd> 打开组件菜单并选择组件。
* **添加图片**：使用 <kbd>/</kbd> 菜单中的图片组件，或输入 <kbd>/image</kbd>。
* **添加视频**：输入 <kbd>/video</kbd> 以上传或选择视频。
* **添加嵌入内容**：输入 <kbd>/youtube</kbd> 或 <kbd>/loom</kbd> 嵌入视频，或输入 <kbd>/embed</kbd> 添加自定义 HTML。详见 [添加媒体](/zh/editor/media)。
* **添加 Mermaid 图表**：输入 <kbd>/mermaid</kbd>，插入带有交互式预览、缩放/平移控件和代码编辑器的 Mermaid 图表。
* **添加代码片段**：输入 <kbd>/snippet</kbd> 以搜索并插入可复用的代码片段。编辑器会自动添加所需的 import 语句。
* **添加数学公式**：输入 <kbd>/inline-math</kbd> 插入行内 LaTeX 公式，或输入 <kbd>/block-math</kbd> 插入居中的块级公式。请先在站点设置中 [启用 LaTeX](/zh/editor/configurations)。
* **添加提示块**：输入 <kbd>/prompt</kbd> 以插入带复制功能的 AI 提示模板。
* **编辑表格**：当光标位于表格内时，使用悬浮工具栏添加或删除行列，或合并单元格。
* **插入表情符号**：输入 <kbd>:</kbd> 后跟关键词以打开表情选择器。使用方向键在网格中移动，并按 <kbd>Enter</kbd> 插入所选表情。选择器会搜索表情名称、标签和短代码。
* **插入链接**：选中文本并按 <kbd>Cmd</kbd> + <kbd>K</kbd>，或将页面从导航树拖入编辑器，以页面标题创建链接。

完整的可用组件列表请参见 [组件](/zh/components)。

<div id="markdown-mode">
  ### Markdown 模式
</div>

编辑 MDX 源代码。

* **直接编辑 MDX**：直接编写 MDX 和 Markdown，以精确控制内容。
* **组件属性**：设置组件属性和配置。
* **Frontmatter**：编辑文件顶部的页面元数据。

有关 MDX 语法的更多信息，请参阅[设置文本格式](/zh/create/text)和[设置代码格式](/zh/create/code)。

  ## 配置页面
</div>

将鼠标悬停在页面上，然后点击齿轮图标。你也可以右键点击文件并选择 **设置**。

<div id="customize-navigation-appearance">
  ### 自定义导航外观
</div>

控制页面在站点导航侧边栏中的显示方式。

* **标题**：设置主标题。它会显示在导航、浏览器标签页和搜索结果中。
* **Slug**：设置页面的 URL 路径。Slug 默认采用相对于仓库根目录的路径，并去掉文件扩展名。例如，`guides/getting-started.mdx` 会变成 `guides/getting-started`。更改 Slug 会重命名并移动文件，使其与新路径一致。
* **侧边栏标题**：当完整标题对于侧边栏来说过长时，在导航中显示较短的文本。
* **图标**：在页面旁添加视觉标识，帮助用户快速识别。
* **外部 URL**：链接到外部站点，而不是某个页面。使用此项可将外部资源添加到导航中。

<div id="optimize-for-search-and-sharing">
  ### 优化搜索与分享效果
</div>

帮助用户找到你的页面，并提升页面在分享时的展示效果。

* **描述**：编写简短摘要。它会显示在搜索结果和 SEO 元标签中。
* **关键词**：添加相关搜索词，帮助用户发现此页面。
* **OG 图片 URL**：为社交媒体分享和链接预览设置自定义预览图。

<div id="control-page-layout">
  ### 控制页面布局
</div>

选择页面的显示方式，以符合你的内容需求。

* **标准布局** (`default`)：默认页面布局，带有侧边栏导航和目录。
* **全宽布局** (`wide`)：隐藏目录，为表格、图表或其他内容提供更宽的展示空间。
* **居中布局** (`center`)：隐藏侧边栏和目录，提高变更日志等文本较多页面的可读性。
* **自定义宽度** (`custom`)：仅保留顶部导航栏的极简布局，适用于落地页或其他特殊布局。

<div id="manage-pages">
  ## 页面管理
</div>

<div id="move-pages">
  ### 移动页面
</div>

拖放页面可在导航中调整顺序，也可在文件树中将文件移动到不同文件夹。

<div id="rename-pages">
  ### 重命名页面
</div>

在文件资源管理器中，右键单击某个文件，然后点击 **Rename**。编辑器会自动保留文件扩展名，因此你只需输入页面名称。

<div id="duplicate-pages">
  ### 复制页面
</div>

右键单击页面，然后选择 **Duplicate**。

<div id="delete-pages">
  ### 删除页面
</div>

右键点击页面，然后选择 **Delete**。删除页面后，它会自动从导航中移除。

<div id="hide-pages">
  ### 隐藏页面
</div>

如果您想将页面从导航中移除而不删除文件，请在页面设置中启用 **Hidden** 开关。被隐藏的页面仍会保留在仓库中，用户仍可通过直接访问该页面的 URL 打开它。您可以在页面设置中取消隐藏，也可以将其添加到 `docs.json` 的导航中。
