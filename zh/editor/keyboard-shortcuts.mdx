使用键盘快捷键可在网页编辑器中更高效地导航和编辑。编辑器支持复制、粘贴、撤销和全选等常用快捷键，以及下方列出的其他快捷键。

<div id="visual-mode">
  ## 可视模式
</div>

在可视模式下编辑时，可使用以下快捷键。

<div id="search-and-navigation">
  ### 搜索与导航
</div>

| 命令          | macOS                         | Windows                        |
| :---------- | :---------------------------- | :----------------------------- |
| **搜索文件和内容** | <kbd>Cmd</kbd> + <kbd>K</kbd> | <kbd>Ctrl</kbd> + <kbd>K</kbd> |

| **代码**  | <kbd>Cmd</kbd> + <kbd>E</kbd>                    | <kbd>Ctrl</kbd> + <kbd>E</kbd>                    |

| **上标**  | <kbd>Cmd</kbd> + <kbd>.</kbd>                    | <kbd>Ctrl</kbd> + <kbd>.</kbd>                    |

<div id="smart-substitutions">
  ### 智能替换
</div>

编辑器会在你输入时自动将某些字符序列转换为排版符号。编辑器会跳过代码块和内联代码中的替换。

| 输入   | 结果 |
| :--- | :- |
| `->` | →  |
| `<-` | ←  |
| `=>` | ⇒  |
| `<=` | ≤  |
| `>=` | ≥  |
| `!=` | ≠  |
