<div id="start-the-local-preview">
  ## 启动本地预览
</div>

进入包含 `docs.json` 文件的文档目录，然后运行：

```bash
mint dev
```

本地预览将在 `http://localhost:3000` 启动。编辑时，更改会实时显示。

默认情况下，预览会自动在浏览器中打开。若要阻止浏览器自动打开，请使用 `--no-open` 标志：

```bash
mint dev --no-open
```

若要在不全局安装 CLI 的情况下生成预览，请运行：

```bash
npx mint dev
```

<div id="log-in-for-search-and-assistant">
  ## 登录后即可使用搜索和Assistant
</div>

您必须使用 Mintlify 账户登录 CLI，才能启用搜索和[Assistant](/zh/assistant/index)。

```bash
mint login
```

使用 `mint login` 命令完成身份验证后，CLI 会将你的凭据存储在 `~/.config/mintlify/config.json` 中，这样你在不同会话中都能保持登录状态。CLI 还会提示你选择一个默认项目，`mint analytics` 等命令会使用该项目。

登录后，运行 `mint dev` 启动本地预览，并启用搜索和Assistant。Assistant使用的索引内容与你已部署的文档站点相同。

要检查身份验证状态，请运行：

```bash
mint status
```

要注销，请运行：

```bash
mint logout
```

<div id="custom-ports">
  ## 自定义端口
</div>

默认情况下，CLI 使用 3000 端口。若要使用其他端口，请添加 `--port` 标志：

```bash
mint dev --port 3333
```

如果该端口已被占用，CLI 会自动尝试使用下一个可用端口。

<div id="skip-openapi-processing">
  ## 跳过 OpenAPI 处理
</div>

如果您有很多 OpenAPI 文件，可以在本地开发时使用 `--disable-openapi` 标志跳过 OpenAPI 处理，以提高性能：

```bash
mint dev --disable-openapi
```

<div id="preview-as-a-specific-group">
  ## 以特定组的身份预览
</div>

如果你使用基于组的访问控制，可使用 `--groups` 标志，以特定身份验证组的身份预览：

```bash
mint dev --groups admin
```

有关组的更多信息，请参阅[身份验证设置](/zh/deploy/authentication-setup#control-access-with-groups)。
