<div id="prerequisites">
  ## 环境要求
</div>

* [Node.js](https://nodejs.org/en) v20.17.0+ (推荐使用 LTS 版本)

<div id="install-the-cli">
  ## 安装 CLI
</div>

<CodeGroup>
  ```bash npm
  npm i -g mint
  ```

  ```bash pnpm
  pnpm add -g mint
  ```
</CodeGroup>

<div id="create-a-new-project">
  ## 创建新项目
</div>

要基于 Mintlify 入门模板创建新的文档项目，请运行以下命令：

```bash
mint new [directory]
```

如果你未指定目录，CLI 会提示你创建新的子目录，或覆盖当前目录。

<Warning>
  覆盖当前目录会删除其中所有现有文件。
</Warning>

| 标志         | 描述                                         |
| ------------ | ------------------------------------------ |
| `--name`     | 项目名称。若未提供，CLI 会提示你输入。                      |
| `--theme`    | 项目[主题](/zh/customize/themes)。若未提供，CLI 会提示你选择。 |
| `--template` | 预定义模板。若未提供，CLI 会提示你选择。                     |
| `--force`    | 不经提示直接覆盖当前目录。                              |

在交互模式下，CLI 会询问你是要选择主题，还是克隆模板。若要跳过该提示，请直接传入 `--template` 标志：

```bash
mint new my-docs --template <template-name>
```

你可以将 `--template` 与 `--theme` 搭配使用，以覆盖模板的默认主题：

```bash
mint new my-docs --template <template-name> --theme <theme>
```

请在 GitHub 上的 [mintlify/templates](https://github.com/mintlify/templates) 仓库中查看可用模板。在交互模式下，CLI 会自动获取并显示可用模板。

在 CI/CD 管道或 AI 编码智能体等非交互式环境中，你必须提供 `--name` 和 `--theme` 标志，或提供 `--template` 标志。

<div id="update">
  ## Update
</div>

如果本地预览与已部署的文档不同步，请将 CLI 更新到最新版本：

```bash
mint update
```

如果你的版本中没有 `mint update`，请重新安装最新版 CLI：

<CodeGroup>
  ```bash npm
  npm i -g mint@latest
  ```

  ```bash pnpm
  pnpm add -g mint@latest
  ```
</CodeGroup>

<div id="troubleshooting">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="错误：无法在 darwin-arm64 运行时中加载“sharp”模块">
    这可能是因为 Node.js 版本过旧。请尝试以下操作：

    1. 卸载当前安装的 mint CLI：`npm uninstall -g mint`
    2. 升级到 Node.js v20.17.0 或更高版本。
    3. 重新安装 mint CLI：`npm install -g mint`
  </Accordion>

  <Accordion title="问题：遇到未知错误">
    **解决方案**：前往设备根目录，删除 `~/.mintlify` 文件夹。然后再次运行 `mint dev`。
  </Accordion>

  <Accordion title="错误：权限被拒绝">
    这是因为你没有全局安装 Node 包所需的权限。

    **解决方案**：尝试运行 `sudo npm i -g mint`。出现提示后，输入你用于解锁电脑的密码。
  </Accordion>

  <Accordion title="本地预览与网页上的文档显示不一致">
    这很可能是因为 CLI 版本过旧。

    **解决方案**：运行 `mint update` 以获取最新更新。
  </Accordion>

  <Accordion title="mintlify 与 mint 包">
    如果 CLI 包出现问题，请先运行 `npm ls -g` 查看全局安装了哪些包。如果你不使用 npm，请尝试运行 `which mint` 来定位安装位置。

    如果你同时安装了 `mint` 和 `mintlify` 包，请卸载 `mintlify`：

    ```bash
    npm uninstall -g mintlify
    npm cache clean --force
    npm i -g mint
    ```
  </Accordion>

  <Accordion title="安装后客户端版本显示为“none”">
    如果你运行 `mint version` 后看到客户端版本显示为 `none`，则 CLI 可能因企业防火墙或 VPN 而无法下载客户端应用。

    **解决方案**：请让 IT 管理员将 `releases.mintlify.com` 添加到网络允许列表中。
  </Accordion>
</AccordionGroup>
