<div id="global-flags">
  ## 全局标志
</div>

这些标志可用于所有命令。

| 标志                  | 描述                              |
| ------------------- | ------------------------------- |
| `--telemetry`, `-t` | 启用或禁用匿名使用遥测。                    |
| `--help`, `-h`      | 显示该命令的帮助信息。                     |
| `--version`, `-v`   | 显示 CLI 版本。是 `mint version` 的别名。 |

<div id="mint-dev">
  ## `mint dev`
</div>

启动文档的本地预览。

```bash
mint dev [flags]
```

| 标志                  | 描述                              |
| ------------------- | ------------------------------- |
| `--port`            | 本地预览运行使用的端口。默认为 `3000`。         |
| `--no-open`         | 不自动打开浏览器。                       |
| `--groups`          | 用于预览模拟的用户组列表，以逗号分隔。             |
| `--disable-openapi` | 跳过 OpenAPI 文件处理以提高性能。           |
| `--local-schema`    | 允许使用通过 HTTP 提供的本地托管 OpenAPI 文件。 |

<div id="mint-login">
  ## `mint login`
</div>

使用你的 Mintlify 账户登录。

```bash
mint login
```

打开浏览器窗口以完成身份验证。如果浏览器没有自动打开，CLI 会显示一个需要手动打开的 URL，并提示你粘贴授权码。凭据会保存在 `~/.config/mintlify/config.json` 中。

如果你有多个部署，CLI 会在你登录后提示你选择一个默认部署。你稍后可以使用 `mint config set subdomain <subdomain>` 更改默认项目。

<div id="mint-analytics">
  ## `mint analytics`
</div>

查看文档的分析数据。需要先通过 `mint login` 完成身份验证。

```bash
mint analytics <subcommand> [flags]
```

所有子命令都支持以下通用标志：

| 标志          | Description                                                        |
| ------------- | ------------------------------------------------------------------ |
| `--subdomain` | 文档子域名。默认为通过 `mint config set subdomain` 设置的值，或您账户中的第一个项目。          |
| `--from`      | `YYYY-MM-DD` 格式的开始日期。默认为 7 天前，或通过 `mint config set dateFrom` 设置的值。 |
| `--to`        | `YYYY-MM-DD` 格式的结束日期。默认为今天，或通过 `mint config set dateTo` 设置的值。      |
| `--format`    | 输出格式：`plain` (默认) 、`table`、`json` 或 `graph`。                       |

  ### `mint analytics stats`
</div>


| -------- | ------------ |
| `--page` | 按特定页面路径进行筛选。 |

| 标志        | 描述             |
| --------- | -------------- |
| `--query` | 按搜索查询中的子字符串筛选。 |
| `--page`  | 按点击次数最高的页面筛选。  |

<div id="mint-config">
  ## `mint config`
</div>

管理 CLI 命令的持久化默认值。配置会保存在 `~/.config/mintlify/config.json` 中。

```bash
mint config <subcommand> <key> [value]
```

| 子命令                 | 描述     |
| ------------------- | ------ |
| `set <key> <value>` | 设置配置值。 |
| `get <key>`         | 显示配置值。 |
| `clear <key>`       | 清除配置值。 |

<div id="configuration-keys">
  ### 配置项
</div>

| 键           | 描述                           | 由以下命令使用          |
| ----------- | ---------------------------- | ---------------- |
| `subdomain` | 默认文档子域名。                     | `mint analytics` |
| `dateFrom`  | 分析查询的默认开始日期 (`YYYY-MM-DD`) 。 | `mint analytics` |
| `dateTo`    | 分析查询的默认结束日期 (`YYYY-MM-DD`) 。 | `mint analytics` |

<div id="mint-broken-links">
  ## `mint broken-links`
</div>

检查文档中的失效内部链接。

```bash
mint broken-links [flags]
```

该命令会排除匹配 [.mintignore](/zh/organize/mintignore) 模式的文件。指向已忽略文件的链接会被报告为失效链接。

| 标志                 | 描述                                        |
| ------------------ | ----------------------------------------- |
| `--check-anchors`  | 还会根据标题 slug 验证锚点链接 (例如 `/page#section`) 。 |
| `--check-external` | 还会检查外部 URL 是否为失效链接。                       |
| `--check-snippets` | 还会检查 `<Snippet>` 组件中的链接。                  |

<div id="mint-validate">
  ## `mint validate`
</div>

以严格模式验证文档构建。如有任何警告或错误，将报错并退出。还会自动验证 `docs.json` 中引用的 OpenAPI 规范。

```bash
mint validate [flags]
```

| 标志                | 描述                                            |
| ------------------- | --------------------------------------------- |
| `--groups`          | 用于模拟验证的用户组列表，多个用户组之间以逗号分隔。                    |
| `--disable-openapi` | 跳过 OpenAPI 文件的处理和验证。                          |
| `--local-schema`    | 允许验证通过 HTTP 提供的本地托管 OpenAPI 文件。生产环境仅支持 HTTPS。 |

<Note>
  独立的 `mint openapi-check` 命令已弃用。请改用 `mint validate`。
</Note>

详见 [离线导出](/zh/deploy/export)。

<div id="mint-score">
  ## `mint score`
</div>

对公开文档站点执行智能体就绪检查。需先使用 `mint login` 完成身份验证。

```bash
mint score <url> [flags]
```

| 标志         | 描述                                                      |
| ---------- | ------------------------------------------------------- |
| `--format` | 输出格式：`table` (默认，带颜色) 、`plain` (可通过管道传输的 TSV) 或 `json`。 |

该命令会显示总体就绪度评分，以及各项检查的明细结果，并标明通过/失败。

<div id="checks">
  ### 检查项
</div>

该评分会评估以下方面：

| 检查项                           | 验证内容                                                                                                                 |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `llmsTxtExists`               | 智能体可以访问站点根目录下的 [llms.txt](/zh/ai/llmstxt) 文件。                                                                           |
| `llmsTxtValid`                | `llms.txt` 文件符合预期格式，包含标题、引用块摘要和 Markdown 链接。                                                                         |
| `llmsTxtSize`                 | `llms.txt` 文件大小在阈值范围内，确保智能体读取时不会被截断。                                                                                 |
| `llmsTxtLinksResolve`         | `llms.txt` 中的链接可解析到可访问的页面。                                                                                           |
| `llmsTxtLinksMarkdown`        | `llms.txt` 中的链接使用 Markdown 语法。                                                                                       |
| `llmsTxtDirective`            | `llms.txt` 文件包含使用指令。                                                                                                 |
| `llmsTxtFullExists`           | 提供了 [llms-full.txt](/zh/ai/llmstxt/#llms-full-txt) 文件，供需要完整内容的智能体使用。此项独立于 `llmsTxtExists` 运行。                           |
| `llmsTxtFullSize`             | `llms-full.txt` 文件大小适中，便于智能体处理。                                                                                      |
| `llmsTxtFullValid`            | `llms-full.txt` 文件包含带标题的有效内容。                                                                                        |
| `llmsTxtFullLinksResolve`     | `llms-full.txt` 中的链接可解析到可访问的页面。                                                                                      |
| `skillMd`                     | 智能体可以访问供其工具使用的 [skill.md](https://www.mintlify.com/docs/ai/skillmd) 文件。                                              |
| `contentNegotiationMarkdown`  | 当智能体通过内容协商请求 Markdown 时，站点会返回 Markdown。                                                                              |
| `contentNegotiationPlaintext` | 当智能体通过内容协商请求纯文本时，站点会返回纯文本。                                                                                           |
| `mcpServerDiscoverable`       | 智能体可以发现供基于工具的智能体使用的 [MCP server](/zh/ai/model-context-protocol)。                                                        |
| `mcpToolCount`                | MCP server 至少提供一个工具。                                                                                                 |
| `openApiSpec`                 | 在标准路径下提供可用的 OpenAPI 或 Swagger 规范。                                                                                    |
| `robotsTxtAllowsAI`           | `robots.txt` 文件不会拦截 AI 爬虫。                                                                                           |
| `sitemapExists`               | 提供了可用于发现页面的站点地图。                                                                                                     |
| `structuredData`              | 首页包含 [JSON-LD](https://json-ld.org/) 结构化数据 (`<script type="application/ld+json">`) 。会报告 JSON-LD 块的数量以及发现的 schema 类型。 |
| `responseLatency`             | 站点响应时间处于智能体可接受的范围内。                                                                                                  |

某些检查只有在其依赖的检查通过后才会运行。如果某项检查失败，所有依赖它的检查都不会运行，并会自动判定为失败。例如，`llmsTxtValid` 只有在 `llmsTxtExists` 先通过时才会通过。

总体评分采用加权计分，因此影响更大的检查项会对你的分数产生更大影响。

| `--template` | 预定义模板。若在交互模式下未提供此项，CLI 会提示你输入。                     |
| `--force`    | 不经提示直接覆盖目录。                                        |

<div id="telemetry">
  ## 遥测
</div>

CLI 会收集匿名使用情况遥测数据，以帮助改进 Mintlify。遥测数据包括命令名称、CLI 版本、操作系统和系统架构。Mintlify **不会** 收集可识别个人身份的信息、项目内容或文件路径。

默认情况下，CLI 会收集遥测数据。你可以随时使用 `--telemetry` 标志退出：

```bash
# 禁用遥测
mint --telemetry false

# 重新启用遥测
mint --telemetry true
```

你也可以通过设置以下任一环境变量来禁用遥测：

| 变量                            | 值   | 描述                                                                |
| ----------------------------- | --- | ----------------------------------------------------------------- |
| `MINTLIFY_TELEMETRY_DISABLED` | `1` | 禁用 Mintlify CLI 的遥测。                                              |
| `DO_NOT_TRACK`                | `1` | 使用 [Console Do Not Track](https://consoledonottrack.com/) 标准禁用遥测。 |

该偏好设置会保存在 `~/.config/mintlify/config.json` 中，并在不同的 CLI 会话中持续生效。
