您可以选择我们的迁移服务，将文档迁移到 Mintlify。本指南将介绍迁移流程、交付时间线以及我们的质量保障方式。

<div id="what-to-expect-for-your-migration">
  ## 迁移过程中你可以期待的内容
</div>

迁移是指在某个时间点对你的文档进行一次性转移，这需要冻结代码。我们会迁移你的文档、API 参考页面、品牌元素 (徽标、颜色和字体) 以及导航结构。迁移服务还包括设计或信息架构咨询，以及落地页或自定义集成等自定义组件开发。

你的迁移服务包含一个用于查看进度的预发布链接，并在交付后提供 7 天的反馈期，以处理内容、资源或品牌相关的任何问题。

<div id="migration-process">
  ## 迁移流程
</div>

迁移过程高度协作。我们会与您的团队密切配合，实施适合您需求的定制方案和构建。

<Steps>
  <Step title="提交迁移表单">
    提交[迁移表单](https://mintlify.typeform.com/ent-migrations)。

    请提供您的文档源、品牌资产 (徽标、颜色代码、字体) 、OpenAPI 规范、上线日期，以及首选交付方式 (GitHub PR 或 zip 文件) 。
  </Step>

  <Step title="启动会议">
    我们会审核您提交的信息，并由迁移团队主持启动会议，带您过一遍当前设置，了解相关限制，并解答您团队可能提出的问题。
  </Step>

  <Step title="接收范围评估和交付时间线（1-2 个工作日）">
    我们会审查并分析会议中的相关背景，并在 24-48 小时内提供预计交付时间线。我们还会标出任何需要进一步讨论的自定义组件或迁移部分。
  </Step>

  <Step title="在迁移过程中查看进度">
    我们会开始迁移，并分享一个预发布链接，方便您实时跟踪进度。
  </Step>

  <Step title="接收最终交付">
    我们会根据您的偏好，通过 GitHub PR 或 zip 文件交付迁移成果。
  </Step>

  <Step title="反馈期（七个工作日）">
    您可以提交有关内容、资产或品牌的任何反馈。我们会在同一时间范围内处理所有范围内的问题。
  </Step>

  <Step title="上线支持">
    我们会提供连接代码仓库、设置重定向和配置自定义域名所需的文档与指导。
  </Step>
</Steps>

<div id="quality-assurance">
  ## 质量保证
</div>

我们与经过严格审核的第三方供应商合作，并在交付前进行内部质量审查。以下是我们的检查项：

<Card title="内容完整性" icon="file-check">
  * 您源站中的所有文档均已完成迁移。
  * 内容已使用 Mintlify 组件正确排版。
  * 导航结构符合您的规范。
</Card>

<Card title="视觉元素" icon="palette">
  * 图片和视频均可正确显示。
  * 自定义字体已应用于整个站点。
  * 浅色和深色模式下的 logo 均使用正确。
  * 两种模式下的配色方案均满足对比度要求。
</Card>

<Card title="功能" icon="rocket">
  * 所有链接均可正常访问 (无失效链接) 。
  * 目录可正常渲染。
  * React 组件可按预期运行。
  * 不存在性能问题。
</Card>

<div id="after-your-migration">
  ## 迁移完成后
</div>

我们交付迁移后，您还需要完成以下步骤，才能正式发布文档：

1. [连接您的 GitHub 仓库并完成设置](/zh/quickstart)。
2. [根据需要设置重定向](/zh/create/redirects)。
3. [配置自定义域名](/zh/customize/custom-domain)。
4. **正式上线前请先测试**——在从旧版文档切换之前：
   * 检查预发布链接上的所有页面。
   * 测试导航和搜索功能。
   * 确认所有图片和视频都能正常加载。
   * 检查代码块是否正常渲染。
   * 在移动端和桌面端分别测试。
5. **上线。** 您的文档已可正式发布。

<Note>
  **需要帮助？** 我们的迁移团队可为您提供指导，协助您完成这些步骤。请通过您的专属 Slack 频道或 [support@mintlify.com](mailto:support@mintlify.com) 联系我们。
</Note>

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="迁移通常需要多久？">
    我们通常会在 2–6 周内完成迁移，具体取决于复杂程度。在启动会议后，你会收到明确的交付时间线。
  </Accordion>

  <Accordion title="交付后还可以提出修改吗？">
    可以。交付后，你有 7 天反馈期，可就内容、素材或品牌元素提出修改需求。我们会在同一期限内处理所有范围内的反馈，并持续与你配合，直到你准备好正式上线。
  </Accordion>

  <Accordion title="迁移完成后，我还需要做什么？">
    迁移会完成内容转移，但你还需要：

    * 将你的文档仓库连接到 Mintlify 仪表板。
    * 为旧文档 URL 设置重定向。
    * 配置自定义域名。

    我们会为上述每一步提供详细文档和支持。
  </Accordion>

  <Accordion title="我可以自定义导航结构吗？">
    可以。你可以提供自定义信息架构，我们会帮你完成实施。如有需要且平台支持，我们也可以与你合作开发自定义组件。
  </Accordion>

  <Accordion title="如果我的文档在迁移期间发生变化，会怎么样？">
    由于迁移需要代码冻结，提交后对源文档所做的任何更改都不会包含在本次迁移中。我们建议你在开始迁移前完成所有更新。

    如果无法做到这一点，我们的团队会与你协作，安排短周期冲刺来迁移特定部分，或在第一轮冲刺后预留专门时间，迁移期间产生的增量更改。
  </Accordion>
</AccordionGroup>
