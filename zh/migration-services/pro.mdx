您的 Pro 计划包含迁移服务，可将现有文档迁移到 Mintlify。本指南将介绍迁移流程、交付周期以及我们的质量保障方式。

<div id="what-to-expect-for-your-migration">
  ## 迁移期间你可以预期的内容
</div>

迁移是对你的文档进行的一次性迁移，需要代码冻结。我们会迁移你的文档、品牌元素 (徽标、颜色和字体) 、API 参考页面以及导航结构。

迁移服务包含一个用于查看进度的预发布链接，并在交付后提供 3 天的反馈期，用于处理内容、素材或品牌元素方面的任何问题。

<Info>
  迁移服务**不**包括：

  * 文档的动态同步
  * 设计或信息架构咨询
  * 自定义组件开发 (落地页、自定义集成等) 
  * 重定向设置
  * 分析设置
</Info>

<div id="migration-process">
  ## 迁移流程
</div>

<Steps>
  <Step title="提交迁移表单">
    提交[迁移表单](https://mintlify.typeform.com/pro-migrations)。

    请提供您的文档源文件、品牌素材 (徽标、颜色代码、字体) 、OpenAPI 规范、上线日期以及首选交付方式 (GitHub PR 或 zip 文件) 。
  </Step>

  <Step title="接收范围评估和时间安排（1-2 个工作日）">
    我们会审核您提交的内容，并在 24-48 小时内提供预计交付时间。对于任何自定义组件或迁移过程中需要进一步讨论的部分，我们会明确指出。
  </Step>

  <Step title="在迁移期间查看进度">
    我们会启动迁移，并分享一个预发布链接，方便您实时跟踪进度。
  </Step>

  <Step title="接收最终交付内容">
    我们会根据您的偏好，通过 GitHub PR 或 zip 文件交付迁移成果。
  </Step>

  <Step title="反馈期（三个工作日）">
    如果您对内容、素材或品牌呈现有任何反馈，请在此期间提交。我们会在同一时间范围内处理所有范围内的问题。
  </Step>

  <Step title="上线支持">
    我们会提供连接仓库、设置重定向以及配置自定义域名所需的文档和指导。
  </Step>
</Steps>

<div id="quality-assurance">
  ## 质量保障
</div>

我们与经过审核的第三方供应商合作，并在交付前进行内部质量审核。以下是我们的检查内容：

<Card title="内容完整性" icon="file-check">
  * 你的源内容中的所有文档均已迁移完成。
  * 内容已使用 Mintlify 组件正确排版。
  * 导航结构符合你的规范要求。
</Card>

<Card title="视觉元素" icon="palette">
  * 图片和视频均可正常显示。
  * 自定义字体已在全站正确应用。
  * 浅色和深色模式下的 logo 均已正确使用。
  * 配色方案在两种模式下都符合对比度要求。
</Card>

<Card title="功能" icon="rocket">
  * 所有链接均可正常访问 (无失效链接) 。
  * 目录可正常渲染。
  * React 组件按预期正常运行。
  * 不存在性能问题。
</Card>

<div id="after-your-migration">
  ## 迁移完成后
</div>

在我们交付迁移内容后，您需要完成以下步骤，才能正式上线文档：

1. [连接您的 GitHub 仓库并完成设置](https://www.mintlify.com/docs/quickstart#install-the-github-app)。
2. [根据需要设置重定向](https://www.mintlify.com/docs/create/redirects)。
3. [配置您的自定义域名](https://www.mintlify.com/docs/customize/custom-domain)。
4. **正式上线前先进行测试** —— 在从旧版文档切换之前：
   * 检查预发布链接中的所有页面。
   * 测试导航和搜索。
   * 确认所有图片和视频均可正常加载。
   * 检查代码块是否能正确渲染。
   * 在移动端和桌面端进行测试。
5. **上线。** 您的文档已可正式发布。

<Note>
  **需要帮助？** 我们的支持团队可为您提供指导，协助您完成这些步骤。请通过 [support@mintlify.com](mailto:support@mintlify.com) 联系我们。
</Note>

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="迁移需要多长时间？">
    我们通常会在 10 个工作日内完成迁移，具体时长取决于复杂程度。提交迁移表单后，您会在 24–48 小时内收到具体时间安排。
  </Accordion>

  <Accordion title="交付后可以提出修改吗？">
    可以。交付后，您有 3 天反馈期，可就内容、素材或品牌元素提出修改要求。对于服务范围内的所有反馈，我们都会在同一时限内处理完成。
  </Accordion>

  <Accordion title="迁移完成后我需要做什么？">
    迁移会转移您的内容，但您还需要：

    * 将您的文档仓库连接到 Mintlify 仪表板。
    * 为旧文档 URL 设置重定向。
    * 配置自定义域名。

    我们会为上述每一步提供详细文档和支持。
  </Accordion>

  <Accordion title="我可以自定义导航结构吗？">
    可以。您可以在迁移表单中提供自定义的信息架构，我们会按此实现。不过，自定义组件开发 (如自定义落地页) 不包含在迁移服务内。
  </Accordion>

  <Accordion title="如果我的文档在迁移期间发生变化，会怎样？">
    由于迁移需要代码冻结，提交后对源文档所做的任何更改都不会包含在本次迁移中。我们建议您在开始迁移前完成所有更新。
  </Accordion>
</AccordionGroup>
