---
title: "手动创建 API 页面"
description: "当你需要完全掌控小型 API、原型或自定义文档的页面布局时，可使用 MDX 文件手动创建 API 参考页面。"
keywords: ["API 文档", "端点文档"]
---

你可以在单独的 MDX 页面中手动定义 API 端点。这种方式适用于小型 API 或原型设计。

<div id="setup">
  ## 设置
</div>

<Steps>
  <Step title="配置 API 设置">
    在 `docs.json` 文件中，定义你的基础 URL 和身份验证方式。

    ```json Example docs.json
    "api": {
      "mdx": {
        "server": "https://api.acme.com/",
        "auth": {
          "method": "key",
          "name": "x-api-key"
        }
      }
    }
    ```

    如果你想隐藏 API 操场，请将 `display` 字段设置为 `none`。如果隐藏 API 操场，则无需包含身份验证方法。

    ```json
    "api": {
      "playground": {
        "display": "none"
      }
    }
    ```

    可在[设置](/zh/organize/settings-api)中查看 API 配置的完整列表。
  </Step>

  <Step title="创建端点页面">
    为每个端点创建一个 MDX 文件。在 frontmatter 中定义 `title` 和 `api`：

    ```mdx
    ---
    title: 'Create new user'
    api: 'POST /v1/users'
    ---
    ```

    `api` frontmatter 字段接受完整 URL 或相对路径：

    * **完整 URL**，例如 `POST https://api.acme.com/v1/users`。对于该端点，`docs.json` 中的 `server` 字段会被忽略。
    * **相对路径**，例如 `POST /v1/users`。需要在 `docs.json` 中提供 `server` 字段。服务器 URL 会加在该路径前面。

    将路径参数括在 `{}` 中即可指定它们：

    ```bash
    https://api.example.com/v1/endpoint/{userId}
    ```

    如需为特定页面覆盖全局 Playground 显示模式，请在 frontmatter 中添加 `playground`：

    ```mdx
    ---
    title: 'Create new user'
    api: 'POST https://api.mintlify.com/user'
    playground: 'none'
    ---
    ```

    选项：

    * `playground: 'interactive'` - 显示交互式 playground (默认)
    * `playground: 'simple'` - 显示可复制的 API 端点，不显示 playground
    * `playground: 'none'` - 完全隐藏 playground
  </Step>

  <Step title="添加参数和响应">
    使用[参数和响应字段](/zh/components/fields)来记录端点的参数和返回值。

    ```mdx
    <ParamField path="userId" type="string" required>
      Unique identifier for the user
    </ParamField>

    <ParamField body="email" type="string" required>
      User's email address
    </ParamField>

    <ResponseField name="id" type="string" required>
      Unique identifier for the newly created user
    </ResponseField>

    <ResponseField name="email" type="string" required>
      User's email address
    </ResponseField>
    ```
  </Step>

  <Step title="将您的 API 端点添加到文档中">
    更新 `docs.json` 中的 `pages` 字段，将你的 API 端点页面添加到导航中：

    ```json docs.json
    "navigation": {
      "tabs": [
        {
          "tab": "API Reference",
          "groups": [
            {
              "group": "Users",
              "pages": [
                "api-reference/users/create-user",
                "api-reference/users/get-user",
                "api-reference/users/update-user"
              ]
            },
            {
              "group": "Orders",
              "pages": [
                "api-reference/orders/create-order",
                "api-reference/orders/list-orders"
              ]
            }
          ]
        }
      ]
    }
    ```

    每个页面路径都对应文档仓库中的一个 MDX 文件。例如，`api-reference/users/create-user.mdx`。有关如何组织文档的更多信息，请参阅[导航](/zh/organize/navigation)。

    ### 在导航中使用 OpenAPI 端点

    如果你有 OpenAPI 规范，就可以直接在导航中引用端点，而无需为每个端点单独创建 MDX 文件。要引用特定端点，请包含 OpenAPI 文件路径和端点：

    ```json docs.json
    "navigation": {
      "pages": [
        "introduction",
        "/path/to/users-openapi.json POST /users",
        "/path/to/orders-openapi.json GET /orders"
      ]
    }
    ```

    你还可以为某个导航组设置默认 OpenAPI 规范，并按 HTTP 方法和路径引用端点：

    ```json docs.json
    {
      "group": "API reference",
      "openapi": "/path/to/openapi-v1.json",
      "pages": [
        "overview",
        "authentication",
        "GET /users",
        "POST /users",
        {
          "group": "Orders",
          "openapi": "/path/to/openapi-v2.json",
          "pages": [
            "GET /orders",
            "POST /orders"
          ]
        }
      ]
    }
    ```

    有关 OpenAPI 集成的更多信息，请参阅 [OpenAPI 设置](/zh/api-playground/openapi-setup)。
  </Step>
</Steps>

<div id="enable-authentication">
  ## 启用身份验证
</div>

你可以在 `docs.json` 中全局设置身份验证，也可以通过 frontmatter 中的 `authMethod` 字段为单个页面单独设置。页面级设置会覆盖全局设置。

<div id="bearer-token">
  ### Bearer Token
</div>

<CodeGroup>
  ```json docs.json
  "api": {
    "mdx": {
      "auth": {
        "method": "bearer"
      }
    }
  }
  ```

  ```mdx 页面元数据
  ---
  title: "你的页面标题"
  authMethod: "bearer"
  ---
  ```
</CodeGroup>

  ### 基本身份验证

<div id="none">
  ### None
</div>

如需对特定页面禁用身份验证，请将 `authMethod` 设为 `none`：

```mdx 页面元数据
---
title: "Your page title"
authMethod: "none"
---
```
