如果用户通过 SDK 而不是直接发起网络请求来与你的 API 交互，你可以使用 `x-codeSamples` 扩展为 OpenAPI 文档添加代码示例，并将其显示在 OpenAPI 页面中。

将此属性添加到任意请求方法上。其 schema 如下。

<ParamField body="lang" type="string" required>
  代码示例的语言。
</ParamField>

<ParamField body="label" type="string">
  示例的标签。这在为单个端点提供多个示例时非常有用。
</ParamField>

<ParamField body="source" type="string" required>
  示例的源代码。
</ParamField>

下面是一个植物追踪应用的代码示例，该应用同时提供 Bash CLI 工具和 JavaScript SDK。

```yaml
paths:
  /plants:
    get:
      # ...
      x-codeSamples:
        - lang: bash
          label: List all unwatered plants
          source: |
            planter list -u
        - lang: javascript
          label: List all unwatered plants
          source: |
            const planter = require('planter');
            planter.list({ unwatered: true });
        - lang: bash
          label: List all potted plants
          source: |
            planter list -p
        - lang: javascript
          label: List all potted plants
          source: |
            const planter = require('planter');
            planter.list({ potted: true });
```
