<div id="headers">
  ## 标题
</div>

标题用于组织内容并创建导航锚点。它们会显示在目录中，帮助用户快速浏览文档。

<div id="creating-headers">
  ### 创建标题
</div>

使用 `#` 符号创建不同级别的标题：

```mdx
## Main section header
### Subsection header
#### Sub-subsection header
```

<Tip>
  使用描述清晰、包含丰富关键词的标题，明确说明后续内容。这既能改善用户导航，也有助于搜索引擎优化。
</Tip>

<div id="custom-heading-ids">
  ### 自定义标题 ID
</div>

默认情况下，Mintlify 会根据标题文本自动生成锚点 ID。你可以使用 `{#custom-id}` 语法，用自定义 ID 替换自动生成的 ID：

```mdx
## My section {#my-custom-anchor}
### Configuration options {#config}
##### Deep detail {#detail}
```

自定义 ID 会替换自动生成的锚点，因此你可以使用 `#my-custom-anchor` 或 `#config` 链接到该标题，而不必使用默认生成的 slug 文本。

当你希望锚点链接保持稳定，不会因标题文本更新而变化，或者需要更短、更容易记住的锚点时，这会很有帮助。

<div id="disabling-anchor-links">
  ### 禁用锚点链接
</div>

默认情况下，标题会包含可点击的锚点链接，用户可直接链接到特定部分。你可以在 HTML 或 React 标题中使用 `noAnchor` 属性来禁用这些锚点链接。

<CodeGroup>
  ```mdx HTML 标题示例
  <h2 noAnchor>
  Header without anchor link
  </h2>
  ```

  ```mdx React 标题示例
  <Heading level={2} noAnchor>
  Header without anchor link
  </Heading>
  ```
</CodeGroup>

使用 `noAnchor` 时，标题不会显示锚点标签，点击标题文本也不会将锚点链接复制到剪贴板。

## 文本格式

我们支持大多数 Markdown 文本格式，可用于强调文本和设置文本样式。

<div id="basic-formatting">
  ### 基本格式
</div>

将以下格式样式应用到文本中：

| 样式      | 语法         | 示例         | 效果        |
| ------- | ---------- | ---------- | --------- |
| **粗体**  | `**text**` | `**重要提示**` | **重要提示**  |
| *斜体*    | `_text_`   | `_强调_`     | *强调*      |
| ~~删除线~~ | `~text~`   | `~已弃用功能~`  | ~~已弃用功能~~ |

<div id="combining-formats">
  ### 组合格式
</div>

您可以组合使用多种格式：

```mdx
**_bold and italic_**
**~~bold and strikethrough~~**
*~~italic and strikethrough~~*
```

***粗体和斜体***<br />
**~~粗体和删除线~~**<br />
*~~斜体和删除线~~*

<div id="superscript-and-subscript">
  ### 上标和下标
</div>

对于数学表达式或脚注，请使用 HTML 标签：

| 类型 | 语法                | 示例                    | 结果                  |
| -- | ----------------- | --------------------- | ------------------- |
| 上标 | `<sup>text</sup>` | `example<sup>2</sup>` | example<sup>2</sup> |
| 下标 | `<sub>text</sub>` | `example<sub>n</sub>` | example<sub>n</sub> |

## 链接

链接可帮助用户在页面之间跳转并访问外部资源。使用描述明确的链接文本，以提升可访问性和用户体验。

<div id="internal-links">
  ### 内部链接
</div>

使用相对于根路径的路径链接到文档中的其他页面：

```mdx
[Quickstart](/quickstart)
[Steps](/components/steps)
```

[快速入门](/zh/quickstart)<br />
[Steps](/zh/components/steps)

<div id="external-links">
  ### 外部链接
</div>

对于外部资源，请使用完整的 URL：

```mdx
[Markdown Guide](https://www.markdownguide.org/)
```

[Markdown 指南](https://www.markdownguide.org/)

<div id="broken-links">
  ### 死链
</div>

你可以使用 [CLI](/zh/cli) 检查文档中的死链：

```bash
mint broken-links
```

<div id="block-quotes">
  ## 块引用
</div>

块引用用于在内容中突出重要信息、引文或示例。

<div id="single-line-block-quotes">
  ### 单行块引用
</div>

在文本前加上 `>`，即可创建块引用：

```mdx
> This is text that stands out from the main content.
```

> 这是一段从正文中突出的文本。

<div id="multi-line-block-quotes">
  ### 多行块引用
</div>

对于较长的引用或包含多个段落的内容：

```mdx
> This is the first paragraph of a multi-line block quote.
>
> This is the second paragraph, separated by an empty line with `>`.
```

> 这是多行块引用的第一段。
>
> 这是第二段，与上一段之间用一行仅包含 `>` 的空行分隔。

<Tip>
  请谨慎使用块引用，以保留其视觉强调效果和语义。对于注释、警告及其他信息，建议使用[提示框](/zh/components/callouts)。
</Tip>

<div id="mathematical-expressions">
  ## 数学表达式
</div>

我们支持使用 LaTeX 渲染数学表达式和公式。你可以在 `docs.json` 的[设置](/zh/organize/settings-appearance#styling)中配置 `styles.latex`，以覆盖自动检测。

<div id="inline-math">
  ### 行内数学公式
</div>

行内数学表达式请使用单个美元符号 `$`：

```mdx
The Pythagorean theorem states that $(a^2 + b^2 = c^2)$ in a right triangle.
```

勾股定理表明，在直角三角形中，$(a^2 + b^2 = c^2)$。

<div id="block-equations">
  ### 块级公式
</div>

对于单独成行的公式，使用双美元符号 `$$`：

```mdx
$$
E = mc^2
$$
```

$$
E = mc^2
$$

<Info>
  LaTeX 支持需要使用正确的数学语法。有关完整的语法指南，请参阅 [LaTeX 文档](https://www.latex-project.org/help/documentation/)。
</Info>

<div id="line-breaks-and-spacing">
  ## 换行与间距
</div>

通过调整间距和换行，提升内容的可读性。

<div id="paragraph-breaks">
  ### 段落换行
</div>

使用空行分隔段落：

```mdx
This is the first paragraph.

This is the second paragraph, separated by a blank line.
```

这是第一段。

这是第二段，与上一段之间用一个空行分隔。

<div id="manual-line-breaks">
  ### 手动换行
</div>

在段落中使用 HTML `<br />` 标签可强制换行：

```mdx
This line ends here.<br />
This line starts on a new line.
```

这一行到此结束。<br />
这一行从新的一行开始。

<Tip>
  大多数情况下，用空行分段比手动换行更便于阅读。
</Tip>

<div id="horizontal-rules">
  ### 水平分隔线
</div>

使用 Markdown `---` 语法或 HTML `<hr />` 标签添加水平分隔线，在视觉上分隔不同的内容部分：

```mdx
Content preceding the rule.

<hr />

Content following the rule.
```

分隔线前的内容。

<hr />

分隔线后的内容。

<Tip>
  请谨慎使用水平分隔线。大多数情况下，标题能更好地分隔内容，而且还附带导航锚点。
</Tip>

<div id="best-practices">
  ## 最佳实践
</div>

<div id="content-organization">
  ### 内容组织
</div>

* 使用标题建立清晰的内容层级
* 遵循正确的标题层级 (不要从 H2 跳到 H4)
* 编写描述清晰、包含丰富关键词的标题

<div id="text-formatting">
  ### 文本格式
</div>

* 用粗体突出重点，不要把整段文字都设为粗体
* 斜体仅用于术语、标题或轻微强调
* 避免过度使用格式，以免分散读者对内容的注意力

<div id="links">
  ### 链接
</div>

* 使用描述性的链接文本，不要写“点击这里”或“阅读更多”
* 内部链接使用相对于根路径的路径
* 定期测试链接，避免出现失效链接
