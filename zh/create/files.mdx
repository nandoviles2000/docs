Mintlify 会自动从您的文档仓库提供静态资源，并通过您域名下的相应路径访问这些资源。例如，如果您的仓库中有 `/images/my-logo.png`，则可通过 `https://docs.your-project.com/images/my-logo.png` 访问该图片文件。

您可以向用户提供任何受支持的文件类型，包括 OpenAPI 规范、图片、视频等。

文件大小必须小于 20 MB。

<Note>
  启用身份验证的文档站点不支持文件托管。如果您的站点需要身份验证，则无法通过静态文件的直接 URL 访问这些文件。
</Note>

<div id="supported-file-types">
  ## 支持的文件类型
</div>

所有套餐支持的文件类型：

* **图片**: `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.ico`
* **视频**: `.mp4`, `.webm`
* **音频**: `.mp3`, `.wav`
* **数据**: `.json`, `.yaml`
* **样式表**: `.css`
* **脚本**: `.js`
* **字体**: `.woff`, `.woff2`, `.ttf`, `.eot`

企业版套餐支持的文件类型：

* **文档**: `.pdf`, `.txt`
* **数据**: `.xml`, `.csv`
* **压缩文件**: `.zip`

<div id="file-organization">
  ## 文件组织
</div>

使用文件夹整理文件，让你的仓库更便于浏览：

```text
/your-project
  |- docs.json
  |- images/
    |- logo.png
    |- screenshots/
      |- dashboard.png
  |- assets/
    |- whitepaper.pdf
    |- demo-video.mp4
```

文件会从你的域名根路径下提供，因此仓库中的目录结构会直接映射为 URL 结构。沿用前面的示例，`assets/whitepaper.pdf` 可通过 `https://docs.your-project.com/assets/whitepaper.pdf` 访问。
