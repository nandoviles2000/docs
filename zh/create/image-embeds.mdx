<div id="images">
  ## 图片
</div>

添加图片，为文档提供视觉上下文、示例或装饰效果。

<div id="basic-image-syntax">
  ### 基本图片语法
</div>

使用 [Markdown 语法](https://www.markdownguide.org/basic-syntax/#images) 在文档中添加图片：

```mdx
![Alt text describing the image](/path/to/image.png)
```

<Tip>
  始终添加具有描述性的 alt 文本，以提升无障碍访问体验和 SEO。alt 文本应清晰说明图片展示的内容。
</Tip>

图片文件必须小于 20 MB。对于更大的文件，请将其托管到 [Amazon S3](https://aws.amazon.com/s3) 或 [Cloudinary](https://cloudinary.com) 等 CDN 服务上。

<div id="html-image-embeds">
  ### 使用 HTML 嵌入图片
</div>

如需更灵活地控制图片显示，请使用 HTML `<img>` 标签：

```jsx
<img 
  src="/images/dashboard.png" 
  alt="Main dashboard interface"
  style={{height: "300px", width: "400px"}}
  className="rounded-lg"
/>
```

<div id="resize-images-with-inline-styles">
  #### 使用内联样式调整图片尺寸
</div>

使用 JSX 的 `style` 内联样式属性来调整图片尺寸：

```jsx
<img
  src="/images/architecture.png"
  style={{width: "450px", height: "auto"}}
  alt="Diagram showing the architecture of the system"
/>
```

<div id="disable-image-zoom">
  #### 禁用图片点击缩放
</div>

如需禁用图片默认的点击缩放效果，请添加 `noZoom` 属性：

```html highlight="4"
<img 
  src="/images/screenshot.png" 
  alt="Descriptive alt text"
  noZoom
/>
```

<div id="link-images">
  #### 为图片添加链接
</div>

要让图片可以点击跳转，请将图片包裹在 `<a>` 标签中，并添加 `noZoom` 属性：

```html
<a href="https://mintlify.com" target="_blank">
  <img 
    src="/images/logo.png" 
    alt="Mintlify logo"
    noZoom
  />
</a>
```

<Note>
  锚点标签内的图片会自动显示指针光标，表明它们可点击。
</Note>

<div id="light-and-dark-mode-images">
  #### 浅色与深色模式图片
</div>

要针对浅色和深色主题显示不同的图片，请使用 Tailwind CSS 类：

```html
<!-- 浅色模式图片 -->
<img 
  className="block dark:hidden" 
  src="/images/light-mode.png" 
  alt="Light mode interface"
/>

<!-- 深色模式图片 -->
<img 
  className="hidden dark:block" 
  src="/images/dark-mode.png" 
  alt="Dark mode interface"
/>
```

<div id="svg-images">
  ### SVG 图像
</div>

使用 `foreignObject` 元素的 SVG 文件在生产环境中的渲染效果与本地开发环境不同。出于安全考虑，Mintlify 的图像 CDN 会从 SVG 中移除 `foreignObject`，这可能导致文本和其他嵌入的 HTML 内容被截断或隐藏。

这类问题常见于从 [draw.io](https://www.drawio.com) 等工具导出的 SVG，尤其是在启用了 HTML 文本格式或自动换行的情况下。要解决此问题，请在导出为 SVG 之前，先在图表中的所有标签上禁用 **Formatted Text** 和 **Word Wrap**。有关 SVG 导出的更多信息，请参阅 [draw.io 文档](https://www.drawio.com/doc/faq/svg-export-text-problems)。

<div id="videos">
  ## 视频
</div>

Mintlify 支持在 Markdown 中使用 [HTML 标签](https://www.markdownguide.org/basic-syntax/#html)，方便你灵活创建更丰富的内容。

<Tip>
  请务必在 video 元素中提供后备文本内容，以便不支持视频播放的浏览器也能显示相关信息。
</Tip>

<div id="youtube-embeds">
  ### 嵌入 YouTube 视频
</div>

使用 iframe 元素嵌入 YouTube 视频：

```html
<iframe
  className="w-full aspect-video rounded-xl"
  src="https://www.youtube.com/embed/4KzFe50RQkQ"
  title="YouTube video player"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
></iframe>
```

<Frame>
  <iframe className="w-full aspect-video rounded-xl" src="https://www.youtube.com/embed/4KzFe50RQkQ" title="YouTube 视频播放器" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen />
</Frame>

<div id="self-hosted-videos">
  ### 自托管视频
</div>

对自托管的视频内容，请使用 HTML `<video>` 元素：

```html
<video
  controls
  className="w-full aspect-video rounded-xl"
  src="link-to-your-video.com"
></video>
```

<div id="autoplay-videos">
  ### 自动播放视频
</div>

如需让视频自动播放，请使用：

```html
<video
  autoPlay
  muted
  loop
  playsInline
  className="w-full aspect-video rounded-xl"
  src="/videos/demo.mp4"
></video>
```

<Note>
  使用 JSX 语法时，请将双词属性写成驼峰式：`autoPlay`、`playsInline`、`allowFullScreen`。
</Note>

<div id="iframes">
  ## Iframes
</div>

使用 iframe 元素嵌入外部内容：

```html
<iframe 
  src="https://example.com/embed" 
  title="Embedded content"
  className="w-full h-96 rounded-xl"
></iframe>
```
