软件开发的一项核心原则是 DRY (Don&#39;t Repeat Yourself，不要重复自己) ，这同样适用于文档编写。如果你发现同样的内容在多个地方反复出现，可以为这部分内容创建自定义内容片段。内容片段中的内容可以导入到其他文件中重复使用。你可以控制内容片段在页面上的显示位置。如果之后需要更新内容，你只需编辑该内容片段，而不必逐个修改所有使用了它的文件。

<div id="how-snippets-work">
  ## 内容片段的工作原理
</div>

内容片段是指导入到另一个文件中的任何 `.mdx`、`.md` 或 `.jsx` 文件。你可以将内容片段文件放在项目中的任何位置。

当你将内容片段导入另一个文件时，它只会显示在导入它的位置，不会渲染为独立页面。`/snippets/` 文件夹中的任何文件始终都会被视为内容片段，即使它没有被导入到其他文件中。

<div id="create-snippets">
  ## 创建内容片段
</div>

创建一个文件，写入你想要复用的内容。内容片段可包含 Mintlify 支持的所有内容类型，也可导入其他内容片段。

<div id="import-snippets-into-pages">
  ## 将内容片段导入页面
</div>

使用绝对路径或相对路径将内容片段导入页面。

* **绝对导入**：以 `/` 开头，用于从项目根目录导入。
* **相对导入**：使用 `./` 或 `../``，相对于当前文件的位置导入内容片段。

<Tip>
  相对导入支持 IDE 导航。在编辑器中按住 <kbd>CMD</kbd> 并单击内容片段名称，即可直接跳转到其定义。
</Tip>

<div id="import-text">
  ### 导入文本内容片段
</div>

1. 将你想复用的内容添加到内容片段文件中。

   ```mdx shared/my-snippet.mdx wrap
   你好，世界！这是我想在多个页面中复用的内容。
   ```

2. 使用绝对路径或相对路径，将该内容片段导入目标文件。

   <CodeGroup>
     ```mdx Absolute import
     ---
     title: "示例页面"
     description: "这是一个导入内容片段的示例页面。"
     ---

     import MySnippet from "/shared/my-snippet.mdx";

     内容片段内容会显示在这句话下方。

     <MySnippet />
     ```

     ```mdx Relative import
     ---
     title: "示例页面"
     description: "这是一个导入内容片段的示例页面。"
     ---

     import MySnippet from "../shared/my-snippet.mdx";

     内容片段内容会显示在这句话下方。

     <MySnippet />
     ```
   </CodeGroup>

<div id="import-variables">
  ### 导入变量
</div>

在页面中引用内容片段中的变量。

1. 在内容片段文件中导出变量。

   ```mdx shared/custom-variables.mdx
   export const myName = "Ronan";

   export const myObject = { fruit: "strawberries" };

   ;
   ```

2. 在目标文件中导入该内容片段，并使用这些变量。

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with variables."
   ---

   import { myName, myObject } from "/shared/custom-variables.mdx";

   Hello, my name is {myName} and I like {myObject.fruit}.
   ```

<div id="import-snippets-with-variables">
  ### 使用变量导入内容片段
</div>

导入内容片段时，可使用变量向内容片段传递数据。

1. 为内容片段添加变量，并在导入时传入属性值。在此示例中，变量为 `{word}`。

   ```mdx shared/my-snippet.mdx
   今日关键词是 {word}。
   ```

2. 在目标文件中导入包含该变量的内容片段。传入的属性值会替换内容片段定义中的变量。

   ```mdx destination-file.mdx
   ---
   title: "示例页面"
   description: "这是一个导入了带变量内容片段的示例页面。"
   ---

   import MySnippet from "/shared/my-snippet.mdx";

   <MySnippet word="bananas" />
   ```

<div id="import-react-components">
  ### 导入 React 组件
</div>

1. 创建一个包含 JSX 组件的内容片段。更多信息，请参阅 [React 组件](/zh/customize/react-components)。

   ```js components/my-jsx-snippet.jsx
   export const MyJSXSnippet = () => {
     return (
       <div>
         <h1>Hello, world!</h1>
       </div>
     );
   };
   ```

<Note>
  创建 JSX 内容片段时，请使用箭头函数语法 (`=>`)，不要使用函数声明。内容片段不支持 `function` 关键字。
</Note>

2. 导入该内容片段。

   ```mdx destination-file.mdx
   ---
   title: "An example page"
   description: "This is an example page that imports a snippet with a React component."
   ---

   import { MyJSXSnippet } from "/components/my-jsx-snippet.jsx";

   <MyJSXSnippet />
   ```
