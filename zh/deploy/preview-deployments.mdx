<Info>
  预览部署功能适用于 [Pro 和 Enterprise 套餐](https://mintlify.com/pricing?ref=preview-deployments)。
</Info>

预览部署可让你在合并到生产环境之前，先查看文档更改后的效果。每个预览都会生成一个可分享的 URL，并且在你推送新更改时会自动更新。

默认情况下，预览 URL 公开可见。你可以将预览链接分享给任何需要审核更改的人。

<div id="create-preview-deployments">
  ## 创建预览部署
</div>

预览部署会通过拉取请求 (PR) 自动创建，也可以在您的仪表板中手动创建。

<div id="automatic-previews">
  ### 自动预览
</div>

<Note>
  仅会为目标分支是你的[部署分支](/zh/guides/git-concepts#deployment-branch)的拉取请求 (PR) 创建自动预览。
</Note>

创建拉取请求 (PR) 后，Mintlify 机器人会自动在拉取请求 (PR) 中添加一个查看预览部署的链接。每次你向该分支推送新提交时，预览都会自动更新。

<div id="manual-previews">
  ### 手动创建预览
</div>

你可以为任意分支手动创建预览。

1. 前往你的[仪表板](https://dashboard.mintlify.com/)。
2. 选择 **Previews**。
3. 选择 **Create custom preview**。
4. 输入要预览的分支名称。
5. 选择 **Create preview**。

<div id="api">
  ### API
</div>

你也可以通过 [Trigger preview deployment](/zh/api/preview/trigger) API 端点以编程方式创建预览部署。这适合将预览创建集成到 CI/CD 流水线或自定义工具中。

<div id="redeploy-a-preview">
  ## 重新部署预览
</div>

重新部署预览以刷新内容，或在部署失败后再次尝试。

1. 在[仪表板](https://dashboard.mintlify.com/)中选择该预览。
2. 选择 **Redeploy**。

<div id="preview-widget">
  ## 预览小部件
</div>

预览小部件会出现在预览部署中，帮助你浏览并审阅已更新的页面。它是位于预览部署右下角的一个悬浮按钮。

<Frame>
  <img src="/images/previews/widget-light.png" alt="展开的预览小部件，显示已更改文件的列表。" className="block dark:hidden" />

  <img src="/images/previews/widget-dark.png" alt="展开的预览小部件，显示已更改文件的列表。" className="hidden dark:block" />
</Frame>

1. 点击该小部件，查看预览中所有新增、修改或删除的文件。
2. 点击某个文件，查看对应页面上的更改。
3. 使用搜索栏筛选已更改文件列表。
4. 将鼠标悬停在某个文件上，然后点击 **在编辑器中打开** 图标，直接在网页编辑器中编辑该文件。

该小部件仅会出现在预览部署中，不会显示在正式站点或本地预览中。

<div id="restrict-access-to-preview-deployments">
  ## 限制预览部署的访问权限
</div>

默认情况下，任何知道 URL 的人都可以访问预览部署。你可以要求所有预览都启用组织身份验证，或为单个预览设置密码保护，以限制访问。

<div id="require-organization-authentication">
  ### 要求组织成员身份验证
</div>

仅允许已通过身份验证的 Mintlify 组织成员访问预览。

1. 在你的仪表板中，前往 [Add-ons](https://dashboard.mintlify.com/products/addons) 页面的 **Previews** 部分。
2. 点击 **Preview authentication** 开关，以启用或禁用预览身份验证。

  <img src="/images/previews/preview-auth-light.png" alt="Add-ons 页面中的预览身份验证开关" className="block dark:hidden" />

  <img src="/images/previews/preview-auth-dark.png" alt="Add-ons 页面中的预览身份验证开关" className="hidden dark:block" />

<div id="password-protect-an-individual-preview">
  ### 为单个预览设置密码保护
</div>

<Info>
  受密码保护的预览仅在 [Enterprise 方案](https://mintlify.com/pricing?ref=preview-deployments) 中提供。
</Info>

为特定预览设置密码保护，这样你就可以在不将外部审核者添加到 Mintlify 组织中的情况下与他们共享该预览。此选项仅在创建手动预览时提供；如果你的部署已启用组织身份验证，则不会显示此选项。

1. 前往你的[仪表板](https://dashboard.mintlify.com/)。
2. 选择 **Previews**。
3. 选择 **Create custom preview**。
4. 输入要预览的分支名称。
5. 打开 **Make private** 开关并输入密码。密码长度必须至少为 8 个字符。

<Frame>
  <img src="/images/previews/private-preview-light.png" alt="“Create a custom preview” 模态框，其中已启用 Make private 开关并显示密码输入框。" className="block dark:hidden" />

  <img src="/images/previews/private-preview-dark.png" alt="“Create a custom preview” 模态框，其中已启用 Make private 开关并显示密码输入框。" className="hidden dark:block" />
</Frame>

6. 选择 **Create preview**。

<div id="troubleshooting-preview-deployments">
  ## 预览部署故障排查
</div>

如果预览部署失败，请尝试以下排查步骤。

* **查看构建日志**：在您的[仪表板](https://dashboard.mintlify.com/)中，前往 **Previews** 并点击失败的预览。部署日志会显示导致失败的错误。
* **检查配置**：
  * `docs.json` 语法无效
  * 导航中引用的文件路径缺失或不正确
  * MDX 文件中的 frontmatter 无效
  * 图片链接失效或图片文件缺失
* **本地验证**：在本地运行 `mint dev`，以便在推送到仓库前发现构建错误。
* **检查最近的更改**：查看分支中最近的提交，确定是哪些更改导致构建失败。
