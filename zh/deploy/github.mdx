Mintlify 使用 GitHub App 自动将你的文档与 GitHub 仓库同步。

<Tip>
  **你需要 GitHub App 吗？**

  * **位于 `mintlify-community` 组织中的 Mintlify 托管仓库**：不需要。GitHub App 已完成配置。
  * **你自己的仓库**：需要。安装 GitHub App，以便在你推送更改时启用自动部署。

  你可以在仪表板的 [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) 页面查看你的仓库。
</Tip>

如果你的仓库是由 Mintlify 组织拥有的私有仓库，GitHub App 会由 Mintlify 自动配置和管理。你可以使用网页编辑器修改文档。如果你想在本地处理文档，请将仓库克隆到你自己的组织中，并更新 Git 设置以改用你自己的仓库。

<div id="clone-to-your-own-repository">
  ## 克隆到你自己的仓库
</div>

如果你在初始引导时跳过了连接自己的 Git 仓库，你的文档会存放在由 Mintlify 组织拥有的私有仓库中。要将其迁移到你自己的账户或组织，请前往仪表板中的 [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings)。设置向导会通过以下两种方式引导你完成这一过程：

<AccordionGroup>
  <Accordion title="一键克隆（推荐）">
    克隆选项会自动在你的 GitHub 账户中创建一份文档副本。

    1. 选择 **GitHub** 作为提供方，然后选择 **Clone**。
    2. 在提示出现时通过 GitHub 完成授权。
    3. 选择你希望创建该仓库的 GitHub 组织。
    4. 确认克隆。Mintlify 会将你的文档文件复制到一个新仓库中。
    5. 你也可以安装 Mintlify GitHub App，以启用自动部署。
  </Accordion>

  <Accordion title="手动设置">
    <Warning>
      此过程会永久删除 Mintlify 托管仓库中的内容。

      在完成手动设置流程之前，请先通过设置向导下载你的文档。
    </Warning>

    如果你想手动设置仓库：

    1. 将文档下载为 zip 文件，作为文件备份。
    2. 选择 **GitHub** 作为提供方，然后选择 **Continue setup**。
    3. 在提示出现时通过 GitHub 完成授权。
    4. 选择你的组织、仓库和分支。
    5. 如果你的文档不在仓库根目录，可以按需指定子目录。
    6. 保存设置。
  </Accordion>
</AccordionGroup>

完成任一流程后，请按照 [安装 GitHub App](#install-the-github-app) 中的步骤安装 GitHub App。

<div id="install-the-github-app">
  ## 安装 GitHub App
</div>

<Note>
  你必须是组织所有者，或拥有仓库管理员权限，才能安装该应用。如果你没有所需权限，则必须由仓库所有者批准安装请求。
</Note>

通过你的[仪表板](https://dashboard.mintlify.com/settings/organization/github-app)安装 Mintlify GitHub App。

<Tip>
  我们建议只授予文档仓库的访问权限。
</Tip>

  <img className="h-80" alt="Mintlify GitHub App 安装页面，其中已选中“Only select repositories”选项。" src="/images/github/select-repos.png" />
</Frame>

<div id="permissions">
  ## 权限
</div>

安装 GitHub App 时，请授予以下权限。

读取权限：

* `metadata`：基本仓库信息

读取和写入权限：

* `checks`：在拉取请求 (PR) 上创建状态检查
* `code`：当你提交到文档分支时，读取文件变更
* `deployments`：为拉取请求 (PR) 生成预览部署
* `pull requests`：通过网页编辑器创建分支和拉取请求 (PR) 

<Info>
  该应用只会访问你明确授予其权限的仓库。如果你启用了分支保护规则，该应用无法直接推送到受保护的分支。
</Info>

<div id="manage-repository-access">
  ## 管理仓库访问权限
</div>

安装 GitHub App 时，您可以授予其访问全部仓库或特定仓库的权限。我们建议您仅授予其访问文档仓库，以及您希望作为智能体上下文提供的任何仓库的权限。您可以随时在 [GitHub App settings](https://github.com/apps/mintlify/installations/new)中修改此选项。

<div id="configure-docs-source">
  ## 配置文档来源
</div>

在仪表板的 [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) 部分，修改用于构建文档的组织、仓库或分支。

<div id="github-enterprise-with-ip-allowlists">
  ## 启用了 IP 允许列表的 GitHub Enterprise
</div>

如果您的 GitHub Enterprise Cloud 组织启用了 IP 允许列表，您需要将 Mintlify 的出口 IP 地址 (`54.242.90.151`) 添加到允许列表中，GitHub App 才能正常运行。

请按照 [GitHub 文档](https://docs.github.com/en/enterprise-cloud@latest/organizations/keeping-your-organization-secure/managing-security-settings-for-your-organization/managing-allowed-ip-addresses-for-your-organization) 配置 IP 允许列表。

<div id="troubleshooting">
  ## 故障排查
</div>

<div id="deployment-not-triggering-automatically">
  ### 部署未自动触发
</div>

如果向仓库推送更改后没有触发部署，请检查以下可能的问题。

<AccordionGroup>
  <Accordion title="确认 GitHub App 安装情况">
    检查是否已在正确的仓库中安装该应用。

    1. 前往仪表板中的 [GitHub App settings](https://dashboard.mintlify.com/settings/organization/github-app)。
    2. 检查你的仓库是否在当前启用的应用安装列表中。
  </Accordion>

  <Accordion title="检查部署分支">
    确保你推送到了正确的分支。

    1. 前往 [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings)
    2. 确认仪表板中配置的分支与你推送到的分支一致。
  </Accordion>
</AccordionGroup>

<div id="github-app-connection-issues">
  ### GitHub App 连接问题
</div>

如果你在使用 GitHub App 时遇到问题，重置连接通常可以解决大多数问题。

<Steps>
  <Step title="通过 GitHub 卸载 Mintlify 应用。">
    1. 在 GitHub 中，前往 [installations](https://github.com/settings/installations)，然后在 Mintlify 应用旁点击 **Configure**。向下滚动并点击 **Uninstall**。
    2. 前往 [Authorized GitHub Apps](https://github.com/settings/apps/authorizations)，然后在 Mintlify 应用旁点击 **Revoke**。
  </Step>

  <Step title="重新安装 Mintlify 应用。">
    1. 在你的 Mintlify 仪表板中，前往 [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) 并安装 GitHub App。
    2. 在仪表板的 [My Profile](https://dashboard.mintlify.com/settings/account) 部分授权你的账户。
  </Step>
</Steps>

<div id="feedback-add-ons-are-unavailable">
  ### 反馈附加功能不可用
</div>

“编辑建议”和“提出问题”这两项反馈功能仅适用于公开的 GitHub 仓库。如果这些选项在您的仪表板中处于禁用状态，请检查仓库的可见性。

如果您的仓库是公开的，但仍无法在仪表板中启用“编辑建议”或“提出问题”选项，请重新验证您的 Git 设置。

<Steps>
  <Step title="前往 Git Settings">
    在仪表板中打开 [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings)。
  </Step>

  <Step title="重新验证设置">
    点击 Git 设置框角的绿色勾选图标，重新验证仓库设置。这样会强制更新仓库设置，以正确反映仓库是公开还是私有。

    <Frame>
      <img src="/images/github/revalidate-settings-light.png" alt="Mintlify 仪表板中的 Git 设置页面。橙色箭头指向用于重新验证仓库设置的绿色勾选图标。" className="block dark:hidden" />

      <img src="/images/github/revalidate-settings-dark.png" alt="Mintlify 仪表板中的 Git 设置页面。橙色箭头指向用于重新验证仓库设置的绿色勾选图标。" className="hidden dark:block" />
    </Frame>
  </Step>
</Steps>
