如果您的文档站点在几秒钟后显示 500 错误，或出现导航变慢的情况，Cloudflare 的防火墙可能正在拦截对 Mintlify 素材的请求。

<div id="symptoms">
  ## 症状
</div>

* 文档页面起初可以正常加载，但在 30–60 秒后会因 500 错误而崩溃
* 页面之间的客户端导航缓慢或失效
* 浏览器控制台中，请求 `/mintlify-assets/*` 路径时出现 403 错误
* Cloudflare 安全质询消息提示“数据格式错误”或“可疑的 URL 模式”

<div id="root-cause">
  ## 根本原因
</div>

Cloudflare 的 Web Application Firewall (WAF) 和 Bot Fight Mode 可能会因以下情况将 Mintlify 的资源请求判定为可疑：

* 编码后的 URL 参数中含有多个 `%` 符号
* 含有特殊字符的长查询字符串
* 来自闲置标签页的自动请求

<div id="solution">
  ## 解决方案
</div>

创建一条 Cloudflare 防火墙规则，将 Mintlify 素材排除在安全检查之外。

<div id="create-the-firewall-exception">
  ### 创建防火墙例外规则
</div>

1. 登录你的 [Cloudflare 仪表板](https://dash.cloudflare.com/)
2. 选择你的域名
3. 前往 **Security &gt; WAF**
4. 选择 **Create rule**
5. 按以下设置配置规则：

**规则名称：** 允许 Mintlify 素材

**当入站请求匹配以下条件时：**

* 字段：`Hostname`
* 运算符：`equals`
* 值：`docs.yourdomain.com` (替换为你的实际文档域名) 

**并且：**

* 字段：`URI Path`
* 运算符：`starts with`
* 值：`/mintlify-assets/`

**然后：**

* 操作：`Skip`
* 选择：`All remaining custom rules`、`Managed rules` 和 `Super Bot Fight Mode`

6. 启用 **Log** 以跟踪匹配到的请求
7. 选择 **Deploy**

<div id="verify-the-rule">
  ### 验证规则
</div>

部署后：

1. 在浏览器中打开你的文档站点
2. 让页面保持空闲 2-3 分钟
3. 在不同页面之间切换
4. 检查浏览器控制台中是否出现 403 错误

如果问题仍然存在，请检查你的规则配置：

* 确保主机名与你的文档域名完全一致
* 确认 URI 路径使用 `starts with` (而不是 `contains`) 
* 不要在路径值中包含通配符 (`*`) 
* 确认规则已启用并已部署

<div id="common-mistakes">
  ## 常见错误
</div>

* 将 `contains` 运算符用于 `/mintlify-assets/*` - `*` 会被视为字面字符，而不是通配符
* 对 URI 路径使用 `equals` - 这只会匹配精确路径 `/mintlify-assets/`，而不会匹配其子路径
* 忘记跳过 Bot Fight Mode - 必须在跳过操作中明确包含此项
* 主机名错误 - 必须与你实际的文档域名一致

<div id="additional-troubleshooting">
  ## 其他故障排查
</div>

如果防火墙例外规则仍无法解决问题：

1. 查看 Cloudflare 的 **Security &gt; Events** 日志，确认是否有请求被拦截
2. 验证你的 Cloudflare Worker (如果使用自定义子路径) 是否正确转发 `Host` 标头
3. 临时将 Security Level 设置为“Essentially Off”，以确认问题是否由 Cloudflare 导致
4. 检查是否存在可能覆盖该防火墙例外规则的自定义 Page Rules

<div id="example-working-configuration">
  ## 可用配置示例
</div>

```
Rule: Allow Mintlify assets
Status: Enabled

When incoming requests match:
  (http.host eq "docs.flashnet.xyz" and starts_with(http.request.uri.path, "/mintlify-assets/"))

Then:
  Skip: All remaining custom rules, Managed rules, Super Bot Fight Mode
  Log: Enabled
```
