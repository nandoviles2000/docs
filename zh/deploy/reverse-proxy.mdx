<Note>
  反向代理配置仅支持 [企业版方案](https://mintlify.com/pricing?ref=reverse-proxy)。
</Note>

要通过自定义反向代理提供文档，您必须配置路由规则、缓存策略和请求头转发。

实施反向代理时，请留意域名验证、SSL 证书签发、身份验证流程、性能和分析跟踪方面的潜在问题。

<div id="choose-your-deployment-approach">
  ## 选择部署方式
</div>

Mintlify 根据你的子路径需求，支持两种反向代理配置。

* **托管在 `/docs`**：使用 `mintlify.dev` 作为代理目标。在仪表板中的[自定义域名设置](https://dashboard.mintlify.com/settings/deployment/custom-domain)页面启用 **托管在 `/docs`** 开关。这种配置更简单，所需路由也更少。
* **自定义子路径**：使用 `mintlify.app` 作为代理目标。这种方式支持任意子路径，但需要额外的路由规则。

<div id="host-at-docs-subpath">
  ## 在 `/docs` 子路径下托管
</div>

如果你希望通过自己域名下的 `/docs` 路径提供文档，请使用此配置。

在配置反向代理之前：

1. 在仪表板中前往 [自定义域名设置](https://dashboard.mintlify.com/settings/deployment/custom-domain)。
2. 打开 **Host at `/docs`** 切换开关。
3. 输入你的域名，然后选择 **Add domain**。

<Warning>
  启用 **Host at `/docs`** 后，文档的规范 URL 将变为 `<your-subdomain>.mintlify.dev`。`mintlify.app` 上的缓存失效将停止生效，你必须代理到 `mintlify.dev`，更新才会显示。
</Warning>

<div id="routing-configuration">
  ### 路由配置
</div>

将这些路径代理到你的 Mintlify 子域名：

| 路径                                 | 目标                                   | 缓存  |
| ---------------------------------- | ------------------------------------ | --- |
| `/docs`                            | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |
| `/docs/*`                          | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |
| `/.well-known/vercel/*`            | `<your-subdomain>.mintlify.dev`      | 不缓存 |
| `/.well-known/skills/*` (可选)       | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |
| `/.well-known/agent-skills/*` (可选) | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |
| `/skill.md` (可选)                   | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |
| `/llms.txt` (可选)                   | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |
| `/llms-full.txt` (可选)              | `<your-subdomain>.mintlify.dev/docs` | 不缓存 |

`/.well-known/skills/*`、`/.well-known/agent-skills/*`、`/skill.md`、`/llms.txt` 和 `/llms-full.txt` 这些路由是可选的。只有当你想在根路径 (例如 `your-domain.com/llms.txt`) 而不是文档子路径 (例如 `your-domain.com/docs/llms.txt`) 下提供 AI 文件时，才需要包含它们。

<div id="required-header-configuration">
  ### 必需的请求头配置
</div>

请按以下请求头要求配置反向代理：

* **Origin**：包含目标子域名 `<your-subdomain>.mintlify.dev`
* **X-Forwarded-For**：保留客户端 IP 信息
* **X-Forwarded-Proto**：保留原始协议 (HTTP/HTTPS) 
* **X-Real-IP**：转发客户端的真实 IP 地址
* **User-Agent**：转发用户代理

<Warning>
  请确保不要转发 `Host` 请求头。
</Warning>

<div id="example-nginx-configuration">
  ### nginx 配置示例
</div>

```nginx
server {
    listen 80;
    server_name <your-domain>.com;

    # Vercel 验证路径
    location ~ ^/\.well-known/vercel/ {
        proxy_pass https://<your-subdomain>.mintlify.dev;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # AI 技能路径
    location ^~ /.well-known/skills/ {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 代理技能发现路径
    location ^~ /.well-known/agent-skills/ {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 技能清单（可选）
    location = /skill.md {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # LLM 索引文件（可选）
    location = /llms.txt {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    location = /llms-full.txt {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 文档根路径
    location = /docs {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }

    # 所有文档路径
    location /docs/ {
        proxy_pass https://<your-subdomain>.mintlify.dev/docs/;
        proxy_set_header Origin <your-subdomain>.mintlify.dev;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header User-Agent $http_user_agent;

        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }
}
```

<div id="custom-subpath">
  ## 自定义子路径
</div>

如果你需要使用 `/docs` 以外的子路径 (例如 `/help` 或 `/resources`) ，请使用以下路由配置。

将这些路径代理到你的 Mintlify 子域名，并按指定的缓存策略进行配置：

| Path                              | Destination                     | Caching |
| --------------------------------- | ------------------------------- | ------- |
| `/.well-known/vercel/*`           | `<your-subdomain>.mintlify.app` | 不缓存     |
| `/.well-known/skills/*`           | `<your-subdomain>.mintlify.app` | 不缓存     |
| `/.well-known/agent-skills/*`     | `<your-subdomain>.mintlify.app` | 不缓存     |
| `/skill.md`                       | `<your-subdomain>.mintlify.app` | 不缓存     |
| `/llms.txt`                       | `<your-subdomain>.mintlify.app` | 不缓存     |
| `/llms-full.txt`                  | `<your-subdomain>.mintlify.app` | 不缓存     |
| `/mintlify-assets/_next/static/*` | `<your-subdomain>.mintlify.app` | 启用缓存    |
| `/_mintlify/*`                    | `<your-subdomain>.mintlify.app` | 不缓存     |
| `/*`                              | `<your-subdomain>.mintlify.app` | 不缓存     |
| `/`                               | `<your-subdomain>.mintlify.app` | 不缓存     |

<Note>
  Mintlify 会在根路径下提供 `llms.txt`、`llms-full.txt` 和 `skill.md`。如果你的文档位于某个子路径下 (例如 `/help`) ，也可以在该子路径下提供这些文件 (例如 `/help/llms.txt`) 。为此，请添加 location 块，将该子路径重写到根路径。下面的 nginx 示例同时展示了这两种模式。
</Note>

<div id="troubleshooting">
  ## 故障排查
</div>

<div id="changes-not-appearing">
  ### 更改未生效
</div>

**症状**：你发布了文档更新，但这些更改没有显示在网站上。

**原因**：你在仪表板中启用了 **Host at `/docs`**，但反向代理指向了 `mintlify.app`，而不是 `mintlify.dev`。

**解决方案**：更新反向代理配置，使其指向 `<your-subdomain>.mintlify.dev`，而不是 `<your-subdomain>.mintlify.app`。

<div id="404-error">
  ### 404 错误
</div>

**症状**：文档可以正常加载，但功能无法使用，API 调用失败。

**原因**：反向代理转发了 `Host` 请求头，或者未传递 `Origin` 请求头。

**解决方案**：

* 移除 `Host` 请求头转发
* 将 `Origin` 请求头设置为你的 Mintlify 子域名 (`/docs` 子路径使用 `mintlify.dev`，其他子路径使用 `mintlify.app`)

<div id="performance-issues">
  ### 性能问题
</div>

**症状**：页面加载缓慢，并出现布局偏移。

**原因**：缓存配置不当。

**解决方案**：如果使用自定义子路径配置，仅对 `/mintlify-assets/_next/static/*` 路径启用缓存。`/docs` 子路径配置会自动处理缓存。
