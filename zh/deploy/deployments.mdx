当你将更改推送到已连接的仓库时，文档站点会自动部署。这要求已正确安装并连接 Mintlify GitHub App。

如果你的最新更改未显示在线上站点中，请先检查拥有文档仓库的 GitHub 账户或组织是否已安装 GitHub App。更多信息，请参阅 [GitHub 故障排查](/zh/deploy/github#troubleshooting)。

如果你已安装 GitHub App，但更改仍未部署，请在仪表板中手动触发一次部署。

<div id="manually-trigger-a-deployment">
  ## 手动触发部署
</div>

<Steps>
  <Step title="确认你的最新提交已成功。">
    检查你的最新提交是否已出现在文档仓库中，且未报错。
  </Step>

  <Step title="手动触发部署。">
    前往你的[仪表板](https://dashboard.mintlify.com)，然后选择部署按钮。

    <Frame>
      <img src="/images/deployments/manual-update-light.png" alt="以橙色矩形标出的手动更新按钮。" className="block dark:hidden" />

      <img src="/images/deployments/manual-update-dark.png" alt="以橙色矩形标出的手动更新按钮。" className="hidden dark:block" />
    </Frame>
  </Step>
</Steps>

<div id="delete-a-deployment">
  ## 删除部署
</div>

你可以在仪表板设置中的[危险区域](https://dashboard.mintlify.com/settings/organization/danger-zone)永久删除部署。此操作不可撤销，并会删除所有部署数据，包括所有关联的预览部署。

<Steps>
  <Step title="前往危险区域。">
    前往仪表板设置页面中的[危险区域](https://dashboard.mintlify.com/settings/organization/danger-zone)。
  </Step>

  <Step title="删除部署。">
    1. 在 **Delete my deployment** 部分中填写删除原因。
    2. 点击删除按钮，并确认要删除该部署。
  </Step>
</Steps>

<Warning>
  删除部署后将无法恢复。如果你有有效订阅，系统会针对当前计费周期内剩余的未使用时长，按比例返还相应额度。
</Warning>

如果你有多个部署，删除后会被重定向到另一个部署。如果你删除的是唯一的部署，则会被重定向到 Mintlify 首页。删除部署后，组织管理员会收到一封确认删除的电子邮件通知。
