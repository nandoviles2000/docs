---

使用 `mint export` 可将整个文档站点打包为一个自包含的 zip 压缩包。接收者解压后即可在浏览器中查看文档，无需互联网连接、Mintlify 账户或任何构建工具——只需安装 [Node.js](https://nodejs.org)。

当您需要将文档分发给无法访问线上站点的用户时，这种方式非常有用，例如面向本地部署客户、隔离网络环境，或用于内部合规审查。

<div id="prerequisites">
  ## 前置条件
</div>

* 已安装 [CLI](/zh/cli/install) 并更新到最新版本
* 已安装 [Node.js](https://nodejs.org) v20.17.0 及以上版本

<div id="export-your-site">
  ## 导出你的站点
</div>

进入包含 `docs.json` 文件的文档目录，然后运行：

```bash
mint export
```

CLI 会构建您的站点，爬取导航中定义的每个页面，并将生成内容打包成当前目录下的 zip 文件。

<div id="options">
  ### 选项
</div>

| 参数                  | 描述                                                                                                               | 默认值          |
| ------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------ |
| `--output <path>`   | 设置输出 zip 文件的路径。                                                                                                  | `export.zip` |
| `--groups <group>`  | 为导出模拟[用户组](/zh/deploy/authentication-setup#control-access-with-groups)。如果你的文档使用基于用户组的访问控制，并且你希望导出的归档包含受限页面，此选项会很有用。 | —            |
| `--disable-openapi` | 在导出过程中跳过 OpenAPI 文件生成。如果你有很多 OpenAPI 规范并希望加快构建速度，请使用此选项。                                                         | —            |

例如，要将你的网站以自定义文件名导出，并指定特定用户组：

```bash
mint export --output customer-docs.zip --groups enterprise
```

<Note>
  导出内容仅包含导航中列出的页面。[隐藏页面](/zh/organize/hidden-pages) 不会包含在压缩包中。
</Note>

<div id="whats-in-the-zip">
  ## zip 中的内容
</div>

导出的压缩包包含离线查看文档所需的全部内容：

| 文件                   | 用途                             |
| -------------------- | ------------------------------ |
| HTML 页面              | 导航中每个页面的预渲染版本                  |
| `_next/static/`      | 打包后的 CSS、JavaScript 和其他静态资源    |
| `serve.js`           | 零依赖的 Node.js HTTP 服务器，用于提供站点内容 |
| `Start Docs.command` | macOS 启动程序——双击即可打开文档           |
| `Start Docs.bat`     | Windows 启动程序——双击即可打开文档         |

<div id="view-the-exported-docs">
  ## 查看导出的文档
</div>

将 zip 文件分享给任何已安装 Node.js 的人。要查看文档，请按以下步骤操作：

<Tabs>
  <Tab title="手动">
    1. 解压压缩包。
    2. 在解压后的目录中打开终端。
    3. 运行 `node serve.js`。
    4. 在浏览器中打开 `http://localhost:3000`。
  </Tab>

  <Tab title="macOS">
    1. 解压压缩包。
    2. 双击 **Start Docs.command**。
    3. 文档会在默认浏览器中打开，地址为 `http://localhost:3000`。

    <Note>
      macOS 可能会阻止打开该文件，因为它是从互联网下载的。如果你看到安全警告，请前往 **系统设置 &gt; 隐私与安全性**，然后选择 **仍要打开**。详情请参阅 [Apple 关于覆盖安全设置的指南](https://support.apple.com/guide/mac-help/mh40617/mac)。
    </Note>
  </Tab>

  <Tab title="Windows">
    1. 解压压缩包。
    2. 双击 **Start Docs.bat**。
    3. 文档会在默认浏览器中打开，地址为 `http://localhost:3000`。

    <Note>
      Windows 可能会显示“Windows 已保护你的电脑”警告，因为该文件是从互联网下载的。选择 **更多信息**，然后选择 **仍要运行**。
    </Note>
  </Tab>
</Tabs>
