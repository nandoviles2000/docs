---

所有 404 页面都会根据请求的 URL 自动推荐相关页面。如果用户来到 404 页面，智能体会分析该路径，并从您的文档中检索语义上相关的页面，帮助他们找到所需内容。

您可以自定义 404 错误页面的标题和描述。您可以通过描述添加有用的链接或说明。

<div id="configuration">
  ## 配置
</div>

在 `docs.json` 文件的 `errors.404` 部分配置你的 404 页面：

```json
"errors": {
  "404": {
    "redirect": false,
    "title": "I can't be found",
    "description": "What ever **happened** to this _page_?"
  }
}
```

<div id="parameters">
  ## 参数
</div>

<ResponseField name="redirect" type="boolean">
  页面未找到时，是否自动重定向到主页。

  将其设为 `true` 可重定向到主页。

  将其设为 `false` 可显示自定义 404 页面。
</ResponseField>

<ResponseField name="title" type="string">
  404 错误页面的自定义标题。这会替换默认的“页面未找到”标题。
</ResponseField>

<ResponseField name="description" type="string">
  404 错误页面的自定义描述。支持 MDX 格式，可包含链接、粗体、斜体文本和自定义组件。
</ResponseField>
