使用 CSS 设置 HTML 元素的样式，或添加自定义 CSS 和 JavaScript，全面自定义文档的外观与体验。

<div id="style-with-tailwind-css">
  ## 使用 Tailwind CSS 设置样式
</div>

使用 Tailwind CSS v3 为 HTML 元素设置样式。你可以控制布局、间距、颜色和其他视觉属性。以下是一些常见类：

* `w-full` - 宽度占满
* `aspect-video` - 16:9 宽高比
* `rounded-xl` - 大圆角
* `block`, `hidden` - 显示控制
* `dark:hidden`, `dark:block` - 深色模式下的显示控制

不支持 Tailwind CSS 任意值。如需使用自定义值，请改用 `style` prop。

```html
<img style={{ width: '350px', margin: '12px auto' }} src="/path/image.jpg" />
```

<Warning>
  使用 `style` 属性可能会在页面加载时导致布局偏移，尤其是在自定义模式页面中。请改用 Tailwind CSS 类或自定义 CSS 文件，以避免页面偏移或闪烁。
</Warning>

<div id="add-custom-css">
  ## 添加自定义 CSS
</div>

将 CSS 文件添加到仓库中，即可应用其中定义的类名，并在所有 MDX 文件中使用这些类名。

常用元素的引用方式和样式可能会发生变化。请谨慎使用自定义样式，因为未来更新可能会引入破坏性变更。

例如，你可以添加以下 `style.css` 文件，自定义导航栏和页脚的样式。

```css
#navbar {
  background: #fffff2;
  padding: 1rem;
}

footer {
  margin-top: 2rem;
}
```

Mintlify 提供两种可用于 CSS 定位的钩子：

* **ID 选择器**：页面级的唯一元素，可在 CSS 中使用 `#value { }` 进行定位
* **元素选择器**：组件和布局元素，可在 CSS 中使用 `value { }` 进行定位 (没有 `#` 或 `.` 前缀) 

<Tip>
  使用“检查元素”功能来查找你想自定义的元素引用。
</Tip>

<div id="custom-javascript">
  ## 自定义 JavaScript
</div>

自定义 JS 可让你在全站范围内添加自定义的可执行代码。这相当于在每个页面里都加入一个包含 JS 代码的 `<script>` 标签。

Mintlify 会将内容目录中的任何 `.js` 文件注入到文档站点的每个页面中。例如，你可以添加以下 `ga.js` 文件，在整个文档站点中启用 [Google Analytics](https://marketingplatform.google.com/about/analytics)。

```js
window.dataLayer = window.dataLayer || [];
function gtag() {
  dataLayer.push(arguments);
}
gtag('js', new Date());

gtag('config', 'TAG_ID');
```

<Warning>
  请谨慎使用，以避免引入安全漏洞。
</Warning>
