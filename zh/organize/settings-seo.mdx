使用 `docs.json` 文件中的这些设置，控制搜索引擎如何索引你的文档、搜索结果中显示哪些元数据、搜索栏的行为，以及页面是否显示最后修改时间戳。

<div id="settings">
  ## 设置
</div>

<div id="description">
  ### `description`
</div>

**Type:** `string`

用于 SEO 和 AI 索引的文档站点描述。这会显示在搜索引擎结果中，AI 工具也会利用它来理解您站点的用途。

```json docs.json
"description": "Documentation for Example Co.'s API and developer platform."
```

***

<div id="seo">
  ### `seo`
</div>

**类型：** `object`

搜索引擎索引和元数据设置。

<ResponseField name="seo.indexing" type="&#x22;navigable&#x22; | &#x22;all&#x22;">
  指定搜索引擎应索引哪些页面。

  * `navigable` — 仅索引 `docs.json` 导航中包含的页面。默认值为此项。
  * `all` — 索引项目中的所有页面，包括未出现在导航中的页面。
</ResponseField>

<ResponseField name="seo.metatags" type="object">
  添加到每个页面的自定义元标签。请以键值对形式提供，其中每个键为元标签名称，对应的值为其内容。

  可用选项请参阅[常见元标签参考](/zh/optimize/seo#common-meta-tags-reference)。

  ```json
  "metatags": {
    "og:site_name": "Example Co. Docs",
    "twitter:card": "summary_large_image"
  }
  ```
</ResponseField>

```json docs.json
"seo": {
  "indexing": "navigable",
  "metatags": {
    "og:site_name": "Example Co. Docs"
  }
}
```

***

<div id="search">
  ### `search`
</div>

**类型：** `object`

搜索栏的显示设置。

<ResponseField name="search.prompt" type="string">
  搜索栏为空时显示的占位文本。
</ResponseField>

```json docs.json
"search": {
  "prompt": "Search the docs..."
}
```

***

<div id="metadata">
  ### `metadata`
</div>

**类型：** `object`

应用于所有页面的全局页面级元数据设置。

<ResponseField name="metadata.timestamp" type="boolean">
  在所有页面上显示最后修改日期。启用后，每个页面都会显示其内容最近一次修改的日期。默认为 `false`。

  你可以使用 `timestamp` frontmatter 字段为单个页面覆盖此设置。详见 [Pages](/zh/organize/pages#last-modified-timestamp)。
</ResponseField>

```json docs.json
"metadata": {
  "timestamp": true
}
```

<div id="example">
  ## 示例
</div>

```json docs.json
{
  "description": "Documentation for Example Co.'s API and developer platform.",
  "seo": {
    "indexing": "navigable",
    "metatags": {
      "og:site_name": "Example Co. Docs",
      "twitter:card": "summary_large_image"
    }
  },
  "search": {
    "prompt": "Search the docs..."
  },
  "metadata": {
    "timestamp": true
  }
}
```
