<div id="ref">
  ### `$ref`
</div>

从另一个 JSON 文件加载配置。你可以在 `docs.json` 的任意层级使用 `$ref`，将配置拆分到多个文件中。

**类型：** string——指向 `.json` 文件的相对路径

* 当 `$ref` 解析为对象时，Mintlify 会将同一配置块中的同级键合并到引用内容之上，因此这些键会优先于引用中对应的键生效。
* 当 `$ref` 解析为非对象值 (例如数组) 时，Mintlify 会忽略任何同级键。
* 被引用的文件也可以包含自己的 `$ref` 条目，并且会相对于该文件进行解析。
* 路径必须位于项目根目录内。循环引用会导致构建错误。

示例请参阅 [使用 `$ref` 拆分配置](/zh/organize/settings#split-configuration-with-%24ref)。

### `theme` - <Badge color="red">必填</Badge>

站点的布局主题。

**类型：** string
**可选值：** `mint`, `maple`, `palm`, `willow`, `linden`, `almond`, `aspen`, `sequoia`, `luma`

请参阅 [Themes](/zh/customize/themes) 查看预览。

***

### `name` - <Badge color="red">必填</Badge>

项目、组织或产品的名称。

**类型：** string

***

### `colors` - <Badge color="red">必填</Badge>

文档中使用的颜色配置。

**类型：** object

<div id="colorsprimary">
  #### `colors.primary`
</div>

<Badge color="red">必填</Badge>

主色。通常在浅色模式下用于突出强调。

**类型：** string—与 `^#([a-fA-F0-9]{6}|[a-fA-F0-9]{3})$` 匹配的十六进制颜色代码

<div id="colorslight">
  #### `colors.light`
</div>

在深色模式下用于强调的颜色。

**类型：** string—符合 `^#([a-fA-F0-9]{6}|[a-fA-F0-9]{3})$` 的十六进制代码

<div id="colorsdark">
  #### `colors.dark`
</div>

在两种模式下，用于按钮和悬停状态的颜色。

**Type:** string—符合 `^#([a-fA-F0-9]{6}|[a-fA-F0-9]{3})$` 的十六进制颜色代码

### `navigation` - <Badge color="red">必填</Badge>

用于定义内容的导航结构。

**类型：** object

完整文档请参阅 [导航](/zh/organize/navigation)。

<div id="navigationglobal">
  #### `navigation.global`
</div>

显示在所有页面和所有语言区域中的全局导航元素。

**Type:** object

<div id="navigationglobaltabs">
  ##### `navigation.global.tabs`
</div>

顶层导航标签页。

**Type:** 对象数组——每个对象包含：`tab` (字符串，必需) 、`icon` (字符串) 、`iconType` (字符串) 、`hidden` (布尔值) 、`href` (字符串 uri，必需)

<div id="navigationglobalanchors">
  ##### `navigation.global.anchors`
</div>

侧边栏中的锚点链接。

**Type:** 对象数组——每个对象包含：`anchor` (字符串，必填) 、`icon` (字符串) 、`iconType` (字符串) 、`color.light` (十六进制字符串) 、`color.dark` (十六进制字符串) 、`hidden` (布尔值) 、`href` (URI 字符串，必填)

<div id="navigationglobaldropdowns">
  ##### `navigation.global.dropdowns`
</div>

下拉菜单。

**类型：** 对象数组——每项包含：`dropdown` (字符串，必填) 、`icon` (字符串) 、`iconType` (字符串) 、`hidden` (布尔值) 、`href` (字符串 URI，必填)

<div id="navigationgloballanguages">
  ##### `navigation.global.languages`
</div>

全局导航中的语言切换器。

**类型：** 对象数组——每个对象包含：`language` (字符串，必填) 、`default` (布尔值) 、`hidden` (布尔值) 、`href` (字符串 uri，必填)

**支持的语言代码：** `ar`, `ca`, `cn`, `cs`, `de`, `en`, `es`, `fr`, `fr-CA`, `he`, `hi`, `hu`, `id`, `it`, `ja`, `jp`, `ko`, `lv`, `nl`, `no`, `pl`, `pt`, `pt-BR`, `ro`, `ru`, `sv`, `tr`, `uk`, `uz`, `vi`, `zh`, `zh-Hans`, `zh-Hant`

<div id="navigationglobalversions">
  ##### `navigation.global.versions`
</div>

全局导航中的版本切换器。

**Type:** 对象数组——每项对象包含：`version` (字符串，必填，最小长度为 1) 、`default` (布尔值) 、`hidden` (布尔值) 、`href` (URI 字符串，必填)

<div id="navigationglobalproducts">
  ##### `navigation.global.products`
</div>

全局导航中的产品切换器。

**Type:** 对象数组——每个对象包含：`product` (字符串，必填) 、`description` (字符串) 、`icon` (字符串) 、`iconType` (字符串)

<div id="navigationlanguages">
  #### `navigation.languages`
</div>

用于多语言站点的语言切换器。每个条目都可以包含特定语言的 `banner`、`footer` 和 `navbar` 覆盖设置。

**类型：** 对象数组——每个对象包含：`language` (字符串，必填) 、`default` (布尔值) 、`hidden` (布尔值) 、`banner` (对象) 、`footer` (对象) 、`navbar` (对象)

**支持的语言代码：** `ar`, `ca`, `cn`, `cs`, `de`, `en`, `es`, `fr`, `fr-CA`, `he`, `hi`, `hu`, `id`, `it`, `ja`, `jp`, `ko`, `lv`, `nl`, `no`, `pl`, `pt`, `pt-BR`, `ro`, `ru`, `sv`, `tr`, `uk`, `uz`, `vi`, `zh`, `zh-Hans`, `zh-Hant`

<div id="navigationversions">
  #### `navigation.versions`
</div>

用于多版本站点的版本切换器。

**类型：** 对象数组——每项包含：`default` (boolean) 、`tag` (string)

<div id="navigationtabs">
  #### `navigation.tabs`
</div>

顶层导航标签页。

**类型：**对象数组——结构请参见 `navigation.global.tabs`。

<div id="navigationanchors">
  #### `navigation.anchors`
</div>

侧边栏中的锚点链接。

**类型：** 对象数组——其结构请参见 `navigation.global.anchors`。

<div id="navigationdropdowns">
  #### `navigation.dropdowns`
</div>

下拉菜单。

**类型：**对象数组——结构请参见 `navigation.global.dropdowns`。

<div id="navigationproducts">
  #### `navigation.products`
</div>

产品切换器。

**类型：** object 数组——其结构请参见 `navigation.global.products`。

<div id="navigationgroups">
  #### `navigation.groups`
</div>

用于将内容组织为带标签的分区。

**Type:** 对象数组

<div id="navigationpages">
  #### `navigation.pages`
</div>

文档中的各个页面。

**Type:** 由字符串或对象组成的数组

<div id="navigationdirectory">
  #### `navigation.directory`
</div>

导航组中根页面的目录布局方式。该设置会递归继承；子项可覆盖。请参阅[目录列表](/zh/organize/navigation#directory-listings)。

**类型：** `"none"` | `"accordion"` | `"card"` — 默认值为 `"none"`

<div id="navbarlinks">
  #### `navbar.links`
</div>

显示在导航栏中的链接。

**类型：** 对象数组——每项包含：

| 字段         | 类型                       | 必填   | 描述                      |
| ---------- | ------------------------ | ---- | ----------------------- |
| `type`     | `"github"` | `"discord"` | 否    | 链接类型。标准链接可省略此字段。        |
| `label`    | string                   | 条件必填 | 省略 `type` 时必填。          |
| `href`     | string (uri)             | 是    | 链接地址。                   |
| `icon`     | string                   | 否    | 图标名称、URL、路径或 SVG。       |
| `iconType` | string                   | 否    | 仅适用于 Font Awesome 图标样式。 |

<div id="navbarprimary">
  #### `navbar.primary`
</div>

导航栏中的主要操作按钮。

**类型：** 对象

| 字段      | 类型                                    | 必填   | 描述                         |
| ------- | ------------------------------------- | ---- | -------------------------- |
