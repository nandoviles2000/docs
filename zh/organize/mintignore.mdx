`.mintignore` 文件可让你将文档仓库中的特定文件和目录排除在处理和发布范围之外，不会发布到文档站点。

使用 `.mintignore` 可以让草稿、内部笔记和源文件不出现在公开文档中，同时仍保留在仓库内进行维护。

<div id="create-a-mintignore-file">
  ## 创建 .mintignore 文件
</div>

在文档目录的根目录下创建一个 `.mintignore` 文件。该文件使用与 `.gitignore` 相同的模式语法。

```plaintext .mintignore
# 排除草稿文档
drafts/
*.draft.mdx

# 排除内部文档
internal/

# 排除特定文件
private-notes.md
```

当 Mintlify 构建你的文档时，它会读取 `.mintignore` 文件，并在处理过程中排除所有匹配的文件或目录。

被排除的文件：

* 不会出现在你发布的文档中。
* 不会被纳入搜索索引。
* 访客无法访问。
* 不会触发[失效链接检查](/zh/cli/commands#mint-broken-links)。指向被忽略文件的链接会失效。

<div id="default-ignored-patterns">
  ## 默认忽略的模式
</div>

Mintlify 会自动忽略以下目录和文件，无需任何配置：

* `.git`
* `.github`
* `.claude`
* `.agents`
* `.idea`
* `.vscode`
* `node_modules`
* `build`
* `dist`
* `coverage`
* `.cache`
* `tmp`
* `temp`
* `README.md`
* `LICENSE.md`
* `CHANGELOG.md`
* `CONTRIBUTING.md`

你无需将这些内容添加到 `.mintignore` 文件中。

<Note>
  与[隐藏页面](/zh/organize/hidden-pages)不同，`.mintignore` 会将匹配的文件从你的网站中完全移除，访客无法通过 URL 访问它们。
</Note>

<div id="pattern-syntax">
  ## 模式语法
</div>

`.mintignore` 文件遵循 `.gitignore` 的语法。常见模式包括：

| Pattern            | Description              |
| ------------------ | ------------------------ |
| `drafts/`          | 排除整个 `drafts` 目录         |
| `*.draft.mdx`      | 排除所有以 `.draft.mdx` 结尾的文件 |
| `private-notes.md` | 排除某个特定文件                 |
| `**/internal/**`   | 排除任意层级的 `internal` 目录    |
| `!important.mdx`   | 取消前一条模式的排除效果 (包含该文件)     |
