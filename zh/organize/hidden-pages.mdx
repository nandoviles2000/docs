隐藏页面不会显示在站点导航中，但任何知道 URL 的人仍可访问这些页面。例如，如果你创建了一个隐藏页面 `guides/hidden-page.mdx`，访问者仍可通过 `docs.yoursite.com/guides/hidden-page` 访问它。

如果某些内容你希望用户可以访问，或供 AI 工具作为上下文参考，但又不想将其列在导航中，就可以使用隐藏页面。

如果你的内容需要严格的访问控制，则必须配置 [身份验证](/zh/deploy/authentication-setup)。

如果要将页面限制为仅特定用户组可访问，请设置 [基于组的访问控制](/zh/deploy/authentication-setup#control-access-with-groups)。

请参阅 [隐藏页面示例](/zh/organize/hidden-page-example)。

<Note>
  某些导航元素 (如侧边栏、下拉菜单和标签页) 在隐藏页面中可能会显示为空，或导致布局发生偏移。
</Note>

<div id="hide-a-page">
  ## 隐藏页面
</div>

要隐藏某个页面，请在该页面的 [frontmatter](/zh/organize/pages) 中设置 `hidden: true`，或将其从 `docs.json` 的导航中移除。

<div id="set-hidden-true-in-frontmatter">
  ### 在 frontmatter 中设置 `hidden: true`
</div>

在页面的 frontmatter 中添加 `hidden: true`，即可将该页面从渲染后的导航中移除，同时仍保留在 `docs.json` 配置中。

```yaml
---
title: "My hidden page"
hidden: true
---
```

要让页面重新显示，请彻底删除 `hidden` 字段。不要设置 `hidden: false`，因为这会导致未定义行为。

<Note>
  搜索引擎无法索引隐藏页面。设置 `hidden: true` 后，该页面会自动从搜索引擎索引、站点地图和 AI 上下文中排除。不过，设置 `noindex: true` **不会**将页面从导航中隐藏。更多信息，请参阅[禁用索引](/zh/optimize/seo#disable-indexing)。
</Note>

<div id="remove-the-page-from-navigation">
  ### 从导航中移除页面
</div>

如果你没有在 `docs.json` 的导航中加入某个页面，它就会被隐藏。这种方法很适合用于那些你根本不希望出现在导航中的页面。

<div id="hide-a-group-of-pages">
  ## 隐藏一组页面
</div>

如需隐藏一组页面，请在 `docs.json` 文件中将该组的 `hidden` 属性设为 `true`：

```json highlight={4}
"groups": [
  {
    "group": "Getting started",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  },
  {
    "group": "Guides",
    "pages": [
      "guides/hidden-page.mdx",
      "guides/hidden-groups.mdx"
    ]
  }
]
```

在此示例中，`Getting started` 组处于隐藏状态，`Guides` 组则显示出来。

<div id="hide-a-tab">
  ### 隐藏标签页
</div>

要隐藏某个标签页，请在 `docs.json` 文件中为其添加 `hidden` 属性：

```json highlight={4}
"tabs": [
  {
    "tab": "Home",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  }
]
```

<div id="search-seo-and-ai-indexing">
  ## 搜索、SEO 和 AI 索引
</div>

默认情况下，隐藏页面不会被搜索引擎收录，也不会出现在文档站点的搜索结果中，或用作 AI 助手的上下文。若要让隐藏页面出现在搜索结果中并作为助手上下文，请在 `docs.json` 中添加 `seo` 属性：

```json
"seo": {
    "indexing": "all"
}
```

<div id="understanding-hidden-versus-noindex">
  ### 理解 hidden 与 noindex 的区别
</div>

`hidden` 与 `noindex` 的关系是单向的：

* **`hidden: true` → 自动应用 `noindex`**：隐藏页面会自动从搜索引擎、站点地图和 AI 上下文中排除。
* **`noindex: true` → 不会应用 `hidden`**：设置了 `noindex: true` 的页面在导航中仍然可见。它只会影响搜索引擎索引和 AI 上下文。

如果你想让某个页面不被搜索引擎收录，同时仍在导航中显示，请在其 frontmatter 中添加 `noindex: true`。如果你想让某个页面同时从导航和搜索引擎中隐藏，请使用 `hidden: true`。
