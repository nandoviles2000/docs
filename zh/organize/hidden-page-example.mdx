此页面处于隐藏状态。它未包含在 `docs.json` 的导航中，因此你只能通过其 URL 访问。

更多信息，请参阅[隐藏页面](/zh/organize/hidden-pages)。

<div id="common-use-cases-for-hidden-pages">
  ## 隐藏页面的常见用例
</div>

<Note>
  默认情况下，隐藏页面可公开访问，但不会通过导航被发现。如果您想限制对隐藏页面的访问，必须配置[身份验证](/zh/deploy/authentication-setup)。
</Note>

* **Beta 文档**：内容可以公开，但不应通过导航被发现。
* **供 AI 工具使用的上下文**：如果隐藏页面被编入索引，AI 工具就可以将其用作上下文。对于与用户无关、但能帮助 AI 工具提供更准确回答的内容，可使用隐藏页面。
* **旧版页面**：通过直接链接保留旧内容的访问方式，同时将其从导航菜单中移除。
* **内部工具**：记录内部工具、预发布 API 或开发流程。
