使用 `docs.json` 文件中的这些设置来控制站点的信息架构和用户体验。你可以修改导航栏、页脚、横幅、导航行为、上下文菜单、重定向以及全局内容变量。

<div id="settings">
  ## 设置
</div>

### `navigation` - <Badge color="red">必填</Badge>

**类型：** `object`

内容的导航结构。你可以在此使用分组、标签页、下拉菜单、锚点等定义站点完整的页面层级。

有关如何构建导航结构的完整说明，请参阅[导航](/zh/organize/navigation)。

<div id="navbar">
  ### `navbar`
</div>

**类型：** `object`

显示在顶部导航栏中的链接和按钮。

<ResponseField name="navbar.links" type="array of object">
  要在导航栏中显示的链接。

  <Expandable title="navbar.links">
    <ResponseField name="type" type="&#x22;github&#x22; | &#x22;discord&#x22;">
      可选的链接类型。省略时表示标准文本链接。设为 `github` 可链接到 GitHub 仓库并显示其 Star 数；设为 `discord` 可链接到 Discord 服务器并显示其在线用户数。
    </ResponseField>

    <ResponseField name="label" type="string">
      链接文本。未设置 `type` 时为必填。对于 `github` 和 `discord` 为可选。若省略，Mintlify 会根据 API 数据生成标签。
    </ResponseField>

    <ResponseField name="href" type="string (uri)" required>
      链接目标。必须是有效的外部 URL。对于 `github`，必须是 GitHub 仓库 URL。对于 `discord`，必须是 Discord 邀请 URL。
    </ResponseField>

    <IconsOptional />
  </Expandable>
</ResponseField>

<ResponseField name="navbar.primary" type="object">
  导航栏中的主行动按钮。

  <Expandable title="navbar.primary">
    <ResponseField name="type" type="&#x22;button&#x22; | &#x22;github&#x22; | &#x22;discord&#x22;" required>
      按钮样式。选择 `button` 表示标准按钮，选择 `github` 表示带 Star 数的 GitHub 仓库链接，选择 `discord` 表示带在线用户数的 Discord 邀请链接。
    </ResponseField>

    <ResponseField name="label" type="string">
      按钮文本。当 `type` 为 `button` 时为必填。对于 `github` 和 `discord` 为可选。
    </ResponseField>

    <ResponseField name="href" type="string (uri)" required>
      按钮目标。必须是外部 URL。对于 `github`，必须是 GitHub 仓库 URL。对于 `discord`，必须是 Discord 邀请 URL。
    </ResponseField>
  </Expandable>
</ResponseField>

```json docs.json
"navbar": {
  "links": [
    { "type": "github", "href": "https://github.com/your-org/your-repo" },
    { "label": "Community", "href": "https://example.com/community" }
  ],
  "primary": {
    "type": "button",
    "label": "Get started",
    "href": "https://example.com/signup"
  }
}
```

<div id="footer">
  ### `footer`
</div>

**类型：** `object`

页脚内容和社交媒体链接。

<ResponseField name="footer.socials" type="object">
  在页脚中显示的社交媒体资料。每个键表示平台名称，每个值表示你的个人资料 URL。

  有效键：`x`、`website`、`facebook`、`youtube`、`discord`、`slack`、`github`、`linkedin`、`instagram`、`hacker-news`、`medium`、`telegram`、`twitter`、`x-twitter`、`earth-americas`、`bluesky`、`threads`、`reddit`、`podcast`

  ```json
  "socials": {
    "x": "https://x.com/yourhandle",
    "github": "https://github.com/your-org"
  }
  ```
</ResponseField>

<ResponseField name="footer.links" type="array of object">
  在页脚中显示的链接列。最多可显示 4 列。

  <Expandable title="footer.links">
    <ResponseField name="header" type="string">
      列标题。最小长度：1。
    </ResponseField>

    <ResponseField name="items" type="array of object" required>
      在该列中显示的链接。

      <Expandable title="items">
        <ResponseField name="label" type="string" required>
          链接文本。最小长度：1。
        </ResponseField>

        <ResponseField name="href" type="string (uri)" required>
          链接目标 URL。
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

```json docs.json
"footer": {
  "socials": {
    "x": "https://x.com/yourhandle",
    "github": "https://github.com/your-org"
  },
  "links": [
    {
      "header": "Company",
      "items": [
        { "label": "Blog", "href": "https://example.com/blog" },
        { "label": "Careers", "href": "https://example.com/careers" }
      ]
    }
  ]
}
```

<div id="banner">
  ### `banner`
</div>

**类型：** `object`

显示在每个页面顶部的全站横幅。

<ResponseField name="banner.content" type="string" required>
  横幅中显示的文本内容。支持基础 MDX 格式，包括链接、粗体和斜体。暂不支持自定义组件。

  ```json
  "content": "我们刚刚发布了新内容。[了解更多](https://example.com)"
  ```
</ResponseField>

<ResponseField name="banner.dismissible" type="boolean">
  是否显示关闭按钮，以便用户关闭横幅。默认为 `false`。
</ResponseField>

```json docs.json
"banner": {
  "content": "We just launched something new. [Learn more](https://example.com)",
  "dismissible": true
}
```

<div id="interaction">
  ### `interaction`
</div>

**类型：** `object`

控制导航元素的用户交互方式。

<ResponseField name="interaction.drilldown" type="boolean">
  控制选择导航分组时是否自动跳转。设为 `true` 时，组展开后会自动跳转到第一个页面。设为 `false` 时，仅展开或折叠该组，不会跳转。留空则使用主题的默认行为。

<div id="contextual">
  ### `contextual`
</div>

**类型：** `object`

上下文菜单让用户能够快速访问 AI 工具和页面操作。它显示在页面页眉或目录侧边栏中。

<Note>
  上下文菜单仅在预览部署和生产部署中可用。
</Note>

<ResponseField name="contextual.options" type="array" required>
  上下文菜单中可用的操作。数组中的第一个选项会显示为默认操作。

  内置选项：

  * `"add-mcp"` — 将你的 MCP server 添加到用户配置中
  * `"aistudio"` — 将当前页面发送到 Google AI Studio
  * `"assistant"` — 以当前页面为上下文打开 AI 助手
  * `"copy"` — 将当前页面以 Markdown 格式复制到剪贴板
  * `"chatgpt"` — 将当前页面发送到 ChatGPT
  * `"claude"` — 将当前页面发送到 Claude
  * `"cursor"` — 在 Cursor 中安装你托管的 MCP server
  * `"devin"` — 将当前页面发送到 Devin
  * `"devin-mcp"` — 在 Devin 中安装你托管的 MCP server
  * `"grok"` — 将当前页面发送到 Grok
  * `"mcp"` — 将你的 MCP server URL 复制到剪贴板
  * `"perplexity"` — 将当前页面发送到 Perplexity
  * `"view"` — 在新标签页中以 Markdown 格式查看当前页面
  * `"vscode"` — 在 VS Code 中安装你托管的 MCP server
  * `"windsurf"` — 将当前页面发送到 Windsurf

  将自定义选项定义为对象：

  <Expandable title="自定义选项">
    <ResponseField name="title" type="string" required>
      自定义选项的显示标题。
    </ResponseField>

    <ResponseField name="description" type="string" required>
      自定义选项的描述文本。
    </ResponseField>

    <ResponseField name="icon" type="string">
      自定义选项的图标。支持图标库名称、URL、路径或 SVG 代码。
    </ResponseField>

    <ResponseField name="href" type="string or object" required>
      链接目标。可以是 URL 字符串，也可以是包含 `base` 和可选 `query` 参数的对象。

      可用占位符值：

      * `$page` — 当前页面内容
      * `$path` — 当前页面路径
      * `$mcp` — MCP server URL
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="contextual.display" type="&#x22;header&#x22; | &#x22;toc&#x22;">
  上下文选项的显示位置。选择 `header` 可将其显示在页面顶部的上下文菜单中；选择 `toc` 可将其显示在目录侧边栏中。默认为 `header`。
</ResponseField>

```json docs.json
"contextual": {
  "options": ["copy", "view", "chatgpt", "claude"],
  "display": "header"
}
```

<div id="redirects">
  ### `redirects`
</div>

**类型：** `对象数组`

用于已移动、重命名或删除页面的重定向规则。重新组织内容时，可使用这些规则来保留链接。

<ResponseField name="redirects[].source" type="string" required>
  要从中重定向的路径。示例：`/old-page`
</ResponseField>

<ResponseField name="redirects[].destination" type="string" required>
  要重定向到的目标路径。示例：`/new-page`
</ResponseField>

<ResponseField name="redirects[].permanent" type="boolean">
  如果为 `true`，则执行永久重定向 (308) 。如果为 `false`，则执行临时重定向 (307) 。默认为 `true`。
</ResponseField>

```json docs.json
"redirects": [
  {
    "source": "/old-page",
    "destination": "/new-page"
  },
  {
    "source": "/temp-redirect",
    "destination": "/destination",
    "permanent": false
  }
]
```

<div id="variables">
  ### `variables`
</div>

**类型：** `object`

可在整个文档中使用的全局变量。Mintlify 会在构建时将 `{{variableName}}` 占位符替换为你定义的值。

<ResponseField name="variables.[variableName]" type="string">
  一个键值对，其中键为变量名，值为替换后的文本。

  * 变量名可以包含字母、数字和连字符。
  * 你必须定义内容中引用的所有变量，否则构建将失败。
  * Mintlify 会对这些值进行清理，以防止 XSS 攻击。
</ResponseField>

```json docs.json
"variables": {
  "version": "2.0.0",
  "api-url": "https://api.example.com"
}
```

在内容中，使用双大括号引用变量：

```mdx
The current version is {{version}}. Make requests to {{api-url}}.
```

全局生效的页面级元数据设置。

<ResponseField name="metadata.timestamp" type="boolean">
  为所有页面启用最后修改日期。启用后，页面会显示内容的最后更新时间。默认为 `false`。

  你可以使用 `timestamp` frontmatter 字段在单个页面中覆盖此设置。详情请参阅 [Pages](/zh/organize/pages#last-modified-timestamp)。
</ResponseField>

```json docs.json
"metadata": {
  "timestamp": true
}
```
