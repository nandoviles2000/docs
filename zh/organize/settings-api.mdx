使用 `docs.json` 中的 `api` 字段，配置哪些 API 规范用于生成 API 页面、用于测试端点的交互式 API 操场，以及代码示例的生成和显示方式。

<div id="settings">
  ## 设置
</div>

<div id="api">
  ### `api`
</div>

**类型：** `object`

在 `api` 键下定义所有 API 相关设置。

<ResponseField name="api.openapi" type="string or array or object">
  用于生成 API 参考页面的 OpenAPI 规范文件。可接受单个路径或 URL、由路径和 URL 组成的数组，或一个用于指定 source 和 directory 的对象。

  <Expandable title="api.openapi 对象">
    <ResponseField name="source" type="string">
      OpenAPI 规范文件的 URL 或路径。最小长度：1。
    </ResponseField>

    <ResponseField name="directory" type="string">
      用于搜索 OpenAPI 文件的目录。请勿包含前导斜杠。
    </ResponseField>
  </Expandable>

  <CodeGroup>
    ```json 单个文件
    "openapi": "openapi.json"
    ```

    ```json 多个文件
    "openapi": [
      "openapi/v1.json",
      "openapi/v2.json",
      "https://api.example.com/openapi.yaml"
    ]
    ```

    ```json 目录
    "openapi": {
      "source": "openapi.json",
      "directory": "api-reference"
    }
    ```
  </CodeGroup>
</ResponseField>

<ResponseField name="api.asyncapi" type="string or array or object">
  用于生成事件驱动型 API 参考页面的 AsyncAPI 规范文件。可接受单个路径或 URL、由路径和 URL 组成的数组，或一个用于指定 source 和 directory 的对象。

  <Expandable title="api.asyncapi 对象">
    <ResponseField name="source" type="string">
      AsyncAPI 规范文件的 URL 或路径。最小长度：1。
    </ResponseField>

    <ResponseField name="directory" type="string">
      用于搜索 AsyncAPI 文件的目录。请勿包含前导斜杠。
    </ResponseField>
  </Expandable>

  <CodeGroup>
    ```json 单个文件
    "asyncapi": "asyncapi.json"
    ```

    ```json 多个文件
    "asyncapi": [
      "asyncapi/events.yaml",
      "asyncapi/webhooks.yaml"
    ]
    ```

    ```json 目录
    "asyncapi": {
      "source": "asyncapi.json",
      "directory": "websockets"
    }
    ```
  </CodeGroup>
</ResponseField>

<ResponseField name="api.playground" type="object">
  交互式 API 操场设置。

  <Expandable title="api.playground">
    <ResponseField name="display" type="&#x22;interactive&#x22; | &#x22;simple&#x22; | &#x22;none&#x22; | &#x22;auth&#x22;">
      操场的显示模式。默认为 `interactive`。

      * `interactive` — 带请求构建器的完整交互式操场
      * `simple` — 不含请求构建器的简化视图
      * `none` — 完全隐藏操场
      * `auth` — 仅向已完成身份验证的用户显示操场
    </ResponseField>

    <ResponseField name="proxy" type="boolean">
      是否通过代理服务器转发 API 请求。默认为 `true`。
    </ResponseField>

    <ResponseField name="credentials" type="boolean">
      当 `proxy` 为 `false` 时，是否在跨域请求中包含 Cookie 和身份验证标头。默认为 `false`。当 `proxy` 为 `true` 时，此设置无效。
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api.params" type="object">
  API 参数的显示设置。

  <Expandable title="api.params">
    <ResponseField name="expanded" type="&#x22;all&#x22; | &#x22;closed&#x22;">
      是否默认展开所有参数。默认为 `closed`。
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api.url" type="&#x22;full&#x22;">
  端点标题区域中基础 URL 的显示模式。设置为 `full` 后，会在每个端点页面上始终显示完整的基础 URL。默认情况下，只有在存在多个可选基础 URL 时才会显示基础 URL。
</ResponseField>

<ResponseField name="api.examples" type="object">
  自动生成的 API 代码示例设置。

  <Expandable title="api.examples">
    <ResponseField name="languages" type="array of string">
      自动生成代码片段所使用的语言。有关可用语言及其别名的完整列表，请参阅[支持的语言](/zh/api-playground/overview#all-supported-languages)。
    </ResponseField>

    <ResponseField name="defaults" type="&#x22;required&#x22; | &#x22;all&#x22;">
      是否在生成的示例中包含可选参数。默认为 `all`。
    </ResponseField>

    <ResponseField name="prefill" type="boolean">
      是否使用 OpenAPI 规范中的示例值预填充操场。默认为 `false`。
    </ResponseField>

    <ResponseField name="autogenerate" type="boolean">
      是否根据 API 规范为各个接口端点自动生成代码示例。默认为 `true`。设置为 `false` 时，操场中只会显示手动编写的代码示例 (来自 OpenAPI 中的 `x-codeSamples` 或 MDX 中的 `<RequestExample>` 组件) 。
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api.mdx" type="object">
  适用于基于 MDX 文件而非 OpenAPI 规范构建的 API 页面的设置。

  <Expandable title="api.mdx">
    <ResponseField name="auth" type="object">
      基于 MDX 的 API 请求的身份验证配置。

      <Expandable title="auth">
        <ResponseField name="method" type="&#x22;bearer&#x22; | &#x22;basic&#x22; | &#x22;key&#x22; | &#x22;cobo&#x22;">
          API 请求的身份验证方式。
        </ResponseField>

        <ResponseField name="name" type="string">
          API 请求的身份验证参数名称。
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="server" type="string or array">
      会附加到页面级 `api` frontmatter 字段中相对路径前的基础 URL。如果 frontmatter 包含完整 URL，则不会使用此项。
    </ResponseField>
  </Expandable>
</ResponseField>

<div id="example">
  ## 示例
</div>

```json docs.json
{
  "api": {
    "openapi": ["openapi/v1.json", "openapi/v2.json"],
    "playground": {
      "display": "interactive"
    },
    "params": {
      "expanded": "all"
    },
    "url": "full",
    "examples": {
      "languages": ["curl", "python", "javascript", "go"],
      "defaults": "required",
      "prefill": true,
      "autogenerate": true
    }
  }
}
```
