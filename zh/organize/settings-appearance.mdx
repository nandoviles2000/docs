使用这些 `docs.json` 设置来控制文档站点的视觉风格——包括布局主题、品牌配色、徽标、排版和背景。

<div id="settings">
  ## 设置
</div>

### `theme` - <Badge color="red">required</Badge>

站点的布局主题。

取值之一：`mint`、`maple`、`palm`、`willow`、`linden`、`almond`、`aspen`、`sequoia`、`luma`。

有关预览和详细信息，请参阅 [Themes](/zh/customize/themes)。

***

### `name` - <Badge color="red">必填</Badge>

**Type:** `string`

您的项目、组织或产品的名称。它会显示在浏览器标签页标题以及站点中的其他位置。

***

### `colors` - <Badge color="red">必填</Badge>

**类型：** `object`

文档中使用的颜色。不同主题下的颜色显示效果会有所不同。如果你只提供主色，它会应用于所有配色项。

<ResponseField name="colors.primary" type="string" required>
  文档的主色。通常用于浅色模式下的强调色，具体会因主题而略有不同。

  必须是以 `#` 开头的十六进制代码。示例：`"#0D9373"`。
</ResponseField>

<ResponseField name="colors.light" type="string">
  用于深色模式下强调的颜色。

  必须是以 `#` 开头的十六进制代码。
</ResponseField>

<ResponseField name="colors.dark" type="string">
  用于浅色和深色模式下按钮及悬停状态的颜色，具体会因主题而略有不同。

  必须是以 `#` 开头的十六进制代码。
</ResponseField>

```json docs.json
"colors": {
  "primary": "#0D9373",
  "light": "#55D799",
  "dark": "#0D9373"
}
```

***

<div id="logo">
  ### `logo`
</div>

**类型：** `string` 或 `object`

站点的徽标。你可以提供单个图片路径，或分别为浅色模式和深色模式提供图片。

<ResponseField name="logo.light" type="string" required>
  浅色模式下徽标文件的路径。请包含文件扩展名。示例：`/logo/light.svg`。
</ResponseField>

<ResponseField name="logo.dark" type="string" required>
  深色模式下徽标文件的路径。请包含文件扩展名。示例：`/logo/dark.svg`。
</ResponseField>

<ResponseField name="logo.href" type="string (uri)">
  点击徽标时跳转到的 URL。如果未提供，徽标会链接到当前所选语言区域的[国际化文档](/zh/guides/internationalization)中的第一页；对于单语言站点，则链接到你的主页。示例：`https://yoursite.com`。
</ResponseField>

```json docs.json
"logo": {
  "light": "/logo/light.svg",
  "dark": "/logo/dark.svg",
  "href": "https://yoursite.com"
}
```

***

<div id="favicon">
  ### `favicon`
</div>

**类型：** `string` 或 `object`

网站图标 文件路径，需包含文件扩展名。系统会自动将其调整为合适的 网站图标 尺寸。你可以提供单个文件，也可以分别为浅色模式和深色模式提供单独的文件。

<ResponseField name="favicon.light" type="string" required>
  浅色模式使用的网站图标 路径。请包含文件扩展名。示例：`/favicon.png`。
</ResponseField>

<ResponseField name="favicon.dark" type="string" required>
  深色模式使用的网站图标 路径。请包含文件扩展名。示例：`/favicon-dark.png`。
</ResponseField>

```json docs.json
"favicon": "/favicon.svg"
```

***

<div id="appearance">
  ### `appearance`
</div>

**类型：** `object`

浅色/深色模式设置。

<ResponseField name="appearance.default" type="&#x22;system&#x22; | &#x22;light&#x22; | &#x22;dark&#x22;">
  默认颜色模式。选择 `system` 可与用户的操作系统设置保持一致，选择 `light` 或 `dark` 则会强制使用指定模式。默认为 `system`。
</ResponseField>

<ResponseField name="appearance.strict" type="boolean">
  当设为 `true` 时，会隐藏浅色/深色模式切换开关，用户将无法切换模式。默认为 `false`。
</ResponseField>

```json docs.json
"appearance": {
  "default": "dark",
  "strict": true
}
```

***

<div id="fonts">
  ### `fonts`
</div>

**类型：** `object`

为文档自定义字体。默认字体因主题而异。支持 [Google Fonts](https://fonts.google.com) 和自托管字体。

<ResponseField name="fonts.family" type="string" required>
  字体族名称，例如 `"Inter"` 或 `"Open Sans"`。支持 [Google Fonts](https://fonts.google.com) 的字体族名称，这些字体会自动加载，无需提供 `source`。
</ResponseField>

<ResponseField name="fonts.weight" type="number">
  字重，例如 `400` 或 `700`。可变字体支持 `550` 这类小数权重。
</ResponseField>

<ResponseField name="fonts.source" type="string (uri)">
  托管字体的 URL，或本地字体文件的路径。使用 Google Fonts 时不需要此字段。

  * 托管：`https://example.com/fonts/MyFont.woff2`
  * 本地：`/fonts/MyFont.woff2`
</ResponseField>

<ResponseField name="fonts.format" type="&#x22;woff&#x22; | &#x22;woff2&#x22;">
  字体文件格式。使用 `source` 字段时必填。
</ResponseField>

<ResponseField name="fonts.heading" type="object">
  仅覆盖标题的字体设置。

  接受与顶层 `fonts` 对象相同的 `family`、`weight`、`source` 和 `format` 字段。
</ResponseField>

<ResponseField name="fonts.body" type="object">
  仅覆盖正文的字体设置。

  接受与顶层 `fonts` 对象相同的 `family`、`weight`、`source` 和 `format` 字段。
</ResponseField>

```json docs.json
"fonts": {
  "family": "Inter",
  "heading": {
    "family": "Playfair Display"
  }
}
```

***

<div id="icons">
  ### `icons`
</div>

**Type:** `object`

图标库设置。每个项目只能使用一个图标库。文档中的所有图标名称都必须来自所选图标库。

<ResponseField name="icons.library" type="&#x22;fontawesome&#x22; | &#x22;lucide&#x22; | &#x22;tabler&#x22;" required>
  整个文档使用的图标库。默认值为 `fontawesome`。

  <Note>
    无论图标库设置为何，你都可以为任意单个图标指定外部托管图标的 URL，或项目中图标文件的路径。
  </Note>
</ResponseField>

```json docs.json
"icons": {
  "library": "lucide"
}
```

***

<div id="background">
  ### `background`
</div>

**类型：** `object`

背景图片、装饰和颜色设置。

<ResponseField name="background.decoration" type="&#x22;gradient&#x22; | &#x22;grid&#x22; | &#x22;windows&#x22;">
  主题的装饰性背景图案。
</ResponseField>

<ResponseField name="background.color" type="object">
  自定义浅色和深色模式的背景颜色。

  <Expandable title="background.color">
    <ResponseField name="light" type="string">
      浅色模式的背景颜色。必须是以 `#` 开头的十六进制颜色代码。
    </ResponseField>

    <ResponseField name="dark" type="string">
      深色模式的背景颜色。必须是以 `#` 开头的十六进制颜色代码。
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="background.image" type="string or object">
  站点的背景图片。可提供单一路径，或分别为浅色和深色模式提供不同路径。

  <Expandable title="background.image">
    <ResponseField name="light" type="string" required>
      浅色模式背景图片的路径。示例：`/background.png`。
    </ResponseField>

    <ResponseField name="dark" type="string" required>
      深色模式背景图片的路径。示例：`/background-dark.png`。
    </ResponseField>
  </Expandable>
</ResponseField>

```json docs.json
"background": {
  "decoration": "gradient",
  "color": {
    "light": "#F8FAFC",
    "dark": "#0F172A"
  }
}
```

***

<div id="styling">
  ### `styling`
</div>

**类型：** `object`

细粒度的视觉样式控制选项。

<ResponseField name="styling.eyebrows" type="&#x22;section&#x22; | &#x22;breadcrumbs&#x22;">
  页面页眉标签的样式 (显示在页面顶部的标签) 。选择 `section` 可显示章节名称，选择 `breadcrumbs` 可显示完整的导航路径。默认值为 `section`。
</ResponseField>

<ResponseField name="styling.latex" type="boolean">
  控制是否加载 LaTeX 样式表。默认情况下，Mintlify 会自动检测内容中是否使用了 LaTeX，并加载所需的样式表。

  * 设置为 `true` 可在自动检测失效时强制加载 LaTeX 样式表。
  * 如果你不使用数学公式，设置为 `false` 可禁止加载 LaTeX 样式表，以提升性能。
</ResponseField>

<ResponseField name="styling.codeblocks" type="&#x22;system&#x22; | &#x22;dark&#x22; | string | object">
  代码块主题。默认值为 `"system"`。

  * `"system"`：匹配当前站点模式 (浅色或深色)
  * `"dark"`：始终使用深色模式
  * [Shiki 主题](https://shiki.style/themes)名称字符串：将该主题应用到所有代码块
  * 包含 `light` 和 `dark` 键的对象：为不同模式分别应用不同的 Shiki 主题

  <Expandable title="styling.codeblocks object">
    <ResponseField name="theme" type="string">
      同时用于两种模式的单个 Shiki 主题。

      ```json
      "styling": {
        "codeblocks": {
          "theme": "dracula"
        }
      }
      ```
    </ResponseField>

    <ResponseField name="theme" type="object">
      分别用于浅色和深色模式的 Shiki 主题。

      <Expandable title="theme">
        <ResponseField name="light" type="string" required>
          浅色模式使用的 Shiki 主题名称。
        </ResponseField>

        <ResponseField name="dark" type="string" required>
          深色模式使用的 Shiki 主题名称。
        </ResponseField>
      </Expandable>

      ```json
      "styling": {
        "codeblocks": {
          "theme": {
            "light": "github-light",
            "dark": "github-dark"
          }
        }
      }
      ```
    </ResponseField>

    <ResponseField name="languages" type="object">
      代码块的自定义语言配置。

      <Expandable title="languages">
        <ResponseField name="custom" type="array of string">
          指向描述自定义 Shiki 语言的 JSON 文件路径。使用此项可为不在 Shiki 默认集合中的语言添加语法高亮。每个文件都必须遵循 [TextMate 语法格式](https://macromates.com/manual/en/language_grammars)。

          ```json
          "styling": {
            "codeblocks": {
              "languages": {
                "custom": ["/languages/my-language.json"]
              }
            }
          }
          ```
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

***

<div id="thumbnails">
  ### `thumbnails`
</div>

**类型：** `object`

用于社交媒体和页面预览的缩略图自定义设置。

<ResponseField name="thumbnails.appearance" type="&#x22;light&#x22; | &#x22;dark&#x22;">
  缩略图的视觉主题。若未设置，缩略图将使用你在 `colors` 中为站点定义的配色方案。
</ResponseField>

<ResponseField name="thumbnails.background" type="string">
  缩略图的背景图片。可以是相对路径或绝对 URL。
</ResponseField>

<ResponseField name="thumbnails.fonts" type="object">
  缩略图的字体配置。仅支持 Google Fonts 字体家族名称。

  <Expandable title="thumbnails.fonts">
    <ResponseField name="family" type="string" required>
      字体族名称，例如 `"Open Sans"` 或 `"Playfair Display"`。支持 [Google Fonts](https://fonts.google.com) 字体族名称。
    </ResponseField>
  </Expandable>
</ResponseField>

<div id="example">
  ## 示例
</div>

```json docs.json
{
  "$schema": "https://mintlify.com/docs.json",
  "theme": "maple",
  "name": "Example Co.",
  "colors": {
    "primary": "#3B82F6",
    "light": "#93C5FD",
    "dark": "#1D4ED8"
  },
  "logo": {
    "light": "/logo/light.svg",
    "dark": "/logo/dark.svg",
    "href": "https://example.com"
  },
  "favicon": "/favicon.svg",
  "appearance": {
    "default": "system"
  },
  "fonts": {
    "family": "Inter"
  },
  "icons": {
    "library": "lucide"
  },
  "background": {
    "decoration": "gradient"
  }
}
```
