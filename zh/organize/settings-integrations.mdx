使用 `docs.json` 中的 `integrations` 字段，将第三方分析平台、聊天工具和其他服务接入你的文档站点。

<div id="settings">
  ## 设置
</div>

在 `docs.json` 文件中，将所有集成都配置在 `integrations` 对象下作为属性：

```json docs.json
"integrations": {
  "ga4": {
    "measurementId": "G-XXXXXXXXXX"
  }
}
```

<div id="example">
  ## 示例
</div>

```json docs.json
"integrations": {
  "ga4": {
    "measurementId": "G-XXXXXXXXXX"
  },
  "posthog": {
    "apiKey": "phc_XXXXXXXXXX"
  },
  "intercom": {
    "appId": "abc12345"
  },
  "telemetry": {
    "enabled": true
  }
}
```
