[llms.txt 文件](https://llmstxt.org)是一项行业标准，可帮助 LLM 更高效地索引内容，类似于站点地图对搜索引擎的作用。AI 工具可以使用此文件来理解您的文档结构，并找到与用户查询相关的内容。

Mintlify 会自动在您项目的根目录托管一个 `llms.txt` 文件，其中列出了文档中所有可用的页面。该文件始终保持最新，无需任何维护。您也可以选择在项目根目录添加自定义 `llms.txt` 文件。

<Note>
  如果您的站点需要身份验证，那么查看 `llms.txt` 和 `llms-full.txt` 也同样需要身份验证。无法通过身份验证访问您站点的 LLM 和 AI 工具将无法访问这些文件。这些文件不会包含属于[用户组](/zh/deploy/authentication-setup#control-access-with-groups)的页面。

  如需了解身份验证如何影响 AI 功能的更多信息，请参阅[功能可用性](/zh/deploy/authentication-setup#feature-availability)。
</Note>

如需查看您的 `llms.txt`，请在文档站点的 URL 后追加 `/llms.txt`。Mintlify 还会在 `/.well-known/llms.txt` 托管该文件，以兼容遵循 `.well-known` 约定的工具。

<PreviewButton href="https://mintlify.com/docs/llms.txt">打开此站点的 llms.txt。</PreviewButton>

Mintlify 会为每个页面响应添加 HTTP 标头，因此 AI 工具无需预先知道 `llms.txt` 文件的位置，也能发现这些文件：

* `Link: </llms.txt>; rel="llms-txt", </llms-full.txt>; rel="llms-full-txt"`：遵循标准 HTTP `Link` 标头的资源发现格式。
* `X-Llms-Txt: /llms.txt`：为会检查 `llms.txt` 支持情况的工具提供的便捷标头。

<div id="llmstxt-structure">
  ## llms.txt 结构
</div>

`llms.txt` 文件是一个纯 Markdown 文件，包含：

* 以 H1 标题显示的**站点标题**。
* 标题下方以块引用摘要形式呈现的**站点描述**，来自你的 `docs.json` 配置中的 `description` 字段。
* **结构化的内容分区**，包含链接以及文档中每个页面的描述。
* **API 规范链接**，指向你的 OpenAPI 和 AsyncAPI 规范 (如果文档中包含它们) 。

`llms.txt` 文件会从根目录开始，按照页面在仓库中出现的顺序，按字母顺序列出你的页面。`llms.txt` 文件中的页面链接带有 `.md` 扩展名，因此 AI 工具可以直接获取每个页面的 Markdown 版本。

每个页面的描述都来自其 frontmatter 中的 `description` 字段。描述会在达到 300 个字符或遇到第一个换行符时截断。对于 API 参考页面，描述还会包含 `openapi` 或 `api` frontmatter 字段中的规范信息。没有 `description` 字段的页面也会出现在 `llms.txt` 文件中，但不会附带描述。

这种结构化方式让 LLM 能够高效地从整体层面处理你的文档，并针对用户查询定位相关内容，从而提升 AI 辅助文档搜索的准确性和速度。

```mdx Example llms.txt
# Site title

> A brief description of the documentation site.

## Docs

- [API](https://example.com/docs/api.md): Endpoint list and usage
- [Install](https://example.com/docs/install.md): Setup steps
- [Getting started](https://example.com/docs/start.md): Intro guide

## OpenAPI Specs

- [openapi](https://example.com/docs/openapi.json)

## AsyncAPI Specs

- [asyncapi](https://example.com/docs/asyncapi.yaml)
```

<div id="llms-fulltxt">
  ## llms-full.txt
</div>

`llms-full.txt` 文件会将你的整个文档站点整合为单个文件，作为 AI 工具和 LLM 建立索引时的上下文。

Mintlify 会自动在你项目的根目录托管一个 `llms-full.txt` 文件。要查看你的 `llms-full.txt`，请在文档站点的 URL 后追加 `/llms-full.txt`。Mintlify 还会在 `/.well-known/llms-full.txt` 托管该文件，以兼容遵循 `.well-known` 约定的工具。

<PreviewButton href="https://mintlify.com/docs/llms-full.txt">打开此站点的 llms-full.txt。</PreviewButton>

<div id="custom-files">
  ## 自定义文件
</div>

要添加自定义 `llms.txt` 或 `llms-full.txt` 文件，请在项目根目录创建 `llms.txt` 或 `llms-full.txt` 文件。添加自定义文件后，会覆盖自动生成的同名文件。如果删除自定义文件，Mintlify 会恢复自动生成的文件。

你的自定义 `llms.txt` 或 `llms-full.txt` 文件必须使用站点标题作为 H1 标题。其他内容可选。有关可选章节和最佳实践的更多信息，请参阅 `llms.txt` 规范中的 [Format](https://llmstxt.org/#format)。
