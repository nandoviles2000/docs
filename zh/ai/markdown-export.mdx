Markdown 提供的是结构化文本，AI 工具处理起来比 HTML 更高效，因此能够提高响应准确性、加快处理速度，并降低 token 用量。

Mintlify 会自动生成面向 AI 工具和外部集成优化的页面 Markdown 版本。

<div id="md-url-extension">
  ## `.md` URL 扩展名
</div>

在任意页面的 URL 后添加 `.md`，即可查看其 Markdown 版本。

<PreviewButton href="https://mintlify.com/docs/ai/markdown-export.md">以 Markdown 格式打开此页面</PreviewButton>

<div id="accept-header">
  ## Accept 请求头
</div>

向任意页面 URL 发送包含 `Accept: text/markdown` 或 `Accept: text/plain` 的请求，即可获取 Markdown 版本，而不是 HTML 版本。这对于以编程方式抓取文档内容的 AI 工具和集成非常有用。

```bash
curl -H "Accept: text/markdown" https://mintlify.com/docs/ai/markdown-export
```

<div id="audience-specific-content">
  ## 面向不同受众的内容
</div>

使用 [visibility](/zh/components/visibility) 组件，分别为人类受众和 AI 受众定制内容。

包裹在 `<Visibility for="humans">` 中的内容会显示在网页上，但不会出现在 Markdown 输出中。包裹在 `<Visibility for="agents">` 中的内容会出现在 Markdown 输出中，但不会显示在网页上。

```mdx
<Visibility for="humans">
  Click the **Get started** button in the top-right corner to create your account.
</Visibility>

<Visibility for="agents">
  To create an account, call `POST /v1/accounts` with a valid email address.
</Visibility>
```

<div id="agent-feedback">
  ## 智能体反馈
</div>

如果启用[智能体反馈](/zh/optimize/feedback#agent-feedback)，Mintlify 会在每个页面导出的 Markdown 中附加一个 `<AgentInstructions>` 块，说明智能体应如何针对页面内容提交反馈。

智能体会通过向该端点发送页面路径和反馈文本来提交反馈。

你可以利用智能体反馈，根据它们发现的不准确、过时或令人困惑的内容改进页面，使页面更适合智能体使用。

<div id="keyboard-shortcut">
  ## 键盘快捷键
</div>

按 <kbd>Command</kbd> + <kbd>C</kbd> (Windows 上为 <kbd>Ctrl</kbd> + <kbd>C</kbd>) 即可将页面以 Markdown 格式复制到剪贴板。
