<div id="what-you-will-build">
  ## 您将构建的内容
</div>

一个可复用的小组件，可将[助手](/zh/assistant/index)直接嵌入您的应用中。该小组件提供：

* 一个浮动按钮，点击后即可打开聊天面板
* 基于您的文档内容实时流式生成的响应
* 支持 Markdown 的消息渲染

用户无需离开应用，即可通过该小组件获取您产品的相关帮助。

  <img src="/images/assistant/assistant-embed-demo.gif" alt="演示助手小组件的打开过程，以及用户输入“如何开始？”后助手作出回复。" />
</Frame>

<div id="prerequisites">
  ## 前提条件
</div>

* [Mintlify Pro 或 Enterprise 套餐](https://mintlify.com/pricing)
* 您的域名，即仪表板 URL 末尾显示的名称。例如，如果您的仪表板 URL 是 `https://dashboard.mintlify.com/org-name/domain-name`，那么您的域名就是 `domain-name`
* [助手 API 密钥](https://dashboard.mintlify.com/settings/organization/api-keys)
* 已安装 Node.js v18 或更高版本，以及 npm
* 具备基本的 React 知识

<div id="get-your-assistant-api-key">
  ### 获取助手 API 密钥
</div>

1. 在仪表板中前往 [API keys](https://dashboard.mintlify.com/settings/organization/api-keys) 页面。
2. 点击 **Create Assistant API Key**。
3. 复制助手 API 密钥 (以 `mint_dsc_` 开头) 并妥善保存。

<Note>
  助手 API 密钥是一种可在前端代码中使用的公开令牌。使用此令牌发起的调用会计入你当前套餐的消息额度，并可能产生超额费用。
</Note>

<div id="set-up-the-example">
  ## 设置示例项目
</div>

克隆[示例仓库](https://github.com/mintlify/assistant-embed-example)，并按需进行自定义。

<Steps>
  <Step title="克隆仓库">
    ```bash
    git clone https://github.com/mintlify/assistant-embed-example.git
    cd assistant-embed-example
    ```
  </Step>

  <Step title="选择开发工具">
    该仓库包含 Next.js 和 Vite 示例。选择你想使用的工具。

    <CodeGroup>
      ```bash title="Next.js"
      cd nextjs
      npm install
      ```

      ```bash title="Vite"
      cd vite
      npm install
      ```
    </CodeGroup>
  </Step>

  <Step title="配置项目">
    打开 `src/config.js`，更新为你的 Mintlify 项目详细信息。

    ```js src/config.js
    export const ASSISTANT_CONFIG = {
      domain: 'your-domain',
      docsURL: 'https://yourdocs.mintlify.app',
    };
    ```

    替换以下内容：

    * 将 `your-domain` 替换为你的 Mintlify 项目域名，可在仪表板 URL 的末尾找到。
    * 将 `https://yourdocs.mintlify.app` 替换为你的实际文档 URL。
  </Step>

  <Step title="添加 API 令牌">
    在项目根目录下创建一个 `.env` 文件。

    ```bash .env
    VITE_MINTLIFY_TOKEN=mint_dsc_your_token_here
    ```

    将 `mint_dsc_your_token_here` 替换为你的助手 API 密钥。
  </Step>

  <Step title="启动开发服务器">
    ```bash
    npm run dev
    ```

    在浏览器中打开你的应用，然后点击 **Ask** 按钮以打开助手小组件。
  </Step>
</Steps>

<div id="source-citations">
  ### 引用来源
</div>

从助手回复中提取并显示来源：

```jsx
const extractSources = (parts) => {
  return parts
    ?.filter(p => p.type === 'tool-invocation' && p.toolInvocation?.toolName === 'search')
    .flatMap(p => p.toolInvocation?.result || [])
    .map(source => ({
      url: source.url || source.path,
      title: source.metadata?.title || source.path,
    })) || [];
};

// 在消息渲染中：
{messages.map((message) => {
  const sources = message.role === 'assistant' ? extractSources(message.parts) : [];
  return (
    <div key={message.id}>
      {/* 消息内容 */}
      {sources.length > 0 && (
        <div className="mt-2 text-xs">
          <p className="font-semibold">Sources:</p>
          {sources.map((s, i) => (
            <a key={i} href={s.url} target="_blank" rel="noopener noreferrer" className="text-blue-600">
              {s.title}
            </a>
          ))}
        </div>
      )}
    </div>
  );
})}
```

<div id="track-conversation-threads">
  ### 跟踪对话线程
</div>

存储线程 ID 和线程密钥，以便在不同会话之间保留对话历史。

当用户创建新的对话线程时，服务器会在响应头中返回两个值：

* `X-Thread-Id`：线程标识符
* `X-Thread-Key`：线程的密钥 (仅在线程创建时返回一次)

你必须在第一次响应时获取并持久化这两个值。此后的每条消息都要在请求体中同时包含 `threadId` 和 `threadKey`。如果你发送了 `threadId`，却没有提供对应的 `threadKey`，服务器会返回 `404` 错误。

<Warning>
  你必须立即存储 `X-Thread-Key` 响应头。服务器只会在线程创建时返回它一次，之后无法再次获取。
</Warning>

```jsx
import { useState, useEffect } from 'react';

export function AssistantWidget({ domain, docsURL }) {
  const [threadId, setThreadId] = useState(null);
  const [threadKey, setThreadKey] = useState(null);

  useEffect(() => {
    // 从 localStorage 中读取已保存的线程 ID 和密钥
    const savedId = localStorage.getItem('assistant-thread-id');
    const savedKey = localStorage.getItem('assistant-thread-key');
    if (savedId && savedKey) {
      setThreadId(savedId);
      setThreadKey(savedKey);
    }
  }, []);

  const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat({
    api: `https://api.mintlify.com/discovery/v1/assistant/${domain}/message`,
    headers: {
      'Authorization': `Bearer ${import.meta.env.VITE_MINTLIFY_TOKEN}`,
    },
    body: {
      fp: 'anonymous',
      retrievalPageSize: 5,
      ...(threadId && { threadId }),
      ...(threadKey && { threadKey }),
    },
    streamProtocol: 'data',
    sendExtraMessageFields: true,
    fetch: async (url, options) => {
      const response = await fetch(url, options);
      const newThreadId = response.headers.get('x-thread-id');
      const newThreadKey = response.headers.get('x-thread-key');
      if (newThreadId) {
        setThreadId(newThreadId);
        localStorage.setItem('assistant-thread-id', newThreadId);
      }
      if (newThreadKey) {
        setThreadKey(newThreadKey);
        localStorage.setItem('assistant-thread-key', newThreadKey);
      }
      return response;
    },
  });

  // ... 组件其余部分
}
```

<div id="add-keyboard-shortcuts">
  ### 添加键盘快捷键
</div>

允许用户通过键盘快捷键打开小组件并发送消息：

```jsx
useEffect(() => {
  const handleKeyDown = (e) => {
    // Cmd/Ctrl + Shift + I 切换小组件
    if ((e.metaKey || e.ctrlKey) && e.shiftKey && e.key === 'I') {
      e.preventDefault();
      setIsOpen((prev) => !prev);
    }

    // Enter（小组件获得焦点时）提交
    if (e.key === 'Enter' && !e.shiftKey && document.activeElement.id === 'assistant-input') {
      e.preventDefault();
      handleSubmit();
    }
  };

  window.addEventListener('keydown', handleKeyDown);
  return () => window.removeEventListener('keydown', handleKeyDown);
}, [handleSubmit]);
```
