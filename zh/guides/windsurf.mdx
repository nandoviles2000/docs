<div id="use-windsurf-with-mintlify">
  ## 将 Windsurf 与 Mintlify 配合使用
</div>

可以对 Windsurf 的 Cascade AI 助手进行配置，使其能够使用 Mintlify 组件，按照你的标准编写文档。工作区规则和记忆可为你的项目提供持续的上下文，从而让 Cascade 给出的建议更加一致。

* **工作区规则** 存储在你的文档仓库中，并可与你的团队共享。
* **记忆** 提供会随着时间逐渐积累的个人上下文。

我们建议你为团队共用的文档标准设置工作区规则。你也可以在工作过程中逐步积累记忆，但由于它们不会共享，因此无法在团队成员之间保持一致。

在文档仓库的 `.windsurf/rules` 目录中创建工作区规则。更多信息，请参阅 Windsurf 文档中的 [Memories &amp; Rules](https://docs.windsurf.com/windsurf/cascade/memories)。

<div id="example-workspace-rule">
  ## 示例工作区规则
</div>

此规则可为 Cascade 提供有关 Mintlify 组件和通用技术写作最佳实践的上下文。

你可以直接使用这条示例规则，也可以根据你的文档进行自定义：

* **写作标准**：更新语言指南，使其符合你的风格指南。
* **组件模式**：添加项目特定的组件，或修改现有示例。
* **代码示例**：将通用示例替换为适用于你产品的真实 API 调用和响应。
* **风格和语气偏好**：调整术语、格式和其他规则。

将你的规则保存为 `.md` 文件，并存放在文档仓库的 `.windsurf/rules` 目录中。

````mdx
# Mintlify 技术写作规则

## 项目背景

- 这是一个基于 Mintlify 平台的文档项目
- 我们使用带有 YAML frontmatter 的 MDX 文件
- 导航在 `docs.json` 中配置
- 我们遵循技术写作最佳实践

## 写作规范

- 使用第二人称（"您"）撰写说明
- 使用主动语态和现在时
- 在步骤开始前说明前提条件
- 为主要步骤说明预期结果
- 使用描述性强、富含关键词的标题
- 保持句子简洁且信息充实

## 页面必要结构

每个页面必须以 frontmatter 开头：

```yaml
---
title: "Clear, specific title"
description: "Concise description for SEO and navigation"
---
```

## Mintlify 组件

### docs.json

- 构建 docs.json 文件和站点导航时，请参阅 [docs.json schema](https://mintlify.com/docs.json)

### 标注组件

- `<Note>` 用于有用的补充信息
- `<Warning>` 用于重要警告和破坏性变更
- `<Tip>` 用于最佳实践和专家建议
- `<Info>` 用于中性的背景信息
- `<Check>` 用于成功确认

### 代码示例

- 在适当情况下，提供完整且可运行的示例
- 使用 `<CodeGroup>` 展示多语言示例
- 为所有代码块指定语言标签
- 使用真实数据，而非占位符
- 在 API 文档中使用 `<RequestExample>` 和 `<ResponseExample>`

### 操作步骤

- 使用 `<Steps>` 组件呈现顺序操作说明
- 在适当情况下，使用 `<Check>` 组件添加验证步骤
- 将复杂流程拆分为更小的步骤

### 内容组织

- 使用 `<Tabs>` 展示平台特定内容
- 使用 `<Accordion>` 实现渐进式信息展示
- 使用 `<Card>` 和 `<CardGroup>` 突出显示内容
- 将图片包裹在 `<Frame>` 组件中，并添加描述性替代文本

## API 文档要求

- 使用 `<ParamField>` 记录所有参数
- 使用 `<ResponseField>` 展示响应结构
- 同时提供成功和错误示例
- 使用 `<Expandable>` 展示嵌套对象属性
- 始终包含身份验证示例

## 质量标准

- 发布前测试所有代码示例
- 内部链接使用相对路径
- 为所有图片添加替代文本
- 确保标题层级正确（从 h2 开始）
- 参照现有模式保持一致性
````

<div id="working-with-cascade">
  ## 使用 Cascade
</div>

设置好规则后，你就可以使用 Cascade 协助处理各种文档任务。更多信息请参阅 Windsurf 文档中的 [Cascade](https://docs.windsurf.com/windsurf/cascade)。

<div id="example-prompts">
  ### 示例提示词
</div>

**撰写新内容**：

```text wrap
Create a new page explaining how to authenticate with our API. Include code examples in JavaScript, Python, and cURL.
```

**改进现有内容**：

```text wrap
Review this page and suggest improvements for clarity and component usage. Focus on making the steps easier to follow.
```

**创建代码示例**：

```text wrap
生成一个完整的代码示例，展示此 API 端点的错误处理方式。使用真实数据并包含预期响应。
```

**保持一致**：

```text wrap
Check if this new page follows our documentation standards and suggest any needed changes.
```

<div id="enhance-with-mcp-server">
  ## 通过 MCP server 增强功能
</div>

将 Mintlify MCP server 连接到 Windsurf，让 Cascade 在协助你编写内容时可以搜索 Mintlify 文档。连接 MCP server 后，Cascade 会从最新的 Mintlify 文档中检索相关上下文，这样你无需离开 IDE 即可查阅文档。

完整设置说明请参阅 [Model Context Protocol](/zh/ai/model-context-protocol#example%3A-connect-to-the-mintlify-mcp-server)。
