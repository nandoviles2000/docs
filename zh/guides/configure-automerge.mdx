---
title: "为 GitHub Apps 配置自动合并"
sidebarTitle: "配置自动合并"
description: "将 Mintlify 机器人添加到仓库规则集的绕过列表中，以设置 GitHub 工作流来自动合并 Mintlify 拉取请求（PR）。"
keywords: ["自动合并", "规则集", "分支保护", "绕过"]
---

将 Mintlify GitHub App 添加到规则集的绕过列表，这样该应用就能在不受审核和状态检查要求限制的情况下创建并合并拉取请求 (PR) 。这样，您就可以配置[工作流](/zh/guides/automate-agent)，自动将更改合并到 `main`。

<Note>
  Mintlify GitHub App 必须在**所有**以您的部署分支为目标的规则集中都具有绕过权限，包括组织级和仓库级定义的规则集。只要有任一规则集缺少该绕过条目，工作流就会创建 PR，但不会将其合并。
</Note>

<div id="prerequisites">
  ## 前提条件
</div>

* 拥有仓库管理员权限 (如果存在组织级规则集，还需要组织管理员权限)
* 已在仓库中安装 [Mintlify GitHub App](/zh/deploy/github)
* 已有一个或多个以 `main` 分支为目标的规则集 (组织级或仓库级)

<div id="steps">
  ## 步骤
</div>

对所有适用于你的部署分支的规则集重复以下步骤，包括**组织级**和**仓库级**规则集。

<Steps>
  <Step title="前往规则集">
    * **仓库规则集**：在 GitHub 上，前往你的仓库 **Settings** -&gt; **Rules** -&gt; **Rulesets**。
    * **组织规则集**：前往你的组织 **Settings** -&gt; **Rules** -&gt; **Rulesets**。
  </Step>

  <Step title="选择规则集">
    点击针对你的部署分支的规则集，通常为 `main`。
  </Step>

  <Step title="将 Mintlify GitHub App 添加到绕过列表">
    1. 在 **Bypass list** 下，点击 **Add bypass**。
    2. 搜索并选择 Mintlify GitHub App。
    3. 将绕过模式设为 **Always**。
  </Step>

  <Step title="保存">
    点击 **Save changes**。
  </Step>

  <Step title="对其余规则集重复此操作">
    如果你还有其他组织级或仓库级规则集针对你的部署分支，请对每个规则集重复步骤 2–4。
  </Step>
</Steps>

<div id="verify-the-setup">
  ## 验证设置
</div>

1. **对于贡献者**：创建一个以 `main` 为目标分支的 PR。确认在合并前，仍需先获得审批并通过状态检查。
2. **对于工作流**：触发一个启用了自动合并的工作流。确认该工作流能够正常运行，并成功合并 PR。
