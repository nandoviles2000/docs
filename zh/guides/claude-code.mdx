Claude Code 是一款具备智能体式的能力的命令行工具，可帮助你维护文档。它可以编写新内容、审核现有页面，并使文档保持最新状态。

你可以通过在项目中添加 `CLAUDE.md` 文件并持续完善它，让 Claude Code 理解你的文档标准和工作流。

<div id="getting-started">
  ## 开始使用
</div>

**前提条件：**

* 已开通 Claude 订阅 (Pro、Max 或 API 访问) 

**设置：**

1. 安装 Claude Code：

```bash
  npm install -g @anthropic-ai/claude-code
```

2. 进入你的文档目录。
3.  (可选) 将下面的 `CLAUDE.md` 文件添加到你的项目中。
4. 运行 `claude` 开始使用。

<div id="claudemd-template">
  ## CLAUDE.md 模板
</div>

将 `CLAUDE.md` 文件保存在文档目录的根目录下，帮助 Claude Code 理解你的项目。该文件可让 Claude Code 学习你的文档标准、偏好和工作流。更多信息，请参阅 Anthropic 文档中的 [Manage Claude&#39;s memory](https://docs.anthropic.com/en/docs/claude-code/memory)。

复制此示例模板，或按你的文档规范进行修改：

```mdx
# Mintlify 文档

## 协作关系
- 你可以对想法提出异议——这有助于写出更好的文档。提出异议时请引用来源并说明理由
- 务必寻求澄清，而非自行假设
- 绝不撒谎、猜测或捏造任何内容

## 项目背景
- 格式：带有 YAML frontmatter 的 MDX 文件
- 配置：docs.json，用于导航、主题和设置
- 组件：Mintlify 组件

## 内容策略
- 文档内容以满足用户需求为准——不多不少
- 优先保证准确性和可用性
- 尽量使内容保持长期有效
- 添加新内容前先搜索现有内容，除非出于策略性原因，否则避免重复
- 检查现有模式以保持一致性
- 从最小合理改动开始

## docs.json

- 构建 docs.json 文件和站点导航时，请参考 [docs.json schema](https://mintlify.com/docs.json)

## 页面 frontmatter 要求
- title：清晰、具有描述性的页面标题
- description：用于 SEO/导航的简洁摘要

## 写作规范
- 使用第二人称（"你"）
- 在操作性内容开头列出前提条件
- 发布前测试所有代码示例
- 与现有页面的风格和格式保持一致
- 同时涵盖基础和高级用例
- 所有代码块添加语言标签
- 所有图片添加替代文本
- 内部链接使用相对路径

## Git 工作流
- 提交时绝不使用 --no-verify
- 开始前询问如何处理未提交的更改
- 若没有明确的分支用于变更，则创建新分支
- 在开发过程中频繁提交
- 绝不跳过或禁用 pre-commit hooks

## 禁止事项
- 在任何 MDX 文件中省略 frontmatter
- 对内部链接使用绝对 URL
- 包含未经测试的代码示例
- 自行假设——务必寻求澄清
```

<div id="extend-claude-code">
  ## 扩展 Claude Code
</div>

除了手动向 Claude Code 发送提示外，您还可以将其集成到现有工作流中。

<div id="automate-with-github-actions">
  ### 使用 GitHub Actions 实现自动化
</div>

在代码发生变更时自动运行 Claude Code，确保文档始终保持最新。你可以在拉取请求 (PR) 中触发文档审查，或在检测到 API 变更时更新示例。

<div id="multi-instance-workflows">
  ### 多实例工作流
</div>

针对不同任务使用独立的 Claude Code 会话——一个用于编写新内容，另一个用于评审和质量保障。这样有助于保持一致性，并发现单个会话可能遗漏的问题。

<div id="team-collaboration">
  ### 团队协作
</div>

与团队共享你完善后的 `CLAUDE.md` 文件，确保所有贡献者遵循一致的文档规范。团队通常会形成项目特定的提示词和工作流，并将其纳入文档编写流程。

<div id="custom-commands">
  ### 自定义命令
</div>

在 `.claude/commands/` 中创建可复用的斜杠命令，用于执行项目或团队中常用的文档任务。

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="使用 Mintlify 搭配 Claude Code 时，我必须要有 CLAUDE.md 文件吗？">
    不需要，但它能显著提升输出质量。没有 CLAUDE.md 时，Claude Code 会根据通用上下文运行，可能无法遵循你的特定风格指南、组件偏好或术语规范。CLAUDE.md 文件可以让 Claude Code 了解你项目的标准，这样你就不必在每次提示中重复说明这些内容。
  </Accordion>

  <Accordion title="对于文档工作，Claude Code 与 Cursor 或 Windsurf 有什么区别？">
    Claude Code 是一款命令行工具，专为跨整个代码仓库执行智能体式的多步骤任务而设计。它非常适合处理这类任务：检查所有页面中缺失的 alt 文本、在每个代码示例中更新某个参数名，或审核一组文件的一致性。Cursor 和 Windsurf 则是基于 IDE 的工具，更适合借助内联建议编辑单个文件。两种方式都可行——具体选哪一种，取决于你的工作是逐个文件处理，还是需要覆盖整个仓库。
  </Accordion>

  <Accordion title="我可以使用 Claude Code 根据代码自动生成文档吗？">
    可以。Claude Code 可以读取你的源代码并生成对应的文档。你可以让它处理某个 API 端点、配置文件或一组函数，并要求它按照你的 CLAUDE.md 标准生成相应文档。请务必审核并完善输出内容——当你把 Claude Code 视为初稿撰写者而不是最终发布者时，自动生成的效果最好。
  </Accordion>

  <Accordion title="如何与团队共享我的 CLAUDE.md 配置？">
    将 CLAUDE.md 文件提交到你的文档仓库中。任何克隆该仓库并运行 Claude Code 的人，都会自动使用你项目的配置。这样一来，无需每个人单独设置自己的上下文，所有贡献者也能遵循一致的文档标准。
  </Accordion>
</AccordionGroup>
