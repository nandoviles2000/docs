Mintlify 的 headless 模式让你在使用 Mintlify 管理内容的同时，自行控制文档的外观和行为。你无需使用 Mintlify 托管的前端，而是可以用 [Astro](https://astro.build) 构建自己的前端，并按需渲染 MDX 内容和 `docs.json` 配置。

如果你需要完全掌控文档的设计、布局或行为，以适配现有设计系统，或将文档嵌入更大型的网站中，同时仍继续使用 Mintlify 的发布、搜索、MDX 组件和 AI 功能，那么这种 headless 方式会非常适合。

`@mintlify/astro` 集成会在构建时读取你的 `docs.json` 配置和 MDX 内容，再将其处理为 Astro 可渲染的格式。你可以在此基础上构建自己的布局、组件和样式。

本指南将带你使用入门模板设置一个 headless Mintlify 项目，并在本地运行它。

  | 布局和样式                                       | 自定义构建 | 包括页眉、页脚、侧边栏、目录、页面模板以及所有 CSS。入门模板中包含使用 Tailwind CSS 构建的示例。                                                     |

<div id="prerequisites">
  ## 前置条件
</div>

* 一个 [Mintlify 账户](https://dashboard.mintlify.com)
* 一个 [GitHub 账户](https://github.com)
* [Node.js](https://nodejs.org) v20.17.0 或更高版本 (推荐使用 LTS 版本)
* 熟悉 [Astro](https://docs.astro.build)

<div id="set-up-your-project">
  ## 设置项目
</div>

<Steps>
  <Step title="使用入门模板创建仓库">
    前往 GitHub 上的 [mintlify-astro-starter](https://github.com/mintlify/mintlify-astro-starter) 仓库，点击 **Use this template**，在你的账户下创建一个新仓库。

    将该仓库克隆到本地。
  </Step>

  <Step title="注册 Mintlify">
    如果你还没有 Mintlify 账户，请前往 [dashboard.mintlify.com/signup](https://dashboard.mintlify.com/signup) 注册。
  </Step>

  <Step title="安装 GitHub 应用">
    在 Mintlify 仪表板的 [Git settings](https://dashboard.mintlify.com/settings/deployment/git-settings) 页面中，安装 [Mintlify GitHub app](/zh/deploy/github)。如果你已经安装了该应用，请先卸载再重新安装，以便连接新仓库。
  </Step>

  <Step title="连接你的仓库">
    1. 在 [Git settings](https://dashboard.mintlify.com/settings/deployment/git-settings) 页面中，选择你通过入门模板创建的仓库。
    2. 启用 **Set up as monorepo** 开关。
    3. 输入 `/docs`，作为包含 `docs.json` 文件的目录路径。
    4. 点击 **Save changes**。

    <Frame>
      <img src="/images/guides/astro/repo-settings-light.png" alt="Git settings 页面中的仓库设置。" className="block dark:hidden" />

      <img src="/images/guides/astro/repo-settings-dark.png" alt="Git settings 页面中的仓库设置。" className="hidden dark:block" />
    </Frame>
  </Step>

  <Step title="配置环境变量">
    在本地克隆你的新仓库，并在项目根目录创建一个 `.env` 文件，填入你的 Mintlify 凭据：

    ```bash .env
    PUBLIC_MINTLIFY_SUBDOMAIN=your-subdomain
    PUBLIC_MINTLIFY_ASSISTANT_KEY=your-assistant-api-key
    ```

    你的子域名就是项目域名中组织名称后面的那一部分。例如，如果你的仪表板 URL 是 `https://dashboard.mintlify.com/org-name/domain-name`，那么你的子域名就是 `domain-name`。

    如果你使用的是 Pro 或 Enterprise 方案，请在仪表板的 [API keys](https://dashboard.mintlify.com/settings/organization/api-keys) 页面生成助手 API 密钥。助手 API 密钥以 `mint_dsc_` 开头。
  </Step>

  <Step title="启动开发服务器">
    在你克隆的仓库中安装依赖并启动本地开发服务器：

    ```bash
    cd path/to/your-repository
    npm install
    npm run dev
    ```

    现在，你的网站会在本地的 `http://localhost:4321` 上运行。
  </Step>
</Steps>

<div id="how-it-works">
  ## 工作方式
</div>

该集成将三个部分连接起来：Astro 构建系统、`docs/` 目录中的内容，以及负责处理和渲染这些内容的 Mintlify 软件包。

<div id="astro-configuration">
  ### Astro 配置
</div>

在 `astro.config.mjs` 中配置 `mintlify()` 集成，并指定文档目录路径：

```javascript astro.config.mjs
import { defineConfig } from 'astro/config';
import react from '@astrojs/react';
import mdx from '@astrojs/mdx';
import { mintlify } from '@mintlify/astro';

export default defineConfig({
  integrations: [mintlify({ docsDir: './docs' }), react(), mdx()],
});
```

在构建时，集成会从 `docsDir` 路径读取你的 `docs.json` 和 MDX 文件，并将其处理到 `.mintlify/docs/` 中，Astro&#39;s 内容集合会从中读取这些文件。

<div id="content-structure">
  ### 内容结构
</div>

你的文档内容位于 `docs/` 目录中，其组织方式与其他 Mintlify 项目相同：

```text
docs/
├── docs.json          # 导航和站点配置
├── index.mdx          # 内容 MDX 页面
├── quickstart.mdx
└── guides/            # 用于组织页面的目录
    ├── setup.mdx
    └── troubleshooting.mdx
```

MDX 文件使用标准的 Mintlify [frontmatter](/zh/organize/pages#page-metadata)，并且可以直接使用 Mintlify 组件，无需导入。

<div id="routing-and-navigation">
  ### 路由和导航
</div>

一个通配路由会渲染每个 MDX 页面。`@mintlify/astro/helpers` 包提供了一些函数，用于根据 `docs.json` 解析导航状态。

* `resolvePageData()`: 返回给定页面路径对应的 Tab、侧边栏导航、页脚链接和锚点。
* `unwrapNav()`: 将导航树展平为列表，用于渲染侧边栏。

<div id="layouts-and-styling">
  ### 布局和样式
</div>

你可以完全控制整个展示层。入门模板包含基于 Tailwind CSS 构建的布局、侧边栏、目录和样式，但你也可以将其中任何部分替换为自己的实现。

需要自定义的关键文件：

| 文件                                   | 用途           |
| ------------------------------------ | ------------ |
| `src/layouts/Layout.astro`           | 根 HTML 布局    |
| `src/pages/[...slug].astro`          | 页面模板和数据加载    |
| `src/components/Header.astro`        | 站点页眉         |
| `src/components/Sidebar/`            | 侧边栏导航        |
| `src/components/TableOfContents.tsx` | 页内目录         |
| `src/styles/`                        | 全局样式、排版和配色方案 |

<div id="connect-search-and-assistant">
  ## 连接搜索和助手
</div>

<Note>
  助手功能适用于 [Pro 和 Enterprise 计划](https://mintlify.com/pricing)。
</Note>

入门模板包含搜索和助手组件，它们会使用你在设置过程中配置的环境变量连接到 Mintlify 的 API。

* **搜索**：`src/components/SearchBar.tsx` 中的 `SearchBar` 组件会查询 Mintlify 搜索 API。
* **Assistant**：`src/components/Assistant/` 中的 `Assistant` 组件提供 AI 聊天界面，可根据你的文档内容回答问题。

两者都需要 `PUBLIC_MINTLIFY_SUBDOMAIN` 和 `PUBLIC_MINTLIFY_ASSISTANT_KEY` 这两个环境变量。

<div id="next-steps">
  ## 后续步骤
</div>

完成项目设置后：

1. 将 `docs/` 中的入门内容替换为你自己的 MDX 文件和 `docs.json` 配置。
2. 自定义布局和样式，使其符合你的设计系统。
3. 将 Astro 站点部署到你选择的托管服务提供商。
