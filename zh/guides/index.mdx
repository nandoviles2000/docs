本节中的指南提供了有关如何创建文档以帮助用户成功完成任务的建议。无论你是从零开始，还是在改进现有文档，这些指南都能帮助你规划、编写和维护文档。

最重要的是，始终以用户的需求和目标为先。记录真正能帮助他们使用你的产品并继续完成手头工作的内容。

<div id="topics">
  ## 主题
</div>

<div id="ai-tools">
  ### AI 工具
</div>

使用 AI 工具加快你的文档工作流。

* [自动化文档更新](/zh/guides/automate-agent)：讲解如何使用智能体设置自动化文档更新的教程。
* [构建应用内助手](/zh/guides/assistant-embed)：讲解如何在 React 应用中添加 AI 聊天机器人，帮助用户从你的文档中找到答案的教程。
* [配置自动合并](/zh/guides/configure-automerge)：将 Mintlify GitHub App 添加到规则集绕过列表中，为工作流启用自动合并。
* [Claude Code](/zh/guides/claude-code), [Cursor](/zh/guides/cursor), [Windsurf](/zh/guides/windsurf)：介绍如何使用 AI 编码助手维护文档的指南。
* [GEO](/zh/guides/geo)：针对 AI 搜索和答案引擎优化文档的最佳实践。

<div id="api-documentation">
  ### API 文档
</div>

创建易于维护的 API 文档，让用户能够测试并了解如何使用你的 API。

* [从 MDX 迁移到 OAS](/zh/guides/migrating-from-mdx)：将 API 文档从单独的 MDX 页面迁移到基于 OpenAPI 规范自动生成的页面。

<div id="best-practices">
  ### 最佳实践
</div>

让你的文档达到行业一流水准。

* [无障碍访问](/zh/guides/accessibility)：尽可能让更多用户都能访问你的文档。
* [内容类型](/zh/guides/content-types)：为教程、操作指南、参考文档和说明内容选择合适的格式。
* [内容模板](/zh/guides/content-templates)：复制并修改适用于各类内容的模板。
* [自定义页面布局](/zh/guides/custom-layouts)：使用页面模式和组件构建落地页及其他自定义布局。
* [改进你的文档](/zh/guides/improving-docs)：利用数据和反馈持续改进文档。
* [国际化](/zh/guides/internationalization)：设置多语言文档，触达全球受众。
* [链接](/zh/guides/linking)：创建内部链接、引用 API 端点，并维护整个文档中的链接完整性。
* [维护](/zh/guides/maintenance)：保持文档准确并及时更新。
* [媒体](/zh/guides/media)：高效添加图片、视频和其他媒体，同时控制维护成本。
* [组织导航](/zh/guides/navigation)：设计适合用户的信息架构。
* [SEO](/zh/guides/seo)：为搜索引擎优化你的文档。
* [风格与语气](/zh/guides/style-and-tone)：以一致的风格和语气写作。
* [了解你的受众](/zh/guides/understand-your-audience)：研究并满足用户的需求和目标。

<div id="use-cases">
  ### 使用场景
</div>

了解 Mintlify 如何支持不同的使用场景，并找到适合你的解决方案。

* [创建开发者文档](/zh/guides/developer-documentation)：通过能够解答疑问并帮助用户尽快回到主要任务的开发者文档，帮助他们充分发挥你的产品或 API 的价值。
* [创建知识库](/zh/guides/knowledge-base)：搭建内部知识库，集中管理团队信息，提升搜索体验，并减轻维护负担。
* [创建帮助中心](/zh/guides/help-center)：构建自助式帮助中心，让用户能够自行查找答案，减少工单量，并提升客户满意度。
* [创建自定义前端](/zh/guides/custom-frontend)：使用 Mintlify Astro 集成，以完全自定义的前端渲染你的文档。
