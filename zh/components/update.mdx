使用 `Update` 组件，以统一格式展示变更日志条目、版本更新和发布说明。

<Update label="示例" description="v0.1.1">
  ## 示例更新

  你可以在此添加任何内容，例如截图、代码片段或变更列表。

  <Frame>
    <img className="block" src="https://mintlify-assets.b-cdn.net/hero-light.png" alt="PearsDB Introduction 页面截图，用作 Update 组件中图片的示例。" />
  </Frame>

  ### 功能

  * 响应式设计
  * 为每条更新提供锚点
  * 为每条更新生成 RSS 订阅源条目
</Update>

<div id="how-to-use">
  ## 使用方法
</div>

```mdx Update example
<Update label="2024-10-11" description="v0.1.0" tags={["Mintlify"]}>
  This is an update with a label, description, and tag.
</Update>
```

使用多个 `Update` 组件创建[更新日志](/zh/create/changelogs)。

`Update` 组件会自动生成 RSS 订阅源条目。这些条目只包含纯 Markdown 内容——不包括组件、代码块、内联代码和原始 HTML 元素。

如果你的更新包含组件或 HTML，请使用 `rss` 属性为 RSS 订阅者提供替代文本。

```mdx Custom RSS content
<Update
  label="March 2025"
  description="v2.0.0"
  rss={{
    title: "March 2025 - Major redesign",
    description: "Complete UI overhaul with new components"
  }}
>
  ## New dashboard

  <Frame>
    <img src="/dashboard.png" alt="New dashboard UI displaying updated components." />
  </Frame>

  Check out our redesigned dashboard with improved navigation.
</Update>
```

<div id="props">
  ## 属性
</div>

<ResponseField name="label" type="string" required>
  更新项的标签文本。显示在更新内容左侧，并会创建一个锚点链接。标签文本应保持唯一。
</ResponseField>

<ResponseField name="tags" type="string[]">
  更新项的标签。显示为右侧面板中的筛选条件。
</ResponseField>

<ResponseField name="description" type="string">
  更新项的描述。显示在标签文本和标签下方。
</ResponseField>

<ResponseField name="rss" type="object">
  Update 组件会自动生成 RSS 订阅源条目。使用 `rss` 属性可创建一条带有自定义标题和描述的 RSS 订阅源条目。

  如果未提供：

  * 带有 Markdown 标题的更新项会为每个标题分别创建一条 RSS 订阅源条目。
  * 不带 Markdown 标题的更新项会使用 `label` 作为标题创建一条 RSS 订阅源条目。

  <Expandable title="属性">
    <ResponseField name="title" type="string">
      RSS 订阅源条目的自定义标题。
    </ResponseField>

    <ResponseField name="description" type="string">
      RSS 订阅源条目的自定义描述。
    </ResponseField>
  </Expandable>
</ResponseField>
