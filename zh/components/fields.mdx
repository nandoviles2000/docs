使用字段为 API 参数和响应编写文档。字段分为两种类型：参数字段和响应字段。

<div id="parameter-field">
  ## 参数字段
</div>

使用 `<ParamField>` 组件为你的 API 或 SDK 定义参数。添加 `ParamField` 后，会自动添加一个 [API 操场](/zh/api-playground/overview)。

<ParamField path="param" type="string" required>
  参数字段示例
</ParamField>

```mdx
<ParamField path="param" type="string" required>
  An example of a parameter field
</ParamField>
```

<div id="properties">
  ### 属性
</div>

<ParamField body="query、path、body 或 header" type="string">
  指定参数属于 query、path、body 还是 header，后面跟参数名称。
</ParamField>

<ParamField body="type" type="string">
  参数值的预期类型。

  支持 `number`、`string`、`boolean`、`object`。

  使用 `[]` 后缀定义数组，例如 `string[]`。
</ParamField>

<ParamField body="required" type="boolean">
  指示是否必须提供该参数。
</ParamField>

<ParamField body="deprecated" type="boolean">
  指示该参数是否已弃用。
</ParamField>

<ParamField body="default" type="any">
  当请求值为空时使用的默认值
</ParamField>

<ParamField body="占位符" type="string">
  playground 中输入框的占位文本。
</ParamField>

<ParamField body="children" type="string">
  参数说明 (支持 Markdown) 。
</ParamField>

<div id="response-field">
  ## 响应字段
</div>

`<ResponseField>` 组件用于定义 API 的返回字段。

<ResponseField name="response" type="string" required>
  响应字段示例
</ResponseField>

```mdx
<ResponseField name="response" type="string" required>
  A response field example
</ResponseField>
```

<div id="properties">
  ### 属性
</div>

<ResponseField name="name" type="string" required>
  响应值的名称。
</ResponseField>

<ResponseField name="type" type="string" required>
  响应值的预期类型。可以是任意字符串。
</ResponseField>

<ResponseField name="default" type="string">
  默认值。
</ResponseField>

<ResponseField name="required" type="boolean">
  表示该响应值是否为必填。
</ResponseField>

<ResponseField name="deprecated" type="boolean">
  表示该字段是否已弃用。
</ResponseField>

<ResponseField name="pre" type="string[]">
  显示在字段名称前的标签。
</ResponseField>

<ResponseField name="post" type="string[]">
  显示在字段名称后的标签。
</ResponseField>
