Accordion 允许用户展开和折叠内容区块。使用 Accordion 可逐步展示内容，并更有条理地组织信息。

当你打开某个 Accordion 时，URL 哈希会随之更新，因此你可以直接分享指向特定 Accordion 区块的链接。

<div id="single-accordion">
  ## 单个 Accordion
</div>

<Accordion title="我是一个 Accordion。">
  你可以在这里添加任何内容，包括代码等其他组件：

  ```java HelloWorld.java
   class HelloWorld {
       public static void main(String[] args) {
           System.out.println("Hello, World!");
       }
   }
  ```
</Accordion>

<div id="accordion-groups">
  ## Accordion 组
</div>

使用 `<AccordionGroup>` 将相关的 Accordion 组合在一起。这样可以创建一个统一的 Accordion 区块，其中每个 Accordion 都可以单独展开或折叠。

<AccordionGroup>
  <Accordion title="快速开始">
    你可以在 Accordion 中放入其他组件。

    ```java HelloWorld.java
    class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="高级功能" icon="bot">
    添加图标，让 Accordion 在视觉上更易区分，也更便于快速浏览。
  </Accordion>

  <Accordion title="故障排查">
    按组组织相关内容，保持结构清晰有序。
  </Accordion>
</AccordionGroup>

<div id="properties">
  ## 属性
</div>

<ResponseField name="title" type="string" required>
  Accordion 预览中显示的标题。
</ResponseField>

<ResponseField name="description" type="string">
  Accordion 预览中标题下方的说明文字。
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Accordion 是否默认展开。
</ResponseField>

<ResponseField name="id" type="string">
  用于锚点链接的 Accordion 自定义 ID。若省略，则默认与 `title` 的值相同。
</ResponseField>
