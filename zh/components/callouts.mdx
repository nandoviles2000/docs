将提示框样式设置为 Note、Warning、Info、Tip、Check、Danger，或创建你自己的提示框：

<Note>这会在内容中添加一条说明</Note>

```mdx
<Note>This adds a note in the content</Note>
```

<Warning>这会显示一条警告，提醒你注意</Warning>

```mdx
<Warning>This raises a warning to watch out for</Warning>
```

<Info>这用于突出重要信息</Info>

```mdx
<Info>This draws attention to important information</Info>
```

<Tip>这表示一条有帮助的提示</Tip>

```mdx
<Tip>This suggests a helpful tip</Tip>
```

<Check>这会使其处于选中状态</Check>

```mdx
<Check>这表示已选中状态</Check>
```

<Danger>这是一个危险警示</Danger>

```mdx
<Danger>This is a danger callout</Danger>
```

<Callout icon="key" color="#FFC107" iconType="regular"> 这是一个自定义提示框</Callout>

```mdx wrap
<Callout icon="key" color="#FFC107" iconType="regular">This is a custom callout</Callout>
```

<div id="custom-callout-properties">
  ## 自定义提示框属性
</div>

通用 `Callout` 组件支持自定义图标和颜色。带类型的提示框 (`Note`、`Warning`、`Info`、`Tip`、`Check`、`Danger`) 使用预设的图标和颜色，且仅接受 `children`。

<IconsOptional />

<ResponseField name="color" type="string">
  使用十六进制代码指定自定义颜色 (例如 `#FFC107`) 。这会设置提示框的边框、背景着色和文本颜色。
</ResponseField>
