---
title: "横幅"
description: "在文档站点顶部添加可关闭的横幅，用于显示重要公告、发布说明或通知。"
keywords: ["banner", "announcements", "site-wide"]
---

使用横幅可在整个文档站点显示重要公告、更新或通知。横幅会显示在每个页面顶部，支持 Markdown 格式，并且你可以将其设置为可关闭。横幅使用你在 `docs.json` 中通过 `colors.dark` 属性定义的颜色。

要添加横幅，请在 `docs.json` 中使用 `banner` 属性：

<CodeGroup>
  ```json 产品公告 wrap
  "banner": {
    "content": "🚀 2.0 版本现已上线！详情请参阅我们的[changelog](/changelog)。",
    "dismissible": true 
  }
  ```

  ```json 维护通知 wrap
  "banner": {
    "content": "⚠️ 计划维护：API 将于 12 月 15 日 UTC 时间 2:00–4:00 不可用",
    "dismissible": false
  }
  ```

  ```json 必需操作 wrap
  "banner": {
    "content": "**需要操作：**请在 1 月 1 日前迁移到我们的新版本。[迁移指南](/migration)",
    "dismissible": true
  }
  ```
</CodeGroup>

<Note>
  你也可以通过在 `navigation.languages` 中设置 `banner`，按语言配置横幅。请参阅[按语言设置横幅](#language-specific-banners)。
</Note>

<div id="properties">
  ## 属性
</div>

<ResponseField name="content" type="string" required>
  横幅中显示的文本内容。支持基本的 MDX 格式，例如链接、粗体和斜体。不支持自定义组件。
</ResponseField>

<ResponseField name="dismissible" type="boolean">
  用户是否可以关闭横幅。设为 `true` 时，会显示关闭按钮。如果用户关闭了横幅，该横幅会对其保持隐藏，直到你更新横幅内容。默认为 `false`。
</ResponseField>

<div id="language-specific-banners">
  ## 按语言设置横幅
</div>

为文档中的每种语言配置不同的横幅内容。在 `docs.json` 的 `navigation.languages` 数组中定义各语言对应的横幅。

```json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "banner": {
          "content": "🚀 Version 2.0 is now live! See our [changelog](/en/changelog) for details.",
          "dismissible": true
        },
        "groups": [
          {
            "group": "Getting started",
            "pages": ["en/overview", "en/quickstart"]
          }
        ]
      },
      {
        "language": "es",
        "banner": {
          "content": "🚀 ¡La versión 2.0 ya está disponible! Consulta nuestro [registro de cambios](/es/changelog) para más detalles.",
          "dismissible": true
        },
        "groups": [
          {
            "group": "Getting started",
            "pages": ["es/overview", "es/quickstart"]
          }
        ]
      }
    ]
  },
  "banner": {
    "content": "🚀 Version 2.0 is now live!",
    "dismissible": true
  }
}
```

<div id="fallback-behavior">
  ### 回退机制
</div>

横幅在确定显示内容时遵循以下优先级顺序：

1. **按语言设置横幅**：如果当前语言配置了 `banner`，则优先显示该横幅。
2. **全局横幅**：如果没有按语言设置横幅，则显示全局 `banner`。
