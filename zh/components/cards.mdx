使用卡片为内容创建可视化容器。卡片是一种灵活的容器，可包含文本、图标、图片和链接。

<div id="basic-card">
  ## 基础 Card
</div>

<Card title="卡片标题" icon="text-align-start" href="/zh/components/columns">
  这就是带图标和链接的 Card 用法。点击此 Card
  会跳转到 Columns 页面。
</Card>

```mdx Card example
<Card title="Card title" icon="text-align-start" href="/components/columns">
  This is how you use a card with an icon and a link. Clicking on this card
  brings you to the Columns page.
</Card>
```

<div id="card-variations">
  ## Card 的变体
</div>

卡片支持多种布局和样式选项，以满足不同的内容需求。

<div id="horizontal-layout">
  ### 水平布局
</div>

添加 `horizontal` 属性，以更紧凑的横向布局显示卡片。

<Card title="横向卡片" icon="text-align-start" horizontal>
  这是一个横向卡片示例。
</Card>

```mdx Horizontal card example
<Card title="Horizontal card" icon="text-align-start" horizontal>
  This is an example of a horizontal card.
</Card>
```

<div id="image-cards">
  ### 图片卡片
</div>

添加 `img` 属性，以在卡片顶部显示图片。

<Card title="图片卡片" img="https://mintlify-assets.b-cdn.net/yosemite.jpg">
  这是一个带有图片的卡片示例。
</Card>

```mdx Image card example
<Card title="Image card" img="/images/card-with-image.png">
  This is an example of a card with an image.
</Card>
```

<div id="link-cards-with-custom-ctas">
  ### 带自定义 CTA 的链接卡片
</div>

你可以自定义行动按钮文本，并控制是否显示箭头。默认情况下，只有外部链接会显示箭头。

<Card title="链接卡片" icon="link" href="/zh/components/columns" arrow="true" cta="点击这里">
  这是一个带有图标和链接的卡片示例。点击此卡片即可前往 Columns 页面。
</Card>

```mdx Link card example
<Card
  title="Link card"
  icon="link"
  href="/components/columns"
  arrow="true"
  cta="Click here"
>
  This is an example of a card with an icon and a link. Clicking on this card brings you to the Columns page.
</Card>
```

<div id="group-cards">
  ## 卡片分组
</div>

使用 [Columns 组件](/zh/components/columns) 将多张卡片并排排列。Columns 组件支持一到四列，并会自动适配较小的屏幕。

<Columns cols={2}>
  <Card title="第一张卡片" icon="panel-left-close">
    这是第一张卡片。
  </Card>

  <Card title="第二张卡片" icon="panel-right-close">
    这是第二张卡片。
  </Card>
</Columns>

```mdx Columns example
<Columns cols={2}>
  <Card title="First card" icon="panel-left-close">
    This is the first card.
  </Card>
  <Card title="Second card" icon="panel-right-close">
    This is the second card.
  </Card>
</Columns>
```

<div id="properties">
  ## 属性
</div>

<ResponseField name="title" type="string">
  卡片上显示的标题。
</ResponseField>

<IconsOptional />

<ResponseField name="color" type="string">
  图标颜色的十六进制值 (例如 `#FF6B6B`) 。
</ResponseField>

<ResponseField name="href" type="string">
  点击卡片后跳转到的 URL。
</ResponseField>

<ResponseField name="horizontal" type="boolean">
  以紧凑的横向布局显示卡片。
</ResponseField>

<ResponseField name="img" type="string">
  显示在卡片顶部的图片 URL 或本地路径。
</ResponseField>

<ResponseField name="cta" type="string">
  操作按钮的自定义文案。
</ResponseField>

<ResponseField name="arrow" type="boolean">
  显示或隐藏链接箭头图标。
</ResponseField>
