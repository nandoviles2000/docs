`Columns` 组件可让你以响应式网格布局排列内容。它最常见的用法是通过指定网格列数，将卡片排布为网格。你也可以使用 `Column` 子组件来包裹任意内容。`Columns` 具备响应式能力，会自动适配较小的屏幕。

<div id="column-sub-component">
  ## Column 子组件
</div>

使用 `Column` 组件可将文本或代码分别放入单独的列中。当你想并排显示任意内容，而不只是卡片或其他组件时，这会很有用。

<Columns cols={2}>
  <Column>
    **安装**

    ```bash
    npm install my-package
    ```
  </Column>

  <Column>
    **用法**

    ```javascript
    import { init } from 'my-package';
    init();
    ```
  </Column>
</Columns>

````mdx Column sub-component example
<Columns cols={2}>
  <Column>

  **安装**

  ```

  </Column>
  <Column>

  **用法**

  ```javascript

  init();
  ```

  </Column>
</Columns>
````

<div id="properties">
  ## 属性
</div>

<ResponseField name="cols" type="number" default={2}>
  每行的列数。可取值为 1 到 4。
</ResponseField>
