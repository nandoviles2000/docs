---
title: "可见性"
description: "控制哪些内容会在 Web 界面中向人类读者显示，哪些内容仅会在面向 AI 智能体的 Markdown 输出中显示。"
keywords: ["可见性", "智能体", "人类", "Markdown", "AI", "条件内容"]
---

使用 `Visibility` 组件可针对阅读站点的人类用户和处理 Markdown 输出的 AI 智能体显示不同内容。这样，你就可以为不同受众定制信息，而无需维护单独的页面。

在已发布的站点上，标记为 `for="humans"` 的内容会正常渲染，而标记为 `for="agents"` 的内容会被隐藏。在 [Markdown 页面视图](/zh/ai/markdown-export) (`.md` URL) 中则恰好相反：智能体内容会在 Markdown 输出中渲染，而仅供人类查看的内容不会显示。

<div id="example">
  ## 示例
</div>

```mdx
<Visibility for="humans">
  <Note>
    您正在**网页端**查看此内容。

    此内容在您网站的标准页面上正常显示。

    可将其用于如下步骤：点击右上角的**开始使用**按钮以创建您的账户。

    在此示例中，面向 UI 的说明显示在标准页面上。查看[此页面的 Markdown 版本](https://mintlify.com/docs/components/visibility.md)，了解面向智能体的面向 API 的说明。
  </Note>
</Visibility>

<Visibility for="agents">
  > 您正在 **Markdown 版本**中查看此内容。
  >
  > 此内容仅出现在页面的 Markdown 版本中。
  >
  > 可将其用于仅供智能体使用的信息，例如：要创建账户，请使用有效的电子邮件地址调用 `POST /v1/accounts`。
  >
  > 在此示例中，面向 API 的说明显示在页面的 Markdown 版本中。查看[标准页面](https://mintlify.com/docs/components/visibility)，了解面向用户的面向 UI 的说明。
</Visibility>
```

<div id="properties">
  ## 属性
</div>

<ResponseField name="for" type="string" required>
  包裹内容的适用对象。必须是以下之一：

  * `humans`：在网页上可见，且不会包含在 Markdown 输出中
  * `agents`：在网页上隐藏，且会包含在 Markdown 输出中
</ResponseField>
