`<RequestExample>` 和 `<ResponseExample>` 组件会在右侧边栏中显示代码块，创建双栏布局，让用户在滚动浏览内容时仍能看到示例。请将这些组件用于 API 文档，但它们也适用于所有页面。

常见用例：

* 包含请求和响应示例的 API 端点文档
* 与说明文字并排显示的配置示例
* 用户按说明操作时需要参考的代码示例
* 教程中的前后对比示例

在移动设备上，`<RequestExample>` 和 `<ResponseExample>` 组件会显示为普通代码块，用户可以直接滚动查看。

<RequestExample>
  ```bash Request
  curl --request POST \
    --url https://dog-api.kinduff.com/api/facts
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  { "status": "success" }
  ```
</ResponseExample>

<div id="requestexample">
  ## RequestExample
</div>

使用 `<RequestExample>` 可将代码示例固定在右侧边栏。该组件的用法与 [CodeGroup](/zh/components/code-groups) 组件类似，但会将代码显示在侧边栏中，而不是直接内嵌在正文中。

你可以在一个 `<RequestExample>` 中包含多个代码块。每个代码块都必须带有 `title` 属性。

````mdx RequestExample
<RequestExample>

```bash Request
curl --request POST \
  --url https://dog-api.kinduff.com/api/facts
```

</RequestExample>
````

<div id="responseexample">
  ## ResponseExample
</div>

`<ResponseExample>` 组件会将代码示例固定在右侧边栏中，并显示在同一页面上任意 `<RequestExample>` 内容的下方。

````mdx ResponseExample
<ResponseExample>

```json Response
{ "status": "success" }
```

</ResponseExample>
````

<div id="properties">
  ## 属性
</div>

`<RequestExample>` 和 `<ResponseExample>` 都支持以下属性：

<ResponseField name="dropdown" type="boolean">
  显示用于在代码块之间切换的语言下拉菜单，而非默认的 Tab 布局。
</ResponseField>
