---
title: "响应字段"
description: "使用 ResponseField 组件通过类型标注、描述以及必填或可选标识来记录 API 响应字段。"
keywords: ["API 输出", "返回值", "响应结构"]
---

使用 `<ResponseField>` 组件定义 API 的返回值。在需要列出某些内容类型的页面中，许多文档也会使用 `<ResponseField>`。

<ResponseField name="response" type="string" required>
  响应字段示例
</ResponseField>

```mdx
<ResponseField name="response" type="string" required>
  A response field example
</ResponseField>
```

<div id="props">
  ## 属性
</div>

<ResponseField name="name" type="string" required>
  响应值的名称。
</ResponseField>

<ResponseField name="type" type="string" required>
  响应值的预期类型，可以是任意字符串。
</ResponseField>

<ResponseField name="default" type="string">
  默认值。
</ResponseField>

<ResponseField name="required" type="boolean">
  在字段名称旁显示“required”。
</ResponseField>

<ResponseField name="deprecated" type="boolean">
  指示该字段是否已弃用。
</ResponseField>

<ResponseField name="pre" type="string[]">
  显示在字段名称前的标签。
</ResponseField>

<ResponseField name="post" type="string[]">
  显示在字段名称后的标签。
</ResponseField>

<RequestExample>
  ```mdx Response Field Example
  <ResponseField name="response" type="string" required>
    响应字段示例
  </ResponseField>
  ```
</RequestExample>
