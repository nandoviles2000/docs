使用 `CodeGroup` 组件在标签页界面中显示多个代码块，以便用户比较不同编程语言的实现，或查看完成同一任务的其他写法。

<CodeGroup>
  ```javascript helloWorld.js
  console.log("Hello World");
  ```

  ```python hello_world.py
  print('Hello World!')
  ```

  ```java HelloWorld.java
  class HelloWorld {
      public static void main(String[] args) {
          System.out.println("Hello, World!");
      }
  }
  ```
</CodeGroup>

代码组会继承 `docs.json` 文件中的全局样式。你可以使用 `styling.codeblocks` 自定义主题。有关配置选项，请参阅[设置](/zh/organize/settings-appearance#styling)。

当标签名称一致时，代码组会自动与同一页面上的其他代码组和[Tabs](/zh/components/tabs)同步。当你在一个代码组中选择某种语言时，所有标签名称相同的 Tabs 和代码组都会更新为显示相同的语言。

<div id="create-code-groups">
  ## 创建代码组
</div>

要创建代码组，请用 `<CodeGroup>` 标签包裹多个代码块。每个代码块都必须包含一个标题，该标题会显示为选项卡标签。

````mdx
<CodeGroup>

```javascript helloWorld.js
console.log("Hello World");
```

```python hello_world.py
print('Hello World!')
```

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

</CodeGroup>
````

<div id="language-dropdown">
  ## 语言下拉菜单
</div>

你可以使用 `dropdown` 属性，将代码组中的 Tabs 替换为下拉菜单，以便在不同语言之间切换。

<CodeGroup dropdown>
  ```javascript helloWorld.js
  console.log("Hello World");
  ```

  ```python hello_world.py
  print('Hello World!')
  ```

  ```java HelloWorld.java
  class HelloWorld {
      public static void main(String[] args) {
          System.out.println("Hello, World!");
      }
  }
  ```
</CodeGroup>
