使用 Frame 以统一样式展示图片、图表、视频或其他视觉内容，并可选择添加说明文字。Frame 会将内容居中，并在视觉上与周围文本区分开来。

</Frame>

<div id="captions">
  ## 说明文字
</div>

使用可选的 `caption` 属性为图片添加更多背景说明。说明文字会显示在图片下方的框内。

<Frame caption="优胜美地国家公园每年接待超过 350 万名游客。">
  <img src="https://mintlify-assets.b-cdn.net/yosemite.jpg" alt="优胜美地山谷的照片。" />
</Frame>

<div id="markdown-in-captions">
  ### 说明文字中的 Markdown
</div>

说明文字支持 Markdown 格式，包括链接和粗体文本。

<Frame caption="详细了解 [优胜美地国家公园](https://www.nps.gov/yose/index.htm)，并规划您的行程。">
  <img src="https://mintlify-assets.b-cdn.net/yosemite.jpg" alt="优胜美地山谷的照片。" />
</Frame>

<Frame caption="**重要提示：** 请查看[公园官网](https://www.nps.gov/yose/index.htm)了解当前状况。">
  <img src="https://mintlify-assets.b-cdn.net/yellowstone.jpeg" alt="黄石国家公园中一片被树木环绕、远处可见群山的湖泊照片。" />
</Frame>

<div id="hints">
  ## 提示
</div>

使用可选的 `hint` 属性添加显示在 Frame 前面的文本。提示会显示在 Frame 上方。

<Frame hint="如果你计划前往优胜美地国家公园，请在出发前办妥许可证。" caption="优胜美地国家公园每年接待超过 350 万名游客。">
  <img src="https://mintlify-assets.b-cdn.net/yellowstone.jpeg" alt="黄石国家公园中一处湖泊的照片，四周树木环绕，远处群山可见。" />
</Frame>

<div id="videos">
  ## 视频
</div>

当你在 Frame 中放置带有 `autoPlay` 的 `video` 元素时，Frame 会添加 `playsInline`、`loop` 和 `muted` 属性。

```mdx Video with autoPlay
<Frame caption="Product demo">
  <video autoPlay src="/path/to/video.mp4" />
</Frame>
```

未启用 `autoPlay` 的视频默认不会添加任何额外属性。

<div id="properties">
  ## 属性
</div>

<ResponseField name="caption" type="string">
  显示在 Frame 中、居中位于内容下方的文本。支持 Markdown 格式，包括链接和粗体文本。
</ResponseField>

<ResponseField name="hint" type="string">
  显示在 Frame 前面的文本。
</ResponseField>

<CodeGroup>
  ```mdx Frame
  <Frame>
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```

  ```mdx 带说明文字的 Frame
  <Frame caption="Caption text">
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```

  ```mdx 说明文字中包含 Markdown 的 Frame
  <Frame caption="Visit the [documentation](/docs) for more details">
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```

  ```mdx 说明文字中包含粗体文本和链接的 Frame
  <Frame caption="**Note:** See the [official guide](https://example.com) for setup instructions">
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```

  ```mdx 带提示文本的 Frame
  <Frame hint="Hint text">
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```

  ```mdx 同时带有提示文本和说明文字的 Frame
  <Frame hint="Hint text" caption="Caption text">
    <img src="/path/image.jpg" alt="Descriptive alt text" />
  </Frame>
  ```
</CodeGroup>
