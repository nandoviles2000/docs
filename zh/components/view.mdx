使用 `View` 组件创建会根据多视图下拉菜单中所选视图切换的内容。这对于展示针对不同编程语言或框架的代码示例或文档尤其有用。

<Tip>
  每种语言在每个页面中只使用一个视图组件。对于因语言不同而有所差异的操作步骤，请使用 [tabs](/zh/components/tabs)；对于因语言不同而有所差异的代码示例，请使用 [代码组](/zh/components/code-groups)。
</Tip>

<View title="JavaScript" icon="js">
  仅当选中 JavaScript 时，才会显示此内容。

  ```javascript
  console.log("Hello from JavaScript!");
  ```
</View>

<View title="Python" icon="python">
  仅当选中 Python 时，才会显示此内容。

  ```python
  print("Hello from Python!")
  ```
</View>

<div id="table-of-contents-behavior">
  ## 目录行为
</div>

目录会自动更新，只显示当前所选视图中的标题。使用多视图下拉菜单切换视图时，目录也会刷新，显示该视图对应的标题。

如果每个视图的标题结构不同，用户只会看到与其所选语言或框架相对应的标题。

<div id="properties">
  ## 属性
</div>

<ResponseField name="title" type="string" required>
  用于标识此视图的标题。必须与多视图下拉菜单中的某个选项一致。
</ResponseField>

<ResponseField name="icon" type="string">
  可以是 [Font Awesome](https://fontawesome.com/icons) 图标、[Lucide](https://lucide.dev/icons) 图标、图标的 URL，或图标的相对路径。
</ResponseField>

<ResponseField name="iconType" type="string">
  仅适用于 Font Awesome 图标：必须是 `regular`、`solid`、`light`、`thin`、`sharp-solid`、`duotone` 或 `brands` 之一。
</ResponseField>
