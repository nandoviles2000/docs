keywords: ["编辑器访问权限", "权限", "团队", "席位", "部署"]
---

拥有 editor 或 admin [角色](/zh/dashboard/roles) 的用户可以使用网页编辑器、触发部署，并在你的仪表板中管理集成。当 editor 或 admin 通过网页编辑器发布内容，或将拉取请求 (PR) 合并到你的文档仓库时，这些更改会自动部署到你的线上站点。

任何有权访问你的文档仓库的人都可以通过将更改推送到仓库来为文档做出贡献，但这些更改不会立即部署，必须由 editor 或 admin 从你的仪表板手动触发部署后才会生效。
