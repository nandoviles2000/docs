<Info>
  SSO 适用于 [Enterprise plans](https://mintlify.com/pricing?ref=sso)。
</Info>

企业管理员可以直接在 Mintlify 仪表板中为 Okta 或 Microsoft Entra 配置 SAML SSO。对于 Google Workspace、Okta OIDC 等其他提供商，请[联系我们](mailto:support@mintlify.com)以设置 SSO。

<div id="configure-sso">
  ## 配置 SSO
</div>

<div id="okta">
  ### Okta
</div>

<Steps>
  <Step title="在 Mintlify 仪表板中配置 Okta SSO">
    1. 在 Mintlify 仪表板中，前往 [单点登录](https://dashboard.mintlify.com/settings/organization/sso) 页面。
    2. 点击 **Configure**。
    3. 选择 **Okta SAML**。
    4. 复制 **Single sign on URL** 和 **Audience URI**。
  </Step>

  <Step title="在 Okta 中创建 SAML 应用">
    1. 在 Okta 中，进入 **Applications**，使用 SAML 2.0 创建新的应用集成。

    2. 输入以下来自 Mintlify 的信息：
       * **Single sign on URL**：从 Mintlify 仪表板复制的 URL
       * **Audience URI**：从 Mintlify 仪表板复制的 URI
       * **Name ID Format**：`EmailAddress`

    3. 添加以下属性声明：

       | 名称          | 名称格式  | 值                |
       | ----------- | ----- | ---------------- |
       | `firstName` | Basic | `user.firstName` |
       | `lastName`  | Basic | `user.lastName`  |
  </Step>

  <Step title="复制 Okta 元数据 URL">
    在 Okta 中，前往应用的 **Sign On** 选项卡并复制元数据 URL。
  </Step>

  <Step title="在 Mintlify 中保存">
    返回 Mintlify 仪表板，粘贴元数据 URL，然后点击 **Save changes**。
  </Step>
</Steps>

<div id="microsoft-entra">
  ### Microsoft Entra
</div>

<Steps>
  <Step title="在 Mintlify 仪表板中配置 Microsoft Entra SSO">
    1. 在 Mintlify 仪表板中，前往[单点登录](https://dashboard.mintlify.com/settings/organization/sso)页面。
    2. 点击 **Configure**。
    3. 选择 **Microsoft Entra ID SAML**。
    4. 复制 **Single sign on URL** 和 **Audience URI**。
  </Step>

  <Step title="在 Microsoft Entra 中创建企业应用程序">
    1. 在 Microsoft Entra 中，前往 **Enterprise applications**。
    2. 选择 **New application**。
    3. 选择 **Create your own application**。
    4. 选择“Integrate any other application you don&#39;t find in the gallery (Non-gallery).”
  </Step>

  <Step title="在 Microsoft Entra 中配置 SAML">
    1. 在 Microsoft Entra 中，前往 **Single Sign-On**。
    2. 选择 **SAML**。
    3. 在 **Basic SAML Configuration** 下，输入以下内容：
       * **Identifier (Entity ID)**：填写 Mintlify 提供的 Audience URI
       * **Reply URL (Assertion Consumer Service URL)**：填写 Mintlify 提供的 Single sign on URL

    其他值留空，然后选择 **Save**。
  </Step>

  <Step title="在 Microsoft Entra 中配置 Attributes & Claims">
    1. 在 Microsoft Entra 中，前往 **Attributes &amp; Claims**。
    2. 在“Required Claim”下选择 **Unique User Identifier (Name ID)**。
    3. 将 Source attribute 更改为 `user.primaryauthoritativeemail`。
    4. 在 **Additional claims** 下，创建以下条目：
       | 名称          | 值                |
       | ----------- | ---------------- |
       | `firstName` | `user.givenname` |
       | `lastName`  | `user.surname`   |
  </Step>

  <Step title="复制 Microsoft Entra 元数据 URL">
    在 **SAML Certificates** 下，复制 **App Federation Metadata URL**。
  </Step>

  <Step title="在 Mintlify 中保存">
    返回 Mintlify 仪表板，粘贴元数据 URL，然后点击 **Save changes**。
  </Step>

  <Step title="分配用户">
    在 Microsoft Entra 中，前往 **Users and groups**。为应有权访问 Mintlify 仪表板的用户分配权限。
  </Step>
</Steps>

<div id="jit-provisioning">
  ## JIT 即时预配
</div>

启用 JIT (即时) 预配后，通过身份提供商登录的用户会自动添加到您的 Mintlify 组织中。

<Note>
  JIT 预配仅适用于由 IdP 发起的登录。用户必须从您的身份提供商 (Okta 仪表板或 Microsoft Entra 门户) 发起登录，而不能从 Mintlify 登录页面开始。
</Note>

要启用 JIT 预配，您必须先启用 SSO。前往仪表板中的 [单点登录](https://dashboard.mintlify.com/settings/organization/sso) 页面，完成 SSO 设置，然后启用 JIT 预配。

<div id="map-rbac-roles-with-saml-groups">
  ## 将 SAML 组映射到 RBAC 角色
</div>

根据用户在身份提供商中的组成员身份，为其分配[角色](/zh/dashboard/roles)。当用户通过 SSO 登录时，Mintlify 会从 SAML 断言中读取 `groups` 属性，并将这些组映射为仪表板角色。

<div id="configure-group-attribute-statements">
  ### 配置组属性声明
</div>

在你的 SAML 身份提供商配置中添加一个 `groups` 属性声明。该属性必须使用 `unspecified` 名称格式。

生成的 SAML 断言中应包含一个 `AttributeStatement`。

```xml Example SAML assertion
<saml2:AttributeStatement xmlns:saml2="urn:oasis:names:tc:SAML:2.0:assertion">
    <saml2:Attribute Name="groups" NameFormat="urn:oasis:names:tc:SAML:2.0:attrname-format:unspecified">
        <saml2:AttributeValue xmlns:xs="http://www.w3.org/2001/XMLSchema"
                              xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                              xsi:type="xs:string">Everyone</saml2:AttributeValue>
        <saml2:AttributeValue xmlns:xs="http://www.w3.org/2001/XMLSchema"
                              xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                              xsi:type="xs:string">Engineering</saml2:AttributeValue>
        <saml2:AttributeValue xmlns:xs="http://www.w3.org/2001/XMLSchema"
                              xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                              xsi:type="xs:string">Admins</saml2:AttributeValue>
    </saml2:Attribute>
</saml2:AttributeStatement>
```

**关键要求：**

* 属性名称必须为 `groups` (区分大小写)
* 名称格式必须为 `urn:oasis:names:tc:SAML:2.0:attrname-format:unspecified`
* 用户所属的每个组都应对应一个单独的 `AttributeValue` 元素

<Tabs>
  <Tab title="Okta">
    在 Okta SAML 应用配置中，添加组属性声明：

    | Name     | Name format | Filter        | Value |
    | -------- | ----------- | ------------- | ----- |
    | `groups` | Unspecified | Matches regex | `.*`  |

    调整筛选条件，使其匹配你要发送到 Mintlify 的特定组。
  </Tab>

  <Tab title="Microsoft Entra">
    在 Microsoft Entra 企业应用程序中：

    1. 前往 **Single Sign-On** &gt; **Attributes &amp; Claims**。
    2. 选择 **Add a group claim**。
    3. 选择要包含的组 (所有组或特定组) 。
    4. 在 **Advanced options** 下，勾选 **Customize the name of the group claim**，并将名称设为 `groups`。
  </Tab>
</Tabs>

配置完成后，Mintlify 会将 SAML 断言中的组名映射为你组织中的角色。要设置或修改组到角色的映射，请联系你的 Mintlify 客户代表。

<div id="change-or-remove-sso-provider">
  ## 更改或移除 SSO 提供商
</div>

1. 在仪表板中，前往 [单点登录](https://dashboard.mintlify.com/settings/organization/sso) 页面。
2. 点击 **Configure**。
3. 选择你要使用的 SSO 提供商，或不使用 SSO。

如果你移除 SSO，用户必须改用密码、魔法链接或 Google OAuth 进行身份验证。

<div id="other-providers">
  ## 其他提供商
</div>

如果您使用的不是 Microsoft Entra 或 Okta SAML，请[联系我们](mailto:support@mintlify.com)配置 SSO。

<div id="google-workspace-with-saml">
  ### 使用 SAML 的 Google Workspace
</div>

<Steps>
  <Step title="创建应用">
    1. 在 Google Workspace 中，前往 **Web and mobile apps**。
    2. 在 **Add app** 下拉菜单中选择 **Add custom SAML app**。

    <Frame>
      ![Google Workspace SAML 应用创建页面截图，其中“Add custom SAML app”菜单项已高亮显示](/images/gsuite-add-custom-saml-app.png)
    </Frame>
  </Step>

  <Step title="将您的 IdP 信息发送给我们">
    复制提供的 SSO URL、Entity ID 和 x509 证书，并将其发送给 Mintlify 团队。

    <Frame>
      ![Google Workspace SAML 应用页面截图，其中 SSO URL、Entity ID 和 x509 证书已高亮显示。这些值的具体内容已做模糊处理。](/images/gsuite-saml-metadata.png)
    </Frame>
  </Step>

  <Step title="配置集成">
    在 Service provider details 页面中，输入以下内容：

    * ACS URL (由 Mintlify 提供)
    * Entity ID (由 Mintlify 提供)
    * Name ID format: `EMAIL`
    * Name ID: `Basic Information > Primary email`

    <Frame>
      ![Service provider details 页面截图，其中 ACS URL 和 Entity ID 输入字段已高亮显示。](/images/gsuite-sp-details.png)
    </Frame>

    在下一页中，输入以下属性声明：

    | Google Directory Attribute | App Attribute |
    | -------------------------- | ------------- |
    | `First name`               | `firstName`   |
    | `Last name`                | `lastName`    |

    完成此步骤并将用户分配给该应用后，请告知我们的团队，我们会为您的账户启用 SSO。
  </Step>
</Steps>

<div id="okta-oidc">
  ### Okta (OIDC)
</div>

<Steps>
  <Step title="创建应用">
    在 Okta 中，前往 **Applications**，使用 OIDC 创建新的应用集成。选择 **Web Application** 应用类型。
  </Step>

  <Step title="配置集成">
    选择授权码授权类型，并输入 Mintlify 提供的重定向 URI。
  </Step>

  <Step title="将你的 IdP 信息发送给我们">
    前往 **General** 选项卡，找到 client ID 和 client secret。请通过安全方式将这些信息连同你的 Okta 实例 URL (例如 `<your-tenant-name>.okta.com`) 一并发送给我们。你可以使用 1Password 或 SendSafely 等服务发送这些信息。
  </Step>
</Steps>
