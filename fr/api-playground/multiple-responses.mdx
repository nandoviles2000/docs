Si votre API renvoie des réponses différentes selon les paramètres d&#39;entrée, le contexte utilisateur ou d&#39;autres conditions de la requête, vous pouvez documenter plusieurs exemples de réponse à l&#39;aide de la propriété `examples`.

Ajoutez cette propriété à n&#39;importe quelle réponse. Elle suit le schéma suivant.

```yaml
responses:
  "200":
    description: Successful response
    content:
      application/json:
        schema:
          $ref: "#/components/schemas/YourResponseSchema"
        examples:
          us:
            summary: Response for United States
            value:
              countryCode: "US"
              currencyCode: "USD"
              taxRate: 0.0825
          gb:
            summary: Response for United Kingdom
            value:
              countryCode: "GB"
              currencyCode: "GBP"
              taxRate: 0.20
```

Le playground gère aussi différemment les types de réponse non JSON selon leur type de contenu.

<div id="audio-response-examples">
  ## Exemples de réponses audio
</div>

Pour les points de terminaison qui renvoient des fichiers audio, définissez le type de contenu de la réponse sur `audio/*` et indiquez l’URL d’un fichier audio comme valeur d’exemple. Le playground affiche alors un lecteur audio interactif à la place d’un extrait de code.

```yaml
responses:
  "200":
    description: Audio file generated successfully
    content:
      audio/mpeg:
        schema:
          type: string
          format: binary
        examples:
          sample:
            summary: Sample audio output
            value: "https://example.com/sample-audio.mp3"
```
