Pour les points de terminaison à usage interne uniquement, les opérations dépréciées, les fonctionnalités en bêta ou les points de terminaison qui doivent être accessibles via une URL directe sans être visibles dans la navigation du site, vous pouvez contrôler quelles opérations OpenAPI sont publiées sous forme de pages de documentation, ainsi que leur visibilité dans la navigation.

Si vos pages sont générées automatiquement à partir d’un document OpenAPI, gérez leur visibilité à l’aide des extensions `x-hidden` et `x-excluded`."

<div id="x-hidden">
  ## `x-hidden`
</div>

L’extension `x-hidden` crée une page pour un point de terminaison, mais la masque dans la navigation. La page n’est accessible qu’en allant directement à son URL.

Les cas d’usage courants de `x-hidden` sont les suivants :

* Les points de terminaison que vous souhaitez documenter sans les mettre en avant.
* Les pages vers lesquelles vous renvoyez depuis d’autres contenus.
* Les points de terminaison destinés à des utilisateurs spécifiques.

<div id="x-excluded">
  ## `x-excluded`
</div>

L’extension `x-excluded` exclut complètement un point de terminaison de votre documentation.

Les cas d’usage courants de `x-excluded` sont :

* Les points de terminaison à usage interne uniquement.
* Les points de terminaison dépréciés que vous ne souhaitez pas documenter.
* Les fonctionnalités bêta qui ne sont pas prêtes à être documentées publiquement.

<div id="implementation">
  ## Mise en œuvre
</div>

Ajoutez l’extension `x-hidden` ou `x-excluded` sous la méthode HTTP dans votre spécification OpenAPI.

Voici des exemples d’utilisation de chaque propriété dans un document de schéma OpenAPI pour un point de terminaison et un chemin de webhook.

```json Endpoint example {11, 19}
"paths": {
  "/plants": {
    "get": {
      "description": "Returns all plants from the store",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  },
  "/hidden_plants": {
    "get": {
      "x-hidden": true,
      "description": "Returns all somewhat secret plants from the store",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  },
  "/secret_plants": {
    "get": {
      "x-excluded": true,
      "description": "Returns all top secret plants from the store (do not publish this endpoint!)",
      "parameters": { /*...*/ },
      "responses": { /*...*/ }
    }
  }
},
```

```json Webhook example {9, 15}
"webhooks": {
  "/plants_hook": {
    "post": {
      "description": "Webhook for information about a new plant added to the store",
    }
  },
  "/hidden_plants_hook": {
    "post": {
      "x-hidden": true,
      "description": "Webhook for somewhat secret information about a new plant added to the store"
    }
  },
  "/secret_plants_hook": {
    "post": {
      "x-excluded": true,
      "description": "Webhook for top secret information about a new plant added to the store (do not publish this endpoint!)"
    }
  }
}
```
