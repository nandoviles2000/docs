Si vos utilisateurs interagissent avec votre API via un SDK plutôt qu’en envoyant directement des requêtes réseau, vous pouvez utiliser l’extension `x-codeSamples` pour ajouter des exemples de code à votre document OpenAPI et les afficher dans vos pages OpenAPI.

Ajoutez cette propriété à n’importe quelle méthode de requête. Elle suit le schéma suivant.

<ParamField body="lang" type="string" required>
  Le langage de l’exemple de code.
</ParamField>

<ParamField body="label" type="string">
  Le libellé de l’exemple. Cela est utile lorsque vous fournissez plusieurs exemples pour un seul point de terminaison.
</ParamField>

<ParamField body="source" type="string" required>
  Le code source de l’exemple.
</ParamField>

Voici un exemple d’exemples de code pour une application de suivi des plantes, avec à la fois un outil CLI Bash et un SDK JavaScript.

```yaml
paths:
  /plants:
    get:
      # ...
      x-codeSamples:
        - lang: bash
          label: List all unwatered plants
          source: |
            planter list -u
        - lang: javascript
          label: List all unwatered plants
          source: |
            const planter = require('planter');
            planter.list({ unwatered: true });
        - lang: bash
          label: List all potted plants
          source: |
            planter list -p
        - lang: javascript
          label: List all potted plants
          source: |
            const planter = require('planter');
            planter.list({ potted: true });
```
