Utilisez CSS pour mettre en forme les éléments HTML, ou ajoutez du CSS et du JavaScript personnalisés pour personnaliser entièrement l’apparence de votre documentation.

<div id="style-with-tailwind-css">
  ## Styliser avec Tailwind CSS
</div>

Utilisez Tailwind CSS v3 pour styliser les éléments HTML. Vous pouvez contrôler la mise en page, l’espacement, les couleurs et d’autres propriétés visuelles. Voici quelques classes courantes :

* `w-full` - Largeur totale
* `aspect-video` - Format d’image 16:9
* `rounded-xl` - Coins largement arrondis
* `block`, `hidden` - Contrôle de l’affichage
* `dark:hidden`, `dark:block` - Visibilité en mode sombre

Les valeurs arbitraires de Tailwind CSS ne sont pas prises en charge. Pour utiliser des valeurs personnalisées, utilisez plutôt la prop `style`.

```html
<img style={{ width: '350px', margin: '12px auto' }} src="/path/image.jpg" />
```

<Warning>
  L’utilisation de la propriété `style` peut provoquer un saut de mise en page au chargement de la page, en particulier sur les pages en mode personnalisé. Utilisez plutôt des classes Tailwind CSS ou des fichiers CSS personnalisés pour éviter ces sauts de mise en page ou le scintillement.
</Warning>

<div id="add-custom-css">
  ## Ajouter du CSS personnalisé
</div>

Ajoutez des fichiers CSS à votre dépôt pour appliquer les noms de classe qu’ils définissent et les rendre disponibles dans tous vos fichiers MDX.

Les références et le style des éléments courants peuvent évoluer. Utilisez les styles personnalisés avec précaution, car des changements incompatibles peuvent être introduits dans de futures mises à jour.

Par exemple, vous pouvez ajouter le fichier `style.css` suivant pour personnaliser le style de la barre de navigation et du pied de page.

```css
#navbar {
  background: #fffff2;
  padding: 1rem;
}

footer {
  margin-top: 2rem;
}
```

Mintlify expose deux types de sélecteurs CSS :

* **Sélecteurs d’ID** : éléments uniques au niveau de la page ciblés avec `#value { }` en CSS
* **Sélecteurs d’élément** : éléments de composant et de mise en page ciblés avec `value { }` en CSS (sans préfixe `#` ni `.`)

<Tip>
  Utilisez l’outil d’inspection de l’élément pour trouver les références des éléments que vous souhaitez personnaliser.
</Tip>

<div id="custom-javascript">
  ## JavaScript personnalisé
</div>

Le JavaScript personnalisé vous permet d’ajouter du code exécutable personnalisé à l’échelle globale. Cela revient à ajouter une balise `<script>` contenant du code JavaScript sur chaque page.

Mintlify inclut tous les fichiers `.js` situés dans votre répertoire de contenu sur chaque page de votre site de documentation. Par exemple, vous pouvez ajouter le fichier `ga.js` suivant pour activer [Google Analytics](https://marketingplatform.google.com/about/analytics) sur l’ensemble de votre documentation.

```js
window.dataLayer = window.dataLayer || [];
function gtag() {
  dataLayer.push(arguments);
}
gtag('js', new Date());

gtag('config', 'TAG_ID');
```

<Warning>
  Veuillez l&#39;utiliser avec prudence afin de ne pas créer de failles de sécurité.
</Warning>
