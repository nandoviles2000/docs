Définissez une police personnalisée pour l’ensemble de votre site, ou séparément pour les titres et le texte courant. Utilisez Google Fonts, des fichiers de police locaux ou des polices hébergées en externe. La police par défaut varie selon le thème.

Configurez les polices à l’aide de la [propriété fonts](/fr/organize/settings-appearance#fonts) dans votre `docs.json`.

<div id="google-fonts">
  ## Google Fonts
</div>

Mintlify charge automatiquement les [Google Fonts](https://fonts.google.com) lorsque vous spécifiez un nom de la famille de polices dans votre `docs.json`.

```json docs.json
"fonts": {
  "family": "Inter"
}
```

<div id="local-fonts">
  ## Polices locales
</div>

Pour utiliser des polices locales, placez vos fichiers de police dans le répertoire de votre projet et indiquez-les dans votre configuration `docs.json`.

<div id="setting-up-local-fonts">
  ### Configurer des polices locales
</div>

<Steps>
  <Step title="Ajoutez les fichiers de police à votre projet">
    Par exemple, créez un répertoire `fonts` et ajoutez-y vos fichiers de police :

    ```text
    your-project/
    ├── fonts/
    │   ├── InterDisplay-Regular.woff2
    │   └── InterDisplay-Bold.woff2
    ├── docs.json
    └── ...
    ```
  </Step>

  <Step title="Configurez les polices dans docs.json">
    Indiquez vos polices locales à l’aide de chemins relatifs depuis la racine de votre projet :

    ```json docs.json
    {
      "fonts": {
        "family": "InterDisplay",
        "source": "/fonts/InterDisplay-Regular.woff2",
        "format": "woff2",
        "weight": 400
      }
    }
    ```
  </Step>
</Steps>

<div id="local-fonts-for-headings-and-body">
  ### Polices locales pour les titres et le texte courant
</div>

Configurez des polices locales distinctes pour les titres et le texte courant dans votre `docs.json` :

```json docs.json
{
  "fonts": {
    "heading": {
      "family": "InterDisplay",
      "source": "/fonts/InterDisplay-Bold.woff2",
      "format": "woff2",
      "weight": 700
    },
    "body": {
      "family": "InterDisplay",
      "source": "/fonts/InterDisplay-Regular.woff2",
      "format": "woff2",
      "weight": 400
    }
  }
}
```

<div id="externally-hosted-fonts">
  ## Polices hébergées en externe
</div>

Utilisez des polices hébergées en externe en indiquant l’URL source de la police dans votre `docs.json` :

```json docs.json
{
  "fonts": {
    "family": "Hubot Sans",
    "source": "https://mintlify-assets.b-cdn.net/fonts/Hubot-Sans.woff2",
    "format": "woff2",
    "weight": 400
  }
}
```

    <ResponseField name="weight" type="number">

    <ResponseField name="source" type="string (uri)">
      URL de la source de votre police, par exemple `https://mintlify-assets.b-cdn.net/fonts/Hubot-Sans.woff2`, ou chemin vers votre fichier de police local, par exemple `/assets/fonts/InterDisplay.woff2`. Les polices Google Fonts sont chargées automatiquement lorsque vous indiquez un nom de `family` Google Font ; aucune URL source n&#39;est donc nécessaire.

      Format du fichier de police. Obligatoire lorsque vous utilisez le champ `source`.
