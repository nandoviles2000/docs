---
title: "Page 404 personnalisée"
description: "Personnalisez le titre, la description et l’apparence de la page d’erreur 404 de votre site de documentation pour qu’elle reflète votre marque et oriente les visiteurs."
keywords: ["page d’erreur 404", "pages d’erreur personnalisées"]
---

Toutes les pages 404 suggèrent automatiquement des pages pertinentes en fonction de l’URL demandée. Si des utilisateurs arrivent sur une page 404, un agent analyse le chemin et récupère dans votre documentation des pages sémantiquement proches pour les aider à trouver ce qu’ils recherchent.

Vous pouvez personnaliser le titre et la description de la page d’erreur 404. Utilisez la description pour ajouter des liens utiles ou des conseils.

<div id="configuration">
  ## Configuration
</div>

Configurez votre page 404 dans la section `errors.404` de votre fichier `docs.json` :

```json
"errors": {
  "404": {
    "redirect": false,
    "title": "I can't be found",
    "description": "What ever **happened** to this _page_?"
  }
}
```

<div id="parameters">
  ## Paramètres
</div>

<ResponseField name="redirect" type="boolean">
  Indique s’il faut rediriger automatiquement vers la page d’accueil lorsqu’une page est introuvable.

  Définissez `true` pour rediriger vers la page d’accueil.

  Définissez `false` pour afficher la page 404 personnalisée.
</ResponseField>

<ResponseField name="title" type="string">
  Titre personnalisé de la page d’erreur 404. Remplace le titre par défaut « Page not found ».
</ResponseField>

<ResponseField name="description" type="string">
  Description personnalisée de la page d’erreur 404. Prend en charge le formatage MDX, y compris les liens, le texte en gras, en italique et les composants personnalisés.
</ResponseField>
