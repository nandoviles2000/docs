Vous pouvez faire appel à nos services de migration pour transférer votre documentation vers Mintlify. Ce guide présente le processus de migration, les délais de livraison et notre approche en matière d’assurance qualité.

<div id="what-to-expect-for-your-migration">
  ## À quoi vous attendre lors de votre migration
</div>

Une migration est un transfert ponctuel de votre documentation qui nécessite un gel du code. Nous migrons votre documentation, vos pages de référence de l’API, votre identité visuelle (logos, couleurs et polices) ainsi que votre structure de Navigation. Les services de migration comprennent également des conseils en design ou en architecture de l’information, ainsi que le développement de composants personnalisés, comme des pages d’accueil ou des intégrations personnalisées.

Votre migration comprend un lien de préproduction pour suivre l’avancement, ainsi qu’une période de retours de 7 jours après la livraison pour signaler tout problème lié au contenu, aux ressources ou à l’identité visuelle.

<div id="migration-process">
  ## Processus de migration
</div>

Le processus de migration est très collaboratif. Nous travaillons en étroite collaboration avec votre équipe pour mettre en place des solutions et des développements personnalisés adaptés à vos besoins.

<Steps>
  <Step title="Soumettre le formulaire de migration">
    Soumettez le [formulaire de migration](https://mintlify.typeform.com/ent-migrations).

    Fournissez la source de votre documentation, vos éléments de marque (logos, codes couleur, polices), vos spécifications OpenAPI, votre date de mise en ligne et votre mode de livraison préféré (PR GitHub ou fichier zip).
  </Step>

  <Step title="Appel de lancement">
    Nous examinons votre demande et organisons un appel de lancement avec notre équipe de migration pour passer en revue votre configuration actuelle, comprendre les éventuelles contraintes et répondre aux questions de votre équipe.
  </Step>

  <Step title="Réception du cadrage et du calendrier (1 à 2 jours ouvrés)">
    Nous examinons et analysons le contexte de l&#39;appel, puis vous communiquons un délai de livraison estimatif sous 24 à 48 heures. Nous signalons également tout composant personnalisé ou tout aspect de votre migration nécessitant une discussion.
  </Step>

  <Step title="Suivre l'avancement pendant la migration">
    Nous lançons la migration et partageons un lien de préproduction afin que vous puissiez suivre l&#39;avancement en temps réel.
  </Step>

  <Step title="Réception de la livraison finale">
    Nous livrons votre migration via une PR GitHub ou un fichier zip, selon votre préférence.
  </Step>

  <Step title="Période de retours (sept jours ouvrés)">
    Transmettez tout retour sur le contenu, les éléments graphiques ou l&#39;identité de marque. Nous traitons tous les problèmes inclus dans le périmètre dans le même délai.
  </Step>

  <Step title="Assistance à la mise en ligne">
    Nous fournissons la documentation et les conseils nécessaires pour connecter votre dépôt, configurer les redirections et paramétrer votre domaine personnalisé.
  </Step>
</Steps>

<div id="quality-assurance">
  ## Assurance qualité
</div>

Nous travaillons avec des prestataires tiers rigoureusement sélectionnés et effectuons un audit qualité interne avant la livraison. Voici ce que nous vérifions :

<Card title="Exhaustivité du contenu" icon="file-check">
  * L’intégralité de votre documentation source a été migrée.
  * Le contenu est correctement mis en forme avec les composants Mintlify.
  * La structure de navigation correspond à vos spécifications.
</Card>

<Card title="Éléments visuels" icon="palette">
  * Les images et les vidéos s’affichent correctement.
  * Les polices personnalisées sont appliquées sur l’ensemble du site.
  * Les logos des modes clair et sombre sont utilisés correctement.
  * Les schémas de couleurs respectent les exigences de contraste dans les deux modes.
</Card>

<Card title="Fonctionnement" icon="rocket">
  * Tous les liens fonctionnent correctement (aucun lien brisé).
  * La table des matières s’affiche correctement.
  * Les composants React fonctionnent comme prévu.
  * Aucun problème de performance.
</Card>

<div id="after-your-migration">
  ## Après votre migration
</div>

Une fois votre migration finalisée, vous devrez suivre les étapes ci-dessous pour mettre votre documentation en ligne :

1. [Connectez votre dépôt GitHub et finalisez la configuration](/fr/quickstart).
2. [Configurez les redirections, si nécessaire](/fr/create/redirects).
3. [Configurez votre domaine personnalisé](/fr/customize/custom-domain).
4. **Testez avant la mise en ligne** - Avant de basculer depuis votre ancienne documentation :
   * Passez en revue toutes les pages sur votre lien de préproduction.
   * Testez la navigation et la recherche.
   * Vérifiez que toutes les images et vidéos se chargent correctement.
   * Vérifiez que les blocs de code s&#39;affichent correctement.
   * Testez sur mobile et sur ordinateur.
5. **Mettez-la en ligne.** Votre documentation est prête à être mise en ligne.

<Note>
  **Besoin d&#39;aide ?** Notre équipe de migration est à votre disposition pour vous accompagner tout au long de ces étapes. Contactez-la via votre canal Slack dédié ou à [support@mintlify.com](mailto:support@mintlify.com).
</Note>

<div id="frequently-asked-questions">
  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Combien de temps prend une migration ?">
    Nous livrons généralement les migrations sous 2 à 6 semaines, selon leur complexité. Vous recevrez un calendrier précis après l’appel de lancement.
  </Accordion>

  <Accordion title="Puis-je demander des modifications après la livraison ?">
    Oui. Vous disposez d’une période de retours de 7 jours après la livraison pour demander des modifications du contenu, des ressources ou de l’identité visuelle. Nous prenons en compte tous les retours inclus dans le périmètre dans ce même délai et travaillons avec vous jusqu’à ce que vous soyez prêt à mettre votre site en ligne.
  </Accordion>

  <Accordion title="Que dois-je faire une fois la migration terminée ?">
    La migration transfère votre contenu, mais vous devrez :

    * Connecter votre dépôt de documentation à votre tableau de bord Mintlify.
    * Configurer des redirections depuis les anciennes URL de votre documentation.
    * Configurer votre domaine personnalisé.

    Nous fournissons une documentation pas à pas et une assistance pour chacune de ces étapes.
  </Accordion>

  <Accordion title="Puis-je personnaliser la structure de navigation ?">
    Oui. Vous pouvez nous fournir une architecture de l’information personnalisée, et nous la mettrons en œuvre pour vous. Nous pouvons également vous accompagner dans le développement de composants personnalisés si nécessaire et si la plateforme le permet.
  </Accordion>

  <Accordion title="Que se passe-t-il si ma documentation change pendant la migration ?">
    Comme les migrations nécessitent un gel du code, toute modification apportée à votre documentation source après sa soumission ne sera pas incluse. Nous vous recommandons de finaliser toutes les mises à jour avant de lancer la migration.

    Si ce n’est pas possible, notre équipe travaille avec vous pour définir de courts sprints afin de migrer certaines sections, ou pour réserver du temps dédié après le premier sprint afin de migrer les modifications apportées pendant la migration.
  </Accordion>
</AccordionGroup>
