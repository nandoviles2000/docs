---
title: "Google Tag Manager"
description: "Intégrez Google Tag Manager à votre documentation Mintlify pour gérer de façon centralisée les balises d’analyse, le suivi des conversions et les événements marketing."
keywords: ["intégration GTM", "gestion des balises", "ID de balise", "consentement aux cookies"]
---

Ajoutez votre ID de balise au fichier `docs.json` et nous injecterons le script Google Tag Manager sur toutes vos pages.

Vous êtes responsable de la mise en place des bannières de consentement aux cookies avec Google Tag Manager si vous en avez besoin.

<CodeGroup>
  ```json Options d’analyse dans docs.json
  "integrations": {
      "gtm": {
          "tagId": "required"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "gtm": {
          "tagId": "GTM-MGBL4PW"
      }
  }
  ```
</CodeGroup>
