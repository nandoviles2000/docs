description: "Intégrez Fathom Analytics à votre documentation Mintlify pour suivre les visiteurs dans le respect de la confidentialité et en conformité avec le RGPD, avec une simple configuration de l’ID du site."

---

Ajoutez ce qui suit à votre fichier `docs.json` pour transmettre les données d’analyse à Fathom.

Vous pouvez récupérer le `siteId` dans les paramètres de votre script.

<CodeGroup>
  ```json Options d’analyses dans docs.json
  "integrations": {
      "fathom": {
          "siteId": "required"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "fathom": {
          "siteId": "YSVMSDAY"
      }
  }
  ```
</CodeGroup>
