Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer les données d’analyse à Amplitude.

<CodeGroup>
  ```json Options d’analyses dans docs.json
  "integrations": {
      "amplitude": {
          "apiKey": "required"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "amplitude": {
          "apiKey": "76bb138bf3fbf58186XXX00000"
      }
  }
  ```
</CodeGroup>
