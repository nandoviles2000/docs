title: "Pirsch"
description: "Intégrez Pirsch à votre documentation Mintlify pour bénéficier d’analyses conformes au RGPD et sans cookies, qui suivent les pages vues sans collecter de données personnelles."
keywords: ["Pirsch Analytics", "analyses respectueuses de la vie privée", "code d’identification", "conforme au RGPD"]
---

Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer des données d’analyse à Pirsch.

Vous pouvez obtenir l’ID de votre site dans Settings &gt; Developer &gt; Identification Code.

<CodeGroup>
  ```json Options d’analyse dans docs.json
  "integrations": {
      "pirsch": {
          "id": "required"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "pirsch": {
          "id": "8Kw7OKxBfswOjnKGZa7P9Day8JmVYwTp"
      }
  }
  ```
</CodeGroup>
