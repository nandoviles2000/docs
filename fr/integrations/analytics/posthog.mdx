Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer les analyses à PostHog.

Vous ne devez inclure `apiHost` que si vous auto-hébergez PostHog. Par défaut, nous envoyons les événements à `https://app.posthog.com`.

<CodeGroup>
  ```json Options d’analyses dans docs.json
  "integrations": {
      "posthog": {
          "apiKey": "YOUR_POSTHOG_PROJECT_API_KEY",
          "apiHost": "optional",
          "sessionRecording": true
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "posthog": {
          "apiKey": "phc_TXdpocbYTeZVm5VJmMzHTMrCofBQu3e0kN7HGMNGTVW"
      }
  }
  ```
</CodeGroup>

<div id="configuration-options">
  ### Options de configuration
</div>

<ParamField path="apiKey" type="string" required>
  La clé API de votre projet PostHog. Elle doit commencer par `phc_`.
</ParamField>

<ParamField path="apiHost" type="string">
  L’URL de votre instance PostHog. N’est requise que si vous auto-hébergez PostHog. La valeur par défaut est `https://app.posthog.com`.
</ParamField>

<ParamField path="sessionRecording" type="boolean" default="true">
  Activez ou désactivez l’enregistrement des sessions. Définissez cette valeur sur `false` pour désactiver l’enregistrement de session tout en conservant les analyses activées.
</ParamField>

<div id="session-recordings">
  ## Enregistrements de session
</div>

Les enregistrements de session sont activés par défaut lorsque vous configurez PostHog. Pour désactiver les enregistrements de session tout en laissant les analyses activées, définissez `sessionRecording` sur `false` dans votre configuration.

```json Disable session recordings
"integrations": {
    "posthog": {
        "apiKey": "phc_your-key",
        "sessionRecording": false
    }
}
```

Vous devez ajouter l’URL de votre site de documentation aux &quot;Authorized domains for recordings&quot; de PostHog avant de pouvoir recevoir des enregistrements de session. L’option permettant d’ajouter votre URL se trouve dans les paramètres du projet PostHog.
