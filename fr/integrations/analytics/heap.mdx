Ajoutez ce qui suit à votre fichier `docs.json` pour transmettre les données d&#39;analyse à Heap.

<CodeGroup>
  ```json Options d'analyse dans docs.json
  "integrations": {
      "heap": {
          "appId": "required"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "heap": {
          "appId": "1234567890"
      }
  }
  ```
</CodeGroup>

Remplacez `1234567890` par l&#39;ID de votre application Heap. Vous pouvez le trouver dans les [paramètres de votre compte Heap](https://heapanalytics.com/app/settings).
