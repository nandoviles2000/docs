Vous devez créer une nouvelle propriété <Tooltip tip="Google Analytics 4">GA4</Tooltip> à utiliser avec Mintlify. Les données collectées sont regroupées dans le même projet que vos autres données Google Analytics.

Si vous utilisez l’ancienne version de Google Analytics, Universal Analytics, vous pouvez quand même créer une propriété <Tooltip tip="Google Analytics 4">GA4</Tooltip>. Les données <Tooltip tip="Google Analytics 4">GA4</Tooltip> diffèrent légèrement des données UA, mais elles sont tout de même collectées dans le même projet.

<div id="connect-ga4-to-mintlify">
  ## Connectez GA4 à Mintlify
</div>

<div id="create-a-web-stream">
  ### Créer un flux Web
</div>

Vous devez créer un flux Web pour obtenir l’ID de mesure à renseigner dans Mintlify.

Cliquez sur l’icône en forme d’engrenage en bas à gauche dans Google Analytics. Cliquez ensuite sur Data Streams.

<Frame>![Capture d’écran de la page Data Streams dans le tableau de bord Google Analytics.](/images/ga4-web-streams.png)</Frame>

Créez un flux Web et saisissez l’URL de votre site de documentation Mintlify comme URL du flux.

Votre ID de mesure ressemble à `G-XXXXXXX` et apparaît dans la section Stream Details immédiatement après la création du flux Web.

<div id="put-measurement-id-in-docsjson">
  ### Ajouter l’ID de mesure dans docs.json
</div>

Ajoutez votre ID de mesure dans votre fichier `docs.json`, comme suit :

```json docs.json
"integrations": {
    "ga4": {
        "measurementId": "G-XXXXXXX"
    }
}
```

<div id="wait">
  ### Patientez
</div>

Google Analytics met deux à trois jours avant d&#39;afficher vos données.

Vous pouvez utiliser le [Google Analytics Debugger](https://chrome.google.com/webstore/detail/google-analytics-debugger/jnkmfdileelhofjcijamephohjechhna?hl=en) pour vérifier votre configuration d&#39;analyses. L&#39;extension consigne des informations dans la console de votre navigateur chaque fois que GA4 envoie une requête.

<Note>
  Les liens de prévisualisation n&#39;ont pas les analyses activées.
</Note>
