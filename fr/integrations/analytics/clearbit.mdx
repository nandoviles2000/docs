Ajoutez les éléments suivants à votre fichier `docs.json` pour envoyer les analyses à Clearbit.

<CodeGroup>
  ```json Options d’analyse dans docs.json
  "integrations": {
      "clearbit": {
          "publicApiKey": "required"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "clearbit": {
          "publicApiKey": "pk_1a1882"
      }
  }
  ```
</CodeGroup>
