keywords: ["intégration Hightouch", "activation des données", "clé d’écriture", "synchronisation d’audience"]
---

Ajoutez ce qui suit à votre fichier `docs.json` pour envoyer les analyses à Hightouch.

<Info>
  N’incluez pas `https://` dans `apiHost`.
</Info>

<CodeGroup>
  ```json Options d’analyses dans docs.json
  "integrations": {
      "hightouch": {
          "writeKey": "required"
          "apiHost": "optional"
      }
  }
  ```

  ```json Exemple
  "integrations": {
      "hightouch": {
          "writeKey": "9132c81do371p76sr11da0075469b54f77649c9a067dp0303p56q0q64n072336"
          "apiHost": "us-east-1.hightouch-events.com" # facultatif, valeur par défaut : `us-east-1.hightouch-events.com`
      }
  }
  ```
</CodeGroup>
