<div id="cookie-consent-and-disabling-telemetry">
  ## Consentement aux cookies et désactivation de la télémétrie
</div>

Si vous devez vérifier si un utilisateur a déjà consenti aux cookies pour être conforme au RGPD, vous pouvez indiquer une clé et une valeur de stockage local sous `cookies` :

```json
  "integrations": {
    "cookies": {
      "key": "LOCAL STORAGE KEY",
      "value": "LOCAL STORAGE VALUE"
    }
  }
```

Si ces valeurs sont définies, votre site vérifie dans le stockage local si la clé et la valeur spécifiées sont présentes afin de déterminer si un utilisateur a consenti aux cookies. Si un utilisateur n’a pas consenti aux cookies, votre site désactive la télémétrie pour cet utilisateur.

Si vous souhaitez désactiver la télémétrie pour tous les utilisateurs, ajoutez ce qui suit à votre fichier `docs.json` :

```json
  "integrations": {
    "telemetry": {
      "enabled": false
    }
  }
```

<Note>
  Si vous désactivez la télémétrie, vous ne pourrez pas recueillir de retours sur vos pages de documentation, même si vous activez les retours dans votre tableau de bord.
</Note>
