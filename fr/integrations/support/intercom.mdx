description: "Intégrez le widget de chat Intercom à votre site de documentation Mintlify pour offrir une messagerie client en temps réel, une assistance et une aide à la prise en main."
keywords: ["intégration Intercom", "widget Intercom", "ID d’application", "messagerie intégrée à l’application"]
---

Ajoutez ce qui suit à votre fichier `docs.json` pour ajouter un widget [Intercom](https://www.intercom.com).

<CodeGroup>
  ```json Options d’intégration dans docs.json
  "integrations": {
        "intercom": {
              "appId": "APP_ID"
        }
  }
  ```

  ```json Exemple
  "integrations": {
        "intercom": {
              "appId": "abc123def4"
        }
  }
  ```
</CodeGroup>
