Markdown fournit un texte structuré que les outils d’IA peuvent traiter plus efficacement que le HTML, ce qui améliore la précision des réponses, accélère le traitement et réduit l’utilisation des tokens.

Mintlify génère automatiquement des versions Markdown des pages, optimisées pour les outils d’IA et les intégrations externes.

<div id="md-url-extension">
  ## Extension d’URL `.md`
</div>

Ajoutez `.md` à l’URL de n’importe quelle page pour afficher sa version Markdown.

<PreviewButton href="https://mintlify.com/docs/ai/markdown-export.md">Ouvrir cette page au format Markdown</PreviewButton>

<div id="accept-header">
  ## En-tête `Accept`
</div>

Envoyez une requête avec `Accept: text/markdown` ou `Accept: text/plain` à l’URL de n’importe quelle page pour obtenir la version Markdown plutôt que la version HTML. C’est utile pour les outils d’IA et les intégrations qui récupèrent le contenu de la documentation par programmation.

```bash
curl -H "Accept: text/markdown" https://mintlify.com/docs/ai/markdown-export
```

<div id="audience-specific-content">
  ## Contenu spécifique au public
</div>

Utilisez le composant [visibility](/fr/components/visibility) pour personnaliser le contenu pour les publics humain et IA.

Le contenu encapsulé dans `<Visibility for="humans">` apparaît sur la page web, mais pas dans la sortie Markdown. Le contenu encapsulé dans `<Visibility for="agents">` apparaît dans la sortie Markdown, mais pas sur la page web.

```mdx
<Visibility for="humans">
  Click the **Get started** button in the top-right corner to create your account.
</Visibility>

<Visibility for="agents">
  To create an account, call `POST /v1/accounts` with a valid email address.
</Visibility>
```

<div id="agent-feedback">
  ## Retours des agents
</div>

Si vous activez les [retours des agents](/fr/optimize/feedback#agent-feedback), Mintlify ajoute un bloc `<AgentInstructions>` à l’export Markdown de chaque page pour indiquer aux agents comment envoyer des retours sur le contenu de la page.

Les agents envoient leurs retours en publiant sur le point de terminaison avec le chemin de la page et le texte du retour.

Utilisez les retours des agents pour améliorer vos pages à l’intention des agents en fonction de ce qu’ils jugent incorrect, obsolète ou peu clair.

<div id="keyboard-shortcut">
  ## Raccourci clavier
</div>

Appuyez sur <kbd>Commande</kbd> + <kbd>C</kbd> (<kbd>Ctrl</kbd> + <kbd>C</kbd> sous Windows) pour copier une page au format Markdown dans le presse-papiers.
