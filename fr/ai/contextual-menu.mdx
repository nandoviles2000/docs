Le menu contextuel permet d’accéder rapidement à du contenu optimisé pour l’IA ainsi qu’à des intégrations directes avec des outils d’IA populaires. Lorsque les utilisateurs ouvrent le menu contextuel sur n’importe quelle page, ils peuvent copier le contenu pour l’utiliser comme contexte dans des outils d’IA, ou lancer des conversations dans ChatGPT, Claude, Perplexity, Google AI Studio, Grok, Devin, Windsurf, ou dans l’outil personnalisé de leur choix, avec votre documentation déjà chargée comme contexte.

<div id="menu-options">
  ## Options du menu
</div>

Le menu contextuel inclut plusieurs options prédéfinies que vous pouvez activer en ajoutant leur identifiant à votre configuration.

| Option                                               | Identifiant  | Description                                                                                  |
| :--------------------------------------------------- | :----------- | :------------------------------------------------------------------------------------------- |
| **Copier la page**                                   | `copy`       | Copie la page actuelle au format Markdown pour la coller comme contexte dans des outils d’IA |
| **Afficher en Markdown**                             | `view`       | Ouvre la page actuelle au format Markdown                                                    |
| **Demander à l’assistant**                           | `assistant`  | Ouvre l’[assistant](/fr/assistant/index) en utilisant la page actuelle comme contexte           |
| **Ouvrir dans ChatGPT**                              | `chatgpt`    | Crée une conversation ChatGPT en utilisant la page actuelle comme contexte                   |
| **Ouvrir dans Claude**                               | `claude`     | Crée une conversation Claude en utilisant la page actuelle comme contexte                    |
| **Ouvrir dans Perplexity**                           | `perplexity` | Crée une conversation Perplexity en utilisant la page actuelle comme contexte                |
| **Ouvrir dans Grok**                                 | `grok`       | Crée une conversation Grok en utilisant la page actuelle comme contexte                      |
| **Ouvrir dans Google AI Studio**                     | `aistudio`   | Crée une conversation Google AI Studio en utilisant la page actuelle comme contexte          |
| **Ouvrir dans Devin**                                | `devin`      | Crée une session Devin en utilisant la page actuelle comme contexte                          |
| **Ouvrir dans Windsurf**                             | `windsurf`   | Ouvre Windsurf Cascade en utilisant la page actuelle comme contexte                          |
| **Copier l’URL du serveur MCP**                      | `mcp`        | Copie l’URL de votre serveur MCP dans le presse-papiers                                      |
| **Copier la commande d’installation du serveur MCP** | `add-mcp`    | Copie la commande `npx add-mcp` pour installer le serveur MCP                                |
| **Se connecter à Cursor**                            | `cursor`     | Installe votre serveur MCP hébergé dans Cursor                                               |
| **Se connecter à VS Code**                           | `vscode`     | Installe votre serveur MCP hébergé dans VS Code                                              |
| **Se connecter à Devin**                             | `devin-mcp`  | Installe votre serveur MCP hébergé dans Devin                                                |
| **Options personnalisées**                           | Object       | Ajoutez des options personnalisées au menu contextuel                                        |

<div id="enabling-the-contextual-menu">
  ## Activer le menu contextuel
</div>

Ajoutez le champ `contextual` à votre fichier `docs.json`, puis indiquez les options à inclure.

```json
{
 "contextual": {
   "options": [
     "copy",
     "view",
     "assistant",
     "chatgpt",
     "claude",
     "perplexity",
     "grok",
     "aistudio",
     "devin",
     "windsurf",
      "mcp",
      "cursor",
      "vscode",
      "devin-mcp"
    ]
 }
}
```

<div id="display-location">
  ## Emplacement de l’affichage
</div>

Par défaut, le menu contextuel apparaît dans l’en-tête de la page. Vous pouvez le configurer pour qu’il s’affiche à la place dans la barre latérale de la table des matières à l’aide de l’option `display`.

```json
{
  "contextual": {
    "options": ["copy", "view", "chatgpt", "claude"],
    "display": "toc"
  }
}
```

| Valeur   | Description                                                                 |
| :------- | :-------------------------------------------------------------------------- |
| `header` | Affiche les options dans le menu contextuel en haut de la page (par défaut) |
| `toc`    | Affiche les options dans la barre latérale de la table des matières         |

<div id="adding-custom-options">
  ## Ajouter des options personnalisées
</div>

Créez des options personnalisées dans le menu contextuel en ajoutant un objet au tableau `options`. Chaque option personnalisée nécessite les propriétés suivantes :

<ResponseField name="title" type="string" required>
  Le titre de l’option.
</ResponseField>

<ResponseField name="description" type="string" required>
  La description de l’option. Elle s’affiche sous le titre lorsque le menu contextuel s’ouvre.
</ResponseField>

<IconsRequired />

<ResponseField name="href" type="string | object" required>
  Le `href` de l’option. Utilisez une chaîne de caractères pour les liens simples ou un objet pour les liens dynamiques avec des paramètres de requête.

  <Expandable title="objet href">
    <ResponseField name="base" type="string" required>
      L’URL de base de l’option.
    </ResponseField>

    <ResponseField name="query" type="object" required>
      Les paramètres de requête de l’option.

      <Expandable title="objet query">
        <ResponseField name="key" type="string" required>
          La clé du paramètre de requête.
        </ResponseField>

        <ResponseField name="value" type="string" required>
          La valeur du paramètre de requête. Mintlify remplace les variables de remplacement suivantes par les valeurs correspondantes :

          * Utilisez `$page` pour insérer le contenu de la page actuelle en Markdown.
          * Utilisez `$path` pour insérer le chemin de la page actuelle.
          * Utilisez `$mcp` pour insérer l’URL du serveur MCP hébergé.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

Exemple d’option personnalisée :

```json {9-14} wrap
{
    "contextual": {
        "options": [
            "copy",
            "view",
            "chatgpt",
            "claude",
            "perplexity",
            {
                "title": "Request a feature",
                "description": "Join the discussion on GitHub to request a new feature",
                "icon": "plus",
                "href": "https://github.com/orgs/mintlify/discussions/categories/feature-requests"
            }
        ]
    }
}
```
