<div id="about-mcp-servers">
  ## À propos des serveurs MCP
</div>

Le Model Context Protocol (MCP) est un protocole ouvert qui établit des connexions standardisées entre les applications d’IA et des services externes, comme la documentation. Mintlify génère un serveur MCP à partir de votre documentation, ce qui prépare votre contenu pour l’écosystème plus large de l’IA, dans lequel n’importe quel client MCP, comme Claude, Cursor, Goose ou ChatGPT, peut se connecter à votre documentation.

Votre serveur MCP expose des outils permettant aux applications d’IA de rechercher dans votre documentation et de récupérer le contenu intégral des pages. Vos utilisateurs doivent connecter votre serveur MCP à leurs outils.

<div id="how-mcp-servers-work">
  ### Fonctionnement des serveurs MCP
</div>

Lorsqu&#39;une application d&#39;IA se connecte au serveur MCP de votre documentation, elle peut effectuer des recherches dans votre documentation et récupérer directement le contenu complet des pages en réponse au prompt d&#39;un utilisateur, au lieu de s&#39;appuyer sur des informations issues de ses données d&#39;entraînement ou d&#39;effectuer une recherche générique sur le Web. Votre serveur MCP donne accès à l&#39;ensemble du contenu indexé de votre site de documentation.

* Les applications d&#39;IA peuvent effectuer de manière proactive des recherches dans votre documentation pendant qu&#39;elles génèrent une réponse, même s&#39;il ne leur a pas été explicitement demandé d&#39;y chercher la réponse.
* Les applications d&#39;IA déterminent quand utiliser les outils disponibles en fonction du contexte de la conversation et de la pertinence de votre documentation.
* Chaque appel à un outil a lieu pendant le processus de génération, de sorte que l&#39;application d&#39;IA s&#39;appuie sur des informations à jour issues de votre documentation pour générer sa réponse.

<Tip>
  Certains outils d&#39;IA, comme Claude, prennent en charge à la fois MCP et les skills. MCP donne accès au contenu de votre documentation, tandis que les skills indiquent aux agents comment utiliser efficacement ce contenu. Ils sont complémentaires, et en connectant votre serveur MCP, vous donnez aux agents accès aux deux.
</Tip>

<div id="mcp-tools">
  ### Outils MCP
</div>

Votre serveur MCP fournit deux outils que les agents peuvent utiliser :

* **Recherche** : Recherche dans toute votre documentation pour trouver du contenu pertinent, et renvoie des extraits avec des titres et des liens. Utilisez cet outil pour découvrir des informations ou trouver des pages correspondant à une requête.
* **Interroger le système de fichiers de la documentation** : Lit et parcourt le système de fichiers virtuel de votre documentation à l’aide de commandes de style shell. Utilisez cet outil pour récupérer le contenu des pages, parcourir la structure de la documentation ou extraire des sections spécifiques, y compris en lisant plusieurs pages par lot en un seul appel.

Les agents déterminent quand utiliser chaque outil en fonction du contexte de la conversation. Par exemple, un agent peut d’abord rechercher dans votre documentation des pages pertinentes, puis utiliser l’outil d’interrogation du système de fichiers de la documentation pour lire le contenu complet des résultats les plus pertinents.

<div id="mcp-resources">
  ### Ressources MCP
</div>

Votre serveur MCP expose également vos [fichiers skill.md](/fr/ai/skillmd) sous forme de ressources MCP. Les agents connectés à votre serveur MCP peuvent découvrir et consulter vos fichiers skill sans avoir à les installer séparément.

Les ressources `Skill.md` apparaissent dans la liste des ressources du serveur MCP et contiennent les descriptions de capacités que Mintlify génère ou que vous définissez dans vos [fichiers skill personnalisés](/fr/ai/skillmd#custom-skill-files).

<div id="search-parameters">
  ### Paramètres de recherche
</div>

L’outil de recherche MCP prend en charge des paramètres facultatifs que les applications d’IA utilisent pour contrôler et affiner les résultats de recherche.

* **`pageSize`**: Nombre de résultats à renvoyer, compris entre 1 et 50. La valeur par défaut est 10.
* **`scoreThreshold`**: Score de pertinence minimal entre 0 et 1. Renvoie uniquement les résultats dont le score est égal ou supérieur à ce seuil. Utilisez ce paramètre pour exclure les correspondances peu pertinentes.
* **`version`**: Filtre les résultats pour une version spécifique de la documentation. Par exemple, `'v0.7'`. Renvoie uniquement le contenu balisé avec la version spécifiée ou le contenu disponible dans toutes les versions.
* **`language`**: Filtre les résultats pour un code de langue spécifique. Par exemple, `'en'`, `'zh'` ou `'es'`. Renvoie uniquement le contenu dans la langue spécifiée ou le contenu disponible dans toutes les langues.

Les applications d’IA déterminent quand appliquer ces paramètres en fonction du contexte de la requête de l’utilisateur. Par exemple, si un utilisateur pose une question sur une version spécifique de l’API, l’application d’IA peut appliquer automatiquement le filtre approprié pour fournir des résultats plus pertinents.

<div id="mcp-compared-to-web-search">
  ### MCP face à la recherche sur le Web
</div>

Les outils d’IA peuvent effectuer des recherches sur le Web, mais MCP présente des avantages spécifiques pour la documentation.

* **Accès direct à la source** : la recherche sur le Web dépend de ce que les moteurs de recherche ont indexé, qui peut être obsolète ou incomplet. MCP interroge directement la version actuelle indexée de votre documentation.
* **Flux de travail intégré** : MCP permet à l’IA d’effectuer une recherche pendant la génération de la réponse, au lieu de lancer une recherche web distincte.
* **Pas de bruit lié à la recherche** : le SEO et les algorithmes de classement influencent les résultats de recherche sur le Web. MCP accède directement au contenu de votre documentation.

<div id="access-your-mcp-server">
  ## Accédez à votre serveur MCP
</div>

Mintlify génère un serveur MCP pour votre documentation et l’héberge au chemin `/mcp` de l’URL de votre documentation. Par exemple, le serveur MCP de Mintlify est accessible à l’adresse `https://mintlify.com/docs/mcp`.

* Pour une documentation publique, votre serveur MCP est accessible à tous. Il effectue des recherches dans toutes les pages publiques indexées.
* Pour une documentation avec authentification partielle, où certaines pages sont publiques et d’autres nécessitent une connexion, vous devez activer votre serveur MCP avant que les utilisateurs puissent y accéder. Les utilisateurs non authentifiés peuvent rechercher dans le contenu public. Les utilisateurs authentifiés peuvent rechercher dans tout le contenu auquel ils sont autorisés à accéder en fonction de leurs [groupes d’utilisateurs](/fr/deploy/authentication-setup).
* Pour une documentation où toutes les pages nécessitent une authentification, vous devez activer votre serveur MCP avant qu’il soit accessible aux utilisateurs. Les utilisateurs doivent s’authentifier avant de se connecter à votre serveur MCP. Votre serveur MCP recherche uniquement dans le contenu auquel chaque utilisateur a accès en fonction de ses [groupes d’utilisateurs](/fr/deploy/authentication-setup).

Consultez et copiez l’URL de votre serveur MCP sur la [page du serveur MCP](https://dashboard.mintlify.com/products/mcp) de votre tableau de bord.

<div id="enable-authenticated-mcp">
  ### Activer le MCP avec authentification
</div>

Si votre documentation nécessite une authentification, les utilisateurs doivent s’authentifier auprès de votre serveur MCP avant de pouvoir s’y connecter. Lorsqu’un utilisateur ajoute l’URL de votre serveur MCP à son outil d’IA, il doit se connecter avec ses identifiants existants. Une fois l’authentification effectuée, il est redirigé vers son outil. Le serveur MCP ne renvoie que le contenu auquel chaque utilisateur est autorisé à accéder, en fonction de ses [groupes d’utilisateurs](/fr/deploy/authentication-setup).

Si votre documentation utilise une authentification partielle, avec à la fois des pages publiques et des pages protégées, votre serveur MCP propose deux points de terminaison :

* `/mcp` : ne nécessite pas d’authentification. Renvoie uniquement le contenu public. Partagez-le avec les utilisateurs qui ont besoin d’accéder au contenu public.
* `/authed/mcp` : nécessite toujours une authentification. Renvoie le contenu autorisé pour chaque utilisateur, en fonction de ses [groupes d’utilisateurs](/fr/deploy/authentication-setup). Partagez-le avec les utilisateurs qui ont besoin d’accéder au contenu protégé.

Le point de terminaison `/authed/mcp` utilise son propre flux OAuth à l’adresse `/authed/mcp/oauth/*`. Les domaines de redirection configurés pour votre serveur MCP s’appliquent à la fois à `/mcp` et à `/authed/mcp`.

Par défaut, votre serveur MCP est accessible uniquement aux outils exécutés en localhost. Pour permettre aux outils web de se connecter, ajoutez leurs domaines de redirection. Un domaine de redirection est le nom d’hôte qu’un outil d’IA utilise une fois qu’un utilisateur a terminé l’authentification, comme `claude.ai` ou `app.cursor.ai`. Les outils d’IA de vos utilisateurs ne peuvent pas finaliser l’authentification tant que leur domaine de redirection ne figure pas dans cette liste.

<Steps>
  <Step title="Activer le MCP avec authentification dans votre tableau de bord">
    1. Accédez à la [page du serveur MCP](https://dashboard.mintlify.com/products/mcp) dans votre tableau de bord.
    2. Cliquez sur le bouton bascule **Enable MCP Server**.
  </Step>

  <Step title="Ajouter des domaines de redirection">
    Ajoutez les domaines de redirection des outils d’IA auxquels vous souhaitez donner accès à vos utilisateurs. Les outils d’IA de vos utilisateurs ne peuvent pas finaliser l’authentification tant que leur domaine de redirection ne figure pas dans cette liste. Les domaines de redirection courants incluent `claude.ai` et `vscode.dev/redirect`.

    Par défaut, les domaines de redirection utilisent `https://`. Pour autoriser un schéma de protocole personnalisé, incluez le protocole complet dans l’entrée du domaine. Par exemple, un callback d’application native comme `myapp://callback`. Mintlify bloque toujours les protocoles dangereux tels que `javascript:`, `data:` et `file:`.

    Les adresses de bouclage (`localhost`, `127.0.0.1`) sont toujours approuvées et n’ont pas besoin d’être ajoutées.
  </Step>
</Steps>

<div id="client-credentials">
  ### Identifiants client
</div>

Les identifiants client vous permettent de vous connecter par programmation à votre serveur MCP authentifié sans passer par une connexion dans le navigateur. Utilisez-les pour les intégrations côté serveur, les pipelines CI/CD, les flux de travail automatisés et tout environnement dans lequel un utilisateur ne peut pas suivre un flux OAuth interactif.

Les identifiants client permettent de s&#39;authentifier auprès du point de terminaison `/authed/mcp` et renvoient le même contenu qu&#39;un utilisateur authentifié ayant accès à toutes les pages.

<Steps>
  <Step title="Créer un identifiant client">
    1. Accédez à la [page du serveur MCP](https://dashboard.mintlify.com/products/mcp) dans votre tableau de bord.
    2. Dans la section **Client Credentials**, sélectionnez **Create credential**.
    3. Saisissez un libellé pour l&#39;identifiant afin d&#39;en préciser l&#39;usage.
    4. Copiez l&#39;**ID client** et le **secret client**. Le secret client n&#39;est affiché qu&#39;une seule fois. Vous ne pourrez pas le récupérer plus tard.
  </Step>

  <Step title="Échanger des identifiants contre un jeton d'accès">
    Envoyez une requête POST au point de terminaison de jeton de votre serveur MCP avec votre ID client et votre secret. Le point de terminaison de jeton correspond au chemin `/authed/mcp/oauth/token` dans l&#39;URL de votre documentation.

    <CodeGroup>
      ```bash cURL
      curl -X POST https://your-docs.com/authed/mcp/oauth/token \
        -H 'Content-Type: application/x-www-form-urlencoded' \
        -d 'grant_type=client_credentials&client_id=CLIENT_ID&client_secret=CLIENT_SECRET'
      ```

      ```bash cURL (Basic Auth)
      curl -X POST https://your-docs.com/authed/mcp/oauth/token \
        -H 'Content-Type: application/x-www-form-urlencoded' \
        -H 'Authorization: Basic BASE64_CLIENT_ID_COLON_SECRET' \
        -d 'grant_type=client_credentials'
      ```
    </CodeGroup>

    La réponse contient un jeton d&#39;accès :

    ```json
    {
      "access_token": "eyJhbGciOi...",
      "token_type": "Bearer",
      "expires_in": 1209600,
      "scope": "mcp:search"
    }
    ```

    Les jetons d&#39;accès expirent après 14 jours. Demandez-en un nouveau à l&#39;expiration du jeton actuel.
  </Step>

  <Step title="Se connecter au serveur MCP">
    Utilisez le jeton d&#39;accès comme jeton Bearer lors de la connexion au point de terminaison `/authed/mcp`.

    <CodeGroup>
      ```bash cURL
      curl -X POST https://your-docs.com/authed/mcp \
        -H 'Authorization: Bearer ACCESS_TOKEN' \
        -H 'Content-Type: application/json' \
        -H 'Accept: application/json, text/event-stream' \
        -d '{
          "jsonrpc": "2.0",
          "id": 1,
          "method": "initialize",
          "params": {
            "protocolVersion": "2025-03-26",
            "capabilities": {},
            "clientInfo": {"name": "my-integration", "version": "1.0.0"}
          }
        }'
      ```

      ```bash Claude Code
      claude mcp add --transport http \
        --header "Authorization: Bearer ACCESS_TOKEN" \
        my-docs https://your-docs.com/authed/mcp
      ```
    </CodeGroup>
  </Step>
</Steps>

<div id="managing-client-credentials">

</div>

Vous pouvez gérer vos identifiants client sur la [page du serveur MCP](https://dashboard.mintlify.com/products/mcp) de votre tableau de bord.

</Warning>

<div id="content-filtering-and-indexing">
  ## Filtrage du contenu et indexation
</div>

Votre serveur MCP effectue des recherches dans le contenu que Mintlify indexe à partir de votre dépôt de documentation. Le traitement des fichiers et l’indexation pour la recherche déterminent quel contenu est disponible via votre serveur MCP.

Pour la documentation qui nécessite une authentification, votre serveur MCP indexe uniquement les pages des [groupes d’utilisateurs publics](/fr/deploy/authentication-setup#make-pages-public). Pour la documentation avec une authentification partielle, votre serveur MCP indexe les pages publiques accessibles aux utilisateurs non authentifiés, ainsi que les pages des groupes d’utilisateurs publics.

<div id="file-processing-with-mintignore">
  ### Traitement des fichiers avec `.mintignore`
</div>

Si des fichiers correspondent aux motifs définis dans [.mintignore](/fr/organize/mintignore), Mintlify ne les traite ni ne les indexe. Ces fichiers ne sont pas accessibles via votre serveur MCP.

<div id="search-indexing-with-docsjson">
  ### Indexation de la recherche avec `docs.json`
</div>

Par défaut, Mintlify indexe uniquement, pour la recherche via votre serveur MCP, les pages incluses dans la navigation de votre `docs.json`.

Mintlify exclut les [pages masquées](/fr/organize/hidden-pages) (les pages qui ne figurent pas dans votre navigation) de l’index de recherche, sauf si vous choisissez d’indexer toutes les pages. Pour inclure les pages masquées dans les résultats de recherche de votre serveur MCP, ajoutez la propriété `seo.indexing` à votre `docs.json`.

```json
"seo": {
    "indexing": "all"
}
```

Pour exclure une page spécifique de l’index de Recherche, ajoutez `noindex: true` à ses métadonnées d’en-tête.

```mdx
---
title: "Hidden page"
description: "This page is not in the navigation and is not available through search."
noindex: true
---
```

<div id="use-your-mcp-server">
  ## Utilisez votre serveur MCP
</div>

Vos utilisateurs doivent connecter votre serveur MCP à leurs outils d’IA préférés.

1. Rendez l’URL de votre serveur MCP publiquement accessible.
2. Les utilisateurs copient l’URL de votre serveur MCP et l’ajoutent à leurs outils.
3. Les utilisateurs accèdent à votre documentation via leurs outils.

Voici quelques façons d’aider vos utilisateurs à se connecter à votre serveur MCP :

<Tabs>
  <Tab title="Menu contextuel">
    Ajoutez des options au [menu contextuel](/fr/ai/contextual-menu) pour permettre à vos utilisateurs de se connecter à votre serveur MCP depuis n’importe quelle page de votre documentation.

    | Option                                               | Identifiant | Description                                                               |
    | :--------------------------------------------------- | :---------- | :------------------------------------------------------------------------ |
    | **Copier l’URL du serveur MCP**                      | `mcp`       | Copie l’URL de votre serveur MCP dans le presse-papiers de l’utilisateur. |
    | **Copier la commande d’installation du serveur MCP** | `add-mcp`   | Copie la commande `npx add-mcp` permettant d’installer le serveur MCP.    |
    | **Se connecter à Cursor**                            | `cursor`    | Installe votre serveur MCP dans Cursor.                                   |
    | **Se connecter à VS Code**                           | `vscode`    | Installe votre serveur MCP dans VS Code.                                  |
  </Tab>

  <Tab title="Claude">
    <Steps>
      <Step title="Récupérez l’URL de votre serveur MCP.">
        Accédez à votre [tableau de bord](https://dashboard.mintlify.com/products/mcp) et repérez l’URL de votre serveur MCP.
      </Step>

      <Step title="Publiez l’URL de votre serveur MCP pour vos utilisateurs.">
        Créez un guide pour vos utilisateurs qui inclut l’URL de votre serveur MCP et les étapes pour le connecter à Claude.

        4. Sélectionnez **Add**.
        5. Lorsque vous utilisez Claude, sélectionnez le bouton des pièces jointes (l’icône +).
        6. Sélectionnez votre serveur MCP.
      </Step>
    </Steps>

    Consultez la [documentation du Model Context Protocol](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server) pour plus de détails.
  </Tab>

  <Tab title="Claude Code">

  </Tab>

<div id="example-connect-to-the-mintlify-mcp-server">
  ### Exemple : se connecter au serveur MCP de Mintlify
</div>

Connectez-vous au serveur MCP de Mintlify pour effectuer des recherches dans ce site de documentation depuis l’outil d’IA de votre choix. Vous obtiendrez ainsi des réponses plus précises sur l’utilisation de Mintlify dans votre environnement local et verrez comment aider vos utilisateurs à se connecter à votre serveur MCP.

<Tabs>
  <Tab title="Menu contextuel">
    En haut de cette page, ouvrez le menu contextuel, puis choisissez **Connect to Cursor** ou **Connect to VS Code** pour connecter le serveur MCP de Mintlify à l’IDE de votre choix.
  </Tab>

  <Tab title="Claude">
    Pour utiliser le serveur MCP de Mintlify avec Claude :

    <Steps>
      <Step title="Ajouter le serveur MCP de Mintlify à Claude">
        1. Accédez à la page [Connectors](https://claude.ai/settings/connectors) dans les paramètres de Claude.
        2. Sélectionnez **Add custom connector**.
        3. Ajoutez le serveur MCP de Mintlify :

        * Nom : `Mintlify`
        * URL : `https://mintlify.com/docs/mcp`

        4. Sélectionnez **Add**.
      </Step>

      <Step title="Accéder au serveur MCP dans votre chat">
        1. Dans Claude, sélectionnez le bouton des pièces jointes (l’icône plus).
        2. Sélectionnez le serveur MCP de Mintlify.
        3. Posez une question à Claude sur Mintlify.

<div id="using-multiple-mcp-servers">
  ### Utiliser plusieurs serveurs MCP
</div>

Les utilisateurs peuvent connecter plusieurs serveurs MCP à leurs outils d’IA. Les serveurs MCP connectés ne consomment pas de contexte tant que l’IA n’appelle pas un outil de recherche. L’IA décide quand lancer une recherche en fonction de la pertinence de la requête, elle n’interroge donc pas systématiquement tous les serveurs connectés pour chaque question.

Lorsque l’IA effectue une recherche, chaque requête renvoie plusieurs résultats qui s’ajoutent au contexte de la conversation. Si l’IA interroge plusieurs serveurs pour une seule question, cela peut consommer une part importante du contexte disponible.

Bonnes pratiques pour utiliser plusieurs serveurs MCP :

* Connectez uniquement les serveurs MCP pertinents pour votre travail en cours.
* Soyez précis dans vos prompts afin que l’IA interroge le serveur le plus pertinent.
* Déconnectez les serveurs que vous n’utilisez pas activement afin de limiter la consommation potentielle de contexte.
