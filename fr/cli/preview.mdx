<div id="start-the-local-preview">
  ## Démarrez l’aperçu local
</div>

Accédez au répertoire de votre documentation contenant votre fichier `docs.json`, puis exécutez :

```bash
mint dev
```

L’aperçu local démarre à l’adresse `http://localhost:3000`. Vos modifications s’affichent en temps réel.

Par défaut, l’aperçu s’ouvre automatiquement dans votre navigateur. Pour empêcher l’ouverture du navigateur, utilisez l’option `--no-open` :

```bash
mint dev --no-open
```

Pour générer un aperçu sans installer la CLI de façon globale, exécutez :

```bash
npx mint dev
```

<div id="log-in-for-search-and-assistant">
  ## Connectez-vous pour utiliser la recherche et l’assistant
</div>

Vous devez vous connecter au CLI avec votre compte Mintlify pour activer la recherche et l’[assistant](/fr/assistant/index).

```bash
mint login
```

Après vous être authentifié avec la commande `mint login`, le CLI enregistre vos identifiants dans `~/.config/mintlify/config.json` pour que vous restiez connecté d’une session à l’autre. Le CLI vous invite également à sélectionner un projet par défaut, utilisé par des commandes comme `mint analytics`.

Une fois connecté, exécutez `mint dev` pour lancer l’aperçu local avec la recherche et l’assistant activés. L’assistant utilise le même contenu indexé que votre site de documentation déployé.

Pour vérifier si vous êtes authentifié, exécutez :

```bash
mint status
```

Pour vous déconnecter, exécutez :

```bash
mint logout
```

<div id="custom-ports">
  ## Ports personnalisés
</div>

Par défaut, la CLI utilise le port 3000. Pour utiliser un autre port, utilisez l’option `--port` :

```bash
mint dev --port 3333
```

Si le port est déjà utilisé, le CLI tente automatiquement d’utiliser le port disponible suivant.

<div id="skip-openapi-processing">
  ## Ignorer le traitement OpenAPI
</div>

Si vous avez de nombreux fichiers OpenAPI, vous pouvez ignorer le traitement OpenAPI pendant le développement local afin d’améliorer les performances à l’aide de l’indicateur `--disable-openapi` :

```bash
mint dev --disable-openapi
```

<div id="preview-as-a-specific-group">
  ## Prévisualiser avec un groupe spécifique
</div>

Si vous utilisez un contrôle d’accès basé sur les groupes, prévisualisez avec un groupe d’authentification spécifique à l’aide de l’indicateur `--groups` :

```bash
mint dev --groups admin
```

Consultez [Configuration de l’authentification](/fr/deploy/authentication-setup#control-access-with-groups) pour en savoir plus sur les groupes.
