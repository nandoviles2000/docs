La commande `mint analytics` vous donne accès aux [analyses de votre documentation](/fr/optimize/analytics) depuis le terminal. C’est utile pour automatiser des rapports d’analyses, transmettre des données à d’autres outils et effectuer des vérifications rapides sans ouvrir le tableau de bord.

<div id="prerequisites">
  ## Prérequis
</div>

Vous devez vous connecter pour utiliser les commandes d’analyses. Exécutez `mint login` pour vous authentifier avec votre compte Mintlify.

Consultez [Prévisualiser localement](/fr/cli/preview#log-in-for-search-and-assistant) pour plus d’informations sur l’authentification.

<div id="view-key-metrics">
  ## Consulter les métriques clés
</div>

Affichez un récapitulatif des vues, des visiteurs, des recherches, des retours et de l’utilisation de l’assistant :

```bash
mint analytics stats
```

Utilisez les options pour filtrer par plage de dates ou par page :

* `--from` : Date de début au format `YYYY-MM-DD`. Par défaut, cette valeur correspond à il y a 7 jours.
* `--to` : Date de fin au format `YYYY-MM-DD`. Par défaut, cette valeur est définie sur aujourd’hui.
* `--page` : Filtre sur un chemin de page spécifique.

```bash Example analytics stats flags
mint analytics stats --from 2025-01-01 --to 2025-01-31
mint analytics stats --page /quickstart
```

<div id="view-search-analytics">
  ## Consultez les analyses de la recherche
</div>

Découvrez ce que vos utilisateurs recherchent, avec le nombre de résultats et les taux de clic :

```bash
mint analytics search
```

Utilisez des options pour filtrer par chaîne de requête ou par page :

* `--query` : Filtre par sous-chaîne de la requête de recherche.
* `--page` : Filtre sur un chemin de page spécifique.

```bash Example analytics search flags
mint analytics search --query "authentication"

mint analytics search --page /api-reference
```

<div id="view-feedback">
  ## Consulter les retours
</div>

Consultez les retours envoyés par les utilisateurs sur vos pages de documentation :

```bash
mint analytics feedback
```

Utilisez des options pour agréger les retours par page ou filtrer ceux des extraits de code :

* `--type` : Agrège les retours par page ou par extrait de code. La valeur par défaut est `page`.
* `--page` : Filtre sur un chemin de page spécifique.

```bash Example analytics feedback flags
mint analytics feedback --type page
mint analytics feedback --type code
```

<div id="view-assistant-conversations">
  ## Afficher les conversations de l’assistant
</div>

Listez les conversations récentes ainsi que les catégories de conversation de l’assistant IA :

```bash
mint analytics conversation list
mint analytics conversation buckets list
```

La sortie de chaque commande de liste inclut un ID pour chaque entrée. Passez cet ID à la commande `view` correspondante pour afficher tous les détails :

```bash
mint analytics conversation view <conversation-id>
mint analytics conversation buckets view <bucket-id>
```

<div id="choose-an-output-format">
  ## Choisissez un format de sortie
</div>

Toutes les commandes d’analyses utilisent par défaut la sortie `plain`, avec des champs séparés par des tabulations, ce qui convient au chaînage avec d’autres outils. Utilisez `--format` pour changer le format de sortie :

```bash
mint analytics stats --format table    # Tableau formaté avec couleurs
mint analytics stats --format json     # JSON brut
mint analytics stats --format graph    # Graphique à barres horizontales
```

La CLI détecte automatiquement les environnements d’agent IA, comme Claude Code, ainsi que les terminaux non interactifs, et utilise par défaut le format de sortie JSON.

<div id="set-defaults-with-config">
  ## Définir des valeurs par défaut avec `mint config`
</div>

Pour éviter de répéter les options courantes, définissez des valeurs par défaut avec `mint config`. La configuration est enregistrée dans `~/.config/mintlify/config.json`.

Lorsque vous exécutez `mint login`, le CLI définit la clé `subdomain`. Si vous avez plusieurs déploiements, le CLI vous invite à en sélectionner un. Vous pouvez remplacer cette valeur par défaut à tout moment avec `mint config set subdomain <subdomain>`.

Clés de configuration disponibles :

| Clé         | Description                                                                                     |
| ----------- | ----------------------------------------------------------------------------------------------- |
| `subdomain` | Sous-domaine par défaut pour les commandes d&#39;analyses. Défini par la commande `mint login`. |
| `dateFrom`  | Date de début par défaut pour les requêtes d&#39;analyses (`YYYY-MM-DD`).                       |
| `dateTo`    | Date de fin par défaut pour les requêtes d&#39;analyses (`YYYY-MM-DD`).                         |

```bash Example configs
mint config set subdomain my-docs
mint config set dateFrom 2025-01-01
```

Une fois définies, les commandes d’analyses utilisent automatiquement ces valeurs :

```bash
# Utilise le sous-domaine et dateFrom configurés sans indicateurs
mint analytics stats
```

Pour afficher ou effacer une valeur, exécutez :

```bash
mint config get subdomain
mint config clear subdomain
```
