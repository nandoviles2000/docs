Mintlify sert automatiquement les ressources statiques de votre dépôt de documentation au chemin approprié sur votre domaine. Par exemple, si votre dépôt contient `/images/my-logo.png`, le fichier image est disponible à l’adresse `https://docs.your-project.com/images/my-logo.png`.

Vous pouvez mettre à la disposition de vos utilisateurs n’importe quel type de fichier pris en charge, notamment des spécifications OpenAPI, des images, des vidéos, etc.

Les fichiers doivent faire moins de 20 Mo.

<Note>
  La diffusion de fichiers n’est pas prise en charge pour les sites de documentation sur lesquels l’authentification est activée. Si votre site nécessite une authentification, les fichiers statiques ne sont pas accessibles via leurs URL directes.
</Note>

<div id="supported-file-types">
  ## Types de fichiers pris en charge
</div>

Types de fichiers pris en charge pour toutes les offres :

* **Images**: `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.ico`
* **Vidéo**: `.mp4`, `.webm`
* **Audio**: `.mp3`, `.wav`
* **Données**: `.json`, `.yaml`
* **Feuilles de style**: `.css`
* **Scripts**: `.js`
* **Polices**: `.woff`, `.woff2`, `.ttf`, `.eot`

Types de fichiers pris en charge pour les offres Enterprise :

* **Documents**: `.pdf`, `.txt`
* **Données**: `.xml`, `.csv`
* **Archives**: `.zip`

<div id="file-organization">
  ## Organisation des fichiers
</div>

Organisez vos fichiers à l’aide de dossiers pour que votre dépôt reste facile à parcourir :

```text
/your-project
  |- docs.json
  |- images/
    |- logo.png
    |- screenshots/
      |- dashboard.png
  |- assets/
    |- whitepaper.pdf
    |- demo-video.mp4
```

Les fichiers sont servis à la racine de votre domaine. La structure de votre dépôt correspond donc directement à celle des URL. Dans l’exemple précédent, `assets/whitepaper.pdf` serait accessible à l’adresse `https://docs.your-project.com/assets/whitepaper.pdf`.
