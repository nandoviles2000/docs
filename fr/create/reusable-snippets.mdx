L’un des principes fondamentaux du développement logiciel est le DRY (Don&#39;t Repeat Yourself), et il s’applique aussi à la documentation. Si vous vous retrouvez à répéter le même contenu à plusieurs endroits, créez un snippet personnalisé pour ce contenu. Les snippets contiennent du contenu que vous pouvez importer dans d’autres fichiers pour le réutiliser. Vous contrôlez l’endroit où le snippet apparaît sur une page. Si vous devez un jour mettre à jour ce contenu, il vous suffit de modifier le snippet plutôt que chaque fichier où il est utilisé.

<div id="how-snippets-work">
  ## Fonctionnement des snippets
</div>

Les snippets sont des fichiers `.mdx`, `.md` ou `.jsx` importés dans un autre fichier. Vous pouvez placer les fichiers de snippet n’importe où dans votre projet.

Lorsque vous importez un snippet dans un autre fichier, il apparaît uniquement à l’endroit où vous l’importez et ne s’affiche pas comme une page autonome. Tout fichier du dossier `/snippets/` est toujours considéré comme un snippet, même s’il n’est pas importé dans un autre fichier.

<div id="create-snippets">
  ## Créer des snippets
</div>

Créez un fichier avec le contenu que vous souhaitez réutiliser. Les snippets peuvent contenir tous les types de contenu pris en charge par Mintlify et importer d’autres snippets.

<div id="import-snippets-into-pages">
  ## Importer des snippets dans les pages
</div>

Importez des snippets dans les pages à l’aide d’un chemin absolu ou relatif.

* **Imports absolus** : commencez par `/` pour importer depuis la racine de votre projet.
* **Imports relatifs** : utilisez `./` ou `../` pour importer des snippets par rapport à l’emplacement du fichier actuel.

<Tip>
  Les imports relatifs permettent la navigation dans l’IDE. Appuyez sur <kbd>CMD</kbd> et cliquez sur le nom d’un snippet dans votre éditeur pour accéder directement à sa définition.
</Tip>

<div id="import-text">
  ### Importer du texte
</div>

1. Ajoutez au fichier de snippet le contenu que vous souhaitez réutiliser.

   ```mdx shared/my-snippet.mdx wrap
   Bonjour le monde ! Voici le contenu que je souhaite réutiliser sur plusieurs pages.
   ```

2. Importez le snippet dans votre fichier cible à l’aide d’un chemin absolu ou relatif.

   <CodeGroup>
     ```mdx Absolute import
     ---
     title: "Une page d'exemple"
     description: "Il s'agit d'une page d'exemple qui importe un snippet."
     ---

     import MySnippet from "/shared/my-snippet.mdx";

     Le contenu du snippet s’affiche sous cette phrase.

     <MySnippet />
     ```

     ```mdx Relative import
     ---
     title: "Une page d'exemple"
     description: "Il s'agit d'une page d'exemple qui importe un snippet."
     ---

     import MySnippet from "../shared/my-snippet.mdx";

     Le contenu du snippet s’affiche sous cette phrase.

     <MySnippet />
     ```
   </CodeGroup>

<div id="import-variables">
  ### Importer des variables
</div>

Faites référence à des variables d’un snippet dans une page.

1. Exportez des variables depuis un fichier de snippet.

   ```mdx shared/custom-variables.mdx
   export const myName = "Ronan";

   export const myObject = { fruit: "strawberries" };

   ;
   ```

2. Importez le snippet dans votre fichier de destination et utilisez la variable.

   ```mdx destination-file.mdx
   ---
   title: "Exemple de page"
   description: "Ceci est un exemple de page qui importe un snippet avec des variables."
   ---

   import { myName, myObject } from "/shared/custom-variables.mdx";

   Bonjour, je m'appelle {myName} et j'aime les {myObject.fruit}.
   ```

<div id="import-snippets-with-variables">
  ### Importer des snippets avec des variables
</div>

Utilisez des variables pour transmettre des données à un snippet au moment de son importation.

1. Ajoutez des variables à votre snippet et transmettez des propriétés lors de son importation. Dans cet exemple, la variable est `{word}`.

   ```mdx shared/my-snippet.mdx
   Mon mot-clé du jour est {word}.
   ```

2. Importez le snippet dans votre fichier de destination avec la variable. La propriété transmise remplace la variable dans la définition du snippet.

   ```mdx destination-file.mdx
   ---
   title: "Une page d’exemple"
   description: "Il s’agit d’une page d’exemple qui importe un snippet avec une variable."
   ---

   import MySnippet from "/shared/my-snippet.mdx";

   <MySnippet word="bananes" />
   ```

<div id="import-react-components">
  ### Importer des composants React
</div>

1. Créez un snippet avec un composant JSX. Consultez [les composants React](/fr/customize/react-components) pour en savoir plus.

   ```js components/my-jsx-snippet.jsx
   export const MyJSXSnippet = () => {
     return (
       <div>
         <h1>Hello, world!</h1>
       </div>
     );
   };
   ```

<Note>
  Lorsque vous créez des snippets JSX, utilisez la syntaxe de fonction fléchée (`=>`) plutôt que la déclaration de fonction. Le mot-clé `function` n’est pas pris en charge dans les snippets.
</Note>

2. Importez le snippet.

   ```mdx destination-file.mdx
   ---
   title: "Une page d’exemple"
   description: "Il s’agit d’une page d’exemple qui importe un snippet contenant un composant React."
   ---

   import { MyJSXSnippet } from "/components/my-jsx-snippet.jsx";

   <MyJSXSnippet />
   ```
