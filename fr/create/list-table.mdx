<div id="lists">
  ## Listes
</div>

Les listes respectent la syntaxe officielle de [Markdown](https://www.markdownguide.org/basic-syntax/#lists-1).

<div id="ordered-list">
  ### Liste ordonnée
</div>

Pour créer une liste ordonnée, faites précéder chaque élément d’un numéro suivi d’un point.

1. Premier élément
2. Deuxième élément
3. Troisième élément
4. Quatrième élément

```mdx
1. First item
2. Second item
3. Third item
4. Fourth item
```

<div id="unordered-list">
  ### Liste non ordonnée
</div>

Pour créer une liste non ordonnée, ajoutez des tirets (`-`), des astérisques (`*`) ou des signes plus (`+`) devant les éléments de la liste.

* Premier élément
* Deuxième élément
* Troisième élément
* Quatrième élément

```mdx
- First item
- Second item
- Third item
- Fourth item
```

<div id="nested-list">
  ### Liste imbriquée
</div>

Mettez les éléments de liste en retrait pour les imbriquer.

* Premier élément
* Deuxième élément
  * Élément supplémentaire
  * Élément supplémentaire
* Troisième élément

```mdx
- First item
- Second item
  - Additional item
  - Additional item
- Third item
```

<div id="tables">
  ## Tableaux
</div>

Les tableaux suivent la [syntaxe Markdown officielle](https://www.markdownguide.org/extended-syntax/#tables).

Pour ajouter un tableau, utilisez au moins trois traits d’union (`---`) pour créer l’en-tête de chaque colonne, et des barres verticales (`|`) pour séparer les colonnes. Pour des raisons de compatibilité, ajoutez également une barre verticale à chaque extrémité de la ligne.

| Propriété | Description                              |
| --------- | ---------------------------------------- |
| Nom       | Nom complet de l’utilisateur             |
| Âge       | Âge déclaré                              |
| A rejoint | Si l’utilisateur a rejoint la communauté |

```mdx
| Propriété | Description                                  |
| --------- | -------------------------------------------- |
| Nom       | Nom complet de l'utilisateur                 |
| Âge       | Âge déclaré                                  |
| Rejoint   | Si l'utilisateur a rejoint la communauté     |
```

<div id="column-alignment">
  ### Alignement des colonnes
</div>

Utilisez des deux-points dans la ligne de séparation pour aligner le contenu des colonnes :

| Aligné à gauche | Centré | Aligné à droite |
| :-------------- | :----: | --------------: |
| Gauche          | Centré |          Droite |
| Texte           |  Texte |           Texte |

```mdx
| Left aligned | Center aligned | Right aligned |
| :----------- | :------------: | ------------: |
| Left         | Center         | Right         |
| Text         | Text           | Text          |
```
