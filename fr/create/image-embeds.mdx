<div id="images">
  ## Images
</div>

Ajoutez des images pour illustrer votre documentation, avec du contexte visuel, des exemples ou des éléments décoratifs.

<div id="basic-image-syntax">
  ### Syntaxe de base des images
</div>

Utilisez la [syntaxe Markdown](https://www.markdownguide.org/basic-syntax/#images) pour ajouter des images à votre documentation :

```mdx
![Alt text describing the image](/path/to/image.png)
```

<Tip>
  Incluez toujours un texte alternatif descriptif pour améliorer l’accessibilité et le SEO. Le texte alternatif doit décrire clairement ce que montre l’image.
</Tip>

Les fichiers d’image doivent faire moins de 20 Mo. Pour les fichiers plus volumineux, hébergez-les sur un CDN comme [Amazon S3](https://aws.amazon.com/s3) ou [Cloudinary](https://cloudinary.com).

<div id="html-image-embeds">
  ### Intégration d’images en HTML
</div>

Pour mieux contrôler l’affichage des images, utilisez des balises HTML `<img>` :

```jsx
<img 
  src="/images/dashboard.png" 
  alt="Main dashboard interface"
  style={{height: "300px", width: "400px"}}
  className="rounded-lg"
/>
```

<div id="resize-images-with-inline-styles">
  #### Redimensionner les images avec des styles en ligne
</div>

Utilisez les styles en ligne de JSX avec l&#39;attribut `style` pour redimensionner les images :

```jsx
<img
  src="/images/architecture.png"
  style={{width: "450px", height: "auto"}}
  alt="Diagram showing the architecture of the system"
/>
```

<div id="disable-image-zoom">
  #### Désactiver le zoom des images
</div>

Pour désactiver le zoom par défaut au clic sur les images, ajoutez la propriété `noZoom` :

```html highlight="4"
<img 
  src="/images/screenshot.png" 
  alt="Descriptive alt text"
  noZoom
/>
```

<div id="link-images">
  #### Images cliquables
</div>

Pour rendre une image cliquable, placez-la dans une balise d’ancrage et ajoutez la propriété `noZoom` :

```html
<a href="https://mintlify.com" target="_blank">
  <img 
    src="/images/logo.png" 
    alt="Mintlify logo"
    noZoom
  />
</a>
```

<Note>
  Les images placées dans des balises d’ancrage affichent automatiquement un curseur pointeur pour indiquer qu’elles sont cliquables.
</Note>

<div id="light-and-dark-mode-images">
  #### Images pour les thèmes clair et sombre
</div>

Pour afficher des images différentes selon le thème clair ou sombre, utilisez les classes Tailwind CSS :

```html
<!-- Image en mode clair -->
<img 
  className="block dark:hidden" 
  src="/images/light-mode.png" 
  alt="Light mode interface"
/>

<!-- Image en mode sombre -->
<img 
  className="hidden dark:block" 
  src="/images/dark-mode.png" 
  alt="Dark mode interface"
/>
```

<div id="svg-images">
  ### Images au format SVG
</div>

Les fichiers SVG qui utilisent des éléments `foreignObject` s’affichent différemment en production et en développement local. Le CDN d’images de Mintlify supprime les `foreignObject` des SVG par mesure de sécurité, ce qui peut tronquer ou masquer le texte et d’autres contenus HTML intégrés.

Cela concerne souvent les SVG exportés depuis des outils comme [draw.io](https://www.drawio.com) lorsque le formatage de texte HTML ou le retour à la ligne automatique est activé. Pour corriger ce problème, désactivez **Formatted Text** et **Word Wrap** sur toutes les étiquettes de votre diagramme avant d’exporter au format SVG. Consultez la [documentation draw.io](https://www.drawio.com/doc/faq/svg-export-text-problems) pour plus d’informations sur l’exportation de fichiers SVG.

<div id="videos">
  ## Vidéos
</div>

Mintlify prend en charge les [balises HTML dans Markdown](https://www.markdownguide.org/basic-syntax/#html), ce qui vous permet de créer du contenu riche avec plus de flexibilité.

<Tip>
  Incluez toujours un texte de secours dans les éléments vidéo pour les navigateurs qui ne prennent pas en charge la lecture des vidéos.
</Tip>

<div id="youtube-embeds">
  ### Intégration de vidéos YouTube
</div>

Intégrez des vidéos YouTube à l’aide d’éléments iframe :

```html
<iframe
  className="w-full aspect-video rounded-xl"
  src="https://www.youtube.com/embed/4KzFe50RQkQ"
  title="YouTube video player"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
></iframe>
```

<Frame>
  <iframe className="w-full aspect-video rounded-xl" src="https://www.youtube.com/embed/4KzFe50RQkQ" title="Lecteur vidéo YouTube" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen />
</Frame>

<div id="self-hosted-videos">
  ### Vidéos auto-hébergées
</div>

Utilisez l’élément HTML `<video>` pour intégrer des vidéos auto-hébergées :

```html
<video
  controls
  className="w-full aspect-video rounded-xl"
  src="link-to-your-video.com"
></video>
```

<div id="autoplay-videos">
  ### Lecture automatique des vidéos
</div>

Pour lire automatiquement une vidéo, utilisez :

```html
<video
  autoPlay
  muted
  loop
  playsInline
  className="w-full aspect-video rounded-xl"
  src="/videos/demo.mp4"
></video>
```

<Note>
  Lorsque vous utilisez la syntaxe JSX, écrivez les attributs de deux mots en camelCase : `autoPlay`, `playsInline`, `allowFullScreen`.
</Note>

<div id="iframes">
  ## Iframes
</div>

Intégrez du contenu externe à l’aide d’éléments `iframe` :

```html
<iframe 
  src="https://example.com/embed" 
  title="Embedded content"
  className="w-full h-96 rounded-xl"
></iframe>
```
