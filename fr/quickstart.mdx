Une fois ce guide terminé, vous disposerez d’un site de documentation en ligne prêt à être personnalisé et mis à jour.

<div id="before-you-begin">
  ## Avant de commencer
</div>

Mintlify utilise une approche docs-as-code pour gérer votre documentation. Chaque page de votre site correspond à un fichier stocké dans le <Tooltip tip="Le code source de votre documentation, où tous les fichiers et leur historique sont stockés. L’éditeur web se connecte au dépôt de votre documentation pour accéder au contenu et le modifier, ou vous pouvez modifier les fichiers localement dans l’IDE de votre choix.">dépôt</Tooltip> de votre documentation.

Lorsque vous connectez le dépôt de votre documentation à votre projet, vous pouvez travailler sur votre documentation en local ou dans l’éditeur web, puis synchroniser toutes les modifications avec votre dépôt distant.

<div id="deploy-your-documentation-site">
  ## Déployez votre site de documentation
</div>

<Tip>
  Si votre code ou votre documentation se trouve déjà dans un dépôt GitHub public, [générez automatiquement votre site de documentation](https://mintlify.com/explore) à la place.

  Remplacez `github.com` par `mintlify.com` dans n’importe quelle URL de dépôt public :

  ```
  https://mintlify.com/github-org/repo-name
  ```
</Tip>

Accédez à [mintlify.com/start](https://mintlify.com/start) et terminez la configuration initiale. Lors de cette étape, vous connecterez votre compte GitHub, créerez ou sélectionnerez un dépôt pour votre documentation, puis installerez l’application GitHub pour activer les déploiements automatiques.

Une fois la configuration initiale terminée, votre site de documentation est déployé et accessible à votre URL `.mintlify.app`.

<AccordionGroup>
  <Accordion title="Facultatif : ne pas connecter de fournisseur Git lors de la configuration initiale">
    Si vous souhaitez démarrer rapidement sans connecter votre propre dépôt, vous pouvez passer l’étape de connexion à un fournisseur Git lors de la configuration initiale. Mintlify crée un dépôt privé dans une organisation privée et configure automatiquement l’application GitHub pour vous.

    Vous pouvez ainsi utiliser immédiatement l’éditeur web. Si vous souhaitez utiliser votre propre dépôt plus tard, accédez aux [Paramètres Git](https://dashboard.mintlify.com/settings/deployment/git-settings) dans votre tableau de bord pour migrer votre contenu à l’aide de l’assistant de configuration Git. Consultez [Cloner vers votre propre dépôt](/fr/deploy/github#clone-to-your-own-repository) pour plus de détails.
  </Accordion>
</AccordionGroup>

<div id="view-your-deployed-site">
  ## Consultez votre site déployé
</div>

Votre site de documentation est maintenant déployé à l’adresse `https://<your-project-name>.mintlify.app`.

Retrouvez votre URL exacte sur la page **Vue d’ensemble** de votre [tableau de bord](https://dashboard.mintlify.com/).

<div id="make-your-first-change">
  ## Faites votre première modification
</div>

<Tabs>
  <Tab title="CLI">
    <Steps>
      <Step title="Installer la CLI">
        La CLI nécessite [Node.js](https://nodejs.org/en) v20.17.0 ou une version ultérieure. Utilisez une version LTS pour plus de stabilité.

        <CodeGroup>
          ```bash npm
          npm i -g mint
          ```

          ```bash pnpm
          pnpm add -g mint
          ```
        </CodeGroup>

        Consultez [Installer la CLI](/fr/cli/install) pour plus de détails et les étapes de dépannage.
      </Step>

      <Step title="Cloner votre dépôt">
        Si vous n’avez pas encore cloné votre dépôt en local, suivez les instructions de [Cloner votre dépôt](/fr/cli/install#clone-your-repository).
      </Step>

      <Step title="Modifier une page">
        Ouvrez `index.mdx` dans l’éditeur de votre choix et mettez à jour la description dans les métadonnées d’en-tête :

        ```mdx
        ---
        title: "Introduction"
        description: "Votre description personnalisée ici"
        ---
        ```
      </Step>

      <Step title="Prévisualiser en local">
        Exécutez la commande suivante depuis votre répertoire de documentation :

        ```bash
        mint dev
        ```

        Affichez l’aperçu à l’adresse `http://localhost:3000`.
      </Step>

      <Step title="Pousser vos modifications">
        Validez et poussez vos modifications pour déclencher un déploiement :

        ```bash
        git add .
        git commit -m "Update description"
        git push
        ```

        Mintlify déploie automatiquement vos modifications. Consultez l’état du déploiement sur la page [Vue d’ensemble](https://dashboard.mintlify.com/) de votre tableau de bord.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Éditeur web">
    <Steps>
      <Step title="Ouvrir l’éditeur web">
        Accédez à l’[éditeur web](https://dashboard.mintlify.com/editor) depuis votre tableau de bord.
      </Step>

      <Step title="Modifier une page">
        Ouvrez la page **Introduction** et mettez à jour la description.

        <Frame>
          <img src="/images/quickstart/hello-world-light.png" alt="Page Introduction ouverte dans l’éditeur web avec la description modifiée en Hello world !." className="block dark:hidden" />

          <img src="/images/quickstart/hello-world-dark.png" alt="Page Introduction ouverte dans l’éditeur web avec la description modifiée en Hello world !." className="hidden dark:block" />
        </Frame>
      </Step>

      <Step title="Publier">
        Cliquez sur le bouton **Publish** en haut à droite de la barre d’outils de l’éditeur web.
      </Step>

      <Step title="Voir le résultat en ligne">
        Sur la page [Vue d’ensemble](https://dashboard.mintlify.com/) de votre tableau de bord, vous pouvez voir l’état du déploiement de votre site. Une fois le déploiement terminé, actualisez votre site de documentation pour voir vos modifications en ligne.
      </Step>
    </Steps>
  </Tab>
</Tabs>
