Utilisez le champ `integrations` dans `docs.json` pour connecter des plateformes d’analyses tierces, des outils de chat et d’autres services à votre site de documentation.

<div id="settings">
  ## Paramètres
</div>

Configurez toutes les intégrations sous forme de propriétés de l’objet `integrations` dans votre fichier `docs.json` :

```json docs.json
"integrations": {
  "ga4": {
    "measurementId": "G-XXXXXXXXXX"
  }
}
```

<div id="example">
  ## Exemple
</div>

```json docs.json
"integrations": {
  "ga4": {
    "measurementId": "G-XXXXXXXXXX"
  },
  "posthog": {
    "apiKey": "phc_XXXXXXXXXX"
  },
  "intercom": {
    "appId": "abc12345"
  },
  "telemetry": {
    "enabled": true
  }
}
```
