Le fichier `.mintignore` vous permet d’exclure du traitement et de la publication sur votre site de documentation certains fichiers et répertoires de votre dépôt de documentation.

Utilisez `.mintignore` pour garder les brouillons, les notes internes et les fichiers sources hors de votre documentation publique tout en les conservant dans votre dépôt.

<div id="create-a-mintignore-file">
  ## Créer un fichier .mintignore
</div>

Créez un fichier `.mintignore` à la racine de votre répertoire de documentation. Ce fichier utilise la même syntaxe de motifs que `.gitignore`.

```plaintext .mintignore
# Exclure les documents brouillons
drafts/
*.draft.mdx

# Exclure la documentation interne
internal/

# Exclure des fichiers spécifiques
private-notes.md
```

Lorsque Mintlify génère votre documentation, Mintlify lit le fichier `.mintignore` et exclut du traitement tous les fichiers ou répertoires correspondants.

Fichiers exclus :

* N&#39;apparaissent pas dans votre documentation publiée.
* Ne sont pas indexés pour la recherche.
* Ne sont pas accessibles aux visiteurs.
* Ne déclenchent pas les [vérifications de liens brisés](/fr/cli/commands#mint-broken-links). Les liens qui pointent vers des fichiers ignorés ne fonctionneront pas.

<div id="default-ignored-patterns">
  ## Motifs ignorés par défaut
</div>

Mintlify ignore automatiquement les répertoires et fichiers suivants, sans aucune configuration :

* `.git`
* `.github`
* `.claude`
* `.agents`
* `.idea`
* `.vscode`
* `node_modules`
* `build`
* `dist`
* `coverage`
* `.cache`
* `tmp`
* `temp`
* `README.md`
* `LICENSE.md`
* `CHANGELOG.md`
* `CONTRIBUTING.md`

Vous n’avez pas besoin de les ajouter à votre fichier `.mintignore`.

<Note>
  Contrairement aux [pages masquées](/fr/organize/hidden-pages), `.mintignore` supprime complètement
  les fichiers correspondants de votre site. Les visiteurs ne peuvent pas y accéder via une URL.
</Note>

<div id="pattern-syntax">
  ## Syntaxe des motifs
</div>

Le fichier `.mintignore` suit la syntaxe de `.gitignore`. Voici quelques motifs courants :

| Motif              | Description                                                |
| ------------------ | ---------------------------------------------------------- |
| `drafts/`          | Exclut l’ensemble du répertoire `drafts`                   |
| `*.draft.mdx`      | Exclut tous les fichiers se terminant par `.draft.mdx`     |
| `private-notes.md` | Exclut un fichier précis                                   |
| `**/internal/**`   | Exclut tout répertoire `internal`, à n’importe quel niveau |
| `!important.mdx`   | Annule un motif précédent (inclut le fichier)              |
