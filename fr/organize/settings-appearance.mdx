Utilisez ces paramètres `docs.json` pour définir l’identité visuelle de votre site de documentation — thème de mise en page, couleurs de marque, logo, typographie et arrière-plan.

<div id="settings">
  ## Paramètres
</div>

### `theme` - <Badge color="red">obligatoire</Badge>

Le thème de mise en page de votre site.

L’un des suivants : `mint`, `maple`, `palm`, `willow`, `linden`, `almond`, `aspen`, `sequoia`, `luma`.

Consultez [Thèmes](/fr/customize/themes) pour voir des aperçus et plus de détails.

***

### `name` - <Badge color="red">obligatoire</Badge>

**Type :** `string`

Le nom de votre projet, de votre organisation ou de votre produit. Il apparaît dans le titre de l’onglet du navigateur et ailleurs sur votre site.

***

### `colors` - <Badge color="red">obligatoire</Badge>

**Type :** `object`

Les couleurs utilisées dans votre documentation. Elles s’affichent différemment selon le thème. Si vous ne fournissez qu’une couleur principale, elle s’applique à tous les éléments colorés.

<ResponseField name="colors.primary" type="string" required>
  La couleur principale de votre documentation. Elle est généralement utilisée pour mettre en évidence des éléments en mode clair, avec quelques variations selon le thème.

  Doit être un code hexadécimal commençant par `#`. Exemple : `"#0D9373"`.
</ResponseField>

<ResponseField name="colors.light" type="string">
  La couleur utilisée pour mettre en évidence des éléments en mode sombre.

  Doit être un code hexadécimal commençant par `#`.
</ResponseField>

<ResponseField name="colors.dark" type="string">
  La couleur utilisée pour les boutons et les états de survol en modes clair et sombre, avec quelques variations selon le thème.

  Doit être un code hexadécimal commençant par `#`.
</ResponseField>

```json docs.json
"colors": {
  "primary": "#0D9373",
  "light": "#55D799",
  "dark": "#0D9373"
}
```

***

<div id="logo">
  ### `logo`
</div>

**Type :** `string` ou `object`

Le logo de votre site. Indiquez le chemin d’une seule image ou des images distinctes pour les modes clair et sombre.

<ResponseField name="logo.light" type="string" required>
  Chemin vers votre fichier de logo pour le mode clair. Incluez l’extension du fichier. Exemple : `/logo/light.svg`.
</ResponseField>

<ResponseField name="logo.dark" type="string" required>
  Chemin vers votre fichier de logo pour le mode sombre. Incluez l’extension du fichier. Exemple : `/logo/dark.svg`.
</ResponseField>

<ResponseField name="logo.href" type="string (uri)">
  URL vers laquelle rediriger lorsque l’utilisateur clique sur le logo. Si elle n’est pas fournie, le logo renvoie vers la première page de la langue actuellement sélectionnée pour les [docs internationalisées](/fr/guides/internationalization), ou vers votre page d’accueil pour les sites monolingues. Exemple : `https://yoursite.com`.
</ResponseField>

```json docs.json
"logo": {
  "light": "/logo/light.svg",
  "dark": "/logo/dark.svg",
  "href": "https://yoursite.com"
}
```

***

<div id="favicon">
  ### `favicon`
</div>

**Type :** `string` ou `object`

Chemin vers votre fichier favicon, extension comprise. Il est automatiquement redimensionné aux dimensions de favicon appropriées. Fournissez un seul fichier ou des fichiers distincts pour les modes clair et sombre.

<ResponseField name="favicon.light" type="string" required>
  Chemin vers votre favicon pour le mode clair. Indiquez l’extension du fichier. Exemple : `/favicon.png`.
</ResponseField>

<ResponseField name="favicon.dark" type="string" required>
  Chemin vers votre favicon pour le mode sombre. Indiquez l’extension du fichier. Exemple : `/favicon-dark.png`.
</ResponseField>

```json docs.json
"favicon": "/favicon.svg"
```

***

<div id="appearance">
  ### `appearance`
</div>

**Type :** `object`

Paramètres du mode clair/sombre.

<ResponseField name="appearance.default" type="&#x22;system&#x22; | &#x22;light&#x22; | &#x22;dark&#x22;">
  Mode de couleur par défaut. Choisissez `system` pour utiliser le paramètre du système d’exploitation de l’utilisateur, ou `light` ou `dark` pour imposer un mode spécifique. La valeur par défaut est `system`.
</ResponseField>

<ResponseField name="appearance.strict" type="boolean">
  Lorsque `true`, masque le commutateur de mode clair/sombre afin d’empêcher les utilisateurs de changer de mode. La valeur par défaut est `false`.
</ResponseField>

```json docs.json
"appearance": {
  "default": "dark",
  "strict": true
}
```

***

<div id="fonts">
  ### `fonts`
</div>

**Type :** `object`

Polices personnalisées pour votre documentation. La police par défaut varie selon le thème. Compatible avec [Google Fonts](https://fonts.google.com) et les polices auto-hébergées.

<ResponseField name="fonts.family" type="string" required>
  Nom de la famille de polices, par exemple `"Inter"` ou `"Open Sans"`. Compatible avec les noms de famille [Google Fonts](https://fonts.google.com) : ils se chargent automatiquement, sans nécessiter de champ `source`.
</ResponseField>

<ResponseField name="fonts.weight" type="number">
  Graisse de la police, par exemple `400` ou `700`. Les polices variables prennent en charge des graisses fractionnaires comme `550`.
</ResponseField>

<ResponseField name="fonts.source" type="string (uri)">
  URL d&#39;une police hébergée ou chemin vers un fichier de police local. Inutile pour Google Fonts.

  * Hébergée : `https://example.com/fonts/MyFont.woff2`
  * Locale : `/fonts/MyFont.woff2`
</ResponseField>

<ResponseField name="fonts.format" type="&#x22;woff&#x22; | &#x22;woff2&#x22;">
  Format du fichier de police. Obligatoire lorsque vous utilisez le champ `source`.
</ResponseField>

<ResponseField name="fonts.heading" type="object">
  Remplace les paramètres de police uniquement pour les titres.

  Accepte les mêmes champs `family`, `weight`, `source` et `format` que l&#39;objet `fonts` de premier niveau.
</ResponseField>

<ResponseField name="fonts.body" type="object">
  Remplace les paramètres de police uniquement pour le corps du texte.

  Accepte les mêmes champs `family`, `weight`, `source` et `format` que l&#39;objet `fonts` de premier niveau.
</ResponseField>

```json docs.json
"fonts": {
  "family": "Inter",
  "heading": {
    "family": "Playfair Display"
  }
}
```

***

<div id="icons">
  ### `icons`
</div>

**Type :** `object`

Paramètres de la bibliothèque d’icônes. Vous ne pouvez utiliser qu’une seule bibliothèque d’icônes par projet. Tous les noms d’icônes de votre documentation doivent provenir de la bibliothèque sélectionnée.

<ResponseField name="icons.library" type="&#x22;fontawesome&#x22; | &#x22;lucide&#x22; | &#x22;tabler&#x22;" required>
  Bibliothèque d’icônes à utiliser dans toute votre documentation. La valeur par défaut est `fontawesome`.

  <Note>
    Vous pouvez spécifier, pour chaque icône, une URL vers une icône hébergée en externe ou le chemin vers un fichier d’icône dans votre projet, quel que soit le paramètre de bibliothèque.
  </Note>
</ResponseField>

```json docs.json
"icons": {
  "library": "lucide"
}
```

***

<div id="background">
  ### `background`
</div>

**Type :** `object`

Paramètres de l’image, de la décoration et des couleurs d’arrière-plan.

<ResponseField name="background.decoration" type="&#x22;gradient&#x22; | &#x22;grid&#x22; | &#x22;windows&#x22;">
  Motif d’arrière-plan décoratif pour votre thème.
</ResponseField>

<ResponseField name="background.color" type="object">
  Couleurs d’arrière-plan personnalisées pour les modes clair et sombre.

  <Expandable title="background.color">
    <ResponseField name="light" type="string">
      Couleur d’arrière-plan pour le mode clair. Doit être un code hexadécimal commençant par `#`.
    </ResponseField>

    <ResponseField name="dark" type="string">
      Couleur d’arrière-plan pour le mode sombre. Doit être un code hexadécimal commençant par `#`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="background.image" type="string or object">
  Image d’arrière-plan de votre site. Indiquez un chemin unique ou des chemins distincts pour les modes clair et sombre.

  <Expandable title="background.image">
    <ResponseField name="light" type="string" required>
      Chemin vers l’image d’arrière-plan pour le mode clair. Exemple : `/background.png`.
    </ResponseField>

    <ResponseField name="dark" type="string" required>
      Chemin vers l’image d’arrière-plan pour le mode sombre. Exemple : `/background-dark.png`.
    </ResponseField>
  </Expandable>
</ResponseField>

```json docs.json
"background": {
  "decoration": "gradient",
  "color": {
    "light": "#F8FAFC",
    "dark": "#0F172A"
  }
}
```

<div id="styling">
  ### `styling`
</div>

**Type :** `object`

Réglages précis du style visuel.

<ResponseField name="styling.eyebrows" type="&#x22;section&#x22; | &#x22;breadcrumbs&#x22;">
  Définit le style du libellé affiché en haut de la page. Choisissez `section` pour afficher le nom de la section ou `breadcrumbs` pour afficher le chemin de Navigation complet. La valeur par défaut est `section`.
</ResponseField>

<ResponseField name="styling.latex" type="boolean">
  Contrôle le chargement des feuilles de style LaTeX. Par défaut, Mintlify détecte automatiquement l&#39;utilisation de LaTeX dans votre contenu et charge les feuilles de style nécessaires.

  * Définissez cette option sur `true` pour forcer le chargement des feuilles de style LaTeX lorsque la détection automatique échoue.
  * Définissez cette option sur `false` pour empêcher le chargement des feuilles de style LaTeX et améliorer les performances si vous n&#39;utilisez pas d&#39;expressions mathématiques.
</ResponseField>

<ResponseField name="styling.codeblocks" type="&#x22;system&#x22; | &#x22;dark&#x22; | string | object">
  Thème des blocs de code. La valeur par défaut est `"system"`.

  * `"system"` : correspond au mode actuel du site (clair ou sombre)
  * `"dark"` : utilise toujours le mode sombre
  * Une chaîne correspondant au nom d&#39;un [thème Shiki](https://shiki.style/themes) : applique ce thème à tous les blocs de code
  * Un objet avec les clés `light` et `dark` : applique des thèmes Shiki distincts selon le mode

  <Expandable title="objet styling.codeblocks">
    <ResponseField name="theme" type="string">
      Un seul thème Shiki pour les deux modes.

      ```json
      "styling": {
        "codeblocks": {
          "theme": "dracula"
        }
      }
      ```
    </ResponseField>

    <ResponseField name="theme" type="object">
      Des thèmes Shiki distincts pour les modes clair et sombre.

      <Expandable title="theme">
        <ResponseField name="light" type="string" required>
          Nom du thème Shiki pour le mode clair.
        </ResponseField>

        <ResponseField name="dark" type="string" required>
          Nom du thème Shiki pour le mode sombre.
        </ResponseField>
      </Expandable>

      ```json
      "styling": {
        "codeblocks": {
          "theme": {
            "light": "github-light",
            "dark": "github-dark"
          }
        }
      }
      ```
    </ResponseField>

    <ResponseField name="languages" type="object">
      Configuration personnalisée des langages pour les blocs de code.

      <Expandable title="languages">
        <ResponseField name="custom" type="array of string">
          Chemins vers des fichiers JSON décrivant des langages Shiki personnalisés. Utilisez ceci pour ajouter la coloration syntaxique de langages qui ne figurent pas dans l&#39;ensemble par défaut de Shiki. Chaque fichier doit respecter le [format de grammaire TextMate](https://macromates.com/manual/en/language_grammars).

          ```json
          "styling": {
            "codeblocks": {
              "languages": {
                "custom": ["/languages/my-language.json"]
              }
            }
          }
          ```
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

***

<div id="thumbnails">
  ### `thumbnails`
</div>

**Type :** `object`

Personnalisation des miniatures pour les réseaux sociaux et les aperçus de page.

<ResponseField name="thumbnails.appearance" type="&#x22;light&#x22; | &#x22;dark&#x22;">
  Thème visuel des miniatures. S’il n’est pas défini, les miniatures utilisent le jeu de couleurs de votre site défini par `colors`.
</ResponseField>

<ResponseField name="thumbnails.background" type="string">
  Image d’arrière-plan des miniatures. Peut être un chemin relatif ou une URL absolue.
</ResponseField>

<ResponseField name="thumbnails.fonts" type="object">
  Configuration des polices des miniatures. Seuls les noms de familles Google Fonts sont pris en charge.

  <Expandable title="thumbnails.fonts">
    <ResponseField name="family" type="string" required>
      Nom de la famille de polices, comme `"Open Sans"` ou `"Playfair Display"`. Prend en charge les noms de familles [Google Fonts](https://fonts.google.com).
    </ResponseField>
  </Expandable>
</ResponseField>

<div id="example">
  ## Exemple
</div>

```json docs.json
{
  "$schema": "https://mintlify.com/docs.json",
  "theme": "maple",
  "name": "Example Co.",
  "colors": {
    "primary": "#3B82F6",
    "light": "#93C5FD",
    "dark": "#1D4ED8"
  },
  "logo": {
    "light": "/logo/light.svg",
    "dark": "/logo/dark.svg",
    "href": "https://example.com"
  },
  "favicon": "/favicon.svg",
  "appearance": {
    "default": "system"
  },
  "fonts": {
    "family": "Inter"
  },
  "icons": {
    "library": "lucide"
  },
  "background": {
    "decoration": "gradient"
  }
}
```
