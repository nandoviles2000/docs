Utilisez ces paramètres dans votre fichier `docs.json` pour définir l’architecture de l’information et l’expérience utilisateur de votre site. Modifiez la barre de navigation, le pied de page, les bannières, le comportement de navigation, les menus contextuels, les redirections et les variables de contenu globales.

<div id="settings">
  ## Paramètres
</div>

### `navigation` - <Badge color="red">requis</Badge>

**Type :** `object`

La structure de navigation de votre contenu. C’est ici que vous définissez la hiérarchie complète des pages de votre site à l’aide de groupes, d’onglets, de menus déroulants, d’ancres, etc.

Consultez [Navigation](/fr/organize/navigation) pour obtenir la documentation complète sur la création de votre structure de navigation.

<div id="navbar">
  ### `navbar`
</div>

**Type :** `object`

Liens et boutons affichés dans la barre de navigation supérieure.

<ResponseField name="navbar.links" type="array of object">
  Liens à afficher dans la barre de navigation.

  <Expandable title="navbar.links">
    <ResponseField name="type" type="&#x22;github&#x22; | &#x22;discord&#x22;">
      Type de lien facultatif. Omettez-le pour utiliser un lien texte standard. Définissez-le sur `github` pour créer un lien vers un dépôt GitHub et afficher son nombre d&#39;étoiles. Définissez-le sur `discord` pour créer un lien vers un serveur Discord et afficher son nombre d&#39;utilisateurs en ligne.
    </ResponseField>

    <ResponseField name="label" type="string">
      Texte du lien. Obligatoire lorsque `type` n&#39;est pas défini. Facultatif pour `github` et `discord`. S&#39;il est omis, Mintlify génère le libellé à partir des données de l&#39;API.
    </ResponseField>

    <ResponseField name="href" type="string (uri)" required>
      Destination du lien. Doit être une URL externe valide. Pour `github`, il doit s&#39;agir de l&#39;URL d&#39;un dépôt GitHub. Pour `discord`, il doit s&#39;agir d&#39;une URL d&#39;invitation Discord.
    </ResponseField>

    <IconsOptional />
  </Expandable>
</ResponseField>

<ResponseField name="navbar.primary" type="object">
  Bouton d&#39;appel à l&#39;action principal dans la barre de navigation.

  <Expandable title="navbar.primary">
    <ResponseField name="type" type="&#x22;button&#x22; | &#x22;github&#x22; | &#x22;discord&#x22;" required>
      Style du bouton. Choisissez `button` pour un bouton standard, `github` pour un lien vers un dépôt GitHub avec son nombre d&#39;étoiles, ou `discord` pour une invitation Discord avec le nombre d&#39;utilisateurs en ligne.
    </ResponseField>

    <ResponseField name="label" type="string">
      Texte du bouton. Obligatoire lorsque `type` est `button`. Facultatif pour `github` et `discord`.
    </ResponseField>

    <ResponseField name="href" type="string (uri)" required>
      Destination du bouton. Doit être une URL externe. Pour `github`, il doit s&#39;agir de l&#39;URL d&#39;un dépôt GitHub. Pour `discord`, il doit s&#39;agir d&#39;une URL d&#39;invitation Discord.
    </ResponseField>
  </Expandable>
</ResponseField>

```json docs.json
"navbar": {
  "links": [
    { "type": "github", "href": "https://github.com/your-org/your-repo" },
    { "label": "Community", "href": "https://example.com/community" }
  ],
  "primary": {
    "type": "button",
    "label": "Get started",
    "href": "https://example.com/signup"
  }
}
```

<div id="banner">
  ### `banner`
</div>

**Type :** `object`

Une bannière affichée en haut de chaque page du site.

<ResponseField name="banner.content" type="string" required>
  Le texte affiché dans la bannière. Prend en charge la mise en forme MDX de base, notamment les liens, le gras et l’italique. Les composants personnalisés ne sont pas pris en charge.

  ```json
  "content": "We just launched something new. [Learn more](https://example.com)"
  ```
</ResponseField>

<ResponseField name="banner.dismissible" type="boolean">
  Indique s’il faut afficher un bouton de fermeture pour permettre aux utilisateurs de fermer la bannière. La valeur par défaut est `false`.
</ResponseField>

```json docs.json
"banner": {
  "content": "We just launched something new. [Learn more](https://example.com)",
  "dismissible": true
}
```

  ### `interaction`
</div>

**Type :** `object`

Contrôle le mode d’interaction des utilisateurs avec les éléments de navigation.

<ResponseField name="interaction.drilldown" type="boolean">
  Contrôle la navigation automatique lors de la sélection d’un groupe de navigation. Définissez `true` pour accéder automatiquement à la première page lorsqu’un groupe se déploie. Définissez `false` pour seulement développer ou réduire le groupe sans naviguer. Laissez cette option non définie pour utiliser le comportement par défaut du thème.

<div id="contextual">
  ### `contextual`
</div>

**Type :** `object`

Le menu contextuel donne aux utilisateurs un accès rapide aux outils d’IA et aux actions sur la page. Il apparaît dans l’en-tête de la page ou dans la barre latérale de la table des matières.

<Note>
  Le menu contextuel est disponible uniquement dans les déploiements de prévisualisation et de production.
</Note>

<ResponseField name="contextual.options" type="array" required>
  Actions disponibles dans le menu contextuel. La première option du tableau est utilisée comme action par défaut.

  Options intégrées :

  * `"add-mcp"` — Ajouter votre serveur MCP à la configuration de l’utilisateur
  * `"aistudio"` — Envoyer la page actuelle à Google AI Studio
  * `"assistant"` — Ouvrir l’assistant IA avec la page actuelle comme contexte
  * `"copy"` — Copier la page actuelle au format Markdown dans le presse-papiers
  * `"chatgpt"` — Envoyer la page actuelle à ChatGPT
  * `"claude"` — Envoyer la page actuelle à Claude
  * `"cursor"` — Installer votre serveur MCP hébergé dans Cursor
  * `"devin"` — Envoyer la page actuelle à Devin
  * `"devin-mcp"` — Installer votre serveur MCP hébergé dans Devin
  * `"grok"` — Envoyer la page actuelle à Grok
  * `"mcp"` — Copier l’URL de votre serveur MCP dans le presse-papiers
  * `"perplexity"` — Envoyer la page actuelle à Perplexity
  * `"view"` — Afficher la page actuelle au format Markdown dans un nouvel onglet
  * `"vscode"` — Installer votre serveur MCP hébergé dans VS Code
  * `"windsurf"` — Envoyer la page actuelle à Windsurf

  Définissez les options personnalisées sous forme d’objets :

  <Expandable title="Option personnalisée">
    <ResponseField name="title" type="string" required>
      Titre d’affichage de l’option personnalisée.
    </ResponseField>

    <ResponseField name="description" type="string" required>
      Texte de description de l’option personnalisée.
    </ResponseField>

    <ResponseField name="icon" type="string">
      Icône de l’option personnalisée. Prend en charge les noms de bibliothèques d’icônes, les URL, les chemins ou le code SVG.
    </ResponseField>

    <ResponseField name="href" type="string or object" required>
      Destination du lien. Peut être une chaîne URL ou un objet avec un paramètre `base` et des paramètres `query` facultatifs.

      Variables de remplacement disponibles :

      * `$page` — Contenu de la page actuelle
      * `$path` — Chemin de la page actuelle
      * `$mcp` — URL du serveur MCP
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="contextual.display" type="&#x22;header&#x22; | &#x22;toc&#x22;">
  Où afficher les options contextuelles. Choisissez `header` pour les afficher dans le menu contextuel en haut de la page, ou `toc` pour les afficher dans la barre latérale de la table des matières. La valeur par défaut est `header`.
</ResponseField>

```json docs.json
"contextual": {
  "options": ["copy", "view", "chatgpt", "claude"],
  "display": "header"
}
```

<div id="redirects">
  ### `redirects`
</div>

**Type :** `tableau d'objets`

Redirections pour les pages déplacées, renommées ou supprimées. Utilisez-les pour conserver les liens lorsque vous réorganisez votre contenu.

<ResponseField name="redirects[].source" type="string" required>
  Le chemin source de la redirection. Exemple : `/old-page`
</ResponseField>

<ResponseField name="redirects[].destination" type="string" required>
  Le chemin de destination de la redirection. Exemple : `/new-page`
</ResponseField>

<ResponseField name="redirects[].permanent" type="boolean">
  Si `true`, effectue une redirection permanente (308). Si `false`, effectue une redirection temporaire (307). La valeur par défaut est `true`.
</ResponseField>

```json docs.json
"redirects": [
  {
    "source": "/old-page",
    "destination": "/new-page"
  },
  {
    "source": "/temp-redirect",
    "destination": "/destination",
    "permanent": false
  }
]
```

<div id="variables">
  ### `variables`
</div>

**Type :** `object`

Variables globales utilisables dans l’ensemble de votre documentation. Mintlify remplace les espaces réservés `{{variableName}}` par les valeurs définies lors de la compilation.

<ResponseField name="variables.[variableName]" type="string">
  Une paire clé-valeur où la clé correspond au nom de la variable et la valeur au texte de remplacement.

  * Les noms de variable peuvent contenir des caractères alphanumériques et des traits d’union.
  * Vous devez définir toutes les variables référencées dans votre contenu, sinon la compilation échoue.
  * Mintlify nettoie les valeurs pour éviter les attaques XSS.
</ResponseField>

```json docs.json
"variables": {
  "version": "2.0.0",
  "api-url": "https://api.example.com"
}
```

Dans votre contenu, référencez les variables à l’aide de doubles accolades :

```mdx
The current version is {{version}}. Make requests to {{api-url}}.
```

Paramètres de métadonnées au niveau des pages, appliqués globalement.

<ResponseField name="metadata.timestamp" type="boolean">
  Active une date de dernière modification sur toutes les pages. Lorsqu’elle est activée, les pages affichent la date de la dernière modification du contenu. La valeur par défaut est `false`.

  Vous pouvez remplacer ce paramètre pour des pages individuelles à l’aide du champ de métadonnées d’en-tête `timestamp`. Consultez [Pages](/fr/organize/pages#last-modified-timestamp) pour en savoir plus.
</ResponseField>

```json docs.json
"metadata": {
  "timestamp": true
}
```
