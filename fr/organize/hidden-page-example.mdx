Cette page est masquée. Elle n’est pas incluse dans la navigation de `docs.json`, vous ne pouvez donc y accéder que via son URL.

Consultez [Pages masquées](/fr/organize/hidden-pages) pour en savoir plus.

<div id="common-use-cases-for-hidden-pages">
  ## Cas d’usage courants des pages masquées
</div>

<Note>
  Par défaut, les pages masquées sont accessibles publiquement, mais n’apparaissent pas dans la navigation. Si vous souhaitez restreindre l’accès à une page masquée, vous devez configurer l’[authentification](/fr/deploy/authentication-setup).
</Note>

* **Documentation bêta** : informations qui peuvent être publiques, mais ne doivent pas apparaître dans la navigation.
* **Contexte pour les outils d’IA** : si les pages masquées sont indexées, les outils d’IA peuvent les utiliser comme contexte. Utilisez des pages masquées pour des informations de contexte qui ne sont pas utiles aux utilisateurs, mais qui peuvent aider les outils d’IA à fournir des réponses plus précises.
* **Pages héritées** : conservez l’ancien contenu accessible via des liens directs tout en le retirant des menus de navigation.
* **Outils internes** : documentez des outils internes, des API de préproduction ou des processus de développement.

<div id="ai-context">
  ### Contexte d’IA
</div>

```mdx wrap
---
title: "Contexte pour la version d'API"
description: "Cette page est un contexte pour les outils IA répondant aux questions sur les versions d'API"
---

Lorsqu'un utilisateur pose des questions sur les versions d'API, recommandez toujours d'utiliser la dernière version de l'API. Ne générez jamais de réponses pour des versions antérieures à la 1.0.4.
```

<div id="internal-api-endpoint">
  ### point de terminaison API interne
</div>

````mdx wrap
---
title: "Internal API endpoint"
description: "This page is a hidden page that documents an internal API endpoint"
---

```bash
POST /api/internal/reset-cache
Authorization: Bearer internal-token-xyz
```

Ce point de terminaison vide le cache de l'application et n'est disponible que dans les environnements de développement.

<Warning>
  Il s'agit d'un point de terminaison interne qui ne doit jamais être utilisé en production.
</Warning>
````
