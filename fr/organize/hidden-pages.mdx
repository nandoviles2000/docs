---

Les pages masquées n’apparaissent pas dans la navigation de votre site, mais toute personne qui connaît l’URL peut quand même y accéder. Par exemple, si vous créez une page masquée comme `guides/hidden-page.mdx`, les visiteurs peuvent y accéder à l’adresse `docs.yoursite.com/guides/hidden-page`.

Utilisez les pages masquées pour le contenu que vous souhaitez rendre accessible aux utilisateurs ou fournir comme contexte à des outils d’IA, sans l’afficher dans la navigation.

Si votre contenu nécessite un contrôle d’accès strict, vous devez configurer l’[authentification](/fr/deploy/authentication-setup).

Pour restreindre l’accès à des pages à des groupes d’utilisateurs spécifiques, configurez le [contrôle d’accès par groupes](/fr/deploy/authentication-setup#control-access-with-groups).

Consultez un [exemple de page masquée](/fr/organize/hidden-page-example).

<Note>
  Certains éléments de navigation, comme les barres latérales, les menus déroulants et les onglets, peuvent sembler vides ou voir leur mise en page se décaler sur les pages masquées.
</Note>

<div id="hide-a-page">
  ## Masquer une page
</div>

Pour masquer une page, définissez `hidden: true` dans les [métadonnées d’en-tête](/fr/organize/pages) de la page ou supprimez-la de la navigation définie dans votre `docs.json`.

<div id="set-hidden-true-in-frontmatter">
  ### Définissez `hidden: true` dans les métadonnées d’en-tête
</div>

Ajoutez `hidden: true` aux métadonnées d’en-tête d’une page pour la retirer de la Navigation affichée tout en la conservant dans votre configuration `docs.json`.

```yaml
---
title: "My hidden page"
hidden: true
---
```

Pour rendre une page de nouveau visible, supprimez entièrement le champ `hidden`. Ne définissez pas `hidden: false`, car cela entraîne un comportement indéfini.

<Note>
  Les moteurs de recherche ne peuvent pas indexer les pages masquées. Lorsque vous définissez `hidden: true`, la page est automatiquement exclue de l’indexation par les moteurs de recherche, des sitemaps et du contexte d’IA. En revanche, définir `noindex: true` ne **masque pas** une page dans la Navigation. Consultez [Désactiver l’indexation](/fr/optimize/seo#disable-indexing) pour en savoir plus.
</Note>

<div id="remove-the-page-from-navigation">
  ### Retirer la page de la navigation
</div>

Si vous n’incluez pas une page dans la navigation de votre `docs.json`, elle sera masquée. Cette méthode convient bien aux pages que vous ne voulez pas voir apparaître du tout dans la navigation.

<div id="hide-a-group-of-pages">
  ## Masquer un groupe de pages
</div>

Pour masquer un groupe de pages, définissez la propriété `hidden` sur `true` pour ce groupe dans votre fichier `docs.json` :

```json highlight={4}
"groups": [
  {
    "group": "Getting started",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  },
  {
    "group": "Guides",
    "pages": [
      "guides/hidden-page.mdx",
      "guides/hidden-groups.mdx"
    ]
  }
]
```

Dans cet exemple, le groupe `Getting started` est masqué et le groupe `Guides` reste visible.

<div id="hide-a-tab">
  ### Masquer un onglet
</div>

Pour masquer un onglet, ajoutez la propriété `hidden` à cet onglet dans votre fichier `docs.json` :

```json highlight={4}
"tabs": [
  {
    "tab": "Home",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  }
]
```

<div id="search-seo-and-ai-indexing">
  ## Recherche, SEO et indexation par l’IA
</div>

Par défaut, les pages masquées n’apparaissent pas dans l’index des moteurs de recherche, dans la Recherche du site de documentation ni dans le contexte de l’assistant IA. Pour inclure les pages masquées dans les résultats de recherche et le contexte de l’assistant, ajoutez la propriété `seo` à votre `docs.json` :

```json
"seo": {
    "indexing": "all"
}
```

<div id="understanding-hidden-versus-noindex">
  ### Comprendre `hidden` et `noindex`
</div>

La relation entre `hidden` et `noindex` est à sens unique :

* **`hidden: true` → applique automatiquement `noindex`** : les pages masquées sont automatiquement exclues des moteurs de recherche, des sitemaps et du contexte d’IA.
* **`noindex: true` → n’applique PAS `hidden`** : les pages avec `noindex: true` restent visibles dans la Navigation. Elles n’affectent que l’indexation par les moteurs de recherche et le contexte d’IA.

Pour exclure une page précise des moteurs de recherche tout en la laissant visible dans la Navigation, ajoutez `noindex: true` à ses métadonnées d’en-tête. Pour masquer une page dans la Navigation et l’exclure des moteurs de recherche, utilisez `hidden: true`.
