Utilisez ces paramètres dans votre fichier `docs.json` pour contrôler la façon dont les moteurs de recherche indexent votre documentation, les métadonnées qui apparaissent dans les résultats de recherche, le comportement de la barre de recherche et l’affichage de la date de dernière modification sur les pages.

<div id="settings">
  ## Paramètres
</div>

<div id="description">
  ### `description`
</div>

**Type :** `string`

Une description de votre site de documentation pour le SEO et l’indexation par l’IA. Elle apparaît dans les résultats des moteurs de recherche, et les outils d’IA l’utilisent pour comprendre à quoi sert votre site.

```json docs.json
"description": "Documentation for Example Co.'s API and developer platform."
```

***

<div id="seo">
  ### `seo`
</div>

**Type :** `object`

Paramètres d’indexation et de métadonnées pour les moteurs de recherche.

<ResponseField name="seo.indexing" type="&#x22;navigable&#x22; | &#x22;all&#x22;">
  Indique les pages que les moteurs de recherche doivent indexer.

  * `navigable` — Indexe uniquement les pages incluses dans la navigation de votre `docs.json`. Il s’agit de la valeur par défaut.
  * `all` — Indexe toutes les pages de votre projet, y compris celles qui ne figurent pas dans la navigation.
</ResponseField>

<ResponseField name="seo.metatags" type="object">
  Balises méta personnalisées ajoutées à chaque page. Indiquez-les sous forme de paires clé-valeur, où chaque clé correspond à un nom de balise méta et la valeur à son contenu.

  Consultez la [référence des balises méta courantes](/fr/optimize/seo#common-meta-tags-reference) pour voir les options disponibles.

  ```json
  "metatags": {
    "og:site_name": "Example Co. Docs",
    "twitter:card": "summary_large_image"
  }
  ```
</ResponseField>

```json docs.json
"seo": {
  "indexing": "navigable",
  "metatags": {
    "og:site_name": "Example Co. Docs"
  }
}
```

***

<div id="search">
  ### `search`
</div>

**Type:** `object`

Paramètres d’affichage de la barre de recherche.

<ResponseField name="search.prompt" type="string">
  Texte indicatif affiché dans la barre de recherche lorsqu’elle est vide.
</ResponseField>

```json docs.json
"search": {
  "prompt": "Search the docs..."
}
```

***

<div id="metadata">
  ### `metadata`
</div>

**Type :** `object`

Paramètres de métadonnées au niveau des pages, appliqués globalement à l’ensemble des pages.

<ResponseField name="metadata.timestamp" type="boolean">
  Affiche une date de dernière modification sur toutes les pages. Lorsqu’elle est activée, chaque page affiche la date à laquelle son contenu a été modifié pour la dernière fois. La valeur par défaut est `false`.

  Vous pouvez remplacer ce paramètre pour chaque page à l’aide du champ de métadonnées d’en-tête `timestamp`. Consultez [Pages](/fr/organize/pages#last-modified-timestamp) pour plus de détails.
</ResponseField>

```json docs.json
"metadata": {
  "timestamp": true
}
```

<div id="example">
  ## Exemple
</div>

```json docs.json
{
  "description": "Documentation for Example Co.'s API and developer platform.",
  "seo": {
    "indexing": "navigable",
    "metatags": {
      "og:site_name": "Example Co. Docs",
      "twitter:card": "summary_large_image"
    }
  },
  "search": {
    "prompt": "Search the docs..."
  },
  "metadata": {
    "timestamp": true
  }
}
```
