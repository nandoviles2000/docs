Utilisez le champ `api` dans `docs.json` pour définir quelles spécifications d’API servent à générer les pages d’API, le bac à sable API interactif pour tester les points de terminaison, ainsi que la manière de générer et d’afficher des exemples de code.

<div id="settings">
  ## Paramètres
</div>

<div id="api">
  ### `api`
</div>

**Type :** `object`

Définissez tous les paramètres liés à l’API sous la clé `api`.

<ResponseField name="api.openapi" type="string or array or object">
  Fichiers de spécification OpenAPI servant à générer des pages de Référence de l’API. Accepte un chemin ou une URL unique, un tableau de chemins et d’URL, ou un objet qui spécifie une source et un répertoire.

  <Expandable title="objet api.openapi">
    <ResponseField name="source" type="string">
      URL ou chemin vers votre fichier de spécification OpenAPI. Longueur minimale : 1.
    </ResponseField>

    <ResponseField name="directory" type="string">
      Répertoire dans lequel rechercher les fichiers OpenAPI. N’incluez pas de barre oblique au début.
    </ResponseField>
  </Expandable>

  <CodeGroup>
    ```json Fichier unique
    "openapi": "openapi.json"
    ```

    ```json Plusieurs fichiers
    "openapi": [
      "openapi/v1.json",
      "openapi/v2.json",
      "https://api.example.com/openapi.yaml"
    ]
    ```

    ```json Répertoire
    "openapi": {
      "source": "openapi.json",
      "directory": "api-reference"
    }
    ```
  </CodeGroup>
</ResponseField>

<ResponseField name="api.asyncapi" type="string or array or object">
  Fichiers de spécification AsyncAPI servant à générer des pages de Référence de l’API orientées événements. Accepte un chemin ou une URL unique, un tableau de chemins et d’URL, ou un objet qui spécifie une source et un répertoire.

  <Expandable title="objet api.asyncapi">
    <ResponseField name="source" type="string">
      URL ou chemin vers votre fichier de spécification AsyncAPI. Longueur minimale : 1.
    </ResponseField>

    <ResponseField name="directory" type="string">
      Répertoire dans lequel rechercher les fichiers AsyncAPI. N’incluez pas de barre oblique au début.
    </ResponseField>
  </Expandable>

  <CodeGroup>
    ```json Fichier unique
    "asyncapi": "asyncapi.json"
    ```

    ```json Plusieurs fichiers
    "asyncapi": [
      "asyncapi/events.yaml",
      "asyncapi/webhooks.yaml"
    ]
    ```

    ```json Répertoire
    "asyncapi": {
      "source": "asyncapi.json",
      "directory": "websockets"
    }
    ```
  </CodeGroup>
</ResponseField>

<ResponseField name="api.playground" type="object">
  Paramètres du bac à sable API interactif.

  <Expandable title="api.playground">
    <ResponseField name="display" type="&#x22;interactive&#x22; | &#x22;simple&#x22; | &#x22;none&#x22; | &#x22;auth&#x22;">
      Mode d’affichage du bac à sable. La valeur par défaut est `interactive`.

      * `interactive` — Bac à sable interactif complet avec générateur de requêtes
      * `simple` — Vue simplifiée sans générateur de requêtes
      * `none` — Masquer entièrement le bac à sable
      * `auth` — Afficher le bac à sable uniquement aux utilisateurs authentifiés
    </ResponseField>

    <ResponseField name="proxy" type="boolean">
      Indique si les requêtes API doivent être acheminées via un serveur proxy. La valeur par défaut est `true`.
    </ResponseField>

    <ResponseField name="credentials" type="boolean">
      Indique s’il faut inclure les cookies et les en-têtes d’authentification pour les requêtes cross-origin lorsque `proxy` est `false`. La valeur par défaut est `false`. N’a aucun effet lorsque `proxy` est `true`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api.params" type="object">
  Paramètres d’affichage des paramètres d’API.

  <Expandable title="api.params">
    <ResponseField name="expanded" type="&#x22;all&#x22; | &#x22;closed&#x22;">
      Indique si tous les paramètres doivent être développés par défaut. La valeur par défaut est `closed`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api.url" type="&#x22;full&#x22;">
  Mode d’affichage de l’URL de base dans l’en-tête du point de terminaison. Définissez cette valeur sur `full` pour toujours afficher l’URL de base complète sur chaque page de point de terminaison. Par défaut, l’URL de base n’est affichée que lorsqu’il y en a plusieurs parmi lesquelles choisir.
</ResponseField>

<ResponseField name="api.examples" type="object">
  Paramètres des exemples de code d’API générés automatiquement.

  <Expandable title="api.examples">
    <ResponseField name="languages" type="array of string">
      Langues des extraits de code générés automatiquement. Consultez les [langues prises en charge](/fr/api-playground/overview#all-supported-languages) pour obtenir la liste complète des langues et alias disponibles.
    </ResponseField>

    <ResponseField name="defaults" type="&#x22;required&#x22; | &#x22;all&#x22;">
      Indique s’il faut inclure les paramètres facultatifs dans les exemples générés. La valeur par défaut est `all`.
    </ResponseField>

    <ResponseField name="prefill" type="boolean">
      Indique s’il faut préremplir le bac à sable avec les valeurs d’exemple de votre spécification OpenAPI. La valeur par défaut est `false`.
    </ResponseField>

    <ResponseField name="autogenerate" type="boolean">
      Indique s’il faut générer des exemples de code pour les endpoints à partir de votre spécification d’API. La valeur par défaut est `true`. Lorsque cette option est définie sur `false`, seuls les exemples de code rédigés manuellement (issus de `x-codeSamples` dans OpenAPI ou des composants `<RequestExample>` dans MDX) apparaissent dans le bac à sable.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="api.mdx" type="object">
  Paramètres des pages d’API créées à partir de fichiers MDX plutôt que de spécifications OpenAPI.

  <Expandable title="api.mdx">
    <ResponseField name="auth" type="object">
      Configuration de l’authentification pour les requêtes d’API basées sur MDX.

      <Expandable title="auth">
        <ResponseField name="method" type="&#x22;bearer&#x22; | &#x22;basic&#x22; | &#x22;key&#x22; | &#x22;cobo&#x22;">
          Méthode d’authentification pour les requêtes d’API.
        </ResponseField>

        <ResponseField name="name" type="string">
          Nom du paramètre d’authentification pour les requêtes d’API.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="server" type="string or array">
      URL de base ajoutée en préfixe aux chemins relatifs dans les champs `api` des métadonnées d’en-tête au niveau de la page. N’est pas utilisée lorsque les métadonnées d’en-tête contiennent une URL complète.
    </ResponseField>
  </Expandable>
</ResponseField>

<div id="example">
  ## Exemple
</div>

```json docs.json
{
  "api": {
    "openapi": ["openapi/v1.json", "openapi/v2.json"],
    "playground": {
      "display": "interactive"
    },
    "params": {
      "expanded": "all"
    },
    "url": "full",
    "examples": {
      "languages": ["curl", "python", "javascript", "go"],
      "defaults": "required",
      "prefill": true,
      "autogenerate": true
    }
  }
}
```
