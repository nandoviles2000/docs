  ## Référence complète des propriétés
</div>

<div id="ref">
  ### `$ref`
</div>

Chargez la configuration depuis un autre fichier JSON. Utilisez `$ref` à n’importe quel niveau de votre `docs.json` pour répartir la configuration entre plusieurs fichiers.

**Type :** string — chemin relatif vers un fichier `.json`

* Lorsque `$ref` pointe vers un objet, Mintlify fusionne les clés sœurs du même bloc avec le contenu référencé, les clés sœurs ayant priorité sur les clés correspondantes de la référence.
* Lorsque `$ref` pointe vers une valeur qui n’est pas un objet, comme un tableau, Mintlify ignore les clés sœurs.
* Les fichiers référencés peuvent contenir leurs propres entrées `$ref`, résolues par rapport à ce fichier.
* Les chemins doivent rester dans la racine du projet. Les références circulaires provoquent une erreur de build.

Consultez [Répartir la configuration avec `$ref`](/fr/organize/settings#split-configuration-with-%24ref) pour obtenir des exemples.

### `theme` - <Badge color="red">obligatoire</Badge>

Le thème de mise en page de votre site.

**Type :** string
**Options :** `mint`, `maple`, `palm`, `willow`, `linden`, `almond`, `aspen`, `sequoia`, `luma`

Consultez [Thèmes](/fr/customize/themes) pour voir des aperçus.

***

### `name` - <Badge color="red">obligatoire</Badge>

Le nom de votre projet, de votre organisation ou de votre produit.

**Type :** string

***

### `colors` - <Badge color="red">obligatoire</Badge>

Les couleurs utilisées dans votre documentation.

**Type :** objet

<div id="colorsprimary">
  #### `colors.primary`
</div>

<Badge color="red">obligatoire</Badge>

La couleur principale. Elle est généralement utilisée pour mettre en évidence des éléments en mode clair.

**Type :** string—code hexadécimal correspondant à `^#([a-fA-F0-9]{6}|[a-fA-F0-9]{3})$`

<div id="colorslight">
  #### `colors.light`
</div>

La couleur utilisée pour mettre en avant des éléments en mode sombre.

**Type :** string—code hexadécimal correspondant à `^#([a-fA-F0-9]{6}|[a-fA-F0-9]{3})$`

<div id="colorsdark">
  #### `colors.dark`
</div>

La couleur utilisée pour les boutons et les états de survol dans les deux modes.

**Type :** string—code hexadécimal correspondant à `^#([a-fA-F0-9]{6}|[a-fA-F0-9]{3})$`

### `navigation` - <Badge color="red">obligatoire</Badge>

La structure de navigation de votre contenu.

**Type :** objet

Consultez la documentation complète dans [Navigation](/fr/organize/navigation).

<div id="navigationglobal">
  #### `navigation.global`
</div>

Éléments de navigation globaux affichés sur l’ensemble des pages et dans toutes les langues.

**Type :** objet

<div id="navigationglobaltabs">
  ##### `navigation.global.tabs`
</div>

Onglets de navigation de premier niveau.

**Type :** tableau d’objets — chacun comportant : `tab` (chaîne, obligatoire), `icon` (chaîne), `iconType` (chaîne), `hidden` (booléen), `href` (chaîne URI, obligatoire)

<div id="navigationglobalanchors">
  ##### `navigation.global.anchors`
</div>

Liens d’ancrage de la barre latérale.

**Type :** tableau d’objets — chacun comportant : `anchor` (chaîne, obligatoire), `icon` (chaîne), `iconType` (chaîne), `color.light` (chaîne hexadécimale), `color.dark` (chaîne hexadécimale), `hidden` (booléen), `href` (URI, obligatoire)

<div id="navigationglobaldropdowns">
  ##### `navigation.global.dropdowns`
</div>

Menus déroulants.

**Type :** tableau d’objets — chacun comprenant : `dropdown` (chaîne, obligatoire), `icon` (chaîne), `iconType` (chaîne), `hidden` (booléen), `href` (URI de chaîne, obligatoire)

<div id="navigationgloballanguages">
  ##### `navigation.global.languages`
</div>

Sélecteur de langue dans la Navigation globale.

**Type :** tableau d’objets — chacun avec : `language` (chaîne, obligatoire), `default` (booléen), `hidden` (booléen), `href` (URI de chaîne, obligatoire)

**Codes de langue pris en charge :** `ar`, `ca`, `cn`, `cs`, `de`, `en`, `es`, `fr`, `fr-CA`, `he`, `hi`, `hu`, `id`, `it`, `ja`, `jp`, `ko`, `lv`, `nl`, `no`, `pl`, `pt`, `pt-BR`, `ro`, `ru`, `sv`, `tr`, `uk`, `uz`, `vi`, `zh`, `zh-Hans`, `zh-Hant`

<div id="navigationglobalversions">
  ##### `navigation.global.versions`
</div>

Sélecteur de version dans la navigation globale.

**Type :** tableau d’objets — chacun avec : `version` (chaîne, obligatoire, longueur minimale : 1), `default` (booléen), `hidden` (booléen), `href` (chaîne au format URI, obligatoire)

<div id="navigationglobalproducts">
  ##### `navigation.global.products`
</div>

Sélecteur de produits dans la navigation globale.

**Type:** tableau d’objets — chacun avec : `product` (chaîne, obligatoire), `description` (chaîne), `icon` (chaîne), `iconType` (chaîne)

<div id="navigationlanguages">
  #### `navigation.languages`
</div>

Sélecteur de langue pour les sites multilingues. Chaque entrée peut inclure des surcharges `banner`, `footer` et `navbar` spécifiques à la langue.

**Type :** tableau d’objets—chacun avec : `language` (chaîne, obligatoire), `default` (booléen), `hidden` (booléen), `banner` (objet), `footer` (objet), `navbar` (objet)

**Codes de langue pris en charge :** `ar`, `ca`, `cn`, `cs`, `de`, `en`, `es`, `fr`, `fr-CA`, `he`, `hi`, `hu`, `id`, `it`, `ja`, `jp`, `ko`, `lv`, `nl`, `no`, `pl`, `pt`, `pt-BR`, `ro`, `ru`, `sv`, `tr`, `uk`, `uz`, `vi`, `zh`, `zh-Hans`, `zh-Hant`

<div id="navigationversions">
  #### `navigation.versions`
</div>

Sélecteur de version pour les sites proposant plusieurs versions.

**Type :** tableau d’objets — chacun avec : `default` (booléen), `tag` (chaîne)

<div id="navigationtabs">
  #### `navigation.tabs`
</div>

Onglets principaux de la navigation.

**Type :** tableau d’objets — voir `navigation.global.tabs` pour la structure.

<div id="navigationanchors">
  #### `navigation.anchors`
</div>

Liens d’ancrage dans la barre latérale.

**Type :** tableau d’objets — voir `navigation.global.anchors` pour la structure.

<div id="navigationdropdowns">
  #### `navigation.dropdowns`
</div>

Menus déroulants.

**Type :** tableau d’objets — voir `navigation.global.dropdowns` pour la structure.

<div id="navigationproducts">
  #### `navigation.products`
</div>

Sélecteur de produits.

**Type :** tableau d’objets — voir `navigation.global.products` pour la structure.

<div id="navigationgroups">
  #### `navigation.groups`
</div>

Groupes permettant d’organiser le contenu en sections intitulées.

**Type:** tableau d’objets

<div id="navigationpages">
  #### `navigation.pages`
</div>

Pages de votre documentation.

**Type :** tableau de chaînes de caractères ou d’objets

<div id="navigationdirectory">
  #### `navigation.directory`
</div>

Présentation du répertoire pour les pages racines des groupes de navigation. Hérité récursivement ; les éléments descendants peuvent le remplacer. Voir [Listes de répertoires](/fr/organize/navigation#directory-listings).

**Type :** `"none"` | `"accordion"` | `"card"` — valeur par défaut `"none"`
