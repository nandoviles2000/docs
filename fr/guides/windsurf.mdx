Faites de Windsurf un expert en documentation capable de comprendre votre guide de style, vos composants et le contexte de votre projet grâce aux règles d’espace de travail et aux mémoires.

<div id="use-windsurf-with-mintlify">
  ## Utiliser Windsurf avec Mintlify
</div>

L&#39;assistant IA Cascade de Windsurf peut être configuré pour rédiger de la documentation selon vos standards à l&#39;aide des composants Mintlify. Les règles d&#39;espace de travail et les mémoires fournissent un contexte durable sur votre projet, ce qui permet à Cascade de proposer des suggestions plus cohérentes.

* Les **règles d&#39;espace de travail** sont stockées dans votre dépôt de documentation et partagées avec votre équipe.
* Les **mémoires** fournissent un contexte individuel qui s&#39;enrichit au fil du temps.

Nous vous recommandons de configurer des règles d&#39;espace de travail pour définir des standards de documentation communs. Vous pouvez enrichir les mémoires au fil de votre travail, mais comme elles ne sont pas partagées, elles varient d&#39;un membre de l&#39;équipe à l&#39;autre.

Créez des règles d&#39;espace de travail dans le répertoire `.windsurf/rules` de votre dépôt de documentation. Consultez [Memories &amp; Rules](https://docs.windsurf.com/windsurf/cascade/memories) dans la documentation de Windsurf pour plus d&#39;informations.

<div id="example-workspace-rule">
  ## Exemple de règle d’espace de travail
</div>

Cette règle donne à Cascade du contexte sur les composants Mintlify et les bonnes pratiques générales de rédaction technique.

Vous pouvez utiliser cet exemple de règle tel quel ou l’adapter à votre documentation :

* **Normes de rédaction** : mettez à jour les consignes linguistiques pour les aligner sur votre guide de style.
* **Modèles de composants** : ajoutez des composants propres à votre projet ou modifiez les exemples existants.
* **Exemples de code** : remplacez les exemples génériques par de vrais appels d’API et les réponses correspondantes pour votre produit.
* **Préférences de style et de ton** : ajustez la terminologie, la mise en forme et les autres règles.

Enregistrez votre règle sous la forme d’un fichier `.md` dans le répertoire `.windsurf/rules` de votre dépôt de documentation.

````mdx
# Règle de rédaction technique Mintlify

## Contexte du projet

- Il s'agit d'un projet de documentation sur la plateforme Mintlify
- Nous utilisons des fichiers MDX avec des métadonnées d'en-tête YAML  
- La navigation est configurée dans `docs.json`
- Nous suivons les bonnes pratiques de rédaction technique

## Normes de rédaction

- Utiliser la deuxième personne (« vous ») pour les instructions
- Écrire à la voix active et au présent
- Commencer les procédures par les prérequis
- Inclure les résultats attendus pour les étapes importantes
- Utiliser des titres descriptifs et riches en mots-clés
- Garder les phrases concises mais informatives

## Structure de page requise

Chaque page doit commencer par des métadonnées d'en-tête :

```yaml
---
title: "Clear, specific title"
description: "Concise description for SEO and navigation"
---
```

## Composants Mintlify

### docs.json

- Consulter le [schéma docs.json](https://mintlify.com/docs.json) lors de la création du fichier docs.json et de la navigation du site

### Encadrés

- `<Note>` pour les informations complémentaires utiles
- `<Warning>` pour les mises en garde importantes et les changements majeurs
- `<Tip>` pour les bonnes pratiques et les conseils d'experts  
- `<Info>` pour les informations contextuelles neutres
- `<Check>` pour les confirmations de succès

### Exemples de code

- Le cas échéant, inclure des exemples complets et exécutables
- Utiliser `<CodeGroup>` pour les exemples en plusieurs langages
- Spécifier les balises de langage sur tous les blocs de code
- Inclure des données réalistes, pas des données fictives
- Utiliser `<RequestExample>` et `<ResponseExample>` pour la documentation API

### Procédures

- Utiliser le composant `<Steps>` pour les instructions séquentielles
- Inclure des étapes de vérification avec les composants `<Check>` lorsque c'est pertinent
- Décomposer les procédures complexes en étapes plus petites

### Organisation du contenu

- Utiliser `<Tabs>` pour le contenu spécifique à une plateforme
- Utiliser `<Accordion>` pour l'affichage progressif
- Utiliser `<Card>` et `<CardGroup>` pour mettre en valeur le contenu
- Envelopper les images dans des composants `<Frame>` avec un texte alternatif descriptif

## Exigences pour la documentation API

- Documenter tous les paramètres avec `<ParamField>` 
- Afficher la structure des réponses avec `<ResponseField>`
- Inclure des exemples de succès et d'erreur
- Utiliser `<Expandable>` pour les propriétés d'objets imbriqués
- Toujours inclure des exemples d'authentification

## Normes de qualité

- Tester tous les exemples de code avant la publication
- Utiliser des chemins relatifs pour les liens internes
- Inclure un texte alternatif pour toutes les images
- Assurer une hiérarchie de titres correcte (commencer par h2)
- Vérifier la cohérence avec les modèles existants
````

<div id="working-with-cascade">
  ## Utiliser Cascade
</div>

Une fois vos règles configurées, vous pouvez utiliser Cascade pour vous aider dans diverses tâches liées à la documentation. Consultez la page [Cascade](https://docs.windsurf.com/windsurf/cascade) de la documentation Windsurf pour plus d’informations.

<div id="example-prompts">
  ### Exemples de prompts
</div>

**Rédiger du nouveau contenu**:

```text wrap
Create a new page explaining how to authenticate with our API. Include code examples in JavaScript, Python, and cURL.
```

**Amélioration du contenu existant** :

```text wrap
Review this page and suggest improvements for clarity and component usage. Focus on making the steps easier to follow.
```

**Créer des exemples de code**:

```text wrap
Generate a complete code example showing error handling for this API endpoint. Use realistic data and include expected responses.
```

**Maintenir la cohérence** :

```text wrap
Check if this new page follows our documentation standards and suggest any needed changes.
```

<div id="enhance-with-mcp-server">
  ## Optimisez avec le serveur MCP
</div>

Connectez le serveur MCP de Mintlify à Windsurf pour permettre à Cascade d’effectuer des recherches dans la documentation Mintlify pendant qu’il vous aide à rédiger. Lorsque vous connectez le serveur MCP, Cascade interroge la documentation Mintlify la plus récente pour obtenir le contexte nécessaire, afin que vous n’ayez pas à quitter votre IDE pour consulter la documentation.

Consultez le [Model Context Protocol](/fr/ai/model-context-protocol#example%3A-connect-to-the-mintlify-mcp-server) pour obtenir les instructions complètes de configuration.
