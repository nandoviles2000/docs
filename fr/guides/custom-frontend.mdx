Le mode headless de Mintlify vous permet de contrôler l’apparence et le comportement de votre documentation tout en utilisant Mintlify pour gérer votre contenu. Au lieu d’utiliser le frontend hébergé de Mintlify, vous pouvez créer votre propre frontend personnalisé avec [Astro](https://astro.build) et afficher votre contenu MDX et la configuration `docs.json` comme vous le souhaitez.

Cette approche headless est utile lorsque vous avez besoin d’un contrôle total sur le design, la mise en page ou le comportement de votre documentation, afin de l’aligner sur un système de design existant ou d’intégrer la documentation à un site plus vaste, tout en continuant à utiliser Mintlify pour la publication, la recherche, les composants MDX et les fonctionnalités d’IA.

L’intégration `@mintlify/astro` lit votre configuration `docs.json` et votre contenu MDX au moment du build, puis transforme l’ensemble dans un format qu’Astro peut afficher. Créez ensuite vos propres mises en page, composants et styles par-dessus.

Ce guide vous explique comment configurer un projet Mintlify headless à partir du modèle de démarrage et l’exécuter en local.

<div id="prerequisites">
  ## Prérequis
</div>

* Un [compte Mintlify](https://dashboard.mintlify.com)
* Un [compte GitHub](https://github.com)
* [Node.js](https://nodejs.org) v20.17.0 ou une version ultérieure (versions LTS recommandées)
* Une connaissance d’[Astro](https://docs.astro.build)

<div id="set-up-your-project">
  ## Configurez votre projet
</div>

<Steps>
  <Step title="Créer un dépôt à partir du modèle de démarrage">
    Accédez au dépôt [mintlify-astro-starter](https://github.com/mintlify/mintlify-astro-starter) sur GitHub, puis cliquez sur **Use this template** pour créer un nouveau dépôt dans votre compte.

    Clonez ensuite le dépôt sur votre machine locale.
  </Step>

  <Step title="Créer un compte Mintlify">
    Si vous n&#39;avez pas encore de compte Mintlify, inscrivez-vous sur [dashboard.mintlify.com/signup](https://dashboard.mintlify.com/signup).
  </Step>

  <Step title="Installer l'application GitHub">
    Sur la page [Git settings](https://dashboard.mintlify.com/settings/deployment/git-settings) de votre tableau de bord Mintlify, installez l&#39;[application GitHub de Mintlify](/fr/deploy/github). Si l&#39;application est déjà installée, désinstallez-la puis réinstallez-la afin d&#39;être prêt à connecter votre nouveau dépôt.
  </Step>

  <Step title="Connecter votre dépôt">
    1. Sur la page [Git settings](https://dashboard.mintlify.com/settings/deployment/git-settings), sélectionnez le dépôt que vous avez créé à partir du modèle de démarrage.
    2. Activez l&#39;option **Set up as monorepo**.
    3. Saisissez `/docs` comme chemin vers le répertoire contenant votre fichier `docs.json`.
    4. Cliquez sur **Save changes**.

    <Frame>
      <img src="/images/guides/astro/repo-settings-light.png" alt="Paramètres du dépôt sur la page Git settings." className="block dark:hidden" />

      <img src="/images/guides/astro/repo-settings-dark.png" alt="Paramètres du dépôt sur la page Git settings." className="hidden dark:block" />
    </Frame>
  </Step>

  <Step title="Configurer les variables d'environnement">
    Clonez votre nouveau dépôt en local, puis créez un fichier `.env` à la racine du projet avec vos identifiants Mintlify :

    ```bash .env
    PUBLIC_MINTLIFY_SUBDOMAIN=your-subdomain
    PUBLIC_MINTLIFY_ASSISTANT_KEY=your-assistant-api-key
    ```

    Votre sous-domaine correspond au nom de domaine de votre projet. Il s&#39;agit de la partie de l&#39;URL de votre tableau de bord qui se trouve après le nom de l&#39;organisation. Par exemple, si l&#39;URL de votre tableau de bord est `https://dashboard.mintlify.com/org-name/domain-name`, votre sous-domaine est `domain-name`.

    Si vous avez un forfait Pro ou Enterprise, générez une clé d&#39;API de l&#39;assistant sur la page [API keys](https://dashboard.mintlify.com/settings/organization/api-keys) de votre tableau de bord. La clé d&#39;API de l&#39;assistant commence par `mint_dsc_`.
  </Step>

  <Step title="Démarrer le serveur de développement">
    Installez les dépendances et démarrez le serveur de développement local dans votre dépôt cloné :

    ```bash
    cd path/to/your-repository
    npm install
    npm run dev
    ```

    Votre site est maintenant accessible localement à l&#39;adresse `http://localhost:4321`.
  </Step>
</Steps>

<div id="how-it-works">
  ## Fonctionnement
</div>

L’intégration relie trois éléments : le système de compilation d’Astro, votre contenu dans le répertoire `docs/` et les packages Mintlify qui traitent et affichent ce contenu.

<div id="astro-configuration">
  ### Configuration d’Astro
</div>

Configurez l’intégration `mintlify()` dans `astro.config.mjs` en indiquant le chemin vers votre répertoire de documentation :

```javascript astro.config.mjs
import { defineConfig } from 'astro/config';
import react from '@astrojs/react';
import mdx from '@astrojs/mdx';
import { mintlify } from '@mintlify/astro';

export default defineConfig({
  integrations: [mintlify({ docsDir: './docs' }), react(), mdx()],
});
```

Lors de la compilation, l’intégration lit votre `docs.json` et vos fichiers MDX depuis le chemin `docsDir`, puis les traite pour les placer dans `.mintlify/docs/`, où les collections de contenu d’Astro les prennent en charge.

<div id="content-structure">
  ### Structure du contenu
</div>

Le contenu de votre documentation se trouve dans le répertoire `docs/`, structuré de la même façon que dans n’importe quel autre projet Mintlify :

```text
docs/
├── docs.json          # Navigation et configuration du site
├── index.mdx          # Pages MDX pour le contenu
├── quickstart.mdx
└── guides/            # Répertoires pour organiser les pages
    ├── setup.mdx
    └── troubleshooting.mdx
```

Les fichiers MDX utilisent les [métadonnées d’en-tête](/fr/organize/pages#page-metadata) standard de Mintlify et peuvent utiliser les composants Mintlify sans avoir à les importer.

<div id="routing-and-navigation">
  ### Routage et navigation
</div>

Une route catch-all affiche chaque page MDX. Le package `@mintlify/astro/helpers` fournit des fonctions pour déterminer l’état de la navigation à partir de votre `docs.json`.

* `resolvePageData()` : renvoie les onglets, les éléments de navigation latérale, les liens de pied de page et les ancres pour le chemin d’une page donnée.
* `unwrapNav()` : convertit l’arborescence de navigation en liste pour le rendu de la barre latérale.

<div id="layouts-and-styling">
  ### Mises en page et styles
</div>

Vous contrôlez entièrement la couche de présentation. Le modèle de démarrage inclut des mises en page, une barre latérale, une table des matières et des styles basés sur Tailwind CSS, mais vous pouvez remplacer chacun de ces éléments par les vôtres.

Principaux fichiers à personnaliser :

| Fichier                              | Rôle                                               |
| ------------------------------------ | -------------------------------------------------- |
| `src/layouts/Layout.astro`           | Mise en page HTML principale                       |
| `src/pages/[...slug].astro`          | Modèle de page et chargement des données           |
| `src/components/Header.astro`        | En-tête du site                                    |
| `src/components/Sidebar/`            | Navigation latérale                                |
| `src/components/TableOfContents.tsx` | Table des matières de la page                      |
| `src/styles/`                        | Styles globaux, typographie et palette de couleurs |

<div id="connect-search-and-assistant">
  ## Connectez la recherche et l’assistant
</div>

<Note>
  L’assistant est disponible dans les offres [Pro et Enterprise](https://mintlify.com/pricing).
</Note>

Le modèle de démarrage inclut des composants de recherche et d’assistant qui se connectent aux API de Mintlify à l’aide des variables d’environnement que vous configurez lors de l’installation.

* **Recherche** : le composant `SearchBar` dans `src/components/SearchBar.tsx` interroge l’API de recherche de Mintlify.
* **Assistant** : le composant `Assistant` dans `src/components/Assistant/` fournit une interface de chat IA qui répond aux questions à partir du contenu de votre documentation.

Les deux nécessitent les variables d’environnement `PUBLIC_MINTLIFY_SUBDOMAIN` et `PUBLIC_MINTLIFY_ASSISTANT_KEY`.

<div id="next-steps">
  ## Étapes suivantes
</div>

Après avoir configuré votre projet :

1. Remplacez le contenu initial de `docs/` par vos propres fichiers MDX et votre configuration `docs.json`.
2. Personnalisez les mises en page et les styles pour qu’ils correspondent à votre système de design.
3. Déployez votre site Astro chez l’hébergeur de votre choix.
