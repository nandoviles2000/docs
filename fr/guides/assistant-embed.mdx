<div id="what-you-will-build">
  ## Ce que vous allez créer
</div>

Un widget réutilisable qui intègre l’[assistant](/fr/assistant/index) directement dans votre application. Ce widget comprend :

* Un bouton flottant qui ouvre un panneau de discussion au clic
* Des réponses diffusées en temps réel à partir des informations de votre documentation
* Le rendu des messages avec prise en charge de Markdown

Les utilisateurs peuvent utiliser le widget pour obtenir de l’aide concernant votre produit sans quitter votre application.

</Frame>

<div id="prerequisites">
  ## Prérequis
</div>

* [Offre Mintlify Pro ou Enterprise](https://mintlify.com/pricing)
* Votre nom de domaine, qui figure à la fin de l’URL de votre tableau de bord. Par exemple, si l’URL de votre tableau de bord est `https://dashboard.mintlify.com/org-name/domain-name`, votre nom de domaine est `domain-name`
* Une [clé API de l’assistant](https://dashboard.mintlify.com/settings/organization/api-keys)
* Node.js v18 ou version ultérieure, ainsi que npm, installés
* Des connaissances de base en React

<div id="get-your-assistant-api-key">
  ### Obtenez votre clé API de l’assistant
</div>

1. Accédez à la page [API keys](https://dashboard.mintlify.com/settings/organization/api-keys) de votre tableau de bord.
2. Cliquez sur **Create Assistant API Key**.
3. Copiez la clé API de l’assistant (elle commence par `mint_dsc_`) et conservez-la en lieu sûr.

<Note>
  La clé API de l’assistant est un jeton public que vous pouvez utiliser dans du code frontend. Les appels effectués avec ce jeton sont décomptés du quota de messages de votre forfait et peuvent entraîner des frais de dépassement.
</Note>

<div id="set-up-the-example">
  ## Configurez l’exemple
</div>

Clonez le [dépôt d’exemple](https://github.com/mintlify/assistant-embed-example) et adaptez-le à vos besoins.

<Steps>
  <Step title="Cloner le dépôt">
    ```bash
    git clone https://github.com/mintlify/assistant-embed-example.git
    cd assistant-embed-example
    ```
  </Step>

  <Step title="Choisir votre outil de développement">
    Le dépôt inclut des exemples Next.js et Vite. Choisissez l’outil que vous préférez.

    <CodeGroup>
      ```bash title="Next.js"
      cd nextjs
      npm install
      ```

      ```bash title="Vite"
      cd vite
      npm install
      ```
    </CodeGroup>
  </Step>

  <Step title="Configurer votre projet">
    Ouvrez `src/config.js` et mettez-le à jour avec les informations de votre projet Mintlify.

    ```js src/config.js
    export const ASSISTANT_CONFIG = {
      domain: 'your-domain',
      docsURL: 'https://yourdocs.mintlify.app',
    };
    ```

    Remplacez :

    * `your-domain` par le domaine de votre projet Mintlify, indiqué à la fin de l’URL de votre tableau de bord.
    * `https://yourdocs.mintlify.app` par l’URL réelle de votre documentation.
  </Step>

  <Step title="Ajouter votre jeton d’API">
    Créez un fichier `.env` à la racine du projet.

    ```bash .env
    VITE_MINTLIFY_TOKEN=mint_dsc_your_token_here
    ```

    Remplacez `mint_dsc_your_token_here` par votre clé d’API de l’assistant.
  </Step>

  <Step title="Démarrer le serveur de développement">
    ```bash
    npm run dev
    ```

    Ouvrez votre application dans un navigateur, puis cliquez sur le bouton **Ask** pour ouvrir le widget de l’assistant.
  </Step>
</Steps>

  ## Idées de personnalisation

<div id="source-citations">
  ### Citations des sources
</div>

Extrayez et affichez les sources des réponses de l’assistant :

```jsx
const extractSources = (parts) => {
  return parts
    ?.filter(p => p.type === 'tool-invocation' && p.toolInvocation?.toolName === 'search')
    .flatMap(p => p.toolInvocation?.result || [])
    .map(source => ({
      url: source.url || source.path,
      title: source.metadata?.title || source.path,
    })) || [];
};

// Dans le rendu de vos messages :
{messages.map((message) => {
  const sources = message.role === 'assistant' ? extractSources(message.parts) : [];
  return (
    <div key={message.id}>
      {/* contenu du message */}
      {sources.length > 0 && (
        <div className="mt-2 text-xs">
          <p className="font-semibold">Sources:</p>
          {sources.map((s, i) => (
            <a key={i} href={s.url} target="_blank" rel="noopener noreferrer" className="text-blue-600">
              {s.title}
            </a>
          ))}
        </div>
      )}
    </div>
  );
})}
```

<div id="track-conversation-threads">
  ### Suivre les fils de conversation
</div>

Stockez les ID et les clés de fil afin de conserver l&#39;historique des conversations d&#39;une session à l&#39;autre.

Lorsqu&#39;un utilisateur crée un nouveau fil de conversation, le serveur renvoie deux valeurs dans les en-têtes de réponse :

* `X-Thread-Id` : l&#39;identifiant du fil
* `X-Thread-Key` : une clé secrète pour le fil (renvoyée une seule fois, lors de la création du fil)

Vous devez récupérer et conserver ces deux valeurs dès la première réponse. Pour chaque message suivant, incluez `threadId` et `threadKey` dans le corps de la requête. Si vous envoyez un `threadId` sans le `threadKey` correspondant, le serveur renvoie une erreur `404`.

<Warning>
  Vous devez enregistrer immédiatement l&#39;en-tête `X-Thread-Key`. Le serveur ne le renvoie que lorsqu&#39;un nouveau fil est créé. Vous ne pourrez pas le récupérer plus tard.
</Warning>

```jsx
import { useState, useEffect } from 'react';

export function AssistantWidget({ domain, docsURL }) {
  const [threadId, setThreadId] = useState(null);
  const [threadKey, setThreadKey] = useState(null);

  useEffect(() => {
    // Récupérer l'ID de fil et la clé enregistrés depuis localStorage
    const savedId = localStorage.getItem('assistant-thread-id');
    const savedKey = localStorage.getItem('assistant-thread-key');
    if (savedId && savedKey) {
      setThreadId(savedId);
      setThreadKey(savedKey);
    }
  }, []);

  const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat({
    api: `https://api.mintlify.com/discovery/v1/assistant/${domain}/message`,
    headers: {
      'Authorization': `Bearer ${import.meta.env.VITE_MINTLIFY_TOKEN}`,
    },
    body: {
      fp: 'anonymous',
      retrievalPageSize: 5,
      ...(threadId && { threadId }),
      ...(threadKey && { threadKey }),
    },
    streamProtocol: 'data',
    sendExtraMessageFields: true,
    fetch: async (url, options) => {
      const response = await fetch(url, options);
      const newThreadId = response.headers.get('x-thread-id');
      const newThreadKey = response.headers.get('x-thread-key');
      if (newThreadId) {
        setThreadId(newThreadId);
        localStorage.setItem('assistant-thread-id', newThreadId);
      }
      if (newThreadKey) {
        setThreadKey(newThreadKey);
        localStorage.setItem('assistant-thread-key', newThreadKey);
      }
      return response;
    },
  });

  // ... reste du composant
}
```

<div id="add-keyboard-shortcuts">
  ### Ajouter des raccourcis clavier
</div>

Permettez aux utilisateurs d’ouvrir le widget et d’envoyer des messages à l’aide de raccourcis clavier :

```jsx
useEffect(() => {
  const handleKeyDown = (e) => {
    // Cmd/Ctrl + Shift + I pour afficher/masquer le widget
    if ((e.metaKey || e.ctrlKey) && e.shiftKey && e.key === 'I') {
      e.preventDefault();
      setIsOpen((prev) => !prev);
    }

    // Entrée (quand le widget est actif) pour envoyer
    if (e.key === 'Enter' && !e.shiftKey && document.activeElement.id === 'assistant-input') {
      e.preventDefault();
      handleSubmit();
    }
  };

  window.addEventListener('keydown', handleKeyDown);
  return () => window.removeEventListener('keydown', handleKeyDown);
}, [handleSubmit]);
```
