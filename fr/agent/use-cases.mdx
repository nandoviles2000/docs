L’agent vous aide à accomplir de nombreuses tâches liées à la documentation. Ces exemples montrent différentes façons de l’intégrer à votre processus de documentation. Essayez une approche adaptée à la façon dont votre équipe travaille aujourd’hui, puis adaptez-la à vos besoins spécifiques.

<div id="iterate-on-a-prompt-in-a-slack-thread">
  ## Itérer sur un prompt dans un fil de discussion Slack
</div>

Envoyez un prompt à l’agent, puis continuez à le mentionner avec `@mintlify` dans le même fil afin d’affiner et de faire évoluer la pull request (PR) qu’il crée.

Par exemple : `@mintlify Notre page de démarrage rapide a besoin d’une nouvelle section sur l’invitation de collaborateurs`. Puis `@mintlify La nouvelle section doit s’appeler "Inviter des collaborateurs"`. Suivi de toute autre itération.

<div id="start-with-the-agent-finish-manually">
  ## Commencez avec l’agent, terminez manuellement
</div>

Demandez à l’agent de lancer un projet, puis passez sur la branche qu’il crée et terminez la tâche dans votre environnement local ou dans l’éditeur web. L’agent peut vous aider à démarrer, puis vous pouvez prendre le relais pour terminer la tâche.

Par exemple : `@mintlify Update the quickstart page to include information about inviting collaborators`, puis passez sur la branche pour apporter toute modification supplémentaire selon la méthode de votre choix.

<div id="update-docs-when-merging-feature-changes">
  ## Mettez à jour la documentation lors de la fusion de modifications de fonctionnalité
</div>

Lorsque vous fusionnez une pull request (PR) de fonctionnalité, partagez le lien de la PR avec l&#39;agent pour mettre à jour la documentation pertinente.

Par exemple : `@mintlify Cette PR ajoute une nouvelle méthode d’authentification. Mettez à jour la documentation pour inclure le nouveau flux d’authentification : [lien de la PR]`.

<div id="generate-release-notes-from-a-pull-request">
  ## Générer des notes de version à partir d’une pull request
</div>

Demandez à l’agent de générer des notes de version ou des mises à jour du journal des modifications à partir de l’historique des commits d’une pull request (PR) spécifique.

Par exemple : `@mintlify Generate release notes for this PR: [PR link]`.

<div id="address-pull-request-review-feedback">
  ## Traiter les retours de revue d’une pull request (PR)
</div>

Partagez un lien vers la pull request (PR) avec l’agent pour qu’il traite les commentaires des réviseurs et les retours de revue de code sur les pull requests (PR) de documentation.

Par exemple : `@mintlify Address the review comments on this PR: [PR link]`.

<div id="generate-code-examples">
  ## Générer des exemples de code
</div>

Demandez à l’agent de générer des exemples de code pour illustrer des fonctionnalités dans l’ensemble de votre documentation ou sur des pages spécifiques.

Par exemple : `@mintlify Génère un exemple de code pour rendre la méthode d’authentification plus facile à comprendre`.

<div id="add-images-or-files-to-your-docs">
  ## Ajoutez des images ou des fichiers à votre documentation
</div>

Joignez directement des fichiers ou des images à votre message Slack lorsque vous demandez quelque chose à l’agent. L’agent traite la pièce jointe et l’intègre à la documentation.

Par exemple : `@mintlify Add this diagram to the architecture overview page`, avec l’image jointe au message.

<div id="review-existing-content">
  ## Vérifier le contenu existant
</div>

Demandez à l’agent de passer en revue le contenu existant afin d’en vérifier l’exactitude technique, le style, la grammaire et tout autre problème.

Par exemple : `@mintlify Review the API rate limiting section. We changed limits last month`.

<div id="respond-to-user-feedback">
  ## Répondre aux retours des utilisateurs
</div>

Transmettez à l’agent les retours de vos utilisateurs afin d’apporter des mises à jour ciblées à votre documentation.

Par exemple : `@mintlify Users are getting confused by step 3 in the setup guide. What might be making it unclear?`.

<div id="automate-with-workflows">
  ## Automatisez avec les flux de travail
</div>

Créez des flux de travail pour automatiser les tâches récurrentes ainsi que les tâches de maintenance réactive, comme la rédaction de journaux de modifications ou la mise à jour du contenu lorsque vous ajoutez de nouvelles fonctionnalités à votre produit.

Consultez [Flux de travail](/fr/agent/workflows) pour plus d’informations.

<div id="automate-with-the-api">
  ## Automatisez avec l’API
</div>

Intégrez l’agent à vos outils d’automatisation existants pour mettre automatiquement à jour la documentation lorsque le code change, déclencher des révisions de contenu ou synchroniser les mises à jour de la documentation entre plusieurs dépôts.

Utilisez les points de terminaison de l’agent pour [créer des tâches](/fr/api/agent/v2/create-agent-job), [obtenir l’état d’une tâche](/fr/api/agent/v2/get-agent-job) et [envoyer des messages](/fr/api/agent/v2/send-message).

Lorsque vous créez des tâches via l’API, vous pouvez indiquer si les pull requests (PR) doivent s’ouvrir en mode brouillon à l’aide du paramètre `asDraft` (par défaut, `false`). Définissez `asDraft: true` pour créer des pull requests (PR) en brouillon, ou conservez la valeur par défaut pour créer des pull requests (PR) prêtes à être examinées et fusionnées immédiatement dans des flux de travail automatisés.

Découvrez comment configurer l’automatisation via l’API dans le tutoriel [Mettre à jour automatiquement la documentation lorsque le code est fusionné](/fr/guides/automate-agent).
