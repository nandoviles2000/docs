<Info>
  L’agent est disponible avec les [offres Pro et Enterprise](https://mintlify.com/pricing?ref=agent).
</Info>

L’agent est un outil d’IA qui crée des pull requests (PR) proposant des modifications de votre documentation à partir de vos instructions. Lorsque vous envoyez une demande, l’agent :

* **Effectue des recherches** : recherche et lit votre documentation existante, les dépôts connectés, le contexte pertinent et le Web.
* **Planifie** : crée une liste de tâches structurée pour les travaux de documentation complexes.
* **Rédige** : génère ou met à jour du contenu en respectant les normes rédactionnelles et les bonnes pratiques.
* **Valide** : exécute les vérifications de la CLI Mintlify pour s’assurer que la documentation se génère correctement.
* **Crée une PR** : ouvre une pull request (PR) contenant les modifications proposées pour examen.

Toutes les modifications passent par des pull requests (PR). L’agent n’effectue jamais de commit directement sur votre branche `main`.

<div id="what-you-can-do-with-the-agent">
  ## Ce que vous pouvez faire avec l’agent
</div>

Utilisez l’agent pour :

* Rédiger du nouveau contenu à partir de vos prompts, de pull requests (PR), de tickets Linear, de fils Slack ou de pièces jointes.
* Mettre à jour la documentation existante pour tenir compte de nouvelles fonctionnalités ou de modifications de l’API.
* Traiter et intégrer des images, des diagrammes et d’autres fichiers issus de pièces jointes Slack.
* Rechercher et mettre à jour des exemples de code et des références de l’API dans l’ensemble de votre documentation.
* Automatiser la maintenance de la documentation avec des flux de travail.
* Répondre à des questions sur votre documentation et sur la rédaction technique.
* Prendre en compte les retours de revue de code afin de préserver la qualité de la documentation.
* Capturer les connaissances issues des conversations Slack et des pull requests (PR) avant qu’elles ne soient perdues.
* Parcourir efficacement plusieurs fichiers et répertoires et coordonner les modifications qui y sont apportées.

<div id="connect-your-github-account">
  ## Connectez votre compte GitHub
</div>

Par défaut, l’agent ouvre des pull requests (PR) attribuées au bot Mintlify. Pour que les pull requests (PR) vous soient attribuées, connectez votre compte GitHub sur la page [Mon profil](https://dashboard.mintlify.com/settings/account) du tableau de bord.

<div id="connect-repositories-as-context">
  ## Connecter des dépôts comme source de contexte
</div>

L’agent peut uniquement accéder aux dépôts que vous connectez via la GitHub App de Mintlify. Configurez les dépôts auxquels l’agent peut accéder dans les **Paramètres** du panneau de l’agent ou dans les [paramètres de la GitHub App](https://github.com/apps/mintlify/installations/new).
