Connectez votre espace de travail Linear à l’agent pour effectuer des mises à jour de la documentation depuis Linear. Lorsque vous mentionnez l’agent Mintlify dans un commentaire Linear ou que vous l’assignez à une issue, l’agent s’appuie sur le contexte de l’issue et ouvre une pull request (PR) avec les modifications proposées pour votre documentation."

<div id="connect-your-linear-workspace">
  ## Connectez votre espace de travail Linear
</div>

1. Accédez à la page [Agent](https://dashboard.mintlify.com/products/agent) dans votre tableau de bord.
2. Dans la section « Agent settings », cliquez sur **Install Linear app**.

<Frame>
  <img src="/images/agent/install-apps-light.png" alt="La section des paramètres de l’application avec les boutons d’installation de Slack, Linear et Notion." className="block dark:hidden" />

  <img src="/images/agent/install-apps-dark.png" alt="La section des paramètres de l’application avec les boutons d’installation de Slack, Linear et Notion." className="hidden dark:block" />
</Frame>

3. Suivez les instructions de Linear pour autoriser l’application Mintlify dans votre espace de travail.

<div id="use-the-agent-in-linear">
  ## Utiliser l’agent dans Linear
</div>

Une fois la connexion établie, mentionnez `@mintlify` dans une issue Linear ou attribuez une issue à `Mintlify` pour déclencher une mise à jour de la documentation. L’agent utilise le titre, la description et le fil de discussion de l’issue comme contexte, puis ouvre une pull request (PR) dans votre dépôt de documentation.

Utilisez l’agent dans Linear pour :

* **Mettre à jour la documentation à partir d’issues liées à des fonctionnalités** : lorsqu’une fonctionnalité est mise en production, mentionnez l’agent dans l’issue pour rédiger ou mettre à jour la documentation correspondante.
* **Traiter les retours sur la documentation** : créez des issues Linear pour améliorer la documentation et mentionnez l’agent pour appliquer les modifications.
* **Générer des notes de version** : mentionnez l’agent dans une issue liée à une version pour rédiger des entrées de changelog à partir des détails de l’issue.
* **Corriger les problèmes signalés** : lorsqu’une personne signale un problème de documentation dans Linear, mentionnez l’agent pour le résoudre.

<div id="best-practices">
  ## Bonnes pratiques
</div>

* **Ajoutez du contexte à l’issue** : plus vous fournissez de contexte dans une issue, meilleure sera la pull request (PR) obtenue.
* **Vérifiez les pull requests** : vérifiez toujours les pull requests créées par l’agent avant de les fusionner.
* **Procédez par itérations dans les commentaires** : répondez dans le même fil d’issue pour affiner le résultat de l’agent, comme vous le feriez dans Slack.
