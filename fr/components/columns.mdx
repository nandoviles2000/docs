Le composant `Columns` vous permet d’organiser du contenu dans une grille responsive. Il est le plus souvent utilisé pour afficher des Card dans une grille en spécifiant le nombre de colonnes. Vous pouvez également utiliser le sous-composant `Column` pour contenir du contenu de votre choix. Les colonnes sont responsives et s’adaptent automatiquement aux écrans plus petits.

<Columns cols={2}>
  <Card title="Commencer" icon="rocket">
    Configurez votre projet avec notre guide de démarrage rapide.
  </Card>

  <Card title="Référence de l’API" icon="code">
    Explorez les points de terminaison, les paramètres et les exemples de votre API.
  </Card>
</Columns>

```mdx Columns example
<Columns cols={2}>
  <Card title="Get started">
    Set up your project with our quickstart guide.
  </Card>
  <Card title="API reference">
    Explore endpoints, parameters, and examples for your API.
  </Card>
</Columns>
```

<div id="column-sub-component">
  ## Sous-composant Column
</div>

Utilisez le composant `Column` pour placer du texte ou du code dans des colonnes distinctes. C&#39;est utile si vous souhaitez afficher du contenu libre côte à côte, et pas seulement des composants Card ou d&#39;autres composants.

<Columns cols={2}>
  <Column>
    **Installation**

    ```bash
    npm install my-package
    ```
  </Column>

  <Column>
    **Utilisation**

    ```javascript
    import { init } from 'my-package';
    init();
    ```
  </Column>
</Columns>

````mdx Column sub-component example
<Columns cols={2}>
  <Column>

  **Installation**

  ```bash
  npm install my-package
  ```

  </Column>
  <Column>

  **Utilisation**

  ```javascript
  import { init } from 'my-package';
  init();
  ```

  </Column>
</Columns>
````

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="cols" type="number" default={2}>
  Nombre de colonnes par ligne. Valeurs acceptées : de 1 à 4.
</ResponseField>
