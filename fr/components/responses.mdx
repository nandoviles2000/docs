keywords: ["sortie d’API", "valeurs de retour", "structure de réponse"]
---

Utilisez le composant `<ResponseField>` pour définir les valeurs renvoyées par une API. `<ResponseField>` est également souvent utilisé dans la documentation pour lister les types d’un élément.

<ResponseField name="response" type="string" required>
  Exemple de champ de réponse
</ResponseField>

```mdx
<ResponseField name="response" type="string" required>
  A response field example
</ResponseField>
```

<div id="props">
  ## Propriétés
</div>

<ResponseField name="name" type="string" required>
  Le nom de la valeur de réponse.
</ResponseField>

<ResponseField name="type" type="string" required>
  Type attendu pour la valeur de réponse - peut être n&#39;importe quelle chaîne.
</ResponseField>

<ResponseField name="default" type="string">
  La valeur par défaut.
</ResponseField>

<ResponseField name="required" type="boolean">
  Affiche &quot;required&quot; à côté du nom du champ.
</ResponseField>

<ResponseField name="deprecated" type="boolean">
  Indique si un champ est obsolète.
</ResponseField>

<ResponseField name="pre" type="string[]">
  Libellés qui apparaissent avant le nom du champ
</ResponseField>

<ResponseField name="post" type="string[]">
  Libellés qui apparaissent après le nom du champ
</ResponseField>
