Utilisez le composant `CodeGroup` pour afficher plusieurs blocs de code dans une interface à onglets, afin de permettre aux utilisateurs de comparer des implémentations dans différents langages de programmation ou de voir d&#39;autres approches pour une même tâche.

<CodeGroup>
  ```javascript helloWorld.js
  console.log("Hello World");
  ```

  ```python hello_world.py
  print('Hello World!')
  ```

  ```java HelloWorld.java
  class HelloWorld {
      public static void main(String[] args) {
          System.out.println("Hello, World!");
      }
  }
  ```
</CodeGroup>

Les groupes de code héritent du style global défini dans votre fichier `docs.json`. Personnalisez votre thème à l’aide de `styling.codeblocks`. Consultez [Paramètres](/fr/organize/settings-appearance#styling) pour découvrir les options de configuration.

Les groupes de code se synchronisent automatiquement avec les autres groupes de code et les [onglets](/fr/components/tabs) de la même page lorsque leurs libellés correspondent. Lorsque vous sélectionnez un langage dans un groupe de code, tous les onglets et groupes de code portant le même libellé se mettent à jour pour afficher ce langage.

<div id="create-code-groups">
  ## Créer des groupes de code
</div>

Pour créer un groupe de code, entourez plusieurs blocs de code avec les balises `<CodeGroup>`. Chaque bloc de code doit inclure un titre, qui sert de libellé d’onglet.

````mdx
<CodeGroup>

```javascript helloWorld.js
console.log("Hello World");
```

```python hello_world.py
print('Hello World!')
```

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

</CodeGroup>
````

<div id="language-dropdown">
  ## Menu déroulant de langue
</div>

Vous pouvez remplacer les onglets d’un groupe de code par un menu déroulant pour passer d’une langue à l’autre à l’aide de la prop `dropdown`.

<CodeGroup dropdown>


  ```java HelloWorld.java

          System.out.println("Hello, World!");
      }
  }
  ```
</CodeGroup>
