Les composants `<RequestExample>` et `<ResponseExample>` affichent des blocs de code dans la barre latérale droite pour créer une mise en page à deux colonnes qui garde les exemples visibles pendant que les utilisateurs font défiler le contenu. Utilisez ces composants pour la documentation API, mais ils fonctionnent sur toutes les pages.

Cas d’utilisation courants :

* Documentation de points de terminaison API avec des exemples de requête et de réponse
* Exemples de configuration accompagnés de texte explicatif
* Exemples de code auxquels les utilisateurs se reportent pendant qu’ils suivent les instructions
* Exemples avant/après dans les tutoriels

Sur mobile, les composants `<RequestExample>` et `<ResponseExample>` s’affichent comme des blocs de code classiques que les utilisateurs peuvent faire défiler.

<RequestExample>
  ```bash Requête
  curl --request POST \
    --url https://dog-api.kinduff.com/api/facts
  ```
</RequestExample>

<ResponseExample>
  ```json Réponse
  { "status": "success" }
  ```
</ResponseExample>

<div id="requestexample">
  ## RequestExample
</div>

Utilisez `<RequestExample>` pour épingler des exemples de code dans la barre latérale droite. Ce composant fonctionne comme le composant [CodeGroup](/fr/components/code-groups), mais affiche le code dans la barre latérale plutôt que dans le contenu.

Vous pouvez inclure plusieurs blocs de code dans un seul `<RequestExample>`. Chaque bloc de code doit avoir un attribut title.

````mdx RequestExample
<RequestExample>

```bash requête
curl --request POST \
  --url https://dog-api.kinduff.com/api/facts
```

</RequestExample>
````

<div id="responseexample">
  ## ResponseExample
</div>

Le composant `<ResponseExample>` fixe des exemples de code dans la barre latérale droite, sous le contenu `<RequestExample>` de la même page.

````mdx ResponseExample
<ResponseExample>

```json réponse
{ "status": "success" }
```

</ResponseExample>
````

<div id="properties">
  ## Propriétés
</div>

`<RequestExample>` et `<ResponseExample>` acceptent toutes deux les propriétés suivantes :

<ResponseField name="dropdown" type="boolean">
  Affiche un menu déroulant de langues pour passer d’un bloc de code à l’autre, au lieu de la disposition par défaut en onglets.
</ResponseField>
