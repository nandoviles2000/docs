Utilisez des onglets pour organiser le contenu en plusieurs panneaux entre lesquels les utilisateurs peuvent basculer. Vous pouvez ajouter autant d’onglets que nécessaire et inclure d’autres composants dans chaque onglet.

<Tabs>
  <Tab title="Premier onglet">
    ☝️ Bienvenue dans le contenu visible uniquement dans le premier onglet.

    Vous pouvez ajouter autant de composants que nécessaire dans les onglets. Par exemple, un bloc de code :

    ```java HelloWorld.java
      class HelloWorld {
          public static void main(String[] args) {
              System.out.println("Hello, World!");
          }
      }
    ```
  </Tab>

  <Tab title="Deuxième onglet" icon="leaf">
    ✌️ Voici le contenu visible uniquement dans le deuxième onglet.

    Celui-ci comporte une icône <Icon icon="leaf" /> !
  </Tab>

  <Tab title="Troisième onglet">
    💪 Voici le contenu visible uniquement dans le troisième onglet.
  </Tab>
</Tabs>

````mdx Tabs example
<Tabs>
  <Tab title="First tab">
    ☝️ Welcome to the content that you can only see inside the first tab.

    You can add any number of components inside of tabs. For example, a code block:
    ```java HelloWorld.java
      class HelloWorld {
          public static void main(String[] args) {
              System.out.println("Hello, World!");
          }
      }
    ```
  </Tab>
  <Tab title="Second tab" icon="leaf">
    ✌️ Here's content that's only inside the second tab.

    This one has a <Icon icon="leaf" /> icon!
  </Tab>
  <Tab title="Third tab">
    💪 Here's content that's only inside the third tab.
  </Tab>
</Tabs>
````

Les onglets dont les titres correspondent restent synchronisés sur toute la page. Par exemple, si vous avez plusieurs groupes d’onglets avec un onglet intitulé `JavaScript`, sélectionner `JavaScript` dans l’un d’eux le sélectionne automatiquement dans les autres. Cela permet aux utilisateurs qui choisissent une langue ou un framework une seule fois de retrouver ce choix partout. Les onglets se synchronisent également avec les [groupes de code](/fr/components/code-groups) dont les titres correspondent.

Pour désactiver la synchronisation des onglets, ajoutez `sync={false}` à un composant `<Tabs>`.

```mdx Disable tab sync example
<Tabs sync={false}>
  <Tab title="First tab">
    This tab group operates independently.
  </Tab>
  <Tab title="Second tab">
    Selecting tabs here won't affect other tab groups.
  </Tab>
</Tabs>
```

<div id="tabs-properties">
  ## Propriétés de Tabs
</div>

Définissez ces propriétés sur le composant conteneur `<Tabs>`.

<ResponseField name="defaultTabIndex" type="number" default="0">
  L’index de l’onglet à afficher par défaut (à partir de zéro). Par exemple, définissez-le sur `1` pour afficher le deuxième onglet au chargement de la page.
</ResponseField>

<ResponseField name="sync" type="boolean" default="true">
  Lorsque `true`, les onglets se synchronisent avec les autres onglets et groupes de code de la page dont les titres correspondent. Définissez `false` pour rendre les onglets indépendants.
</ResponseField>

<ResponseField name="borderBottom" type="boolean">
  Ajoute une bordure inférieure et un espacement interne au conteneur d’onglets. Utile pour séparer visuellement le contenu des onglets du reste de la page, en particulier lorsque les onglets contiennent du contenu de longueurs différentes.
</ResponseField>

<div id="tab-properties">
  ## Propriétés d’un onglet
</div>

Définissez ces propriétés sur chaque composant `<Tab>`.

<ResponseField name="title" type="string" required>
  Le titre de l’onglet. Les titres courts sont plus faciles à parcourir. Les onglets dont les titres correspondent synchronisent leur sélection.
</ResponseField>

<ResponseField name="id" type="string">
  ID personnalisé de l’onglet utilisé pour les liens d’ancrage. S’il n’est pas fourni, la valeur de `title` est utilisée par défaut.
</ResponseField>

<ResponseField name="icon" type="string">
  Une icône [Font Awesome](https://fontawesome.com/icons), une icône [Lucide](https://lucide.dev/icons), une URL d’icône ou un chemin relatif vers une icône.
</ResponseField>

<ResponseField name="iconType" type="string">
  Pour les icônes Font Awesome uniquement : `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ResponseField>
