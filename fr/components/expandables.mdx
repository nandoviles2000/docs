title: "Expandables"
description: "Utilisez le composant Expandable pour afficher ou masquer les propriétés d’objet imbriquées dans la documentation d’API, en affichant les champs enfants pour les objets de requête et de réponse."
keywords: ["expandables", "propriétés imbriquées", "champs extensibles", "afficher/masquer le contenu"]
---

Utilisez les Expandables pour afficher ou masquer du contenu imbriqué dans les champs de réponse. Ils sont particulièrement utiles pour présenter des propriétés d’objet complexes dans la documentation d’API.

<ResponseField name="user" type="Objet User">
  <Expandable title="propriétés">
    <ResponseField name="full_name" type="string">
      Le nom complet de l’utilisateur
    </ResponseField>

    <ResponseField name="is_over_21" type="boolean">
      Indique si l’utilisateur a plus de 21 ans
    </ResponseField>
  </Expandable>
</ResponseField>

```mdx Expandable example
<ResponseField name="user" type="User Object">
  <Expandable title="properties">
    <ResponseField name="full_name" type="string">
      The full name of the user
    </ResponseField>

    <ResponseField name="is_over_21" type="boolean">
      Whether the user is over 21 years old
    </ResponseField>
  </Expandable>
</ResponseField>
```

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="title" type="string">
  Le nom de l’objet affiché.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Définissez cette propriété sur `true` pour que l’Expandable s’ouvre au chargement de la page.
</ResponseField>
