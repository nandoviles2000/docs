Les Accordions permettent aux utilisateurs d’ouvrir et de refermer des sections de contenu. Utilisez-les pour révéler progressivement les informations et les organiser.

Lorsque vous ouvrez un Accordion, le fragment d’URL est mis à jour, ce qui vous permet de partager des liens directs vers des sections spécifiques de l’Accordion.

<div id="single-accordion">
  ## Accordion simple
</div>

<Accordion title="Je suis un Accordion.">
  Vous pouvez y mettre n’importe quel contenu, y compris d’autres composants, comme du code :

  ```java HelloWorld.java
   class HelloWorld {
       public static void main(String[] args) {
           System.out.println("Hello, World!");
       }
   }
  ```
</Accordion>

<div id="accordion-groups">
  ## Groupes d’Accordions
</div>

Regroupez les Accordions associés à l’aide de `<AccordionGroup>`. Cela crée une section cohérente d’Accordions que vous pouvez développer ou réduire individuellement.

<AccordionGroup>
  <Accordion title="Prise en main">
    Vous pouvez placer d’autres composants dans des Accordions.

    ```java HelloWorld.java
    class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="Fonctionnalités avancées" icon="bot">
    Ajoutez des icônes pour rendre les Accordions plus faciles à distinguer visuellement et à parcourir.
  </Accordion>

  <Accordion title="Dépannage">
    Organisez le contenu associé en groupes.
  </Accordion>
</AccordionGroup>

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="title" type="string" required>
  Titre dans l’aperçu de l’Accordion.
</ResponseField>

<ResponseField name="description" type="string">
  Détail affiché sous le titre dans l’aperçu de l’Accordion.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Indique si l’Accordion est ouvert par défaut.
</ResponseField>

<ResponseField name="id" type="string">
  ID personnalisé de l’Accordion, utilisé pour les liens d’ancrage. S’il n’est pas renseigné, la valeur de `title` est utilisée par défaut.
</ResponseField>
