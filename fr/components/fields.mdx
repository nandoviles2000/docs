Utilisez les champs pour documenter les paramètres et les réponses de l’API. Il existe deux types de champs : les champs de paramètres et les champs de réponse.

<div id="parameter-field">
  ## Champ de paramètre
</div>

Utilisez le composant `<ParamField>` pour définir les paramètres de vos API ou SDK. L&#39;ajout d&#39;un `ParamField` crée automatiquement un [bac à sable API](/fr/api-playground/overview).

<ParamField path="param" type="string" required>
  Un exemple de champ de paramètre
</ParamField>

```mdx
<ParamField path="param" type="string" required>
  An example of a parameter field
</ParamField>
```

<div id="properties">
  ### Propriétés
</div>

<ParamField body="query, path, body, or header" type="string">
  Indique si le paramètre correspond à un `query`, `path`, `body` ou `header`. Il est suivi du
  nom du paramètre.
</ParamField>

<ParamField body="type" type="string">
  Type attendu pour la valeur du paramètre.

  Prend en charge `number`, `string`, `boolean`, `object`.

  Définissez les tableaux avec le suffixe `[]`. Par exemple, `string[]`.
</ParamField>

<ParamField body="required" type="boolean">
  Indique si le paramètre est requis.
</ParamField>

<ParamField body="deprecated" type="boolean">
  Indique si le paramètre est déprécié.
</ParamField>

<ParamField body="default" type="any">
  Valeur par défaut utilisée lorsque la valeur de la requête est vide
</ParamField>

<ParamField body="placeholder" type="string">
  Texte d’espace réservé du champ de saisie dans le playground.
</ParamField>

<ParamField body="children" type="string">
  Description du paramètre (compatible Markdown).
</ParamField>

<div id="response-field">
  ## Champ de réponse
</div>

Le composant `<ResponseField>` définit les valeurs renvoyées par une API.

<ResponseField name="response" type="string" required>
  Un exemple de champ de réponse
</ResponseField>

```mdx
<ResponseField name="response" type="string" required>
  A response field example
</ResponseField>
```

<div id="properties">
  ### Propriétés
</div>

<ResponseField name="name" type="string" required>
  Le nom de la valeur de réponse.
</ResponseField>

<ResponseField name="type" type="string" required>
  Type attendu de la valeur de réponse. Il peut s’agir de n’importe quelle chaîne de caractères.
</ResponseField>

<ResponseField name="default" type="string">
  La valeur par défaut.
</ResponseField>

<ResponseField name="required" type="boolean">
  Indique si la réponse est obligatoire.
</ResponseField>

<ResponseField name="deprecated" type="boolean">
  Indique si un champ est déprécié.
</ResponseField>

<ResponseField name="pre" type="string[]">
  Libellés qui apparaissent avant le nom du champ.
</ResponseField>

<ResponseField name="post" type="string[]">
  Libellés qui apparaissent après le nom du champ.
</ResponseField>
