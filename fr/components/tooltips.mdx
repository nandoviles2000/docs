---
title: "Infobulles"
description: "Ajoutez des infobulles pour afficher des définitions et des explications contextuelles lorsque les utilisateurs survolent des termes, des abréviations ou des concepts techniques dans votre documentation."
keywords: ["infobulles", "aide contextuelle", "informations contextuelles", "explicatives", "définitions"]
---

Utilisez des infobulles pour fournir des explications ou définitions supplémentaires lorsqu’un utilisateur survole un texte. Les infobulles peuvent inclure des liens d’appel à l’action facultatifs.

**Exemple** : la documentation <Tooltip headline="API" tip="Interface de programmation d’applications : un ensemble de protocoles permettant à des applications logicielles de communiquer." cta="Lire notre guide de l’API" href="/fr/api-reference">API</Tooltip> aide les développeurs à comprendre comment intégrer votre service.

```mdx Tooltip example wrap
<Tooltip headline="API" tip="Application Programming Interface: a set of protocols for software applications to communicate." cta="Read our API guide" href="/api-reference">API</Tooltip> documentation helps developers understand how to integrate with your service.
```

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="tip" type="string" required>
  Le texte affiché dans l’infobulle.
</ResponseField>

<ResponseField name="headline" type="string">
  Texte affiché avant le texte de `tip`.
</ResponseField>

<ResponseField name="cta" type="string">
  Le texte d’appel à l’action d’un lien dans l’infobulle.
</ResponseField>

<ResponseField name="href" type="string">
  URL du lien d’appel à l’action. Obligatoire lorsque vous utilisez `cta`.
</ResponseField>
