Utilisez le composant `View` pour créer du contenu qui change en fonction de la vue sélectionnée dans une liste déroulante à vues multiples. Cela est particulièrement utile pour afficher des exemples de code ou de la documentation propres à différents langages de programmation ou frameworks.

<Tip>
  Utilisez un composant `View` par langage sur chaque page. Utilisez des [onglets](/fr/components/tabs) pour les procédures qui varient selon le langage, et des [groupes de code](/fr/components/code-groups) pour les exemples de code qui varient selon le langage.
</Tip>

<View title="JavaScript" icon="js">
  Ce contenu n’est visible que lorsque JavaScript est sélectionné.

  ```javascript
  console.log("Hello from JavaScript!");
  ```
</View>

<View title="Python" icon="python">
  Ce contenu n’est visible que lorsque Python est sélectionné.

  ```python
  print("Hello from Python!")
  ```
</View>

<div id="table-of-contents-behavior">
  ## Comportement de la table des matières
</div>

La table des matières se met automatiquement à jour pour n’afficher que les titres correspondant à la vue actuellement sélectionnée. Lorsque vous passez d’une vue à l’autre à l’aide de la liste déroulante à vues multiples, la table des matières s’actualise pour afficher les titres pertinents pour cette vue.

Si la structure des titres diffère d’une vue à l’autre, les utilisateurs ne voient que les titres pertinents pour la langue ou le framework sélectionné.

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="title" type="string" required>
  Le titre qui identifie cette vue. Il doit correspondre à l’une des options du menu déroulant à vues multiples.
</ResponseField>

<ResponseField name="icon" type="string">
  Une icône [Font Awesome](https://fontawesome.com/icons), une icône [Lucide](https://lucide.dev/icons), l’URL d’une icône ou le chemin relatif vers une icône.
</ResponseField>

<ResponseField name="iconType" type="string">
  Pour les icônes Font Awesome uniquement : `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone` ou `brands`.
</ResponseField>
