---
title: "Panel"
description: "Personnalisez le contenu du panneau latéral droit des pages de documentation pour afficher des informations complémentaires, des exemples ou des éléments de navigation."
keywords: ["barre latérale"]
---

Vous pouvez utiliser le composant `<Panel>` pour personnaliser le panneau latéral droit d’une page avec les composants de votre choix.

Si une page contient un composant `<Panel>`, tous les composants [RequestExample](/fr/components/examples#requestexample) et [ResponseExample](/fr/components/examples#responseexample) doivent se trouver dans `<Panel>`.

Les composants d’un `<Panel>` remplacent la table des matières de la page.

```mdx
<Panel>
  <Info>Épinglez des informations dans le panneau latéral. Ou ajoutez n'importe quel autre composant.</Info>
</Panel>
```
