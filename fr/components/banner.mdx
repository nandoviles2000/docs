title: "Bannière"
description: "Ajoutez une bannière que les utilisateurs peuvent fermer en haut de votre site de documentation pour afficher des annonces importantes, des notes de version ou des notifications."
keywords: ["bannière", "annonces", "à l’échelle du site"]
---

Utilisez des bannières pour afficher des annonces, des mises à jour ou des notifications importantes sur l’ensemble de votre site de documentation. Elles apparaissent en haut de chaque page, prennent en charge la mise en forme Markdown et peuvent être fermées. Les bannières utilisent la couleur définie par la propriété `colors.dark` dans votre `docs.json`.

Pour ajouter une bannière, utilisez la propriété `banner` dans votre `docs.json` :

<CodeGroup>
  ```json Annonces produit wrap
  "banner": {
    "content": "🚀 La version 2.0 est maintenant disponible ! Consultez notre [journal des modifications](/changelog) pour en savoir plus.",
    "dismissible": true 
  }
  ```

  ```json Avis de maintenance wrap
  "banner": {
    "content": "⚠️ Maintenance planifiée : l’API sera indisponible le 15 décembre, de 2 h à 4 h UTC",
    "dismissible": false
  }
  ```

  ```json Actions requises wrap
  "banner": {
    "content": "**Action requise :** Migrez vers notre nouvelle version avant le 1er janvier. [Guide de migration](/migration)",
    "dismissible": true
  }
  ```
</CodeGroup>

<Note>
  Vous pouvez également configurer des bannières spécifiques à la langue en définissant `banner` dans `navigation.languages`. Consultez [Bannières spécifiques à la langue](#language-specific-banners).
</Note>

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="content" type="string" required>
  Le texte affiché dans la bannière. Prend en charge la mise en forme MDX de base, y compris les liens, le gras et l’italique. Les composants personnalisés ne sont pas pris en charge.
</ResponseField>

<ResponseField name="dismissible" type="boolean">
  Indique si les utilisateurs peuvent fermer la bannière. Lorsque `true`, un bouton de fermeture s’affiche. Si un utilisateur ferme la bannière, elle reste masquée pour lui jusqu’à ce que vous mettiez à jour son contenu. La valeur par défaut est `false`.
</ResponseField>

<div id="language-specific-banners">
  ## Bannières spécifiques à la langue
</div>

Configurez un contenu de bannière différent pour chaque langue de votre documentation. Définissez des bannières spécifiques à la langue dans le tableau `navigation.languages` de votre `docs.json`.

```json
{
  "navigation": {
    "languages": [
      {
        "language": "en",
        "banner": {
          "content": "🚀 Version 2.0 is now live! See our [changelog](/en/changelog) for details.",
          "dismissible": true
        },
        "groups": [
          {
            "group": "Getting started",
            "pages": ["en/overview", "en/quickstart"]
          }
        ]
      },
      {
        "language": "es",
        "banner": {
          "content": "🚀 ¡La versión 2.0 ya está disponible! Consulta nuestro [registro de cambios](/es/changelog) para más detalles.",
          "dismissible": true
        },
        "groups": [
          {
            "group": "Getting started",
            "pages": ["es/overview", "es/quickstart"]
          }
        ]
      }
    ]
  },
  "banner": {
    "content": "🚀 Version 2.0 is now live!",
    "dismissible": true
  }
}
```

<div id="fallback-behavior">
  ### Comportement de repli
</div>

Les bannières suivent un ordre de priorité pour déterminer le contenu à afficher :

1. **Bannière spécifique à la langue** : si la langue actuelle dispose d’une configuration `banner`, celle-ci est prioritaire.
2. **Bannière globale** : s’il n’existe pas de bannière spécifique à la langue, la `banner` globale est affichée.
