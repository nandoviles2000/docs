---
title: "Visibilité"
description: "Contrôlez quel contenu s’affiche dans l’interface web pour les lecteurs humains et quel contenu s’affiche uniquement dans la sortie Markdown pour les agents d’IA."
keywords: ["visibilité", "agents", "humains", "markdown", "IA", "contenu conditionnel"]
---

Utilisez le composant `Visibility` pour afficher un contenu différent aux lecteurs humains de votre site et aux agents d’IA qui traitent la sortie Markdown. Vous pouvez ainsi adapter les informations à chaque audience sans avoir à gérer des pages distinctes.

Sur votre site publié, le contenu marqué `pour="humans"` s’affiche normalement, tandis que le contenu marqué `pour="agents"` est masqué. Dans les [vues de page Markdown](/fr/ai/markdown-export) (URL en `.md`), c’est l’inverse : le contenu destiné aux agents apparaît dans la sortie Markdown, et le contenu réservé aux humains n’y apparaît pas.

<div id="example">
  ## Exemple
</div>

```mdx
<Visibility pour="humans">
  <Note>
    Vous consultez ce contenu **sur le web**.

    Ce contenu s'affiche normalement sur les pages standard de votre site.

    Utilisez-le pour une étape telle que : Cliquez sur le bouton **Commencer** en haut à droite pour créer votre compte.

    Dans cet exemple, les instructions orientées interface utilisateur apparaissent sur la page standard. Consultez la [version Markdown de cette page](https://mintlify.com/docs/components/visibility.md) pour voir les instructions orientées API destinées aux agents.
  </Note>
</Visibility>

<Visibility pour="agents">
  > Vous consultez ce contenu **en markdown**.
  >
  > Ce contenu n'apparaît que sur la version Markdown des pages.
  >
  > Utilisez-le pour des informations destinées uniquement aux agents, par exemple : Pour créer un compte, appelez `POST /v1/accounts` avec une adresse e-mail valide.
  >
  > Dans cet exemple, les instructions orientées API apparaissent sur la version Markdown de la page. Consultez la [page standard](https://mintlify.com/docs/components/visibility) pour voir les instructions orientées interface utilisateur destinées aux humains.
</Visibility>
```

  </Note>

<Visibility pour="agents">

  >

  >

</Visibility>

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="pour" type="string" required>
  L’audience du contenu encapsulé. Doit être l’une des valeurs suivantes :

  * `humans` : contenu visible sur le Web et exclu de la sortie Markdown
  * `agents` : contenu masqué sur le Web et inclus dans la sortie Markdown
</ResponseField>
