Utilisez le composant `Update` pour afficher les entrées du journal des modifications, les mises à jour de version et les notes de version avec une mise en forme cohérente.

<Update label="Exemple" description="v0.1.1">
  ## Exemple de mise à jour

  Vous pouvez ajouter n’importe quoi ici, comme une capture d’écran, un extrait de code ou une liste de modifications.

  <Frame>
    <img className="block" src="https://mintlify-assets.b-cdn.net/hero-light.png" alt="Capture d’écran de la page d’introduction de PearsDB, comme exemple d’image dans un composant Update." />
  </Frame>

  ### Fonctionnalités

  * Design responsive
  * Une ancre pour chaque mise à jour
  * Une entrée de flux RSS générée pour chaque mise à jour
</Update>

<div id="how-to-use">
  ## Utilisation
</div>

```mdx Update example
<Update label="2024-10-11" description="v0.1.0" tags={["Mintlify"]}>
  This is an update with a label, description, and tag.
</Update>
```

Utilisez plusieurs composants `Update` pour créer des [journaux de modifications](/fr/create/changelogs).

Les composants `Update` génèrent automatiquement des entrées de flux RSS. Ces entrées contiennent uniquement du Markdown brut -- les composants, les blocs de code, le code en ligne et les éléments HTML bruts ne sont pas inclus.

Si votre mise à jour contient des composants ou du HTML, utilisez la prop `rss` pour fournir un texte de remplacement aux abonnés RSS.

```mdx Custom RSS content
<Update
  label="March 2025"
  description="v2.0.0"
  rss={{
    title: "March 2025 - Major redesign",
    description: "Complete UI overhaul with new components"
  }}
>
  ## New dashboard

  <Frame>
    <img src="/dashboard.png" alt="New dashboard UI displaying updated components." />
  </Frame>

  Check out our redesigned dashboard with improved navigation.
</Update>
```

<div id="props">
  ## Propriétés
</div>

<ResponseField name="label" type="string" required>
  Libellé de la mise à jour. Apparaît à gauche de la mise à jour et crée un lien d’ancrage. Les libellés doivent être uniques.
</ResponseField>

<ResponseField name="tags" type="string[]">
  Tags de la mise à jour. S’affichent comme filtres dans le panneau latéral droit.
</ResponseField>

<ResponseField name="description" type="string">
  Description de la mise à jour. Apparaît sous le libellé et le tag.
</ResponseField>

<ResponseField name="rss" type="object">
  Les composants Update génèrent automatiquement des entrées de flux RSS. Utilisez la propriété `rss` pour créer une seule entrée de flux RSS avec un titre et une description personnalisés.

  Si elle n’est pas renseignée :

  * Les mises à jour avec des titres Markdown créent une entrée de flux RSS distincte pour chaque titre.
  * Les mises à jour sans titre Markdown créent une seule entrée de flux RSS en utilisant le `label` comme titre.

  <Expandable title="propriétés">
    <ResponseField name="title" type="string">
      Titre personnalisé pour l’entrée du flux RSS.
    </ResponseField>

    <ResponseField name="description" type="string">
      Description personnalisée pour l’entrée du flux RSS.
    </ResponseField>
  </Expandable>
</ResponseField>
