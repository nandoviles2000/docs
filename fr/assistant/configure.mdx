Configurez l’assistant et gérez la facturation depuis la page [Assistant](https://dashboard.mintlify.com/products/assistant) de votre tableau de bord.

<div id="enable-or-disable-the-assistant">
  ## Activer ou désactiver l’assistant
</div>

Utilisez le bouton de bascule de l’assistant pour l’activer ou le désactiver sur votre site de documentation.

<div id="set-deflection-email">
  ## Définir l’adresse e-mail de redirection
</div>

Dans la section Response Handling, activez l’option permettant à l’assistant de rediriger les questions sans réponse vers votre équipe de support.

Indiquez une adresse e-mail que l’assistant pourra communiquer aux utilisateurs s’il ne peut pas répondre à leur question. Vous pouvez également activer l’affichage d’un bouton « Contacter le support » dans le panneau de chat de l’assistant.

<div id="search-domains">
  ## Domaines de recherche
</div>

Dans la section Response Handling, configurez les domaines que l’assistant peut utiliser pour effectuer des recherches sur le web afin d’obtenir davantage de contexte lorsqu’il répond aux questions.

* Les domaines doivent être accessibles publiquement.
* Les domaines dont le chargement nécessite JavaScript ne sont pas pris en charge.

<Frame>
  <img src="/images/assistant/search-domains-light.png" alt="Le panneau des domaines de recherche de l’assistant est activé dans le tableau de bord. L’assistant est configuré pour rechercher dans le domaine mintlify.com/pricing." className="block dark:hidden" />

  <img src="/images/assistant/search-domains-dark.png" alt="Le panneau des domaines de recherche de l’assistant est activé dans le tableau de bord. L’assistant est configuré pour rechercher dans le domaine mintlify.com/pricing." className="hidden dark:block" />
</Frame>

Pour contrôler plus précisément ce que l’assistant peut rechercher, utilisez une syntaxe de filtrage.

* **Filtrage au niveau du domaine**
  * `example.com` : recherchez uniquement dans le domaine `example.com`
  * `docs.example.com` : recherchez uniquement dans le sous-domaine `docs.example.com`
  * `*.example.com` : recherchez dans tous les sous-domaines de `example.com`
* **Filtrage au niveau du chemin**
  * `docs.example.com/api` : recherchez dans toutes les pages du sous-chemin `/api`
* **Plusieurs motifs**
  * Ajoutez plusieurs entrées pour cibler différentes sections de sites

<div id="add-sample-questions">
  ## Ajouter des questions types
</div>

Aidez vos utilisateurs à engager la conversation avec l’assistant en ajoutant des questions de départ.

L’assistant peut générer des questions propres à chaque page en fonction de celle que l’utilisateur consulte, ou vous pouvez ajouter des questions permanentes disponibles sur toutes les pages.

Vous pouvez ajouter jusqu’à trois questions de départ. Cliquez sur **Ask AI** pour obtenir des questions recommandées en fonction de votre documentation.

<div id="bot-protection">
  ## Protection contre les bots
</div>

Dans la section Bot Protection, activez le captcha invisible pour protéger votre assistant contre les abus automatisés. Cette protection contre les bots respecte la vie privée et est invisible pour la quasi-totalité des visiteurs.

Pour activer la protection contre les bots :

1. Accédez à la page des [paramètres de l’Assistant](https://dashboard.mintlify.com/products/assistant/settings) dans votre tableau de bord.
2. Dans la section **Bot Protection**, activez l’option **Invisible Captcha**.

Les modifications peuvent prendre jusqu’à 10 minutes à se propager.

<Note>
  Si vous utilisez des [en-têtes de politique de sécurité du contenu personnalisés](/fr/deploy/csp-configuration), vous devez inclure `hcaptcha.com` et `*.hcaptcha.com` dans votre liste d’autorisations.
</Note>

<div id="manage-billing">
  ## Gérer la facturation
</div>

L’assistant fonctionne avec des quotas de messages par palier. Un message correspond à toute interaction d’un utilisateur avec l’assistant qui reçoit une réponse valide. Si vous avez des messages inutilisés, jusqu’à la moitié de votre quota peut être reportée sur le cycle de facturation suivant. Par exemple, si vous disposez d’un quota de 1 000 messages et que vous en utilisez 300, 500 messages sont reportés sur le cycle de facturation suivant, ce qui vous donne un total de 1 500 messages pour ce cycle.

Par défaut, l’assistant autorise les dépassements. Vous pouvez les désactiver pour éviter des frais supplémentaires liés à une utilisation au-delà de votre palier. Si vous atteignez votre quota de messages alors que les dépassements sont désactivés, l’assistant devient indisponible jusqu’à la réinitialisation de votre quota. Si vous autorisez les dépassements, chaque message au-delà de votre quota entraîne des frais de dépassement. Toutefois, selon votre utilisation, des dépassements occasionnels peuvent coûter moins cher que de passer à un palier supérieur.

<div id="change-your-assistant-tier">
  ### Modifier le palier de votre assistant
</div>

Les paliers d’assistant déterminent votre quota mensuel de messages et votre tarification.

Consultez et modifiez votre palier actuel dans l’[onglet Facturation](https://dashboard.mintlify.com/products/assistant?tab=billing) de la page de l’assistant dans votre tableau de bord.

Dans la section **Contrôle des dépenses**, sélectionnez le palier souhaité dans le menu déroulant.

**Passer à un palier supérieur :**

* Votre nouveau quota de messages est disponible immédiatement.
* Vous payez la différence au prorata pour le cycle de facturation en cours.

**Passer à un palier inférieur :**

* Votre quota de messages est mis à jour immédiatement.
* Les changements tarifaires prennent effet au début de votre prochain cycle de facturation.
* Les messages non utilisés de votre palier actuel **ne sont pas** reportés.

<div id="allow-overages">
  ### Autoriser les dépassements
</div>

Si vous ne souhaitez pas autoriser les dépassements, désactivez-les dans la section **Contrôles de facturation** de l’[onglet Facturation](https://dashboard.mintlify.com/products/assistant?tab=billing) de la page de l’assistant dans votre tableau de bord.

<div id="set-usage-alerts">
  ### Définir des alertes de consommation
</div>

Dans la section Contrôle de facturation, définissez des alertes de consommation pour recevoir un e-mail lorsque vous atteignez un certain pourcentage de votre quota de messages.
