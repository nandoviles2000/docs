Les utilisateurs disposent de plusieurs façons de démarrer une conversation avec l’assistant. Chaque méthode ouvre un panneau de discussion sur le côté droit de votre documentation. Les utilisateurs peuvent poser n’importe quelle question, et l’assistant recherche une réponse dans votre documentation. Si l’assistant ne trouve pas d’informations pertinentes, il indique qu’il ne peut pas répondre à la question.

<div id="use-the-assistant-in-local-preview">
  ## Utiliser l’assistant dans l’aperçu local
</div>

L’assistant est disponible dans votre aperçu local lorsque vous vous connectez via la CLI. Cela vous permet de tester le comportement de l’assistant, les instructions personnalisées dans `Assistant.md` et ses réponses pendant que vous développez votre documentation en local.

1. Si ce n’est pas déjà fait, installez la CLI avec `npm i -g mint`.
2. Exécutez `mint login` pour vous authentifier.
3. Exécutez `mint dev` pour démarrer l’aperçu local.

L’assistant dans l’aperçu local utilise le même contenu indexé que votre site de documentation déployé.

  ## Emplacement dans l’interface

<div id="keyboard-shortcut">
  ## Raccourci clavier
</div>

Ouvrez le panneau de discussion de l’assistant avec le raccourci clavier <kbd>Command</kbd> + <kbd>I</kbd> sur macOS et <kbd>Ctrl</kbd> + <kbd>I</kbd> sous Windows.

<div id="highlight-text">
  ## Surligner du texte
</div>

Surlignez du texte sur une page, puis cliquez sur le bouton contextuel **Ajouter à l’assistant** pour ouvrir le panneau de discussion de l’assistant et ajouter le texte surligné au contexte. Vous pouvez ajouter plusieurs extraits de texte ou blocs de code au contexte de l’assistant.

<div id="code-blocks">
  ## Blocs de code
</div>

Cliquez sur le bouton **Ask AI** dans un bloc de code pour ouvrir le panneau de discussion de l’assistant et ajouter ce bloc de code au contexte. Vous pouvez ajouter plusieurs blocs de code ou extraits de texte au contexte de l’assistant.

<div id="file-attachments">
  ## Pièces jointes
</div>

Joignez des fichiers aux messages de l’assistant pour fournir un contexte supplémentaire.

Types de fichiers pris en charge :

* **Images** : JPEG, PNG, GIF, WebP, SVG
* **Documents** : PDF
* **Fichiers de code et de texte** : JavaScript (`.js`, `.jsx`, `.mjs`, `.cjs`), TypeScript (`.ts`, `.tsx`), Python, HTML, CSS, Markdown, MDX, JSON, YAML, XML, SQL, CSV, texte brut, scripts shell (`.sh`, `.bash`, `.env`), GraphQL, TOML, Go, Rust, Ruby, Java, Kotlin, Swift, C (`.c`, `.h`), C++ (`.cpp`, `.hpp`), C#, PHP, Lua, R, Scala

Limites :

* Taille maximale du fichier : 5 Mo par pièce jointe
* Nombre maximal de pièces jointes par message : 10

<div id="urls">
  ## URL
</div>

Ouvrez l’assistant à l’aide d’un paramètre de requête dans l’URL pour créer des liens directs vers des informations précises ou partager des conversations de l’assistant avec des questions préremplies.

* **Ouvrir l’assistant** : ajoutez `?assistant=open` pour ouvrir le panneau de discussion de l’assistant au chargement de la page.
  * Exemple : [https://mintlify.com/docs?assistant=open](https://mintlify.com/docs?assistant=open)
* **Ouvrir avec une requête préremplie** : ajoutez `?assistant=YOUR_QUERY` pour ouvrir l’assistant et envoyer automatiquement une question.
  * Exemple : [https://mintlify.com/docs?assistant=explain webhooks](https://mintlify.com/docs?assistant=explain%20webhooks)

<div id="troubleshooting">
  ## Dépannage
</div>

<Accordion title="Barre de discussion de l’assistant non visible">
  Si l’interface de l’assistant n’est pas visible dans certains navigateurs, vous devrez peut-être signaler un faux positif à [EasyList](https://easylist.to). Les navigateurs qui utilisent la liste EasyList Cookies, comme Brave et Comet, bloquent parfois l’assistant ou d’autres éléments de l’interface. Cette liste inclut une règle propre à certains domaines qui masque les éléments fixes afin de bloquer les bannières de cookies. Cette règle affecte par inadvertance des composants d’interface légitimes.

  Signalez un faux positif à [EasyList](https://github.com/easylist/easylist) pour demander la suppression de cette règle. Le problème sera alors résolu pour tous les utilisateurs une fois la liste de filtres mise à jour.
</Accordion>
