<Info>
  Les journaux d’audit sont disponibles sur [Enterprise plans](https://mintlify.com/pricing?ref=audit-logs).
</Info>

Utilisez les journaux d’audit pour surveiller les actions effectuées par les membres de votre organisation. Les journaux d’audit fournissent un historique des activités à des fins de sécurité, de conformité et de dépannage.

* **Surveiller la sécurité** : Suivez les tentatives d’authentification et les modifications des autorisations.
* **Assurer la conformité** : Conservez un historique de toutes les activités de l’organisation.
* **Résoudre les problèmes** : Analysez les actions ayant échoué et leurs causes.
* **Suivre les modifications** : Vérifiez qui a effectué des modifications précises et à quel moment.

<div id="view-audit-logs">
  ## Consulter les journaux d’audit
</div>

Accédez à la page [Audit log](https://dashboard.mintlify.com/settings/organization/audit-logs) de votre tableau de bord pour consulter les journaux d’audit.

Cliquez sur une entrée du journal pour la déplier et afficher des informations détaillées, notamment :

| Champ       | Description                                             |
| ----------- | ------------------------------------------------------- |
| Horodatage  | Date et heure auxquelles l’action a eu lieu             |
| Acteur      | Adresse e-mail de l’utilisateur ayant effectué l’action |
| Action      | Action effectuée par l’utilisateur                      |
| Catégorie   | Type de ressource affectée                              |
| Résultat    | Indique si l’action a réussi ou échoué                  |
| Métadonnées | Contexte supplémentaire sur l’action                    |

<div id="filter-logs">
  ### Filtrer les journaux
</div>

Filtrez les journaux d’audit pour repérer des activités précises.

**Plage de dates** : sélectionnez une plage de dates prédéfinie pour afficher les journaux sur une période donnée.

**Catégorie** : filtrez les journaux selon le type d’action.

| Catégorie                       | Description                                                                                                                                                 |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Organisation                    | Mises à jour des paramètres de l’organisation et demandes de suppression.                                                                                   |
| Membre                          | Invitations de membres de l’équipe, suppressions et changements de rôle.                                                                                    |
| Déploiement                     | Modifications de la configuration du déploiement, y compris les domaines personnalisés, l’authentification, les sources Git et les identifiants client MCP. |
| Déploiement de prévisualisation | Création et mises à jour des déploiements de prévisualisation, ainsi que modifications de l’authentification.                                               |
| Clé API                         | Création et suppression des clés API et des clés API de découverte.                                                                                         |
| Assistant                       | Mises à jour des paramètres d’Assistant, comme l’adresse e-mail de déviation, les sites de recherche sur le Web et les questions initiales.                 |
| Export PDF                      | Génération et suppression des exports PDF.                                                                                                                  |
| Intégration                     | Installations et suppressions de GitHub, Slack, Linear et Notion.                                                                                           |
| Facturation                     | Mises à jour de l’abonnement, achats de modules complémentaires et consultation des factures.                                                               |
| Quota                           | Modifications de la politique de dépassement et de la configuration des alertes.                                                                            |
| Utilisateur                     | Paramètres de notification de chaque utilisateur.                                                                                                           |
| Flux de travail                 | Configurations des flux de travail et gestion du dépôt.                                                                                                     |
| Journal d’audit                 | Consultations et exportations des journaux d’audit.                                                                                                         |
| Auth                            | Tentatives de connexion, déconnexions et créations de session.                                                                                              |

<div id="export-audit-logs">
  ## Exporter les journaux d’audit
</div>

Exportez les journaux d’audit au format CSV à des fins d’analyse, de conformité ou d’archivage à long terme.

1. Accédez à la page [Audit log](https://dashboard.mintlify.com/settings/organization/audit-logs) de votre tableau de bord.
2. Si nécessaire, appliquez des filtres pour affiner les journaux à exporter.
3. Cliquez sur **Export CSV**.
4. Mintlify vous envoie un e-mail contenant un lien de téléchargement lorsque l’export est prêt.
