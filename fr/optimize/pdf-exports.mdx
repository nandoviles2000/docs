<Info>
  Les exportations PDF sont disponibles avec les [offres Enterprise](https://mintlify.com/pricing).
</Info>

Vous pouvez exporter votre documentation en un seul fichier PDF pour la consulter hors ligne. Le PDF contient tout le contenu de la documentation, y compris les images et les liens, ainsi qu’une table des matières interactive.

Les exportations PDF ne sont pas prises en charge pour les sites de documentation qui utilisent l’authentification.

<div id="export-a-pdf">
  ## Exporter un PDF
</div>

1. Accédez à la page [General](https://dashboard.mintlify.com/settings/deployment/general) dans la section Paramètres du projet de votre tableau de bord.
2. Sélectionnez le bouton **Export all content**.
3. Vous pouvez éventuellement personnaliser les options d’exportation :
   * **Page format** : Choisissez le format de page du PDF.
   * **Scale percentage** : Ajustez l’échelle du PDF.
   * **Include footer** : Ajoutez un pied de page avec le numéro de page et le nombre total de pages.
4. Sélectionnez **Export** pour lancer l’exportation.
5. Une fois l’exportation terminée, vous recevrez un e-mail contenant un lien de téléchargement.
6. Cliquez sur le lien de téléchargement pour télécharger le fichier PDF.
