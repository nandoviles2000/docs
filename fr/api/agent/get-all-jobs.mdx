<Warning>Ce point de terminaison est obsolète. Utilisez plutôt le point de terminaison [v2 get agent job](/fr/api/agent/v2/get-agent-job).</Warning>

<div id="usage">
  ## Utilisation
</div>

Ce point de terminaison récupère toutes les tâches d’agent pour le domaine spécifié et fournit une vue d’ensemble de l’ensemble des activités des agents ainsi que de leur statut actuel. Cela est utile pour surveiller et gérer plusieurs tâches d’agent simultanées ou passées.

<div id="response">
  ## Réponse
</div>

Utilisez ce point de terminaison pour obtenir un aperçu complet de toutes les sessions d’agent précédentes.
