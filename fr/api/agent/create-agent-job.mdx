<Warning>Ce point de terminaison est obsolète. Utilisez plutôt le point de terminaison [v2 create agent job](/fr/api/agent/v2/create-agent-job).</Warning>

Ce point de terminaison crée une tâche d’agent à partir des messages et des informations de branche fournis. La tâche s’exécute de manière asynchrone et renvoie une réponse en flux contenant les détails d’exécution et les résultats.

Si une branche n’existe pas, l’agent en crée une. Si les fichiers sont modifiés avec succès, une pull request (PR) est automatiquement créée à la fin de la tâche.

<div id="rate-limits">
  ## Limites de débit
</div>

L’API de l’agent est soumise aux limites suivantes :

* 100 utilisations par projet Mintlify et par heure

<div id="suggested-usage">
  ## Utilisation recommandée
</div>

Pour de meilleurs résultats, utilisez le [hook useChat d’ai-sdk](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#usechat) pour envoyer des requêtes et gérer les réponses.
