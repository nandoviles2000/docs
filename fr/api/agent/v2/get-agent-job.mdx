---
title: "Récupérer une tâche d’agent"
description: "Récupérez l’état et les détails d’une tâche d’agent, y compris son
  avancement et le lien vers la pull request (PR)."
openapi: /fr/admin-openapi.json GET /v2/agent/{projectId}/job/{id}
keywords: [ "tâche d’agent", "état", "récupérer", "détails", "interroger" ]
---

Interrogez ce point de terminaison pour suivre l’avancement d’une tâche d’agent. Le champ `status` passe de `active` à `completed` ou `failed`.

Une fois que l’agent a créé une pull request (PR), le champ `prLink` est renseigné.
