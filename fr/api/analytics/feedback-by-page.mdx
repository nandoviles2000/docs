<div id="usage">
  ## Utilisation
</div>

Utilisez ce point de terminaison pour exporter les retours des utilisateurs, agrégés par chemin de page de la documentation. Chaque entrée indique le nombre total de retours pour une page, ventilé par type.

<div id="filtering">
  ## Filtrage
</div>

Filtrez les retours en fonction de :

* **Plage de dates** : utilisez `dateFrom` et `dateTo` pour limiter les résultats à une période précise
* **Source** : filtrez par type de retour `code_snippet`, `contextual` ou `agent`
* **Statut** : filtrez par valeurs de statut telles que `pending`, `in_progress`, `resolved` ou `dismissed`
