<div id="usage">
  ## Utilisation
</div>

Utilisez ce point de terminaison pour voir comment les requêtes adressées à l’assistant se répartissent entre les différents types d’appelant. La réponse ventile le nombre total de requêtes comme suit :

* **web** : Requêtes provenant du site de documentation
* **api** : Requêtes provenant d’appels API directs
* **other** : Requêtes provenant d’autres sources (par exemple, des intégrations, des SDK)
* **total** : Somme de tous les types de requêtes

<div id="filtering">
  ## Filtrage
</div>

Filtrez par intervalle de dates à l’aide des paramètres `dateFrom` et `dateTo`.
