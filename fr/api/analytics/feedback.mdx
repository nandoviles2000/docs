<div id="usage">
  ## Utilisation
</div>

Utilisez ce point de terminaison pour exporter les retours des utilisateurs recueillis dans votre documentation. Ces retours incluent les retours contextuels issus des évaluations de page, les retours sur les extraits de code et les retours de l’agent.

Parcourez les résultats à l’aide du paramètre `cursor` renvoyé dans la réponse. Continuez à récupérer les résultats tant que `hasMore` est `true`.

<div id="filtering">
  ## Filtrage
</div>

Filtrez les retours selon :

* **Plage de dates** : utilisez `dateFrom` et `dateTo` pour limiter les résultats à une période donnée
* **Source** : filtrez par type de retour `code_snippet`, `contextual` ou `agent`
* **Statut** : filtrez par valeurs de statut comme `pending`, `in_progress`, `resolved` ou `dismissed`

<div id="response-types">
  ## Types de réponse
</div>

La réponse contient différents types de retours selon la source :

* **Retour contextuel** : inclut le booléen `helpful` et l&#39;adresse e-mail `contact` facultative
* **Retour sur l&#39;extrait de code** : inclut les champs `code`, `filename` et `lang`
* **Retour de l&#39;agent** : inclut un `comment` contenant le texte du retour de l&#39;agent et le `path` de la page concernée
