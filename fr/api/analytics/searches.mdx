<div id="usage">
  ## Utilisation
</div>

Utilisez ce point de terminaison pour exporter les données d’analyses de recherche de la documentation. Les résultats sont classés par nombre d’occurrences décroissant, ce qui indique les termes les plus recherchés par vos utilisateurs.

Parcourez les résultats page par page à l’aide du paramètre `nextCursor` renvoyé dans la réponse. Continuez à récupérer les résultats tant que `nextCursor` n’est pas nul.

<div id="filtering">
  ## Filtrage
</div>

Filtrez les données de Recherche par plage de dates à l’aide des paramètres `dateFrom` et `dateTo`.
