L’API REST (Representational State Transfer) de Mintlify vous permet d’interagir avec votre documentation de façon programmatique, de déclencher des mises à jour, d’intégrer des expériences de chat alimentées par l’IA et d’exporter des données d’analyses.

<div id="endpoints">
  ## Points de terminaison
</div>

* [Déclencher une mise à jour](/fr/api/update/trigger): Déclenchez une mise à jour de votre site à la demande.
* [Obtenir le statut d’une mise à jour](/fr/api/update/status): Obtenez le statut d’une mise à jour et d’autres informations sur votre documentation.
* [Déclencher un déploiement de prévisualisation](/fr/api/preview/trigger): Créez ou mettez à jour un déploiement de prévisualisation pour une branche spécifique.
* [Créer un job d’agent](/fr/api/agent/v2/create-agent-job): Créez un job d’agent pour modifier automatiquement votre documentation.
* [Obtenir un job d’agent](/fr/api/agent/v2/get-agent-job): Récupérez les détails et le statut d’un job d’agent spécifique.
* [Envoyer un message de suivi](/fr/api/agent/v2/send-message): Envoyez un message de suivi à un job d’agent existant.
* [Créer un message d’assistant](/fr/api/assistant/create-assistant-message-v2): Intégrez l’Assistant, entraîné sur votre documentation, dans l’application de votre choix.
* [Rechercher dans la documentation](/fr/api/assistant/search): Effectuez une recherche dans votre documentation.
* [Obtenir le contenu d’une page](/fr/api/assistant/get-page-content): Récupérez l’intégralité du contenu textuel d’une page de documentation.
* [Obtenir les retours des utilisateurs](/fr/api/analytics/feedback): Exportez les retours des utilisateurs de votre documentation.
* [Obtenir les retours par page](/fr/api/analytics/feedback-by-page): Exportez le nombre de retours agrégé par page.
* [Obtenir les conversations de l’Assistant](/fr/api/analytics/assistant-conversations): Exportez l’historique des conversations avec l’Assistant IA.
* [Obtenir les statistiques des appelants de l’Assistant](/fr/api/analytics/assistant-caller-stats): Récupérez une ventilation du nombre de requêtes de l’Assistant par type d’appelant.
* [Obtenir les requêtes de recherche](/fr/api/analytics/searches): Exportez les termes de recherche dans la documentation ainsi que les données d’analyse.
* [Obtenir les vues de page](/fr/api/analytics/views): Exportez le nombre de vues du contenu par page et pour l’ensemble du site.
* [Obtenir les visiteurs uniques](/fr/api/analytics/visitors): Exportez le nombre de visiteurs uniques par page et pour l’ensemble du site.

<div id="common-use-cases">
  ### Cas d’utilisation courants
</div>

* **Déploiements automatisés** : Déclenchez des mises à jour du site à intervalles définis ou lors de certains événements avec [Déclencher une mise à jour](/fr/api/update/trigger) et [Obtenir le statut d’une mise à jour](/fr/api/update/status).
* **Intégration CI/CD** : Mettez à jour la documentation dans votre pipeline de déploiement lorsque le code évolue avec [Déclencher une mise à jour](/fr/api/update/trigger).
* **Déploiements de prévisualisation** : Créez ou mettez à jour des déploiements de prévisualisation de façon programmatique dans votre pipeline CI/CD avec [Déclencher un déploiement de prévisualisation](/fr/api/preview/trigger).
* **Intégrations personnalisées** : Intégrez l’assistant IA à votre produit, portail d’assistance ou outils internes avec [Créer un message d’assistant](/fr/api/assistant/create-assistant-message-v2), [Rechercher dans la documentation](/fr/api/assistant/search) et [Obtenir le contenu d’une page](/fr/api/assistant/get-page-content).
* **Édition automatisée** : Utilisez des jobs d’agent pour mettre à jour la documentation de façon programmatique à grande échelle avec [Créer un job d’agent](/fr/api/agent/v2/create-agent-job), [Obtenir un job d’agent](/fr/api/agent/v2/get-agent-job) et [Envoyer un message de suivi](/fr/api/agent/v2/send-message).
* **Export d’analyses** : Exportez les retours, les conversations de l’assistant, les analyses de recherche, les vues de page et les données sur les visiteurs pour une analyse externe avec [Obtenir les retours utilisateurs](/fr/api/analytics/feedback), [Obtenir les retours par page](/fr/api/analytics/feedback-by-page), [Obtenir les conversations de l’assistant](/fr/api/analytics/assistant-conversations), [Obtenir les statistiques des appelants de l’assistant](/fr/api/analytics/assistant-caller-stats), [Obtenir les requêtes de recherche](/fr/api/analytics/searches), [Obtenir les vues de page](/fr/api/analytics/views) et [Obtenir les visiteurs uniques](/fr/api/analytics/visitors).

<div id="authentication">
  ## Authentification
</div>

Générez des clés API sur la [page des clés API](https://dashboard.mintlify.com/settings/organization/api-keys) de votre tableau de bord. Chaque clé API est associée à une organisation : vous pouvez utiliser des clés sur plusieurs déploiements au sein de la même organisation.

Vous pouvez créer jusqu’à 10 clés API par heure et par organisation.

<div id="admin-api-key">
  ### Clé API d’administrateur
</div>

Utilisez la clé API d’administrateur pour authentifier les requêtes vers [Déclencher une mise à jour](/fr/api/update/trigger), [Obtenir le statut d’une mise à jour](/fr/api/update/status), [Déclencher un déploiement de prévisualisation](/fr/api/preview/trigger), [Créer un job d’agent](/fr/api/agent/v2/create-agent-job), [Obtenir un job d’agent](/fr/api/agent/v2/get-agent-job), [Envoyer un message de suivi](/fr/api/agent/v2/send-message), [Obtenir les retours des utilisateurs](/fr/api/analytics/feedback), [Obtenir les retours par page](/fr/api/analytics/feedback-by-page), [Obtenir les conversations de l’assistant](/fr/api/analytics/assistant-conversations), [Obtenir les statistiques des appelants de l’assistant](/fr/api/analytics/assistant-caller-stats), [Obtenir les requêtes de recherche](/fr/api/analytics/searches), [Obtenir les vues de page](/fr/api/analytics/views) et [Obtenir les visiteurs uniques](/fr/api/analytics/visitors).

Les clés API d’administrateur commencent par le préfixe `mint_`.

La clé API d’administrateur est un secret côté serveur. Ne l’exposez pas dans du code côté client.

<div id="assistant-api-key">
  ### Clé API de l’assistant
</div>

Utilisez la clé API de l’assistant pour authentifier les requêtes vers les points de terminaison [Créer un message d’assistant](/fr/api/assistant/create-assistant-message-v2), [Rechercher dans la documentation](/fr/api/assistant/search) et [Obtenir le contenu d’une page](/fr/api/assistant/get-page-content).

Les clés API de l’assistant commencent par le préfixe `mint_dsc_`.

La clé API de l’assistant est un jeton public que vous pouvez utiliser dans votre code front-end.

<Note>
  Les appels effectués avec le jeton API de l’assistant peuvent entraîner des coûts, soit en utilisant vos crédits d’assistant, soit en générant des dépassements.
</Note>
