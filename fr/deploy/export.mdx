Utilisez `mint export` pour regrouper l’intégralité de votre site de documentation dans une archive zip autonome. Les destinataires peuvent la décompresser et consulter la documentation dans leur navigateur sans connexion Internet, sans compte Mintlify ni outil de build : il leur suffit d’avoir [Node.js](https://nodejs.org) installé.

C’est utile lorsque vous devez distribuer de la documentation à des utilisateurs qui ne peuvent pas accéder à votre site en ligne, par exemple des clients avec un déploiement sur site, des environnements isolés ou des revues internes de conformité.

<div id="prerequisites">
  ## Prérequis
</div>

* [CLI](/fr/cli/install) installé et à jour
* [Node.js](https://nodejs.org) v20.17.0+ installé

<div id="export-your-site">
  ## Exportez votre site
</div>

Accédez au répertoire de votre documentation contenant votre fichier `docs.json` et exécutez :

```bash
mint export
```

La CLI génère votre site, parcourt chaque page définie dans votre navigation et regroupe le tout dans un fichier .zip dans votre répertoire courant.

<div id="options">
  ### Options
</div>

| Flag                | Description                                                                                                                                                                                                                                          | Par défaut   |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| `--output <path>`   | Définissez le chemin du fichier ZIP de sortie.                                                                                                                                                                                                       | `export.zip` |
| `--groups <group>`  | Simulez des [groupes d’utilisateurs](/fr/deploy/authentication-setup#control-access-with-groups) pour l’export. Utile lorsque votre documentation utilise un contrôle d’accès par groupe et que vous voulez que l’archive inclue des pages restreintes. | —            |
| `--disable-openapi` | Ignorez la génération des fichiers OpenAPI pendant l’export. Utilisez cette option si vous avez de nombreuses spécifications OpenAPI et souhaitez accélérer les builds.                                                                              | —            |

Par exemple, pour exporter votre site avec un nom de fichier personnalisé et un groupe d’utilisateurs spécifique :

```bash
mint export --output customer-docs.zip --groups enterprise
```

<Note>
  L’export inclut uniquement les pages répertoriées dans votre navigation. Les [pages masquées](/fr/organize/hidden-pages) ne sont pas incluses dans l’archive.
</Note>

<div id="whats-in-the-zip">
  ## Ce que contient le fichier zip
</div>

L’archive exportée contient tout le nécessaire pour consulter votre documentation hors ligne :

| Fichier              | Description                                                   |
| -------------------- | ------------------------------------------------------------- |
| Pages HTML           | Version pré-rendue de chaque page de votre navigation         |
| `_next/static/`      | CSS, JavaScript et autres ressources statiques regroupées     |
| `serve.js`           | Serveur HTTP Node.js sans dépendance pour servir le site      |
| `Start Docs.command` | Lanceur macOS — double-cliquez pour ouvrir la documentation   |
| `Start Docs.bat`     | Lanceur Windows — double-cliquez pour ouvrir la documentation |

<div id="view-the-exported-docs">
  ## Consulter la documentation exportée
</div>

Partagez le fichier ZIP avec toute personne ayant Node.js installé. Pour consulter la documentation :

<Tabs>
  <Tab title="Manuel">
    1. Décompressez l’archive.
    2. Ouvrez un terminal dans le dossier décompressé.
    3. Exécutez `node serve.js`.
    4. Ouvrez `http://localhost:3000` dans votre navigateur.
  </Tab>

  <Tab title="macOS">
    1. Décompressez l’archive.
    2. Double-cliquez sur **Start Docs.command**.
    3. La documentation s’ouvre dans votre navigateur par défaut à l’adresse `http://localhost:3000`.

    <Note>
      macOS peut bloquer le fichier, car il a été téléchargé depuis Internet. Si vous voyez un avertissement de sécurité, accédez à **Réglages Système &gt; Confidentialité et sécurité** et sélectionnez **Ouvrir quand même**. Consultez le [guide d’Apple pour passer outre les réglages de sécurité](https://support.apple.com/guide/mac-help/mh40617/mac) pour en savoir plus.
    </Note>
  </Tab>

  <Tab title="Windows">
    1. Décompressez l’archive.
    2. Double-cliquez sur **Start Docs.bat**.
    3. La documentation s’ouvre dans votre navigateur par défaut à l’adresse `http://localhost:3000`.

    <Note>
      Windows peut afficher un avertissement « Windows a protégé votre PC », car le fichier a été téléchargé depuis Internet. Sélectionnez **More info**, puis **Run anyway**.
    </Note>
  </Tab>
</Tabs>
