Mintlify utilise une GitHub App pour synchroniser automatiquement votre documentation avec votre dépôt GitHub.

<Tip>
  **Avez-vous besoin de la GitHub App ?**

  * **Dépôt hébergé par Mintlify** dans l&#39;organisation `mintlify-community` : non. La GitHub App est déjà configurée.
  * **Votre propre dépôt** : oui. Installez la GitHub App pour activer les déploiements automatiques lorsque vous envoyez des modifications.

  Consultez votre dépôt sur la page [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) de votre tableau de bord.
</Tip>

Si votre dépôt est un dépôt privé appartenant à l&#39;organisation Mintlify, la GitHub App est automatiquement configurée et gérée par Mintlify. Vous pouvez utiliser l&#39;éditeur web pour modifier votre documentation. Si vous souhaitez travailler sur votre documentation en local, clonez le dépôt dans votre propre organisation et mettez à jour vos paramètres Git pour utiliser votre propre dépôt.

<div id="clone-to-your-own-repository">
  ## Cloner vers votre propre dépôt
</div>

Si vous n’avez pas connecté votre propre dépôt Git lors de l’onboarding, votre documentation est hébergée dans un dépôt privé appartenant à l’organisation Mintlify. Pour la transférer vers votre propre compte ou organisation, rendez-vous dans [Paramètres Git](https://dashboard.mintlify.com/settings/deployment/git-settings) depuis votre tableau de bord. Un assistant de configuration vous guide tout au long du processus avec deux options :

<AccordionGroup>
  <Accordion title="Clonage en un clic (recommandé)">
    L’option de clonage crée automatiquement une copie de votre documentation dans votre compte GitHub.

    1. Sélectionnez **GitHub** comme fournisseur et choisissez **Clone**.
    2. Autorisez l’accès via GitHub lorsque vous y êtes invité.
    3. Sélectionnez l’organisation GitHub dans laquelle vous souhaitez créer le dépôt.
    4. Confirmez le clonage. Mintlify copie vos fichiers de documentation dans un nouveau dépôt.
    5. Vous pouvez également installer l’application GitHub de Mintlify pour activer les déploiements automatiques.
  </Accordion>

  <Accordion title="Configuration manuelle">
    <Warning>
      Ce processus supprime définitivement votre contenu du dépôt hébergé par Mintlify.

      Téléchargez votre documentation depuis l’assistant de configuration avant de terminer la configuration manuelle.
    </Warning>

    Si vous préférez configurer votre dépôt manuellement :

    1. Téléchargez votre documentation sous forme de fichier zip afin d’en conserver une sauvegarde.
    2. Sélectionnez **GitHub** comme fournisseur et choisissez **Continue setup**.
    3. Autorisez l’accès via GitHub lorsque vous y êtes invité.
    4. Sélectionnez votre organisation, votre dépôt et votre branche.
    5. Indiquez éventuellement un sous-répertoire si votre documentation ne se trouve pas à la racine du dépôt.
    6. Enregistrez vos paramètres.
  </Accordion>
</AccordionGroup>

Après avoir suivi l’une ou l’autre de ces procédures, installez l’application GitHub en suivant les étapes décrites dans [Installer l’application GitHub](#install-the-github-app).

<div id="install-the-github-app">
  ## Installer l’application GitHub
</div>

<Note>
  Vous devez être propriétaire de l’organisation ou disposer des autorisations d’administrateur sur un dépôt pour installer l’application. Si vous ne disposez pas des autorisations nécessaires, le propriétaire du dépôt doit approuver la demande d’installation.
</Note>

Installez l’application GitHub de Mintlify depuis votre [tableau de bord](https://dashboard.mintlify.com/settings/organization/github-app).

<Tip>
  Nous vous recommandons d’accorder l’accès uniquement à votre dépôt de documentation.
</Tip>

<div id="permissions">
  ## Autorisations
</div>

Lorsque vous installez l’application GitHub, accordez les autorisations suivantes.

Autorisations en lecture :

* `metadata` : Informations de base sur le dépôt

Autorisations en lecture et écriture :

* `checks` : Créer des vérifications de statut sur les pull requests
* `code` : Lire les modifications de fichiers lorsque vous validez des changements sur votre branche de documentation
* `deployments` : Générer des déploiements de prévisualisation pour les pull requests
* `pull requests` : Créer des branches et des pull requests depuis l’éditeur web

<Info>
  L’application accède uniquement aux dépôts pour lesquels vous lui accordez explicitement l’accès. Si des règles de protection de branche sont activées, l’application ne peut pas effectuer de push directement vers les branches protégées.
</Info>

<div id="manage-repository-access">
  ## Gérer l&#39;accès aux dépôts
</div>

Lors de l&#39;installation de l&#39;application GitHub, vous pouvez accorder l&#39;accès à tous vos dépôts ou seulement à certains d&#39;entre eux. Nous vous recommandons d&#39;accorder l&#39;accès uniquement à votre dépôt de documentation et à tout dépôt que vous souhaitez fournir comme contexte à l&#39;agent. Vous pouvez modifier cette sélection à tout moment dans les [paramètres de votre application GitHub](https://github.com/apps/mintlify/installations/new).

<div id="configure-docs-source">
  ## Configurer la source de la documentation
</div>

Modifiez l’organisation, le dépôt ou la branche utilisés pour générer votre documentation dans la section [Paramètres Git](https://dashboard.mintlify.com/settings/deployment/git-settings) de votre tableau de bord.

<div id="github-enterprise-with-ip-allowlists">
  ## GitHub Enterprise avec des listes d’autorisation d’adresses IP
</div>

Si une liste d’autorisation d’adresses IP est activée pour votre organisation GitHub Enterprise Cloud, vous devez ajouter l’adresse IP sortante de Mintlify (`54.242.90.151`) à cette liste pour que l’application GitHub fonctionne correctement.

Suivez [la documentation de GitHub](https://docs.github.com/en/enterprise-cloud@latest/organizations/keeping-your-organization-secure/managing-security-settings-for-your-organization/managing-allowed-ip-addresses-for-your-organization) pour configurer votre liste d’autorisation d’adresses IP.

<div id="troubleshooting">
  ## Dépannage
</div>

<div id="deployment-not-triggering-automatically">
  ### Le déploiement ne se déclenche pas automatiquement
</div>

Si les pushs vers votre dépôt ne déclenchent pas de déploiement, vérifiez les problèmes potentiels suivants.

<AccordionGroup>
  <Accordion title="Vérifier l’installation de l’application GitHub">
    Vérifiez que l’application est bien installée sur le bon dépôt.

    1. Accédez aux [paramètres de l’application GitHub](https://dashboard.mintlify.com/settings/organization/github-app) dans votre tableau de bord.
    2. Vérifiez que votre dépôt figure dans la liste des installations actives.
  </Accordion>

  <Accordion title="Vérifier la branche de déploiement">
    Assurez-vous d’effectuer vos pushs vers la bonne branche.

    1. Accédez à [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings)
    2. Vérifiez que la branche indiquée dans votre tableau de bord correspond à celle vers laquelle vous poussez vos modifications.
  </Accordion>
</AccordionGroup>

<div id="github-app-connection-issues">
  ### Problèmes de connexion à l’application GitHub
</div>

Si vous rencontrez des problèmes avec l’application GitHub, réinitialiser la connexion peut en résoudre la plupart.

<Steps>
  <Step title="Désinstallez l’application Mintlify depuis GitHub.">
    1. Dans GitHub, accédez à [installations](https://github.com/settings/installations) et sélectionnez **Configure** à côté de l’application Mintlify. Faites défiler jusqu’en bas de la page, puis sélectionnez **Uninstall**.
    2. Accédez à [Authorized GitHub Apps](https://github.com/settings/apps/authorizations) et sélectionnez **Revoke** à côté de l’application Mintlify.
  </Step>

  <Step title="Réinstallez l’application Mintlify.">
    1. Dans votre tableau de bord Mintlify, accédez à [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) et installez l’application GitHub.
    2. Autorisez votre compte dans la section [My Profile](https://dashboard.mintlify.com/settings/account) de votre tableau de bord.
  </Step>
</Steps>

<div id="feedback-add-ons-are-unavailable">
  ### Les modules complémentaires de feedback ne sont pas disponibles
</div>

Les fonctionnalités de suggestion de modifications et de signalement de problèmes sont uniquement disponibles pour les dépôts GitHub publics. Si ces options sont désactivées dans votre tableau de bord, vérifiez la visibilité de votre dépôt.

Si votre dépôt est public et que vous ne pouvez pas activer les options de suggestion de modifications ou de signalement de problèmes dans votre tableau de bord, revalidez vos paramètres Git.

<Steps>
  <Step title="Accéder aux paramètres Git">
    Accédez à [Git Settings](https://dashboard.mintlify.com/settings/deployment/git-settings) dans votre tableau de bord.
  </Step>

  <Step title="Revalider vos paramètres">
    Cliquez sur la coche verte dans l’angle de l’encadré des paramètres Git pour revalider les paramètres de votre dépôt. Cela force la mise à jour des paramètres de votre dépôt afin d’indiquer s’il est public ou privé.

      <img src="/images/github/revalidate-settings-dark.png" alt="La page Git Settings dans le tableau de bord Mintlify. Une flèche orange pointe vers la coche verte qui revalide les paramètres du dépôt." className="hidden dark:block" />
    </Frame>
  </Step>
</Steps>
